# 脱离跑道



手动

: 当航空器处于安全且可控的速度时，**应**{.red}发出 Exit Runway 指令，通常低于 70kts。[更多信息？](../../atc-manual/3.-tower/3.5-exit-runway-go-around.md#3.5.1)



@[vimeo](563268378)



第 1 步

: 在地图上点击航空器（然后选择 "Other Message"），或点击飞行进度条以调出通信菜单



第 2 步

: 点击 "Exit Runway > [select left/right/any] > [select from options below]"



| 选项                                       | 含义                                                         |
| ------------------------------------------ | ------------------------------------------------------------ |
| "Send"                                     | 发送普通脱离指令，并允许切换频率 |
| "Expedite"                                 | 发送“加速”脱离指令，并允许切换频率 |
| "Expedite, Traffic on [Select Final/Base]" | 发送“加速”脱离指令（并告知着陆交通的位置），并允许切换频率 |
| "Cross Runway > [Select RWY]"              | 发送普通脱离指令，允许穿越另一条跑道并切换频率 |
| "Hold Short > [Select RWY]"                | 发送普通脱离指令，并指示在另一条跑道前等待。航空器保持在当前频率上，只有在交通穿越跑道后才切换到地面频率 |



提示

: 当有航空器在最后进近 2nm 内时，通常最适合使用 expedite 指令（如果另一架航空器已在跑道上对准并准备起飞，则为 3nm） 



第 3 步

: 根据发送的选项，可能需要切换频率。要执行此操作，请点击 "Contact Other Frequency > [select frequency]"

# 间隔



![Image 3.1.1.1 - Tower Separation](../../../_images/manual/graphics/atc-tower-separation.jpg)



手动

: 下表概述了**必须**{.red}对**所有**{.red}航空器应用的间隔要求：

| Type                  | Rule                                                         |
| --------------------- | ------------------------------------------------------------ |
| Departure / Departure | 第一架航空器**必须**{.red}在第二架航空器*开始起飞滑跑前已离地 |
| Arrival / Arrival     | 第一架航空器**必须**{.red}在第二架航空器越过跑道入口前已脱离跑道边缘（不是等待线） |
| Departure / Arrival   | 第一架航空器**必须**{.red}在第二架航空器越过跑道入口前已离地 |
| Arrival / Departure   | 第一架航空器**必须**{.red}在第二架航空器开始起飞滑跑前已脱离跑道边缘（不是等待线） |
| Intersecting          | 在交叉跑道上，如果一架离场/进场航空器要开始起飞滑跑，或者一架到达航空器要越过跑道入口，航空器**必须**{.red}先越过跑道交叉点。对于跑道并未实际相交、但航空器在起飞和着陆过程中飞行轨迹会相交的延长中线，也**应**{.red}予以考虑。在这些情况下，**应**{.red}采用相同的间隔标准 |

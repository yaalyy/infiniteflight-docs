# 复飞



复飞（Go-Around，G/A）是航空器在最后进近阶段终止着陆的一种机动，可以由飞行员或 ATC 发起。



可能需要复飞的原因包括：



- 与前机失去间隔
- 着陆/穿越跑道被其他航空器占用
- 或进近不稳定（由飞行员操作引起，或由于环境因素造成）



需要注意的是，在存在 ATC 的情况下，复飞的责任由飞行员和管制员共同承担。



手动

: 如果你与雷达管制员协同工作，**应该**{.red} 尽量告知他们该航空器是“go-around”流量，这样他们就可以将其纳入计划；随后可将该航空器移交给雷达管制员，除非其为 VFR 流量，或管制员之间已提前作出安排。[更多信息？](../../atc-manual/3.-tower/3.5-exit-runway-go-around.md#3.5.4)



@[vimeo](563272230)



步骤 1

: 点击地图上的航空器（然后选择“Other Message”），或点击飞行进度条以打开通信菜单



步骤 2

: 点击 “Go Around > make [left/right] traffic > [select RWY]”



提示

: 在选择 G/A 流量方向时，务必将其他航空器和地形考虑在内！ 



步骤 3

: 如果有航空器已获准起飞且存在碰撞风险，请点击 “Cancel Take-Off Clearance” 取消其起飞许可



步骤 4

: 除非该流量为 VFR（或与雷达管制员已提前作出安排），否则通过点击 “Contact Other Frequency > [select frequency]” 将复飞流量移交给他们（如有）



+++ 场景 - 避免复飞

::: scenario-heading
场景
:::

::: scenario
*N1DC* 和 *I-DRUM* 都在 RWY05L 最后进近。由于间隔很小，且进近速度差超过 80 节，复飞的可能性很高。
::: 

![](../../../_images/manual/screens/atcg-pw-go-around.png){.scenario}

| 技巧 1                                                     |
| ---------------------------------------------------------- |
| 1: 尽量提前通过拉开间隔来预判问题，而不是拖到最后再处理 |
| 2: 如果两架航空器都在 downwind 段，与其让 *I-DRUM* 以最小间隔跟随 *N1DC*，不如指示 *I-DRUM* “延长 downwind，我会呼叫你的 base”，以拉开两机之间的间隔 |

{.technique}

| 技巧 1       | 优点还是缺点？                                              |
| ------------ | ----------------------------------------------------------- |
| :fa-check-circle: | 良好的态势感知和流量管理                                  |
| :fa-times-circle: | 需要更高的工作负荷，以确保不会忘记或不必要地延迟“turn base”指令 |

{.prosandcons}



| 技巧 2                                                     |
| ---------------------------------------------------------- |
| 1: 指示 *I-DRUM* “maintain slowest practical speed”   |
| 2: 一旦 *N1DC* 已经着陆并减速到合适速度，如果是全停落地，可以指示其尽快脱离跑道 |

{.technique}

| 技巧 2       | 优点还是缺点？                              |
| ------------ | ------------------------------------------- |
| :fa-check-circle: | 尽可能使用所有可用手段来防止复飞              |
| :fa-times-circle: | 会增加飞行员的压力                            |

{.prosandcons}



| 技巧 3                                                     |
| ---------------------------------------------------------- |
| 1: 如果你有多条可用跑道，可以更改 *I-DRUM* 获准使用的跑道 |
| 2: 指示 *I-DRUM* “enter straight in RWY 05R”          |
| 3: 如果是 touch & go，则根据相应的 traffic pattern 指令，重新批准 *I-DRUM* 使用 RWY05R |

{.technique}

| 技巧 3       | 优点还是缺点？                             |
| ------------ | ------------------------------------------ |
| :fa-check-circle: | 充分利用所有可用跑道                      |
| :fa-times-circle: | 可能增加飞行员工作负荷并造成混淆          |

{.prosandcons}



提示

: 复飞并没有什么问题，但它是最后的防线 - 如果你能通过积极主动的管制来避免复飞，那就最好不过了！

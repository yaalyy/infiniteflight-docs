## 航线入口、排序与放行

在 Infinite Flight 中，航线高度对螺旋桨飞机为 1000ft AAL（高于机场标高），对喷气式飞机为 1500ft AAL。它由多个航段组成，每个航段之间通过 90 度转弯连接，如下图所示：



![进场航线](../../../_images/manual/graphics/atc-traffic-pattern.jpg)



航线入口是确保飞行员知道应从哪里加入航线的关键，通过这样做可以提升机场效率并改善交通管理。管制员可以把每个航线航段想象成从机场向外延伸。与飞机飞行路径相交的那个航段通常是最佳选择，但管制员可能需要根据当前交通情况进行调整。 



排序的作用在于让管制员告诉飞行员他们应该跟随谁，而且并不只适用于航线内的飞机。所有进场飞机都需要被告知它们应跟随谁，当然，如果它们不需要跟随任何人，那就另当别论！要实现有效排序，需要：



- 管制员和飞行员都了解不同的航线航段
- 管制员要及时下达排序，确保飞行员知情
- 当情况变化或未按计划进行时，管制员要更新排序
- 飞行员之间要互相礼让，给每架飞机留出所需的机动空间
- 飞行员要遵从已发布的排序

提示

: 当你处于左 downwind 时，机场会在你的左侧；当你处于右 downwind 时，机场会在你的右侧。crosswind 和 base leg 也是同样的道理。

![图 3.3.1.1 - 塔台排序](../../../_images/manual/graphics/atc-tower-sequencing.jpg)

手册

: 当没有 Radar Controller 在场时，Tower **必须**{.red} 至少向 **所有**{.red} 飞机发布航线入口和放行，且无论飞机是如何通过 Tower 频率报到的 - 排序的使用将取决于交通情况。[更多信息？](../../atc-manual/3.-tower/3.3-inbounds.md#3.3.1)



@[vimeo](560880041)



步骤 1

: 当一架飞机呼叫进场时，地图上的飞机图标以及飞行进度条上的呼号都会闪烁琥珀色



步骤 2

: 可以点击地图上的飞机（然后选择 "Other Message"），或者点击飞行进度条来打开通信菜单



步骤 3

: 确定所需的航线入口，然后点击 "Pattern Instructions > [select Pattern Entry] > [select RWY] > Send"



步骤 4

: 一旦飞机获得航线入口（如果不是 1 号，还包括排序），即可通过点击 "Cleared to Land/For the Option > [select number] > [select Cleared to Land/Cleared for the Option] > [select RWY]" 将其放行



提示

: 如果该飞机不是 1 号，一旦你知道它正在跟随哪架飞机，就可以通过点击 "Sequencing... > [select number] > [select current position of traffic to follow]" 下达排序



+++ 场景 - 多架进场

::: scenario-heading
场景
:::

::: scenario
多架飞机刚刚宣布进场，但管制员不确定应按什么顺序排序。
::: 

![](../../../_images/manual/screens/atcg-pw-inbound.png){.scenario}



| 技巧 1                                                   |
| ------------------------------------------------------------ |
| 1：只向你在排序上不确定的那架飞机发送航线入口指令 |
| 2：等飞机更接近后，一旦确定了它们的顺序，再连同放行一起发出 |

{.technique}

| 技巧 1       | 优点还是缺点？                                                  |
| ----------------- | ------------------------------------------------------------ |
| :fa-check-circle: | 提供灵活性                                           |
| :fa-check-circle: | 确保飞机知道自己在跟随谁                 |
| :fa-times-circle: | 由于需要发送两条独立指令，可能增加工作量 |

{.prosandcons}




| 技巧 2                                                  |
| ------------------------------------------------------------ |
| 1：向所有飞机发送航线入口和最可能的排序 |
| 2：持续监控，如有需要，随着飞机接近再修改排序 |

{.technique}

| 技巧 2       | 优点还是缺点？                                                  |
| ----------------- | ------------------------------------------------------------ |
| :fa-check-circle: | 有利于工作负荷管理                                 |
| :fa-times-circle: | 如果排序过早给出，飞机可能会不确定自己在跟随谁 |

{.prosandcons}



提示

: 从内向外处理，确保所有最靠近机场的飞机都已收到航线入口、排序（除非它是 1 号）和放行。然后再逐步向外处理其他所有飞机！

## 跑道变更

一旦发布了跑道分配，理想情况下我们不应再更改它。然而，通过使用所有可用跑道，在需要时更改分配跑道是帮助应对动态环境并促进高效运行的有用手段。



手册

: 如果发布了跑道变更，**必须**{.red} 重新给出新的航线入口和放行（排序的使用将取决于交通情况）。[更多信息？](../../atc-manual/3.-tower/3.3-inbounds.md#3.3.3)



@[vimeo](562931877)



步骤 1

: 如果一架飞机请求跑道变更，地图上的飞机图标以及飞行进度条上的呼号都会闪烁琥珀色



步骤 2

: 可以点击地图上的飞机（然后选择 "Other Message"），或者点击飞行进度条来打开通信菜单



步骤 3

: 如果管制员无法批准该请求，点击 "Unable"



步骤 4

: 如果管制员能够批准该请求，或者管制员决定在没有飞机请求的情况下直接发布跑道变更（例如由于交通情况），先确定所需的航线入口，然后点击 "Pattern Instructions > [select Pattern Entry] > [select RWY] > Send"



步骤 5

: 一旦飞机获得航线入口（如果不是 1 号，还包括排序），即可通过点击 "Cleared to Land/For the Option > [select number] > [select Cleared to Land/Cleared for the Option] > [select RWY]" 将其放行



提示

: 如果该飞机不是 1 号，一旦你知道它正在跟随哪架飞机，就可以通过点击 "Sequencing... > [select number] > [select current position of traffic to follow]" 下达排序



+++ 场景 - 跑道变更

::: scenario-heading
场景
:::

::: scenario
*VP-MAX* 正从 RWY32L 起飞，*I F A E Eleven* 正从 RWY32R 起飞。两次起飞同时发生。随后 *I F A E Eleven* 请求将跑道改为 RWY32L。
::: 

![](../../../_images/manual/screens/atcg-pw-runway-change.png){.scenario}

| 技巧 1                                                  |
| ------------------------------------------------------------ |
| 1：指示 *I F A E Eleven* “进入 RWY32L 右 downwind，2 号，前机在左 downwind” |
| 2：如果你担心另一端会有冲突，也可以告诉 *I F A E Eleven* “延长 downwind，我来叫你的 base”，以缓解这种情况 |
| 3：当你放行 *I F A E Eleven* 后，如果愿意，可以让它改为左航线，以便后续航线从那一侧进入 |

{.technique}

| 技巧 1       | 优点还是缺点？                                 |
| ----------------- | ------------------------------------------- |
| :fa-check-circle: | 提供灵活性                          |
| :fa-times-circle: | 可能会让谁在跟随谁变得混乱 |

{.prosandcons}




| 技巧 2                                                  |
| ------------------------------------------------------------ |
| 1：指示 *VP-MAX* “转 crosswind”                     |
| 2：当你对间隔满意时，告诉 *I F A E Eleven* “进入 RWY32L 左 downwind，2 号，前机在左 downwind” |
| 3：如果在此期间，*I F A E Eleven* 开始向 RWY32R 右转进入 right downwind，那么改用技巧 1 |

{.technique}

| 技巧 2       | 优点还是缺点？                                                  |
| ----------------- | ------------------------------------------------------------ |
| :fa-check-circle: | 确保两架飞机之间保持间隔                     |
| :fa-times-circle: | 在你来得及给出新的航线入口之前，*I F A E Eleven* 可能已经开始转入右 downwind |

{.prosandcons}




| 技巧 3                                                  |
| ------------------------------------------------------------ |
| 1：指示 *I F A E Eleven* “延长 upwind，我来叫你的 crosswind” |
| 2：等待 *VP-MAX* 与 *I F A E Eleven* 之间的间隔足够安全（你可以通过告诉 *VP-MAX* “转 crosswind” 来加快这一过程），然后告诉 *I F A E Eleven* “进入 RWY32L 左 downwind，2 号，前机在左 downwind” |
| 3：新的航线入口指令会覆盖之前的指令 |

{.technique}

| 技巧 3       | 优点还是缺点？                                                  |
| ----------------- | ------------------------------------------------------------ |
| :fa-check-circle: | 可防止 *I F A E Eleven* 进入右 downwind |
| :fa-times-circle: | 在用航线入口代替 "turn crosswind" 时，可能会增加混淆 |

{.prosandcons}



提示

: 记住，其他变量（例如地形）也可能会影响当天最适合采用哪种技巧，要保持灵活！

## Cleared for the Option



手册

: 如果一架飞机在航线内，**必须**{.red} 使用 "Cleared for the Option"，因为它会让飞行员可以选择着陆 / touch & go / stop & go 或低空通场。[更多信息？](../../atc-manual/3.-tower/3.3-inbounds.md#3.3.5)



@[vimeo](562934956)



步骤 1

: 当一架飞机呼叫进场执行 touch & go 时，地图上的飞机图标以及飞行进度条上的呼号都会闪烁琥珀色



步骤 2

: 可以点击地图上的飞机（然后选择 "Other Message"），或者点击飞行进度条来打开通信菜单



步骤 3

: 确定所需的航线入口，然后点击 "Pattern Instructions > [select Pattern Entry] > [select RWY] > Send"



步骤 4

: 一旦飞机获得航线入口（如果不是 1 号，还包括排序），即可通过点击 "Cleared to Land/For the Option > [select number] > [select Cleared for the Option] > [select RWY] > [select send or make left/right traffic]" 将其放行



提示

: 如果该飞机不是 1 号，一旦你知道它正在跟随哪架飞机，就可以通过点击 "Sequencing... > [select number] > [select current position of traffic to follow]" 下达排序



| 选项                      | 何时使用                                                  |
| ------------------------- | ------------------------------------------------------------ |
| "Send"                    | 如果飞机已经在初始起飞放行或上一条着陆放行中被指示执行左/右航线 |
| "Make Left/Right Traffic" | 如果飞行员获得了新的航线入口或新的跑道      |

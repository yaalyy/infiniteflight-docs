## 等待停止线（Hold Short）



“hold short”的使用主要用于离场交通，以确保他们在获准之前不会进入跑道。



手册

: 如果某架飞机请求起飞，而你无法放行它们或发出 LUAW 指令，那么**必须**{.red}使用“hold short”指令。[更多信息？](../../atc-manual/3.-tower/3.2-departures.md#3.2.1)



步骤 1

: 当飞机呼叫 ready for departure 时，地图上的飞机图标以及飞行进度条上的呼号都会闪烁琥珀色



步骤 2

: 点击地图上的飞机（然后选择 "Other Message"），或点击飞行进度条以打开通信菜单



步骤 3

: 如果不适合发出起飞或 LUAW 放行，改为点击 "Hold Short > [select RWY]"

## 离场顺序



当有多架飞机排队等待离场时，提供顺序信息会很有用，这样飞机就能知道预期的离场顺序。



手册

: 已获准起飞的飞机不再被视为离场顺序的一部分 - 因此下一架等待停止线的飞机被视为第 1 架离场飞机。然而，如果某架飞机已经被指示 LUAW，那么下一架等待停止线的飞机被视为第 2 架离场飞机。[更多信息？](../../atc-manual/3.-tower/3.2-departures.md#3.2.2)



步骤 1

: 要让飞机知道自己的离场序号，可以点击地图上的飞机（然后选择 "Other Message"），或点击飞行进度条以打开通信菜单



步骤 2

: 点击 "Departure Sequence > [select departure number]"

## 排队等待（LUAW）



当一架飞机正在滑跑，另一架飞机在跑道外等待时，有时根据预期间隔，直接给第二架飞机起飞许可会更合适，前提是你知道第一架飞机在第二架开始滑跑时已经离地。但如果你拿不准，或者刚有飞机着陆，那么使用 "Line Up & Wait"（LUAW）指令可能更合适。



使用该指令会要求等待停止线的飞机滑行进入跑道并排好队，准备起飞，这意味着一旦满足间隔条件，你就可以放行它们起飞。



手册

: 在不影响即将离场的第一架飞机完整性的前提下，管制员可以向多架飞机发出 LUAW 指令。[更多信息？](../../atc-manual/3.-tower/3.2-departures.md#3.2.3)



步骤 1

: 当飞机呼叫 ready for departure 时，地图上的飞机图标以及飞行进度条上的呼号都会闪烁琥珀色



步骤 2

: 点击地图上的飞机（然后选择 "Other Message"），或点击飞行进度条以打开通信菜单



步骤 3

: 如果你要发出 LUAW 指令，点击 "Line Up & Wait > [select RWY]"

## 反向滑行（Back-Taxi）

如果飞机无法使用全跑道长度起飞，或者着陆飞机已经通过最后一个可用的跑道出口，就需要发出反向滑行指令。



手册

: 管制员**应**{.red}提前为最坏情况下的间隔做规划，并且尤其**应**{.red}预计飞机反向滑行的速度不会快于正常滑行速度。[更多信息？](../../atc-manual/3.-tower/3.2-departures.md#3.2.4)



@[vimeo](560560579)



步骤 1

: 当飞机呼叫 ready for departure 时，地图上的飞机图标以及飞行进度条上的呼号都会闪烁琥珀色



步骤 2

: 点击地图上的飞机（然后选择 "Other Message"），或点击飞行进度条以打开通信菜单



步骤 3

: 如果你要发出反向滑行指令，点击 "Back Taxi > [select RWY] > [select Contact Ground when off the Runway / LUAW] > [select Send / Expedite]"



| 选项                                | 含义                                                         |
| ------------------------------------ | ------------------------------------------------------------ |
| "Contact Ground when off the Runway" | 飞机完成反向滑行并脱离跑道后，即可联系 Ground |
| "Line Up & Wait"                     | 飞机完成反向滑行后，可以在跑道上做 180 度转弯，准备起飞 |
| "Send"                               | 发送反向滑行指令                                             |
| "Expedite"                           | 发送反向滑行指令，但要求飞机加快执行（通常是因为到达交通） |

## 交叉点离场



使用跑道的多个入口点进行离场，会让你更灵活地决定离场顺序。下表给出了一些这种做法何时有用的示例：



| 考虑因素             | 原因                                                         |
| -------------------- | ------------------------------------------------------------ |
| 飞机飞行计划         | 如果即将放行多次离场且其间没有到达，选择飞行计划朝不同方向离开的飞机有助于缓解空域拥堵（例如，一架离场飞行计划向北，另一架向南） |
| 飞机大小             | 如果两架到达之间的间隔看起来很近，可以考虑选择你知道能更快起飞的飞机（例如，战斗机而不是大型民航机） |
| 飞机位置             | 如果你同时让两架飞机进入跑道排队，可能会更快放行飞机 |



手册

: 管制员**不应**{.red}将交叉点离场视为“插队”，而应善加利用，以提供更高效的服务。[更多信息？](../../atc-manual/3.-tower/3.2-departures.md#3.2.5)

## 起飞



步骤 1

: 当飞机呼叫 ready for departure 时，地图上的飞机图标以及飞行进度条上的呼号都会闪烁琥珀色



步骤 2

: 点击地图上的飞机（然后选择 "Other Message"），或点击飞行进度条以打开通信菜单



步骤 3

: 如果你想发出起飞放行，点击 "Cleared for Takeoff > [select option]"



| 选项                        | 何时使用                                                     |
| --------------------------- | ------------------------------------------------------------ |
| "Send"                      | 大多数情况下，当你只想发送正常的起飞放行时使用 |
| "Straight Out (Altitude)"   | 当当前 ATIS 正在广播 "Straight Out Dept." 时使用。飞机将沿跑道航向飞行，直到达到指定高度且不存在冲突 |
| "Request Immediate Takeoff" | 当预计在离场飞机与最后进近的到达交通之间会失去间隔时推荐使用（通常在 2nm 以内） |

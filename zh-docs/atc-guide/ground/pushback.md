# 推出



推出是一种机动，用于将飞机从停机位置移动到滑行道上，以便开始滑行。



提示

: 通用航空（GA）和军用飞机（C-130 除外）无法执行推出机动



@[vimeo](558244099)



步骤 1

: 当某架飞机请求推出时，地图上的飞机符号以及飞行进度条上的呼号都会闪烁琥珀色



步骤 2

: 点击地图上的飞机（然后选择“其他消息”），或点击飞行进度条以打开通信菜单



步骤 3

: 如果情况允许，点击“推出已批准 > 发送”。在其他情况下，点击“保持位置”



提示

: 通过点击地图上的飞机，然后选择“设置提醒”来设置提醒。计时结束时，该飞机及其飞行进度条会闪烁绿色！

## 流量控制

流量控制是管制员用来限制前往某一目的地的进港飞机数量的一种技术。通常通过在登机口让飞机等待来帮助错开发出发。



@[vimeo](560106119)



步骤 1

: 当某架飞机请求推出时，地图上的飞机符号以及飞行进度条上的呼号都会闪烁琥珀色



步骤 2

: 如果“流量控制”正在生效，点击地图上的飞机，然后选择“显示信息”



步骤 3

: 在信息标签页中，检查提交的目的地



步骤 4

: 如果有大量飞机正飞往该目的地，你可以通过让飞机在登机口等待来错开发出发



步骤 5

: 打开通信菜单，然后点击“保持位置”



提示

: 通过点击地图上的飞机，然后选择“设置提醒”来设置提醒。计时结束时，该飞机及其飞行进度条会闪烁绿色！

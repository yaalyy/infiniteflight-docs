# 滑行



飞机在地面上依靠自身动力机动时，称为滑行。通常这是为了从登机口前往离港跑道，或在降落后从跑道前往登机口。



步骤 1

: 当一架飞机请求滑行时，地图上的飞机图标以及飞行进度条上的呼号都会闪烁琥珀色



步骤 2

: 点击地图上的飞机（然后选择“其他消息”），或点击飞行进度条以打开通信菜单



步骤 3

: 点击“滑行至 > [选择跑道]”



提示

: 根据交通情况，滑行指令后可能需要立即跟进分流滑行或避让指令

## 分流滑行和避让

除了使用常规滑行指令外，分流滑行和避让指令也可用于帮助管制员进行地面管理，尤其是在单向系统、潜在冲突和跑道交叉起飞情况下。 



手册

: “滑行至 RWYXX，准备好时联系塔台”和“滑行至停机位”是管制员在飞机离场/进场时**必须**{.red}使用的默认指令。[更多信息？](../../atc-manual/2.-ground/2.2-taxi-and-use-of-give-way.md#2.2.2)

**避让指令**

步骤 1

: 如果出现潜在冲突，点击你想要采取纠正措施的飞机。你可以通过点击地图上的飞机（然后选择“其他消息”），或点击其飞行进度条来完成此操作



步骤 2

: 这将打开通信菜单，点击“向 > [选择其他飞机的相应参考对象] 让行”



步骤 3

: 一旦冲突解除，让行的飞机即可按放行继续



提示

: 尽量主动而不是被动！预测地面移动和潜在冲突，并使用可用工具尽早解决问题，这将帮助你保持领先并维持较低的工作负荷！



**分流滑行指令**

步骤 1

: 如果需要分流滑行指令（例如布局复杂或存在潜在冲突），点击你想要引导的飞机。你可以通过点击地图上的飞机（然后选择“其他消息”），或点击其飞行进度条来完成此操作



步骤 2

: 这将打开通信菜单。在发出常规滑行放行后（即滑行至 RWYXX 或滑行至停机位），点击“分流滑行 > [选择相应方向]”



步骤 3

: 在完成分流滑行指令后，点击“分流滑行 > 按你的判断继续滑行”，允许飞机自行继续滑行

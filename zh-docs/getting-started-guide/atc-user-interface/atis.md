# ATIS

自动终端情报服务，通常称为 ATIS，只要你在覆盖范围内，就会在指定频率上发送最新的机场信息（如果有 ATC 存在）。

![ATIS 页面](../../../_images/manual/frames/atc-atis.png)

1. 气象终端航路报告（通常称为 **METAR**）是机场当前天气，通常会显示记录日期/时间、风向和风速、能见度、天气与云况、温度和露点，以及气压

2. 可用跑道可在此标签中选择，并将使用红/琥珀/绿色颜色编码

   | 指示 | 含义 |
   | ---------------------------------------- | ---------------------------------------- |
   | ![](../../../_images/manual/tables/weather-green.png) | 顺风大于 3 节（或低于 3 节时来自任意方向的风）- 推荐使用该跑道 |
   | ![](../../../_images/manual/tables/weather-orange.png) | 侧风大于 3 节 |
   | ![](../../../_images/manual/tables/weather-red.png) | 顺风大于 3 节 - 不推荐使用该跑道 |

3. **REMARKS** 可添加到 ATIS 中，以向飞行员提供更多信息，例如“禁止航线练习”

4. **NOTAMS** 的用法与上面的 REMARKS 相同，也会为飞行员提供更多信息

5. 当使用多个频率时，ATIS 可用于告诉飞行员应从哪个方向联系哪个频率

6. 完成选择你想使用的跑道、REMARKS、NOTAMS 和频率后，你可以检查最终消息的显示效果，确保其正确无误

7. 准备发布时，选择 ATIS 信息（即 Alpha、Bravo、Charlie 等），然后点击 **PUBLISH**

提示

: 别忘了保持 ATIS 为最新状态！当天气、使用中的跑道/频率、REMARKS 或 NOTAMS 发生变化时，请更新 ATIS，并使用下一个语音字母表字母进行发布

数字 ATIS（D-ATIS）将显示与 ATIS 相同的信息，但以文本格式呈现。要查找 D-ATIS，请按以下步骤操作：

步骤 1

: [在地图上点击机场附近](../pilot-user-interface/flight-planning.md#getting-more-from-your-map-and-mini-map)，会出现一个下拉列表

  

步骤 2

: 信息标签将首先显示；点击 "wx"（天气）标签

步骤 3

: 只要所选机场有 ATC 存在（并且正在使用 ATIS 频率），D-ATIS 就会显示这些信息

提示

: D-ATIS 的范围不受限制，使用它可以在调频到活动频率之前帮助你进行规划

# 状态

可从屏幕左侧选择“状态”选项卡，它会显示空域状态以及所有进港飞机。



![ATC Status Page](../../../_images/manual/frames/atc-status.png)



1. “空域状态”表格显示当前正在被管制的所有机场、预计到达的进港飞机数量，以及每个机场当前开放的具体频率（使用绿色人物图标显示）

   

2. 其下方是“进港飞机”表格，它会提供关于你正在管制的机场到达航班的更详细信息

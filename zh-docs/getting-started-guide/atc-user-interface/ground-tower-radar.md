# 地面、塔台与雷达

Ground、Tower 和 Radar 频率共用一套界面，但每种模式会根据飞机所处的飞行阶段以及飞行员的请求提供不同的指令。

## 未在频率上的飞机

![Aircraft Not On Frequency](../../../_images/manual/frames/atc-aircraft-not-on-frequency.png)



1. 状态页面、塔台视图以及用户当前打开的所有频率会以标签页形式显示在屏幕左侧。只需轻点任意标签页即可选中

   

2. 此处显示当前天气

   

3. 此处显示当前时间（UTC）、设备电池电量以及已控制时长。轻点已用时间后，管制员可以设置多个计时器，这些计时器可在管制过程中重置并使用

   

4. 未在频率上的飞机会以灰色显示，轻点飞机后会显示各种选项

## 在频率上的飞机

![Aircraft On Frequency](../../../_images/manual/frames/atc-aircraft-on-frequency.png)



1. 在频率上的飞机会以蓝色显示，轻点飞机后会显示各种选项

   

2. 每架在频率上的飞机都会显示一条信息条，其中填充了基础信息

   

3. 当轻点“other message”或飞机信息条时，会出现一个菜单，允许管制员向飞机发送消息

## 消息菜单

![Message Menu 1](../../../_images/manual/frames/atc-message-menu-1.png)



1. 打开消息菜单后，管制员可以选择要发送给正在管制的飞机的消息

   

2. 接收或发送的任何消息都会记录在菜单下方的消息框中



![Message Menu 2](../../../_images/manual/frames/atc-message-menu-2.png)



3. 当飞机向管制员发送消息时，只要管制员当前显示了该频率，飞机信息条和飞机都会闪烁琥珀色

   

4. 发送的消息也会显示在屏幕右下角的消息框中。此消息框会显示所有飞机之间的全部消息

   

5. 可自定义设置、放大/缩小功能以及居中屏幕按钮始终可在此处使用



![Message Menu 3](../../../_images/manual/frames/atc-message-menu-3.png)



6. 打开消息菜单后，管制员可以查看之前向该特定飞机发送过哪些消息，以及是在什么频率上发送的

## 飞机标签

![Aircraft Tag](../../../_images/manual/frames/atc-aircraft-tag.png)



1. 飞机标签会在呼号和机型之间轮换显示。其下方始终显示飞机高度和地速。如果飞机正在为某机场接收 ATC 服务，还会显示该服务、机场代码以及跑道（如适用）

## 拖拽与向量引导工具

![Drag & Vector Tool](../../../_images/manual/frames/atc-drag-and-vector.png)



1. 拖拽与向量引导工具可用于任何雷达频率（例如进近和离场）。按住飞机并从飞机位置向你希望引导其前往的方向拖动即可。拖动时会显示信息，包括航向、距离、到达拖拽点所需时间（按飞机当前速度计算）以及周围地形。松开后，会显示可向飞机发送该消息的选项

# 模式

可选择四种模式，分别是：

- [自由飞行](mode.md#free-flight) - 选择你的飞机和机场，自定义飞行计划，并按照自己的节奏享受沉浸式飞行体验
- [任务](mode.md#missions) - 根据交通流量和 ATC 推荐的航线，直接进入行动
- [飞行训练](mode.md#free-training) - 通过互动教程提升你的驾驶技能（仅限单人模式）
- [ATC](air-traffic-control.md) - 离开驾驶舱，前往塔台，控制 Infinite Flight 天空中的飞机（仅限多人模式）



![Modes](../../../_images/manual/getting-started/Home-User-Interface/mode-mode.png)



1. 选择单人或多人
2. 选择模式类型
3. 如果选择了多人，你还可以选择在线服务器
4. 选择以确认该选择

## 自由飞行



![Free Flight](../../../_images/manual/getting-started/Home-User-Interface/home-screen-main.png)


1. 左上角的图标可点击进入我们的新闻页面，以及排行榜、你的[飞行日志](logbook.md#logbook)和[设置](settings.md#settings)。旁边还能找到 [Get Pro](subscriptions.md) 订阅按钮。如果你已经订阅，这里会显示你的[用户资料](user-profile.md)
2. 位置（机场/停机位）选择 - 这个搜索功能可让你轻松[找到机场](home-screen.md#airport-and-gate-selection)。如果你知道 ICAO 四字代码（例如代表旧金山国际机场的 KSFO），就可以输入部分或全部代码，系统会显示可选列表。或者，也可以直接输入部分或全部城市/机场名称（仅在[自由飞行](mode.md#free-flight)模式下可用）
3. 点击这里[选择你的飞机](home-screen.md#aircraft-selection)（仅在[自由飞行](mode.md#free-flight)模式下可用）。如果你开启了多人模式，也可以在这里选择你的[呼号](user-profile.md#callsigns)，并查看你所选机场是否开放空中交通管制；可用设施会在飞机图标下方以绿色高亮显示（仅适用于特定[服务器](mode.md#servers)）
4. 通过拖动滑块、点击箭头或点击时间打开时间菜单来选择一天中的时间
5. 此处显示天气，可使用箭头图标进行调整（仅限单人[自由飞行](mode.md#free-flight)模式）
6. 地图左下角有居中地图图标。你也可以使用地图来寻找起飞位置。只需用手指在地球上移动，捏合即可放大和缩小，然后点击你想要的机场。你也可以先放大，再点击代表所选停机位的浅蓝色圆点，来选择具体的登机口（仅在[自由飞行](mode.md#free-flight)模式下可用）。如果你没有[Pro](subscriptions.md)订阅，则会显示绿色边框。飞行和机场选择仅限于全球各个区域内
7. 选择[模式](mode.md#mode)，如果你选择了多人模式，也要选择[服务器](mode.md#servers)
8. 准备起飞了吗？点击[飞行按钮](../pilot-user-interface/fly-screen.md)开始

## 服务器

当选择多人模式时，可以使用各种在线服务器。每个服务器都有自己的规则和最低等级要求，在尝试加入前务必先查看这些要求！



| 服务器   | 描述                                                  | 最低[等级](user-profile.md#the-grade-table) |
| -------- | ------------------------------------------------------------ | ------------------------------------------------------------ |
| 休闲   | 所有等级都可以访问此服务器。ATC 不可用，飞行员可以自由飞行，不会影响其统计数据或等级。所有用户仍应对其他飞行员保持尊重和礼貌 | 不适用                                                          |
| 训练   | 此服务器用于练习飞行员和 ATC 技能。所有 ATC 设施（ATIS 除外）均可使用，并通过[违规](../pilot-user-interface/violations.md#violations)来执行程序 | 2                                                            |
| 专家*  | 这是一个必须遵守已发布规则的服务器。所有程序都由 ATC 严格执行。违规可能会导致被判定[违规](../pilot-user-interface/violations.md#violations) | 3*                                                           |

**要在 Expert 服务器上进行管制，你必须接受正式培训 - 更多信息可在 [Infinite Flight Community Forum](https://community.infiniteflight.com/t/infinite-flight-atc-recruiting/564656) 上找到*

***除了最低等级要求外，总计 Level 1 违规的数量还必须至少比总降落次数少 50%，且飞行员在最近 365 天内不得有[5 次或以上 Level 2 或 3 违规](../pilot-user-interface/violations.md#what-happens-if-i-get-a-violation%3F)*

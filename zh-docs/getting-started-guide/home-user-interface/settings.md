# 设置

设置菜单允许你在飞行前和飞行中自定义你的 Infinite Flight 体验。下面是一份指南，帮助你熟悉各项内容，并找到最适合你的设置！


![General Settings](../../../_images/manual/frames/settings-general-243.png)


1. 屏幕左侧有 5 个类别，用来将设置进行分类，点击每个类别即可查看其中的设置

   

2. 每项设置都有标签，下面还附有简短说明

   

3. 在屏幕右侧，你可以通过点击方框来选择该设置，勾选后表示它已被启用

   

4. 有些设置显示的是标签而不是方框，点击标签后可选择切换到其他设置（同样，设置完成后会显示勾选标记）

   

5. 返回按钮会带你回到 [主页](home-screen.md)

## 一般



| 设置                                    | 作用                                                         |
| --------------------------------------- | ------------------------------------------------------------ |
| 语言                                    | 设置应用界面的语言                                           |
| 界面超时                                | 控制用户界面控件在屏幕上保持显示的时长                         |
| 隐藏状态栏                              | 当界面超时时隐藏状态栏                                         |
| 控制灵敏度                              | 设置控制灵敏度                                               |
| 机场名称                                | 飞行时显示机场名称和距离（显示在外部场景中，包括机场的 4 位 ICAO 代码和距离） |
| 着陆辅助                                | 在着陆路径周围显示一组矩形，帮助实现稳定着陆（为了更真实的体验，建议将其**关闭**） |
| 反转外部摄像机垂直移动                  | 反转外部摄像机的垂直移动（锁定的、位于飞机外部的摄像机）       |
| 反转内部摄像机垂直移动                  | 反转内部摄像机的垂直移动（塔台和驾驶舱）                       |
| 自动设置起飞机场                        | 自动将上一次飞行结束的位置设置为起飞机场                       |
| 自动协调                                | 自动联动副翼和方向舵（仅限地面）                               |
| 启用 EFB 链接                            | 向运行 EFB 的本地设备发送位置/高度/交通数据，例如 [ForeFlight](settings.md#foreflight)、Garmin Pilot 或其他应用 |
| 启用 Infinite Flight Connect             | 启用 Infinite Flight Connect API 系统（开启后可让 Infinite Flight 与 InFlight Assistant、Fly-By-Wire 等第三方应用在同一网络下进行桥接） |
| 显示触控点                              | 在录制视频/教程时很有用                                       |
| 启用自动低电量模式                      | 在长途飞行中进入低电量模式以节省电池                           |
| 重量单位                                | 选择你想使用的重量单位，例如 Kg 或 Lbs（飞机燃油数量和消耗将以该单位显示） |
| 显示性能指标                            | 显示指标，包括当前帧率                                         |
| 清除场景缓存                            | 清除本地存储中缓存的场景数据（如果用户遇到掉入滑行道、停机坪、引桥、跑道或任何其他与场景相关的问题，应点击“清除缓存”。如果在尝试后问题仍然存在，建议提交一个 [#support](https://community.infiniteflight.com/c/support/17) 工单来报告你的问题） |
| 截图分辨率缩放                          | 截图的分辨率缩放因子                                         |



提示

: 为了在 [侧风起飞](../../flying-guide/take-off-to-cruise/crosswind-tailwind-take-off-technique.md#crosswind-take-off) 和 [着陆](../../flying-guide/descent-to-landing/crosswind-tailwind-landing.md#crosswind-landing) 时获得更强的操控性和稳定性，请关闭自动协调

## 图形

Infinite Flight 同时支持 iOS 和 Android 设备；因此，设置可能需要调整，以确保最佳性能。遗憾的是，并非所有设备都能在所有设置都调到最高时保持流畅。可能需要以高、中、低的不同组合进行搭配。若想详细了解你的设备可以承受哪些图形设置，请查看 Infinite Flight Community Forum 上的 [这个](https://community.infiniteflight.com/t/device-compatibility-thread-20-3-built-by-us-for-you/323610) 主题。



![Graphics Settings](../../../_images/manual/frames/settings-graphics-243.png)



| 设置              | 作用                                                         |
| ----------------- | ------------------------------------------------------------ |
| 渲染质量          | 控制渲染质量                                                 |
| 3D 对象密度       | 控制机场内对象的密度                                         |
| 渲染分辨率        | 控制飞机和场景的渲染分辨率                                   |
| 纹理质量          | 控制纹理质量                                                 |
| 抗锯齿            | 让线条/图形更平滑，减轻你可能遇到的锯齿/粗糙图形（并非所有设备都支持，因此可能会运行得很慢 - 如果设备性能开始下降，请将此设置调为**关闭**） |
| 帧率限制          | 设置允许的最高帧率                                           |

## 在线

 

![Online Settings](../../../_images/manual/frames/settings-online-243.png)



| 设置                                         | 作用                                                         |
| -------------------------------------------- | ------------------------------------------------------------ |
| 隐藏飞机名称                                 | 隐藏 Infinite Flight Live 中其他玩家的名称（这是显示在其他飞机上方的标签，显示飞行员呼号、显示名称、速度、与你的距离、高度和等级颜色） |
| 隐藏飞机点                                   | 隐藏 Infinite Flight Live 中其他玩家的点/白框                 |
| 自动通过蜂窝数据下载飞机                     | 即使在蜂窝网络下也自动下载飞机                                 |
| 飞机数量                                     | 控制 Live 模式中显示多少架飞机（如果设备性能下降，可以考虑降低此设置，直到找到适合你设备的值） |
| 飞行中显示用户名                             | 在飞行中显示你的用户名。取消勾选即可保持匿名                 |
| 飞行员语音                                   | 为你的 ATC 通讯选择语音（不同语音可在 Infinite Flight 外的设备设置中下载*） |
| 语音音高                                     | 更改所选语音的音高                                           |
| 默认语音                                     | 为其他飞行员/ATC 选择默认语音（你设备上下载的语音可同时用于飞行员语音和/或默认语音） |



**按照以下步骤下载新的飞行员语音：*

- *iOS: 设置 > 辅助功能 > 朗读内容 > 声音*
- *Android: 通用管理 > 语言和输入 > 文本转语音输出 > 点击首选引擎右侧的设置 > 安装语音数据*

## 音频

有两个滑块可以调整 SFX 和 ATC 音量。沿着滑块拖动手指即可找到所需设置。



![Audio Settings](../../../_images/manual/frames/settings-audio-243.png)



| 设置                                 | 作用                                                         |
| ------------------------------------ | ------------------------------------------------------------ |
| SFX 音量（音效音量）                 | 此音量将调整飞机和环境音效（发动机、襟翼、座舱内、座舱外、风声、城市等） |
| ATC 音量（空中交通管制音量）         | 此音量将调整空中交通管制员说话时的音量大小                   |



提示

: 对于这两个设置，建议找到一个折中值，既能欣赏飞机的声音，又能听清管制员，并且不错过无线电呼叫。此外，你还可以使用设备音量来调整整体音量

## 控制

在控制设置中，你可以调整每个轴的控制灵敏度，也可以为摇杆、键盘或其他控制设备自定义设置。你的设备加速度计使用的 2 个轴分别是：



| 设置 | 作用                                                         |
| ---- | ------------------------------------------------------------ |
| 滚转 | 滚转是围绕纵轴的运动（纵轴从机头延伸到机尾）。这是通过机翼上的副翼实现的左右倾斜（横滚）动作 |
| 俯仰 | 俯仰是围绕横轴的运动（横轴从一侧翼尖延伸到另一侧翼尖）。这是通过尾部升降舵实现的机头上/下运动 |
| 偏航* | 偏航是围绕垂直轴的旋转。这种运动通过尾部方向舵转化为机头向左或向右转动 |



**偏航是第三个轴；不过，它并不是通过加速度计来控制的。你通过在生成飞机时位于右下角的 [方向舵刹车](../pilot-user-interface/flight-controls.md) 滑块来控制偏航*




![Control Settings](../../../_images/manual/frames/settings-controls-243.png)



1. Motion 选项卡可让你自定义当前设备的加速度计（如果你连接了摇杆或其他控制设备，此选项卡会首先显示）

2. Keyboard 选项卡可让你自定义任何已连接键盘的体验

3. 可绑定到摇杆或键盘的各种选项会列在这里

4. “Tap to Assign” 可让你将可用命令分配给驾驶盘、摇杆、键盘或其他控制设备

5. Config 会显示可调整的俯仰和滚转灵敏度（左侧滑块）以及死区（右侧滑块）

6. Defaults 会将你的控制设置重置为出厂默认选项

   提示

   : 如果你在灵敏度或其他控制问题上遇到困难，建议使用此项

7. 过滤器可用于仅查看已分配的命令



> 你可以将某个轴（例如滚转）绑定到多个设备，但它一次只会从一个设备接收输入。优先级顺序从左到右（已连接设备 > motion > keyboard）

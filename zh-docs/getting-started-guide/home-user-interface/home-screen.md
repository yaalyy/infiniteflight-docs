# 主页



@[vimeo](880529317)



欢迎来到你新下载的 Infinite Flight 应用主页。下面你会找到关于此页面以及如何在其中导航所需了解的一切。

![Free Flight](../../../_images/manual/getting-started/Home-User-Interface/home-screen-main.png)


1. 左上角的图标可点击，用于访问我们的新闻页面、排行榜、你的 [日志本](logbook.md#logbook) 和 [设置](settings.md#settings)。其旁边是 [Get Pro](subscriptions.md) 订阅按钮。如果你已经订阅，则会显示你的 [用户资料](user-profile.md)
2. 位置（机场/机位）选择 - 这个搜索功能可让你轻松地 [查找机场](home-screen.md#airport-and-gate-selection)。如果你知道 ICAO 四字代码（例如旧金山国际机场的 KSFO），可以输入其中的一部分或全部，随后会显示选项列表。或者，也可以直接输入城市/机场名称的一部分或全部（仅适用于 [Free Flight](mode.md#free-flight) 模式）
3. 点击这里可 [选择你的飞机](home-screen.md#aircraft-selection)（仅适用于 [Free Flight](mode.md#free-flight) 模式）。如果你开启了多人模式，你还可以在这里选择你的 [呼号](user-profile.md#callsigns)，并查看你所选机场是否开放空中交通管制；若该机场有可用管制设施，它们会在飞机图标下方以绿色高亮显示（仅适用于特定 [服务器](mode.md#servers)）
4. 可通过拖动滑块、点击箭头，或点击时间以打开时间菜单来选择一天中的时间
5. 这里会显示天气，可通过箭头图标进行调整（仅适用于单人 [Free Flight](mode.md#free-flight) 模式）
6. 地图左下角是居中地图图标。你也可以直接使用地图来查找起始位置。只需用手指在地球上拖动浏览，使用捏合手势放大或缩小，然后点击你想要的机场。你也可以先放大，再点击所选机位对应的浅蓝色圆点，从而选择特定机位（仅适用于 [Free Flight](mode.md#free-flight) 模式）。如果你没有 [Pro](subscriptions.md) 订阅，则会显示绿色边框。飞行和机场选择仅限于全球这些不同区域内
7. 选择 [模式](mode.md#mode)，如果你选择了多人模式，也要选择 [服务器](mode.md#servers)
8. 准备好起飞了吗？点击 [飞行按钮](../pilot-user-interface/fly-screen.md) 开始

## 飞机选择

在 [Free Flight](mode.md#free-flight) 模式下，你可以从大量不同的飞机和涂装中进行选择。也许是你最喜欢的航空公司，或者是你刚刚完成私人飞行执照训练所用的机型，选择几乎是无限的！



![Aircraft Selection](../../../_images/manual/getting-started/Home-User-Interface/home-screen-aircraftSelectionAircraft.png)



1. 每个分组上方显示的分组标题
   

2. 在每个分组下方，你会看到可滚动浏览的飞机缩略图列表。点击你想要选择的飞机，即可进入涂装选择（在运营模式下则进入飞机选择）

     

3. 搜索所有飞机，可按机型/型号或涂装搜索

     

4. 打开筛选菜单

     

5. 进入当前所选飞机的涂装选择界面（以橙色边框显示）


6. 返回上一级菜单

7. 返回上一级菜单

## 机场和机位选择

在 [Free Flight](mode.md#free-flight) 模式下，你也可以选择起始位置。



![Airport Selection](../../../_images/manual/getting-started/Home-User-Interface/home-screen-airportSelection.png)

 

1. 搜索功能可让你轻松找到想要的机场。如果你知道 ICAO 四字代码（例如圣地亚哥的 KSAN），可以输入其中一部分或全部，随后会显示选项列表。或者，也可以直接输入城市/机场名称的一部分或全部
2. 蓝色圆点表示该机场有塔台设施（但不一定有活跃的 ATC），洋红色圆点表示无管制机场
3. 已添加建筑物的机场会以 “3D” 标识标记
4. 在单人模式中，你可以停在任何你想停的位置。但在多人模式中，所有停机位都有尺寸限制。如果所选机型在该机场没有可用停机位，在尝试选择时会提示该机场太小



提示

: 在选择停机位之前，先 [选择你要飞行的飞机](home-screen.md#aircraft-selection)，这样你就能看到哪些位置可以停放，哪些不可以



如果你即将在线飞行，我们还会使用不同颜色来帮助你判断天气状况：

| 标识                                     | 含义                         |
| ---------------------------------------- | ---------------------------- |
| ![](../../../_images/manual/tables/weather-vfr.png)  | 目视飞行规则                 |
| ![](../../../_images/manual/tables/weather-mvfr.png) | 目视飞行规则边缘状态         |
| ![](../../../_images/manual/tables/weather-ifr.png)  | 仪表飞行规则                 |



![Gate Selection](../../../_images/manual/getting-started/Home-User-Interface/home-screen-gateSelection.png)



1. 跑道颜色代码可帮助你判断风从哪里来，以及哪些跑道“最可能”正在使用。不过要注意，有时管制员会使用与你预期不同的跑道，务必留意空中交通！请查看下表：

   | 标识                                     | 含义                                                         |
   | ---------------------------------------- | ------------------------------------------------------------ |
   | ![](../../../_images/manual/tables/weather-green.png)  | 顶风大于 3 节（或在风速低于 3 节时来自任意方向的风）- 建议使用该跑道 |
   | ![](../../../_images/manual/tables/weather-orange.png) | 侧风大于 3 节                                                |
   | ![](../../../_images/manual/tables/weather-red.png)    | 顺风大于 3 节 - 不建议使用该跑道                             |

   

2. 在单人模式中，你可以停在任何你想停的位置。但在多人模式中，所有停机位都有尺寸限制。如果停机位标为红色，说明你的飞机太大了！

    

   提示

   : 在选择停机位之前，先 [选择你要飞行的飞机](home-screen.md#aircraft-selection)，这样你就能看到哪些位置可以停放，哪些不可以

   

3. 一旦你确定了出生点，就能在机场上看到你的飞机以及出生位置名称。即使不在选择界面中，也会显示机场名称

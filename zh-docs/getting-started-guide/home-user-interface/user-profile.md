# 用户资料



![用户资料](../../../_images/manual/frames/user-profile-243.png)



1. 点击左上角的设置图标，可进入你的 [账户](user-profile.md#account)
2. 点击 Grade 旁边的箭头会展开，显示你的 [等级表](user-profile.md#the-grade-table) 以及你需要达成的下一等级要求
3. 点击 [违规](../pilot-user-interface/violations.md) 旁边的箭头会展开，显示你的违规明细
4. 这是返回箭头，可用于返回上一页；你也可以点击右上角的 "X" 图标
5. 点击可查看你的关注者或你正在关注的人。底部有一个搜索栏，可用于查找你想关注的用户
6. 点击可关联你的 [Discord 账户](user-profile.md#linking-a-discord-account)
7. 这会将你带到 [Infinite Flight Community](https://community.infiniteflight.com)

## 关联社区论坛账户

[呼号](user-profile.md#callsigns) 在飞行时用于识别你，空中交通管制员也会用它与你通信。除此之外，默认还会显示一个唯一用户标识符。不过，如果你有一个 [Infinite Flight Community](https://community.infiniteflight.com)（IFC）账户，你可以选择让你的用户名与呼号一起显示。要关联你的账户，请按以下步骤操作：



步骤 1

: 在 Community Forum Account 旁边，点击“连接”按钮



步骤 2

: 会弹出一个窗口，确认你同意在 *Infinite Flight* 应用和网站之间共享你的信息。点击“继续”



步骤 3

: 会弹出一个 *community.infiniteflight.com* 窗口，你可以登录或创建新账户（如果你已在该设备上登录，它会自动识别，你只需点击“授权”）



步骤 4

: 完成后会返回应用，你会看到 IFC 用户名现在已显示



提示

: 不想让你的 IFC 用户名在飞行中显示？没问题！如果你愿意，仍然可以先关联账户，然后前往 [设置 > Live](settings.md#live)，在那里取消勾选“飞行中显示用户名”选项！

## 关联 Discord 账户

要关联 Discord 账户并获得我们 [仅限 Pro](subscriptions.md#how-do-i-get-a-pro-subscription%3F) 服务器的专属访问权限，请按以下步骤操作：



步骤 1

: 在 Discord Account 旁边，点击“连接”按钮



> 在你能够点击“连接”按钮之前，必须先拥有有效的 [Pro 订阅](subscriptions.md#how-do-i-get-a-pro-subscription%3F)



步骤 2

: 会弹出一个窗口，确认你同意在 *Infinite Flight* 应用和网站之间共享你的信息。点击“继续”



步骤 3

: 会弹出一个 *discord.com* 窗口，你可以登录或创建新账户（如果你已在该设备上登录，它会自动识别，你只需点击“授权”）



步骤 4

: 完成后会返回应用，并询问你是否要加入 Infinite Flight Discord 服务器。如果你想这样做，请点击“确定”；如果你想稍后再做，请点击“暂不”



> 点击“确定”会打开一个 *discord.com* 窗口，点击“接受邀请”



步骤 6

: 完成后，你会看到 Discord 用户名现在已显示

## 虚拟组织归属

你的虚拟组织归属会显示在应用中用户名旁边，也会显示在“info”标签页中（在地图或小地图上点击任意飞机，然后选择对应的呼号/用户名即可显示“info”标签页）。



要添加你的 VO 归属，请按以下步骤操作：



提示

: 要让 VO 归属显示在应用中，你的 Community Forum 账户必须先关联，按照[上方步骤](user-profile.md#linking-community-forum-account)完成即可！



步骤 1

: 访问 [Infinite Flight Community](https://community.infiniteflight.com) 网站并登录



步骤 2

: 点击右上角的头像，会弹出一个下拉菜单。点击人物图标，并选择下拉菜单右上角的“偏好设置”齿轮



步骤 3

: 会出现一个新页面，左侧有导航栏。选择“Profile”（在移动设备上，请先选择名为“Account”的下拉框，然后选择“Profile”）



步骤 4

: 向下滚动到“Virtual Organization”，然后在下拉框中选择你所属的 VO



步骤 5

: 然后滚动到页面底部，点击“保存更改”

## 等级表

提示

: 你可以通过点击用户资料图标，然后点击显示等级旁边的箭头来找到等级表



等级表分为以下 4 个部分：



- 通用飞行员统计
- 一级违规
- 二级违规
- 三级违规



![等级表](../../../_images/manual/frames/stat-page-243.png)



1. 第一列列出了决定你等级的参数，下表列出了这些参数

   

2. 这一列（白色显示）展示你作为飞行员目前已记录/获得的数据

   

3. 最后一列显示你需要满足的要求，才能晋升到下一等级：

   - 绿色参数表示你已满足下一等级要求
   - 橙色参数表示你尚未满足要求，这可能是由于不足或超出限制导致的

+++ 等级表参数

下表列出了所有等级表参数及其简要说明：

| 参数                                   | 说明                                                     |
| -------------------------------------- | -------------------------------------------------------- |
| XP                                     | 该数值通过着陆次数和飞行时间计算得出。这并不代表技术水平 |
| 总飞行时间                             | 你累计的总飞行时间，以小时（hrs）和分钟（mn）表示       |
| 总着陆次数                             | 你已记录的着陆总次数                                     |
| 飞行时间（90 天）                      | 最近 90 天内累计的飞行小时数                             |

| 一级违规/着陆比率（12 个月）           | 你的一级违规总数除以你的着陆次数（过去 12 个月）得到违规/着陆比率* |

- 10 次一级违规（总计）和 10 次着陆（12 个月）会得到 **1.00** 的比率
- 20 次一级违规（总计）和 10 次着陆（12 个月）会得到 **2.00** 的比率

## 呼号

呼号在飞行时用于识别你，空中交通管制员也会用它与你通信。按以下步骤更改你的呼号： 



步骤 1

: 从 [主界面](home-screen.md) 进入，点击屏幕右下角的“模式”



步骤 2

: 切换到多人游戏，然后选择自由飞行



步骤 3

: 呼号现在会显示在屏幕右侧的飞机图标下方，点击箭头即可打开该页面



步骤 4

: 使用屏幕左侧的导航栏，你可以选择“航空公司”或“通用航空”选项卡



步骤 5

: 页面会显示三列内容，可用于自定义你的呼号。如果你选择了“航空公司”选项卡，可以滚动第一列选择你想使用的航空公司。第二列可点击输入字母数字标识符，输入完成后点击“确定”。最后，可以通过点击所需的“后缀”来添加后缀。如果你不想使用后缀，可以选择“无”



提示

: 想要更真实的体验？尽量让你的飞机涂装与你所使用的呼号相匹配！另外，只有在总起飞重量超过 300,000 磅（136,000 千克）时才添加“Heavy”后缀；驾驶 A380 时才添加“Super”后缀



步骤 6

: 如果你选择了“通用航空”选项卡，操作方式与上面相同，但这里使用的是“国家代码”而不是航空公司呼号



> 你也可以使用搜索栏查找你想要的航空公司或通航代码



提示

: 国家代码对应的是飞机的注册地，因此它不必与你起飞或降落的国家相同！

#### Infinite Flight（应用内）

你的应用内账户可从用户资料页面删除。这将删除你的账户，移除你的统计数据和任何已关联账户（但不会删除这些已关联账户本身）。**此操作不可撤销。**

请注意，你的订阅不会自动取消。下次重新启动应用时，它仍会在一个新的匿名账户下可用。

步骤 1

: 从 [主界面](home-screen.md) 进入，点击你设备左上角的用户资料

步骤 2

: “账户”选项卡应会自动显示；如果没有，也可以从设备左侧的导航栏中选择它

步骤 3

: 点击“删除账户”旁边的“删除”

步骤 4

: 系统会要求你确认是否要删除账户，然后你必须输入 DELETE 来确认删除。

#### Infinite Flight Community（论坛）

你的 Infinite Flight Community 账户创建于我们的论坛。这里没有自助删除选项，但你可以随时联系我们的版主以删除你的账户。

步骤 1

: 前往 [Infinite Flight Community](https://community.infiniteflight.com/new-message?groupname=moderators&title=Account%20Deletion%20Request&body=%3E%20To%20delete%20your%20Infinite%20Flight%20Community%20account%2C%20you%20need%20to%20message%20the%20Moderator%20team%20who%20will%20confirm%20your%20account%20deletion%20request.%20Accounts%20are%20anonymized%2C%20which%20means%20all%20personally-identifiable%20information%20is%20deleted%2C%20but%20past%20posts%20remain%20(tied%20to%20an%20anonymous%20account)%20so%20that%20forum%20discussions%20are%20not%20missing%20context.%0A%3E%20%0A%3E%20If%20you%20wish%20to%20delete%20your%20Infinite%20Flight%20account%2C%20please%20check%20the%20Account%20page%20inside%20the%20app%2C%20or%20contact%20support%40infiniteflight.com%20for%20help.%0A%0A**I%20have%20read%20the%20above%20account%20deletion%20information%20in%20the%20Preferences%20tab%20and%20I%20would%20like%20to%20anonymize%20my%20Infinite%20Flight%20Community%20account.**)（此链接会生成一条发送给版主的私信）。

步骤 2

: 发送消息，并等待版主确认账户删除。

提示

: 如果是已关联的 Discord 账户，请参阅 [Discord Support 的说明](https://support.discord.com/hc/en-us/articles/212500837-How-do-I-permanently-delete-my-account) 了解如何删除你的 Discord 账户。

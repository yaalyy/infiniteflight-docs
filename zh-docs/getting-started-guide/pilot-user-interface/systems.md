# 系统

系统图标允许你在不同的飞机系统之间进行选择（请注意，不同机型的系统可能有所不同）。



@[vimeo](389045630)



步骤 1

: 要打开系统菜单，请点击“Systems”按钮，这将为所选系统打开系统菜单



步骤 2

: 要更改所选系统，请按住“Systems”按钮。选项框将出现在系统菜单旁边。当前系统旁会显示一个实心橙色框



步骤 3

: 最多可以有 7 个不同的系统，但可用选项会因机型而异。当你继续按住屏幕时，在选项框中的飞机系统之间滑动。一个空心橙色框会移动，当你高亮显示想要展示的系统后，松开手指



步骤 4

: 系统菜单将切换到所选系统，然后即可选择该系统中的各种选项

# 摄像机

@[vimeo](389091484)



1. 摄像机图标可让你在多种视角之间进行选择

   

步骤 1

: 要更改摄像机角度，可以轻点摄像机图标，或长按以查看更多选项

步骤 2

: 当你长按时，摄像机图标上方会出现一个选项框，当前所选项旁边会有一个实心橙色框

步骤 3

: 共有 7 个不同类别，每个类别中都有多个可选项。保持手指按住屏幕时，在各个类别之间滑动，然后在该类别中的不同选项之间滑动。一个空心橙色框会移动，选中你想显示的选项后，松开手指



提示

: 一旦选好所需的摄像机，你可以用手指拖动摄像机来移动视角，或用两根手指进行捏合操作来放大/缩小。对于 [Free Cams](cameras.md#operating-the-drone-camera)（即 Free 和 Exterior/Interior Drone 1/2），你可以使用屏幕左侧进行左/右移动或放大/缩小；使用屏幕右侧改变摄像机朝向

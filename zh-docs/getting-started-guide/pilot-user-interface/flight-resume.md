# 航班恢复

如果你当前的飞行满足某些条件，无论发生何种中断（自愿或非自愿），你都可以完全按离开时的状态继续飞行。

## 航班恢复的要求

**单人模式：**

- 你的高度必须达到 5,000ft AMSL 或更高

- 你必须处于平飞状态

  

**多人模式：**

- 你的高度必须达到 28,000ft AMSL 或更高

- 你必须处于平飞状态

- 必须已激活 LNAV

- 到目的地的预计航程时间（ETE）必须为 30 分钟或更长

- 你必须位于飞行计划航迹上

  

> 由于实时环境的原因，多人模式下的 Flight Resume 有更多条件，以确保顺利重新进入且不干扰 ATC。

## 如何使用 Flight Resume



步骤 1

: 要检查 Flight Resume 是否可用，请点击屏幕右下角的此图标



步骤 2

: “Flight Resume” 选项卡会显示“ON”或“OFF”，以指示它是否可用。你也可以点击它展开选项卡，查看哪些要求尚未满足（以灰色对勾标记）



步骤 3

: 只要 Flight Resume 显示为“ON”（并以绿色高亮显示），你就可以离开飞行，Flight Resume 功能将可用



步骤 4

: 当你准备返回飞行时，设备上会出现“Resume Last Flight”选项卡

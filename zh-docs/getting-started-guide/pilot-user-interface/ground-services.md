# 地面服务

地面服务按钮允许你为当前所用的机型选择不同的服务（请注意，不同机型变体之间可用服务可能会有所不同）。



![Ground Services](../../../_images/manual/frames/ground-services1.png)



步骤 1

: 要打开地面服务菜单，请轻触“Ground Services”按钮



步骤 2

: 在菜单中有各种可选项。已选中的服务会以橙色高亮显示



> 要使用地面服务，飞机必须停靠在适合该机型尺寸的机位上，设置停机刹车，并关闭发动机和信标灯。只有在取消选择所有其他地面服务时，才可以进行 pushback（前提是该飞机支持 pushback）



步骤 3

: 地面服务标签页中可能还提供其他菜单。要更改这一点，请长按“Ground Services”按钮。地面服务菜单旁边会出现一个选项框。当前的地面服务旁边会显示一个实心橙色框



步骤 4

: 最多可以有 2 个不同的地面服务菜单，但可用选项会因飞机变体而异。在继续按住屏幕的同时，在选项框中滑动以切换地面服务。一个空心橙色框会移动，当你高亮显示想要展示的系统后，松开手指

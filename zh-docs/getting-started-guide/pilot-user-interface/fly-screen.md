# 飞行界面

![Fly Screen](../../../_images/manual/frames/hud-screen-1.png)



让我们为起飞做好准备！欢迎来到你在[校准设备](calibration.md#calibration)后会看到的界面。下面是屏幕上各个部分的说明：



1. 这是[抬头显示器（HUD）](hud.md#head-up-display-(hud))，会显示速度、高度和飞机姿态等所有主要信息 

   

2. [小地图](flight-planning.md#mini-map)是一个很好的工具，让你无需离开主屏幕查看飞行计划，也能了解周围环境

   

3. 如果你正在某个实时服务器上，会显示一个耳机图标，你可以通过这个按钮[与空中交通管制员通话](communication.md#communication)

   

4. 小地图可用于制定[飞行计划](flight-planning.md)，但如果你想要更详细的视图以及查看整颗地球，也可以使用这个功能

   

5. 屏幕底部的[状态栏](status-bar.md#status-bar)可以提供大量信息，而且完全可自定义，这样你就可以选择自己想看到的内容

   

6. [相机图标](cameras.md#camera)可用于在使用应用时切换视角 

   

7. 点击这个图标会带你进入[暂停菜单](pause-menu.md)，你可以在这里编辑设置、重新校准设备、编辑重量与平衡，以及调整时间/天气/位置（取决于你是在 Fly Solo 还是 Fly Online 模式）

   

   提示

   ：在实时服务器上时，尽量避免[暂停](pause-menu.md#pause-menu)太久，你虽然已暂停，但飞机仍会按真实时间继续飞行！ 

   

8. [地面服务](ground-services.md)按钮包含可向飞机提供的各类服务，例如 pushback 和连接登机桥

  

8. [系统](systems.md#systems)按钮包含一些杂项操作，例如开门、供电、灯光、标志和发动机启动

   

9. [导航](navigation.md#navigation)按钮包含航空电子系统，可在其中选择使用 NAV 1 和 2、GPS、VOR/ADF 和 ILS 导航时的航线与来源

   

10. [自动驾驶](autopilot.md#autopilot)按钮包含飞行控制单元（FCU）功能，可在此打开/关闭自动驾驶和导航，设置高度和航向指示，以及设定垂直速度（VS）和速度

    

11. 主要[飞行控制](flight-controls.md#flight-controls)通过设备的物理移动来控制，利用加速度计实现，方向舵/刹车除外，它们位于屏幕右下角。所有飞机都可以使用驻车刹车和配平按钮，如果机型配备了起落架、襟翼和扰流板，也会在屏幕上提供这些按钮

    

    提示

    ：确保你的设备已[校准](calibration.md#calibration)，并将灵敏度调整到适合你的设置！

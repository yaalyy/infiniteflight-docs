# 飞行控制

在你开始首次飞行后，系统会要求你选择想要使用的控制模式：倾斜或触控。你可以随时在设置中更改。

倾斜模式使用设备的加速度计来控制俯仰和横滚，方向舵和油门也都触手可及。

触控模式使用 2 个屏幕虚拟摇杆来控制飞机。一个用于横滚/俯仰，另一个用于方向舵/油门。

## 倾斜


![Flight Controls - Tilt](../../../_images/manual/getting-started/Pilot-User-Interface/flight-controls-tilt.png)



1. 所有机型都具备停机刹车和配平，部分机型还具备可收放起落架、襟翼和扰流板。起落架和停机刹车可分别通过轻点图标进行收放和开启/关闭（起落架只能在空中收起）。扰流板、配平和襟翼可通过按住图标，然后滑动手指到所需位置来调整

   

   提示

   : 有时你会在配平按钮中看到一条洋红色线条，这表示你的设备位置与校准后的中立位置存在差异。你应始终让设备保持舒适的握持姿势，定期进行[重新校准](calibration.md)，并使用配平来设置新的基准点

    

2. 方向舵由屏幕右下角的 RUD BRAKES 图标控制。按住该图标，然后向左或向右移动，可使方向舵朝相同方向偏转。此外，方向舵还提供对起落装置的差动刹车。为此，按住该图标并将手指向屏幕底部拖动。系统会显示一个百分比，用于指示当前实现的刹车力度

## 触控


![Flight Controls - Touch](../../../_images/manual/getting-started/Pilot-User-Interface/flight-controls-tilt.png)

1. 油门可通过上下拖动来调整，方向舵可通过左右拖动来控制。继续向下拖动即可控制刹车
2. 横滚可通过左右拖动调整，俯仰可通过上下拖动调整

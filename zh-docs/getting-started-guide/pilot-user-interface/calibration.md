# 校准

![Calibration Screen](../../../_images/manual/frames/calibration-screen.png)



1. 当你点击 "fly" 后，加载完成时会显示校准屏幕。只需轻点屏幕即可继续

   

   提示

   : 在轻点屏幕之前，请先调整到一个舒适的位置，以便飞机能够正确配置。需要重新校准？没问题，只需前往[暂停菜单](pause-menu.md#pause-menu)！

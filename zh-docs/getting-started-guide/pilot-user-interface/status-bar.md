# 状态栏

@[vimeo](388347259)



1. 状态栏允许你选择 10 个不同的选项在任意时刻显示，这些选项可以随时更改，并能为你提供大量信息

   

步骤 1

: 要更改状态栏上的某个显示内容，请按住你想更改的那个项目

步骤 2

: 状态栏上方会出现一个选项框，当前选中的项目旁边会显示一个实心橙色方框

步骤 3

: 共有 8 个不同的类别，每个类别中都有多个可选选项。在持续按住屏幕的同时，在各类别之间滑动，然后在该类别内的不同选项之间滑动。一个空心橙色方框会移动，等你高亮显示想要展示的选项后，松开手指

# 暂停菜单

暂停菜单允许你通过更改天气、时间以及重量和平衡来自定义飞行。它还允许你立即将飞机设置为位于跑道上、已准备好起飞，或者设置为短五边进近位置。在在线飞行时，某些功能由服务器控制，因此无法更改（例如天气）。此外，其他功能，例如将飞机生成在跑道上，也不可用。

![暂停菜单](../../../_images/manual/getting-started/pause-menu-solo.png)

1. [设置菜单](getting-started-guide/home-user-interface/settings.md)（某些设置无法在飞行中更改）
2. [用户资料](getting-started-guide/home-user-interface/user-profile.md)
3. 如果正在在线飞行，这里会显示当前服务器；如果是单人模式，则会显示“Solo”
4. 根据你的出发机场和飞行计划显示本次飞行的出发和到达机场
5. 显示重量和平衡概览。点击可进入[重量和平衡界面](#weight-%26-balance)
6. 显示时间概览。使用滑块或跳转箭头来调整时间。也可点击进入[时间界面](#time)
7. 显示天气概览。点击可进入[天气界面](#weather)
8. 点击退出暂停界面并恢复飞行
9. 向后跳转 20 秒（仅在单人模式下可见）
10. 将你的飞机移动到最近的跑道以便起飞（仅在单人模式下可见）
11. 将你的飞机移动到最近跑道的短五边进近位置（仅在单人模式下可见）
12. 点击校准你的设备
13. 点击结束飞行并返回主菜单
14. [自动驾驶 + 菜单](flying-guide/take-off-to-cruise/autopilot-plus.md)

## 天气

![天气界面](../../../_images/manual/getting-started/pause-screen-weather.png)

在单人模式下，你可以更改环境条件，以便通过调整以下项目来练习各种天气条件：
 
1. 风向
2. 风速
3. 阵风速度
4. 湍流等级
5. 能见度
6. 温度

在多人模式下，大多数天气设置不可用，因为天气会根据该地点当前经历的实际天气实时更新。只有以下项目可以更改（单人模式下也可更改）：

7. 云层覆盖程度（云量等级。晴朗/少云/零散云/多云/阴天）
8. 云层高度（20,000 英尺 - 50,000 英尺）

## 时间

![时间界面](../../../_images/manual/getting-started/pause-screen-time.png)


时间设置在所有模式、所有服务器中都可用，你可以按自己的偏好设置，也可以根据你所在位置的当前时间进行设置。

1. 当前模拟器时间
2. 跳回到上一个白天时段（夜晚/日出/正午/日落）
3. 当前白天时段图标（夜晚/日出/正午/日落）
4. 跳转到下一个白天时段（夜晚/日出/正午/日落）
5. 使用滑块选择特定时间（橙色表示白天/灰色表示夜间）
6. 将模拟器时间重置为当前时间（模拟器 UTC 与现实世界 UTC 保持一致）

## 重量和平衡

![重量和平衡界面 - A320](../../../_images/manual/getting-started/pause-screen-w&b.png)



1. 根据巡航燃油流量估算的飞行时间

提示

: 一定要携带比你所需更多的燃油，尤其是在实时服务器上。由于启用的 ATC 较多，繁忙时可能会出现较长延误！


2. 飞机总重量

 

3. 显示你的最大起飞重量（MTOW）和最大着陆重量（MLW）。如果超过 MTOW，它会变为红色；如果超过 MLW，它会变为橙色（与[状态栏](getting-started-guide/pilot-user-interface/status-bar.md)中的“Aircraft Load”相同）


4. 不想自定义重量？没问题，只需点击底部的“轻载”、“正常”或“重载”，我们会自动为你设置重量！ 

5. 这里还可以选择以 Kg 或 Lbs 显示重量。（也可在设置中更改）

6. 调整油箱燃油的滑块。它们可以分别调整，也可以同步调整（见 9.）。不同飞机的油箱数量会不同。我们建议保持左右油箱平衡
   
   
7. 调整乘客的滑块。某些飞机（战斗机）可能不会显示此选项

8. 调整货物的滑块。每种飞机的货物选项数量和容量都不同

9. 同步按钮。默认情况下，一个类别中的所有滑块会相互关联并一起移动。如果你希望单独移动它们，请点击此按钮（图标会变成断开的链条）。再次点击即可重新同步

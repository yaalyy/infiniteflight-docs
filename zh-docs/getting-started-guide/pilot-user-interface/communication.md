# 通信

![Communication](../../../_images/manual/frames/communication.png)



1. 通信框左上角显示你当前调谐的频率、空中交通管制员详情（如果是有效频率）以及 METAR

   

2. 通信框右上角包含雷达管制频率下发的最后一次高度、航向、速度和跑道指令提醒，请确保遵循它们

   

3. 当你进入有效频率（以绿色文字显示）或 Unicom（无管制）频率的范围时，对应框会自动填充。只需轻点你想调谐到的频率。你也可以退出某个频率的调谐

   

   提示

   : 如果你已调谐到有效频率，在更换频率前务必先获得许可！

   

4. 所有通信都会记录在这里，双击该区域可仅显示你自己的通信以及管制员与你的通信

   

5. 除了通信框之外，当 ATC 发送或接收消息时，它们还会在屏幕顶部短暂显示。如果管制员向你发送消息，它会以橙色显示，屏幕左下角的通信符号会闪烁，提示你打开通信框并回复

## 使用地图和小地图进行通信


@[vimeo](428621440) 


步骤 1

: 使用 ["Getting more from your Map and Mini Map"](flight-planning.md#getting-more-from-your-map-and-mini-map) 中所示的方法选择你想要的机场

 

步骤 2

: 信息选项卡会显示所有有效频率，你当前调谐的频率会以绿色高亮，并标注为 "COM 1"

 

步骤 3

: 轻点任意频率旁边的 "TUNE" 即可将其设为 COM 1（你必须在机场覆盖范围内才能调谐其频率，并且只有在空中时才能调谐到雷达频率）

## 离开模式

![Away Mode](../../../_images/manual/frames/away-mode.png)



当飞机调谐到有管制员的频率时，其飞行条上会显示一个绿色或琥珀色圆圈，用于向管制员指示飞行员是“active”还是“away”。



这在你长途飞行且无法全程使用设备时会很有用。经过 2 分钟无操作（即设备没有任何输入）后，管制员会将你的飞机显示为“away”。只要你处于巡航阶段，这会让他们知道你不太可能回复，并且任何冲突都将视为非故意！



提示

: 在飞行的关键阶段或进入繁忙空域时，请务必保持使用设备并遵循所有 ATC 指令！

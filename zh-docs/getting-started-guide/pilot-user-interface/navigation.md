## GPS 导航

起飞后，只要你有飞行计划，就可以使用 GPS 导航。



步骤 1

: 确保在点击 LNAV 按钮时，Avionics 选项卡中的 "SOURCE" 已设置为 GPS



步骤 2

: 品红色的 Course Select Pointer（这表示到下一个航点的径向）和 Lateral Deviation Bar（表示偏离所需航迹的程度）将显示在 [HSI](hud.md#head-up-display-(hud)) 上。保持它们对齐，你就会沿着航线飞向下一个航点。当你接近地图上的航点时，飞行计划会自动切换到下一个航点，Course Select Pointer 也会移动，这样你就可以沿着新的航向飞行



步骤 3

: 如果你启用 [Autopilot](autopilot.md#autopilot) 和 LNAV，飞机将继续按照你的飞行计划飞行

## 调谐 ILS

@[vimeo](429403253)

步骤 1

: 使用 ["从地图和小地图获取更多信息"](flight-planning.md#getting-more-from-your-map-and-mini-map) 中展示的方法选择你想要的机场

 

步骤 2

: 切换到 Runway 选项卡

 

步骤 3

: 点击你想要调谐的跑道（它必须有 ILS）

 

步骤 4

: 点击 "Set NAV 1"。"NAV 1" 会在跑道旁以绿色显示，表示已成功调谐

Tip

: 在将 ILS 进近程序添加到你的飞行计划时，勾选 "Add to FPL" 旁边的 "Auto tune ILS" 复选框，这样就会自动调谐到你选择跑道的 ILS

## 在飞机中显示 ILS

@[vimeo](436875640)


步骤 1

: 在 Fly Screen 上点击 "NAV" 显示 Avionics 选项卡

 

步骤 2

: "NAV 1" 将显示 ILS 频率和 ident，下面的 "CRS (course) 1" 会显示跑道航向



步骤 3

: 确保 "SOURCE" 设置为 "NAV 1"，以便在飞机中使用它

 

步骤 4

: Horizontal Situation Indicator ([HSI](hud.md#head-up-display-(hud))) 将显示 Localizer（横向）偏差刻度，Altitude tape 将显示 Glideslope（纵向）偏差刻度

 

步骤 4

: 横向偏差刻度的航向可使用 "CRS 1" 调整（如果你想沿 Back Course Localizer 飞行，可以使用此功能）

## 在飞机中显示 VOR

@[vimeo](436896110)


步骤 1

: 将 VOR 调谐到 NAV 1 或 2 后，在 Fly Screen 上点击 "NAV"

 

步骤 2

: Avionics 选项卡将出现，NAV 1 或 2 会显示 VOR 频率和 ident。BRG (bearing) 1 或 2 可以更改为 "NAV 1 (or 2)"，所选指针会在 Horizontal Situation Indicator (HSI) 上显示这些信息

 

步骤 3

: CRS (course) 1 或 2 默认设置为 360，但可以选择任意径向。只要 "SOURCE" 设置为 "NAV 1 (or 2)"，[HSI](hud.md#head-up-display-(hud)) 就会显示横向偏差刻度，并且可以调整航向，以截获并沿着 VOR 信标的不同径向飞行

## Traffic Collision Avoidance System (TCAS)


![TCAS on Map](../../../_images/manual/frames/tcas.png) 


1. 在 Map 和 Mini Map 上，你的飞机会以白色飞机符号显示。这些符号的大小/形状会因所驾驶的飞机而异

   

2. 其他交通会以蓝色飞机显示

   

3. 如果满足以下条件，飞机会变为**Amber**，作为 Traffic Advisory (TA) 警报：

   

   -    两架飞机都在空中，速度高于 40kts

   -    高度差小于 2000ft

   -    按当前速度，另一架飞机将在 40 秒内接近

   

4. 如果满足以下条件，飞机会变为**Red**，作为 Resolution Advisory (RA) 警报：

   

   -    满足 TCAS TA Alert (amber) 的所有条件

   -    高度差小于 600ft

   

**如果生成 TCAS RA Alert (red)，则需要飞行员手动干预，下面的表格可帮助你了解该怎么做：**

 

| **Example** | **Meaning**                      | **Pilot Actions**                                            |
| ----------- | -------------------------------- | ------------------------------------------------------------ |
| ![](../../../_images/manual/graphics/tcas-1.svg)     | 该飞机在你上方 3000ft | 无需采取行动                                           |
| ![](../../../_images/manual/graphics/tcas-2.svg)   | 该飞机在你上方 1000ft | 空中交通管制员会始终确保 3 miles 横向或 1000ft 垂直间隔。无需采取行动 |
| ![](../../../_images/manual/graphics/tcas-3.svg)    | 该飞机在你下方 800ft  | 飞机间隔即将被打破 - 如果处于主动 ATC 管制下，且未收到指令，请申请偏离航线 |
| ![](../../../_images/manual/graphics/tcas-4.svg)      | 该飞机在你下方 100ft  | 无论是否处于主动 ATC 管制下，都应平滑调整你的飞行路径以避开该飞机；如果对方在你下方，我们建议爬升；如果对方在你上方，我们建议下降 |

 

Tip

: 你在任何时候都必须保持的最小飞机间隔为横向 3nm，或垂直 1000ft。在主动 ATC 管制下，他们会确保这一间隔得到维持。在繁忙空域中，经常会看到很多 Amber 飞机符号 - 不要过度反应，飞行时只需密切留意你的小地图即可!

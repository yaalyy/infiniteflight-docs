# 飞行计划



![Flight Plan Screen](../../../_images/manual/getting-started/flight-planning-main.png)



1. 飞行计划（FPL）部分显示你的下一个航路点（WPT）、期望航迹（DTK）、距离（DIST）、预计航路时间（ETE）和高度（ALT）。DIST 和 ETE 可以改为累计显示。当前活动航路点始终以品红色显示。如果高度以橙色或红色显示，表示到该航路点的下降率可能过高，因此最好检查一下

   

2. FPL 页面底部的按钮具有以下功能：

   | 按钮          | 功能                                                     |
   | ------------- | ------------------------------------------------------------ |
   | -             | 删除一个航路点                                            |
   | Act. Leg      | 先选择一个航路点，然后点此按钮，将该航路点设为活动航段 |
   | Clear         | 清除整个飞行计划                                    |
   | PROC | 快捷进入你飞行计划中任意机场的程序页面|
   | OPT.          | 点选一个航路点，然后点此按钮，可设置/编辑/删除一个可与 VNAV 配合使用的高度目标。点按“Set Autopilot ALT”会把 [自动驾驶](autopilot.md) 中选定的高度改为所选航路点的高度 |
   | Double Arrow  | 如果你已经有一个飞行计划，可以使用此按钮打开它，你也可以[分享](flight-planning.md#share-flight-plan)它，或者从 SimBrief 加载飞行计划 |



3. 搜索功能可用于在数据库中查找任何机场或航路点

   

   提示

   : 如果你已经有想要飞行的航线，把航线粘贴到搜索功能中，它会自动填入你的飞行计划（这也可以包含纬度/经度坐标）

   

4. 你可以点按地图上的任意定位点/机场/导航台，并使用“+”符号将其添加到你的飞行计划中。如果你点按旁边的符号，它会执行“direct to”功能，清除你全部的飞行计划并直接前往所选航路点

   

5. 屏幕右下角有设置、居中和放大/缩小功能。此外，你可以在仅显示地图、飞行计划，或两者同时显示之间切换。要自定义显示，可使用以下设置：

| 设置               | 功能                                                 |
| ------------------ | ------------------------------------------------------------ |
| Fixes             | 显示或隐藏称为 fixes 的 GPS 航路点                    |
| Navaids           | 显示或隐藏导航台（VOR/NDB）                       |
| Airspaces         | 显示或隐藏空域                                        |
| Taxiways          | 显示或隐藏滑行道线                                   |
| Approaches        | 显示或隐藏进近程序                                      |
| Uncontrolled Airports | 通过此设置显示或隐藏所有以品红色圆点表示的机场 |



提示

: 如果你正在使用较旧的设备和/或遇到“崩溃”，请尝试选择“Hide Airspaces”，这可能会提升设备性能！

## 向你的飞行计划添加坐标

添加坐标到飞行计划时，需要使用以下格式：



ddmmx/ddmmy



> **键：**
>
> d - 度
>
> m - 分
>
> x - N 或 S
>
> y - E 或 W



添加坐标时，你需要至少包含另一个航路点或坐标，因为不能只单独添加一个坐标。例如，如果你想添加 55N050W（使用上述兼容格式为 5500N/05000W），你需要同时选择另一个坐标或航路点添加到飞行计划中（例如 5500N/05000W 5500N/04000W 5500N/03000W 等）。



> 目前无法添加秒，因此在添加到飞行计划时需要将其四舍五入到最接近的分钟

## 分享飞行计划



“Open/Share”按钮可让你保存特定的飞行计划、分享飞行计划，或导入其他用户制作的飞行计划。 



**导出**

步骤 1

: 创建一个飞行计划



步骤 2

: 查看 FPL 并点击“箭头”图标



步骤 3

: 选择“Share”



步骤 4

: 选择一种分享方式（例如 AirDrop、电子邮件、备忘录等）



步骤 5

: 与相应用户分享，或保存以便以后使用



**导入**

步骤 1

: 将飞行计划保存到 Files 应用



步骤 2

: 在一次飞行中查看飞行计划页面并点击“箭头”图标



步骤 3

: 选择“Open Flight Plan”



步骤 4

: 从 Files 应用中打开相应的飞行计划

## 地图

![Map](../../../_images/manual/frames/map-227-v2.png)

 

1. 机场始终以蓝色或品红色圆点表示，如果你在线飞行，它们中间也可能有一个[彩色圆点](../home-user-interface/home-screen.md#airport-and-gate-selection)用于参考天气



2. VOR（Very High Frequency [VHF] Omnidirectional Range）导航台以此符号表示。如果你所选飞机配备了 NAV 1 或 2，它们可以调谐到对应频率

   

3. NDB（Non Directional Beacon）导航台以此符号表示。如果你所选飞机配备了 ADF 1（Automatic Direction Finder），它们可以调谐到该设备

   

4. GPS（Global Positioning System）定位点以此符号表示

   

5. 屏幕右下角有设置、居中和放大/缩小功能。此外，你可以在仅显示地图、飞行计划，或两者同时显示之间切换



6. 点按地图任意位置时，会弹出一个下拉列表，显示该点附近的任何对象。你可以从列表中选择你想要的对象以查看更多信息。如果它是一个定位点/导航台，你可以点按“+”符号将其添加到你的飞行计划，或点按旁边的符号执行“direct to”功能

   ![Information Tab](../../../_images/manual/frames/map2-227-v2.png)

   

7. 如果你点按了列表中的任何内容，将会显示一个“更多信息”标签页。如果点按的是机场，还会提供天气、跑道和程序等额外标签页

     

8. 如果点按的是一架飞机，你可以点按“Copy FPL”来复制它的飞行计划

## 在地图上查看高空风数据

可以在地图上查看从地表到 FL430 的多个高度层的风速和风向。
要启用此功能，请点按地图上的设置齿轮图标，然后点按“Winds Aloft”。这会将该图层添加到地图上。 

地图上的每个图标称为风羽，能为你提供风速和风向信息。风羽朝向表示风的吹向。风速依据显示的线条（风羽）和三角形（旗标）数量计算。每个短风羽（半线）代表 5 节，每个长风羽（整线）代表 10 节，每个旗标（三角形）代表 50 节。示例如下图所示：


![Winds Aloft](../../../_images/manual/getting-started/flight-planning-wind-barbs.png)

1. 按住并拖动此控件，可以设置所选风数据的高度。选择“Auto”将使用你当前飞机的高度 
2. 2 个旗标（50）、3 个长风羽（10）和 1 个短风羽（5），表示来自西方的 135 节风
3. 1 个旗标（50）、4 个长风羽（10）和 1 个短风羽（5），表示来自西北偏西的 95 节风
4. 没有旗标（50）、4 个长风羽（10）和 1 个短风羽（5），表示来自西南方的 45 节风

## 选择起飞、到达和进近程序


@[vimeo](429377642)


步骤 1

: 按照上面的[分步指南](flight-planning.md#getting-more-from-your-map-and-mini-map)打开程序标签页



步骤 2

: 你可以选择 Departure（SID）、Arrival（STAR）或 Approach（你想要飞行的进近）



步骤 3

: 选择 Approach 后，会显示你所选机场不同跑道的进近列表（见下表），在你逐个浏览时，地图上会显示预览。选中你想要的进近后，点按底部的“select”



提示

: 请确保选择在 ATIS 中广播为正在使用的进近程序（如果有 ATC）；如果没有管制，则应选择有利于天气和当前交通量的进近。进近列表会根据风向排序



步骤 4

: 某些进近程序还会提供一个名为 Transition 的进一步选项。这些通常会从某个导航台开始进近，例如 VOR，但如果你愿意，也可以直接选择“Vectors to Final”，这样就不会包含转换段



步骤 5

: 对选择满意后，你可以点按“Add to Flight Plan”。如果你改变主意，可以使用“Back”按钮



步骤 6

: 现在你可以使用与上面相同的方式选择到达和起飞程序



**以下前缀用于帮助区分机场可用的不同进近程序：**

| 前缀 | 含义                                       |
| ---- | --------------------------------------------- |
| D      | VOR/DME 进近                              |
| H      | RNAV (RNP) 进近                           |
| I      | ILS 进近                                  |
| J      | GLS 进近                                  |
| L      | 仅 LOC（Localizer）进近                 |
| N      | NDB 进近                                  |
| Q      | ILS/DME/VOR/NDB 的组合（两个或以上）  |
| R      | RNAV (GPS) 进近                           |
| S      | 仅 VOR 进近                             |
| X      | LDA（Localizer Type Directional Aid）进近 |



**在前缀之后，会显示跑道标识（例如 27 对应 27 号跑道）。随后会显示任何相关后缀，下表中列出了这些后缀：**

| 后缀      | 含义                                                      |
| --------- | ------------------------------------------------------------ |
| L         | 左                                                         |
| R         | 右                                                        |
| Y or Z    | 区分使用相同引导的跑道 |
| 1, 2 etc. | 表示同一引导用于某条跑道，但采用不同的进近路径（常见于 VOR/DME/NDB 进近） |



**示例：**

H35LZ - 35L 号跑道的 RNAV (RNP) 进近，Zulu 程序

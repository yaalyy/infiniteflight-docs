# 平视显示器（HUD）

![Head Up Display](../../../_images/manual/frames/hud-v2.png)



1. 外界空气温度（OAT）以摄氏度显示在这里

    

2. 空速带显示飞机速度。根据你正在驾驶的机型，它也可能用颜色来表示飞行速度过慢/过快（红色）或处于正确速度（绿色）

    

3. 地速（GS）、马赫数（M）以及风向/风速显示在这里

    

4. 姿态指示器显示飞机相对于地平线的姿态，并提供飞行路径矢量（在 [系统菜单](systems.md#systems) 中启用的绿色圆圈）

    

5. 高度带显示飞机高度、当前垂直速度（显示在高度带底部）以及一个青绿色标记，表示在 [自动驾驶仪](autopilot.md#autopilot) 飞行控制单元（FCU）中选定的高度

    

6. 功率以百分比显示，如果该机型适用，对应的 N1 也会显示在其上方

    

7. 水平态势指示器（HSI）显示在这里，用于[导航](navigation.md#navigation)。这里有一个与高度带类似的青绿色标记，显示飞机 FCU 中选定的航向

   

8. 当前坡度角显示在顶部，并通过指针和刻度表示。当指针位于中线下方时，表示机翼水平或坡度为 0 度。两侧的刻度线表示以 10 度为增量的坡度角（即 10、20、30、40 和 50）

# 违规原因



下面列出了管制员在对飞行员发出 [Violation](violations.md) 时可使用的全部原因。不确定什么是违规？下面有一个简要说明，但更多信息可以在专门的 [Violation](violations.md) 页面找到：



Level 1 Violation

: 如果飞行员在一次飞行中收到 3 次或更多 Level 1 Violation，将会被自动移出服务器，并且需要重新开始一次飞行



Level 2 Violation (Amber)

: 飞行员会与服务器断开连接，但仍可离线继续飞行。只要 Level 2 和 3 Violation 的数量仍低于服务器允许的上限，飞行员可通过开始新的飞行立即返回 Expert Server



Level 3 Violation (Red)

: 飞行员会与服务器断开连接，但仍可离线继续飞行。飞行结束后，飞行员将无法返回 Expert Server，并且在此后的 7 天内会被限制访问



提示

: 本页面应能帮助你识别收到违规的原因，但这些原因有时比较笼统，可能不会列出与你情况完全对应的具体细节。还是不确定吗？不妨在我们的 Community Forum 上 [直接联系管制员](violations.md#appealing-a-level-2-or-3-violation)？

## 机场环境内速度过快

*由：塔台/雷达*

*违规等级：3*



在飞行过程中保持态势感知是飞行员在 Expert Server 上获得真实体验时必须维持的重要方面。未与其他航空器保持适当间隔、未遵循排序、速度过快、进场程序错误、对准错误跑道，或从错误跑道起降，都可能导致被移出 Expert Server。



+++ 战斗机飞行礼仪

目前对战斗机速度没有自动系统限制，但在受管制空域内，无论是塔台还是进近，都应始终保持合理速度。 



强制执行的程序：

- 在 10,000 英尺以下且受 ATC 管制时，不得超过 350KIAS 



建议程序：

- 正常飞行时不应超过 M1.0
- 在拥挤的民航环境中运行时不应超过 250KIAS 
- 监控周边交通的速度，并相应调整速度 



> 适用于民航飞机的标准速度限制同样适用于军用货运飞机（即在 10,000 英尺以下且受 ATC 管制时最大为 250 KIAS）



指令、排序和交通流量应**始终**决定你的速度，并促使你提高对周围环境的警觉性。

+++

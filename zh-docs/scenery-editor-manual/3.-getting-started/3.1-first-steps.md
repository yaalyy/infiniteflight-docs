## 打开 Scenery Editor

<a id="3.1.2"></a>
<a id="312"></a>
<a id="3.1.2"></a>
<a id="312"></a>
### 3.1.2

步骤 1

: 打开 Infinite Flight 应用并选择“Scenery Editor”



步骤 2

: 选择你想编辑的机场，然后选择任意跑道或停机位。点击“Ok”，然后点击“Open”开始



步骤 3

: 如果你正在编辑一个新机场（或者正在处理一个尚未在 IFC 上有主题帖的现有机场），系统会自动在 [Scenery Editor Category](https://community.infiniteflight.com/c/scenery-editing/editors/52) 中创建一个主题。每当上传新版本时，更新日志会自动添加到每个主题中，便于跟踪。关于某个机场的所有交流**必须**{.red} 保持在其对应的专属主题中



步骤 4

: 当你第一次上传某个机场时，系统会自动将该机场分配给你（这可以防止其他人向同一机场上传）

# 3.3 机场边界



<a id="3.3.1"></a>
<a id="331"></a>
<a id="3.3.1"></a>
<a id="331"></a>
### 3.3.1

机场边界以一条浅绿色线条显示，包围着机场。机场边界内的地形高度将始终完全平坦，以便进行编辑，并防止任何建筑物/物体悬空或下沉。机场边界外的所有地形将根据真实世界地形呈现不同的海拔高度。



> 所有物体**必须**{.red}位于机场边界内，唯一的例外是诸如航向信标天线之类的机场设备。在这些情况下，Editor **必须**{.red}确保该物体与地形正确对齐



提示

: 如果你发现建筑物/物体悬空或下沉，可能是因为它们离机场边界太近。你可以移动机场边界，或者将建筑物/物体稍微向内移动一点，远离边界



<a id="3.3.2"></a>
<a id="332"></a>
<a id="3.3.2"></a>
<a id="332"></a>
### 3.3.2

要编辑机场边界，请按照以下步骤操作：



> 如果更改了机场边界，在应用中反映新边界之前，需要先进行一次导航数据库更新。因此，在此更新完成之前，Editors **不应**{.red}在新的机场边界内添加任何新的建筑物/物体



步骤 1

: 点击浅绿色线条上或附近，并选择 "airport boundary" **(1)**



> 你可能不会看到选择 "airport boundary" 的选项，但如果它已被选中，你可以通过查看屏幕左下角来确认，那里会显示当前所选内容



步骤 2

: 点击右侧编辑按钮中的 "Modify Shape" **(2)**，它会变成琥珀色以表示已被选中



步骤 3

: 会出现节点 **(3)**，你可以点击它们来移动（它会变成品红色以表示已被选中）



步骤 4

: 点击、按住并拖动中心圆点以移动节点 **(4)**



步骤 5

: 可以通过点击右侧编辑按钮中的 "insert point" **(5)** 来添加更多节点

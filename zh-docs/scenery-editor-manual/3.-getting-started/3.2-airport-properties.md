# 3.2 机场属性



<a id="3.2.1"></a>
<a id="321"></a>
<a id="3.2.1"></a>
<a id="321"></a>
### 3.2.1

要编辑机场属性，**必须**{.red}按照以下步骤进行： 



步骤 1

: 点击屏幕左侧管理按钮中的 "File > Airport Properties" **(1)**



步骤 2

: 机场属性会显示在屏幕右侧 **(2)**



步骤 3

: 除了 "Frequencies" 之外，所有属性都通过点击该属性进行调整 *(见下方 [3.2.3](3.2-airport-properties.md#3.2.3))*，然后输入新的值/名称并点击 "OK"



步骤 4

: 某些属性可能已经预先填入，编辑者**必须**{.red}确保这些内容正确，并补全所有缺失的属性

### 3.2.2

| 机场属性                 | 用途                                                         |
| ------------------------ | ------------------------------------------------------------ |
| ICAO                     | 四字母 ICAO 代码（例如 KSFO 或 EGLL）**不应**{.red}更改，因为这会影响机场保存系统。如果必须更改（例如真实机场更改了其 ICAO 代码），则该机场**必须**{.red}先使用新 ICAO 代码发布，之后才能创建进一步的草稿。 |
| Elevation                | 机场海拔（米）                                               |
| Name                     | 机场名称                                                     |
| Spoken Name              | 会在应用内被播报的机场名称                                   |
| City                     | 机场主要服务的城市。这不一定与地理位置上的城市相同（例如 KJFK 的城市名称应为 New York，而不是 Queens） |
| Country                  | 机场所在国家                                                 |
| State                    | 机场所在州或等效行政区（例如县）                             |
| IATA Code                | 三字母 IATA 代码（例如 SFO 或 LHR）                          |
| FAA Code                 | 仅适用于美国机场的三到五位字母数字代码（通常与 IATA 代码类似） |
| Airport Class            | 机场等级（从 Alpha 到 Echo）                                 |
| Latitude                 | 机场纬度（**不应**{.red}更改）                               |
| Longitude                | 机场经度（**不应**{.red}更改）                               |
| Frequencies              | 机场频率                                                     |
| Taxiway Routes Available | 选中后会显示橙色勾选标记（**必须**{.red}选中，ATC 才能向管制员和飞行员提供滑行道网络） |
| Jet Bridges Available    | 选中后会显示橙色勾选标记（**必须**{.red}先添加并可用登机廊桥后才能选中，这样飞行员才能使用动画登机廊桥 - *见下方 [11.4.1](../11.-airport-gates/11.4-jet-bridge-animations.md#11.4.1)*） |

### 3.2.3

要添加/删除或编辑频率，**必须**{.red}按照以下步骤进行： 



步骤 1

: 点击 "Frequencies" 旁边的 "+" 符号 **(1)**



步骤 2

: 该机场当前列出的所有频率会显示在下方。点击某个频率左侧的 "+" 符号以展开其属性 **(2)**



步骤 3

: Frequency Type、Name、Frequency 和 Spoken Name 都可以按照其他机场属性的方式进行更改 *(见上方 [3.2.1](3.2-airport-properties.md#3.2.1))*



步骤 4

: 点击同一频率左侧的 "-" 符号可“关闭”其属性选项卡 **(3)**



步骤 5

: 要删除某个频率，点击该频率右侧的 "-" 符号 **(4)**



步骤 6

: 要添加新的频率，点击所有频率下方右下角的 "+" 符号 **(5)**

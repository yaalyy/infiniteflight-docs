# 10.5 模型线



<a id="10.5.1"></a>
<a id="1051"></a>
<a id="10.5.1"></a>
<a id="1051"></a>
### 10.5.1

使用 "Model Line" 工具，你可以沿着一条线添加一系列物体。每一段线 **必须**{.red} 至少和你要添加到它上面的物体一样长（例如，如果一段栅栏长 4m，那么模型线至少需要 4m），否则物体会超出线段。可用它来创建长段栅栏。



提示

: 每当你连接建筑/线条/人行道时，**必须**{.red} 使用 "Snap" 功能来避免间隙和/或重叠 *(见上方 [2.1.4](../2.-user-interface/2.1-editor-screen.md#2.1.4))*

## 创建模型线

<a id="10.5.2"></a>
<a id="1052"></a>
<a id="10.5.2"></a>
<a id="1052"></a>
### 10.5.2

步骤 1

: 点击 "Object"，然后点击 "Create Model Line" **(1)**



步骤 2

: 右侧会打开属性选项卡，点击 "Model Ref Name" 并从列表中选择所需物体，即可选择用于模型线的物体



步骤 3

: 点击你想创建模型线的机场区域 **(2)**，第一个节点就会放置



步骤 4

: 继续点击以添加节点 **(3)**，模型线会继续在节点之间绘制

## 编辑现有模型线

<a id="10.5.3"></a>
<a id="1053"></a>
<a id="10.5.3"></a>
<a id="1053"></a>
### 10.5.3



步骤 1

: 点击线条上或附近来选中模型线，如果附近有多个项目，你可能需要从下拉列表中选择模型线 *(或者使用矩形选择工具 - 见上方 [2.1.6](../2.-user-interface/2.1-editor-screen.md#2.1.6))*



步骤 2

: 点击右侧的 "Modify Shape" 按钮 **(1)**



步骤 3

: 被选中时，线条会变为洋红色，并显示节点



步骤 4

: 点击某个节点后，它会变为洋红色 **(2)**，表示已被选中 *(或者使用矩形选择工具 - 见上方 [2.1.6](../2.-user-interface/2.1-editor-screen.md#2.1.6))*



步骤 5

: 然后你可以在屏幕上点击、按住并拖动手指，将节点移动到所需位置



步骤 6

: 编辑完成后，点击 "Modify Shape" 取消选择它（在此之前你将无法编辑其他模型线） 



![Image 10.5.3.1 - Editing Model Lines](../../../_images/manual/frames/9.5.3.1a.png)

## 移动/更改模型线方向

<a id="10.5.4"></a>
<a id="1054"></a>
<a id="10.5.4"></a>
<a id="1054"></a>
### 10.5.4



步骤 1

: 点击线条上或附近来选中模型线 *(或者使用矩形选择工具 - 见上方 [2.1.6](../2.-user-interface/2.1-editor-screen.md#2.1.6))*



步骤 2

: 如果附近有多个模型线，你可能需要从下拉框中选择模型线。模型线的轮廓会变为洋红色，表示它已被选中 **(1)**



提示

: 如果你刚刚创建了模型线，只需点击 "Modify Shape" 取消选择它，然后模型线就会被选中



步骤 3

: 会出现两个圆圈以及一个罗盘玫瑰。点击并按住圆圈 **(2)** 可移动模型线或更改方向：



| 圆圈   | 功能                                                     |
| ------ | ------------------------------------------------------------ |
| 中心   | 通过拖动手指到所需位置来移动模型线 |
| 外圈   | 通过沿着你希望它朝向的方向拖动手指来更改模型线的方向 |



![Image 10.5.4.1 - Moving/Changing Orientation of a Model Line](../../../_images/manual/frames/9.5.4.1a.png)

## 模型线属性

<a id="10.5.5"></a>
<a id="1055"></a>
<a id="10.5.5"></a>
<a id="1055"></a>
### 10.5.5

步骤 1

: 点击线条上或附近来选中模型线 *(或者使用矩形选择工具 - 见上方 [2.1.6](../2.-user-interface/2.1-editor-screen.md#2.1.6))*



步骤 2

: 如果附近有多个模型线，你可能需要从下拉框中选择模型线。模型线的轮廓会变为洋红色，表示它已被选中 **(1)** 



步骤 3

: 点击屏幕右侧的 "Properties" 选项卡 **(2)**



![Image 10.5.5.1 - Changing Model Line Properties](../../../_images/manual/frames/9.5.5.1a.png)



步骤 4

: 然后你可以调整以下属性：



| 按钮                | 功能                                                     | 备注                                                        |
| -------------------- | ------------------------------------------------------------ | ------------------------------------------------------------ |
| Model Ref Name       | 点击以选择要与模型线一起放置的物体 | 目前仅使用栅栏或类似物体                      |
| Spacing              | 点击 "+/-" 符号来调整物体之间的间距  | 这需要与栅栏段的长度相同（即 12m 的栅栏填 12.00） |
| Orientation Offset   | 点击 "+/-" 符号来围绕各自中心旋转线上物体  | 默认的 90.0 偏移可确保栅栏正确连接（建议不要更改） |
| Center Offset        | 点击 "+/-" 符号将物体从零节点向外偏移  | 这需要是栅栏段长度的一半（即 6m 的栅栏填 3.00） |
| Latitude / Longitude | 物体当前的纬度/经度                     |                                                              |
| Altitude             | 这会显示模型线当前的高度（以米为单位）。点击数字后输入新值即可调整 | 模型线的高度不能更改                   |
| Name                 | 你可以在此字段中为模型线命名                 |                                                              |

<a id="10.5.6"></a>

<a id="10.5.6"></a>

### 10.5.6

步骤 1

: 点击线条上或附近来选中模型线 *(或者使用矩形选择工具 - 见上方 [2.1.6](../2.-user-interface/2.1-editor-screen.md#2.1.6))*

: 点击屏幕右侧编辑按钮中的 "Delete Selection" **(2)**

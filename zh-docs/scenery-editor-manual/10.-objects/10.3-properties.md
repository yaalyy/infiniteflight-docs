# 10.3 属性



<a id="10.3.1"></a>
<a id="1031"></a>
<a id="10.3.1"></a>
<a id="1031"></a>
### 10.3.1

步骤 1

: 通过轻点对象中心的蓝色圆圈或其附近来选择对象 *(或者使用矩形选择工具 - 参见上方的 [2.1.6](../2.-user-interface/2.1-editor-screen.md#2.1.6))*



步骤 2

: 圆圈会变成洋红色，表示它已被选中 **(1)**。如果附近有多个对象，会出现一个列表，方便你选择想要的对象



步骤 3

: 点击屏幕右侧的 "Properties" 选项卡 **(2)**



![Image 7.3.1.1 - Changing Object Properties](../../../_images/manual/frames/7.3.1.1b.png)



步骤 4

: 然后你可以调整以下属性：



| 按钮                 | 功能                                                       | 说明                                                                 |
| -------------------- | ---------------------------------------------------------- | -------------------------------------------------------------------- |
| Scale                | 轻点 "+/-" 符号来调整对象的缩放比例                           | 对于让对象尺寸与外部来源所见保持一致非常有用（例如照明空调机组和喷流挡板等）。**不得**{.red}更改登机桥的缩放比例 |
| Orientation          | 轻点 "+/-" 符号来调整对象的方向                               |                                                                      |
| Animations           | 如果某个对象（例如登机桥）内置了动画，这里会显示出来            |                                                                      |
| Latitude / Longitude | 对象当前的纬度/经度                                          |                                                                      |
| Altitude             | 这里显示对象当前的高度（以米为单位）。轻点数字，然后输入新值即可调整 | 始终以你所处理表面的底部为基准。如果你在进行分层处理，例如，可以在这里手动调整，或者前往 "Object > Auto Altitude" |
| Name                 | 你可以使用此字段为对象命名                                   |                                                                      |

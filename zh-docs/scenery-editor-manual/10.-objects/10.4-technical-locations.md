# 10.4 技术位置



<a id="10.4.1"></a>

### 10.4.1

## 航向道

<a id="10.4.2"></a>
<a id="1042"></a>
<a id="10.4.2"></a>
<a id="1042"></a>
### 10.4.2

**应**{.red}优先使用卫星图像作为放置依据，因为实际情况可能会有差异，不过下面的距离信息可以帮助放置：

![Image 7.4.2.1 - Localizer Location](../../../_images/manual/frames/localizer.png)

| 航向道 | 详情 |
| ----------- | ------------------------------------------------------------ |
| 何时 | 仅当机场具有 ILS 和/或仅航向道（LOC-Only）进近时 |
| 位置 | 放置在距离跑道入口 1000ft 处（与 ILS/LOC-Only 进近的相对一端 - 例如，如果 ILS 对应 RWY36，则天线应放在 RWY18 的末端）- 请注意，入口点可能是错位的，因此应从白色钢琴键标志开始算 1000ft，而不是从混凝土边缘算 1000ft！ |
| 朝向 | 经验上，将天线放置成与跑道垂直，且电气箱一侧背向跑道 |

> 还可以添加一个额外的红白相间电气箱，但其位置差异很大。如果你能在 Google Maps 或某些机场照片中找到它，那会是最好的办法。不过它通常位于 LOC 天线的一侧，并且两者之间一般会有一点距离（也就是不会像 G/S 天线那样紧挨在一起）

## 下滑道

<a id="10.4.3"></a>
<a id="1043"></a>
<a id="10.4.3"></a>
<a id="1043"></a>
### 10.4.3

**应**{.red}优先使用卫星图像作为放置依据，因为实际情况可能会有差异，不过下面的距离信息可以帮助放置：

![Image 7.4.3.1 - Glideslope Location](../../../_images/manual/frames/glideslope.png)

| 下滑道 | 详情 |
| ----------- | ------------------------------------------------------------ |
| 何时 | 仅当机场具有 ILS 进近时 |
| 位置 | 放置在距离跑道入口 750 - 1250ft 处（这次是进近端 - 例如，如果 ILS 对应 RWY36，则应放置在 RWY36 入口点 750 - 1250ft 处），并且距离跑道中心线 250 - 650ft（大多数情况下，该位置与主接地区标志带平齐）- 同样可以查看 Google Maps，放大后你大概能看出它位于哪一侧，以及它与哪些跑道标志对齐 |
| 朝向 | 将天线放置成白色/灰色天线朝向进近中的飞机（见下图） |

> 将一个红白相间的电气箱放在 G/S 天线后方

## 着陆引导系统（PAPI）

<a id="10.4.4"></a>
<a id="1044"></a>
<a id="10.4.4"></a>
<a id="1044"></a>
### 10.4.4

着陆引导系统由几盏灯组成，用于直观显示下滑路径，飞行员借此在着陆最后阶段保持下滑道。它们位于跑道接地区附近，请按照以下步骤正确配置 PAPI：



步骤 1

: 添加着陆引导系统对象 *(见上文 [10.2.1](10.2-selection-and-placement.md#10.2.1))*



步骤 2

: 灯光**必须**{.red}调整到与着陆跑道对齐，可以通过圆圈 *(见上文 [10.2.2](10.2-selection-and-placement.md#10.2.2))* 或在“属性”选项卡中（使用滑块或“+/-”符号）完成



步骤 3

: 此外，还必须调整以下属性：

- 跑道标识符（**必须**{.red}与跑道编号匹配）
- 引导类型（见步骤 4）
- 下滑道（见步骤 5）



步骤 4

: 对于引导类型，**必须**{.red}根据 PAPI 的位置（即跑道左侧或右侧）进行更改，如下所示：



| 引导类型 | 说明 |
| ------------------ | ------------------------------------------------------------ |
| VASI | 待定 |
| PAPI4L | 两个灯并排成一列，仅用于跑道左侧（如适用） |
| PAPI4R | 两个灯并排成一列，仅用于跑道右侧（如适用） |
| Space Shuttle PAPI | 未使用 |
| Tri Color VASI | 待定 |
| Runway Guard | 未使用 |



步骤 5

: 下滑道，**必须**{.red}调整为与现实中使用的下滑道角度一致，不过默认情况下通常为 3 度

## VOR

<a id="10.4.5"></a>
<a id="1045"></a>
<a id="10.4.5"></a>
<a id="1045"></a>
### 10.4.5

| VOR | 详情 |
| ----------- | ------------------------------------------------------------ |
| 何时 | 仅当机场有一个**同址** VOR（即位于机场边界内的 VOR）时 |
| 位置 | 你需要查看图表，大致判断 VOR 所在位置，然后前往 Google Maps 并在该位置放大查看（使用卫星选项）以确定精确位置。这样你也能判断它是大型还是小型（大型：比另一个更大，且有大量天线从中心向外伸出 - 小型：更紧凑，伸出的天线少得多） |
| 朝向 | 我想不会有人真的注意到，所以不用太担心这个！ |

## 塔台视角点

<a id="10.4.7"></a>
<a id="1047"></a>
<a id="10.4.7"></a>
<a id="1047"></a>
### 10.4.7

作为飞行员或管制员选择不同摄像机的方式，可参见 [新手入门指南](../../getting-started-guide/pilot-user-interface/cameras.md)。ATC 塔台视角是通过添加一个“View Point”来创建的 *(见上文 [10.2.2](10.2-selection-and-placement.md#10.2.2))*。



<a id="10.4.8"></a>
<a id="1048"></a>
<a id="10.4.8"></a>
<a id="1048"></a>
### 10.4.8

添加视角点后，**必须**{.red}将其放置在 3D 塔台对象的中心位置。如果有多个塔台，**必须**{.red}为每个塔台都添加一个视角点。



> 在应用内只会选中对象列表中的第一个视点，因此最先添加的那个视点必须放在“主”ATC 塔台中



<a id="10.4.9"></a>
<a id="1049"></a>
<a id="10.4.9"></a>
<a id="1049"></a>
### 10.4.9

每添加一个视点，编辑者**必须**{.red}切换摄像机视角 *(见上文 [2.1.5](../2.-user-interface/2.1-editor-screen.md#2.1.5))* 来检查该视点是否正确位于塔台内。可以调整视点的高度，以确保它与塔台本身的视角高度一致 *(见上文 [10.3.1](10.3-properties.md#10.3.1))*。

## 实用提示

<a id="10.4.10"></a>
<a id="10410"></a>
<a id="10.4.10"></a>
<a id="10410"></a>
### 10.4.10

- 上网查看是否能找到有助于对象放置的机场图片
- 查找某个机场的图表，尤其是地面图，因为它们通常会显示风向标、塔台、货运区和消防站的位置
- 使用多个卫星地图进行交叉参考
- 上面关于航向道和下滑道位置的提示仅适用于标准进近。像 LOWI 这样的地方属于特殊情况 - 如果不确定，就直接问！

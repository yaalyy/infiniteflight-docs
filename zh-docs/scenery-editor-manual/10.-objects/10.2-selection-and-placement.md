## 选择并放置对象

<a id="10.2.1"></a>
<a id="1021"></a>
<a id="10.2.1"></a>
<a id="1021"></a>
### 10.2.1

步骤 1

: 向上/向下滚动屏幕右侧的列表以查看对象仓库（必须选中 **“Library”**{.red} 选项卡）



步骤 2

: 轻点你想放置的对象来选中它 **(1)**



步骤 3

: 在你想添加该对象的机场区域轻点（你可能需要按住不放），这会放置一个白色光标 **(2)**。按需要调整后，轻点 "Add Object" **(3)**



提示

: 你可能需要“冻结”线条和跑道面，以避免在屏幕上轻点时选中它们。为此，轻点 "Edit > Freeze All Lines / Freeze All Pavements"

## 更改对象朝向

<a id="10.2.2"></a>
<a id="1022"></a>
<a id="10.2.2"></a>
<a id="1022"></a>
### 10.2.2

步骤 1

: 轻点对象中心的蓝色圆圈上或附近来选中对象 *(或者使用矩形选择工具 - 见上文 [2.1.6](../2.-user-interface/2.1-editor-screen.md#2.1.6))*



步骤 2

: 圆圈会变为洋红色，表示它已被选中。如果附近有多个对象，会显示一个列表，供你选择所需对象



步骤 3

: 会出现三个圆圈以及一个罗盘玫瑰。按住圆圈 **(1)** 可移动对象，或更改高度/朝向：



| 圆圈                           | 功能                                                     |
| ------------------------------ | ------------------------------------------------------------ |
| 中心                           | 通过将手指拖动到所需位置来移动对象 |
| 上方（就在中心圆上方）         | 调整对象的海拔或高度          |
| 外圈                           | 通过沿着你希望其朝向的方向拖动手指来更改对象的朝向 |



![Image 7.2.2.1 - Changing Object Orientation](../../../_images/manual/frames/7.2.3.1b.png)

## 复制与粘贴对象

<a id="10.2.3"></a>
<a id="1023"></a>
<a id="10.2.3"></a>
<a id="1023"></a>
### 10.2.3

步骤 1

: 轻点对象中心的蓝色圆圈上或附近来选中对象 **(1)** *(或者使用矩形选择工具 - 见上文 [2.1.6](../2.-user-interface/2.1-editor-screen.md#2.1.6))*



步骤 2

: 圆圈会变为洋红色，表示它已被选中。如果附近有多个对象，会显示一个列表，供你选择所需对象



步骤 3

: 轻点屏幕左侧的 "Edit" 按钮 **(2)**，然后轻点 "Copy" 按钮 **(3)**



步骤 4

: 在你想添加复制对象的机场区域轻点（你可能需要按住不放），这会放置一个白色光标 **(4)**。按需要调整后，轻点 "Paste" **(5)**



![Image 7.2.3.1 - Copy & Pasting an Object](../../../_images/manual/frames/7.2.4.1b.png)

## 删除对象

<a id="10.2.4"></a>
<a id="1024"></a>
<a id="10.2.4"></a>
<a id="1024"></a>
### 10.2.4

步骤 1

: 轻点对象中心的蓝色圆圈上或附近来选中对象 *(或者使用矩形选择工具 - 见上文 [2.1.6](../2.-user-interface/2.1-editor-screen.md#2.1.6))*



步骤 2

: 圆圈会变为洋红色，表示它已被选中。如果附近有多个对象，会显示一个列表，供你选择所需对象



步骤 3

: 轻点屏幕右侧的 "Delete Selection" 按钮 **(1)**

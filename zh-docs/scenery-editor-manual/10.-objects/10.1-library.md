# 10.1 库



+++ Do and Do Not

| :fa-check-circle: 应当                                         | :fa-times-circle: 不应当                                     |
| ------------------------------------------------------------ | ------------------------------------------------------------ |
| :fa-check-circle: 在机场周围以符合现实的方式添加对象 | :fa-times-circle: 在登机口区域内放置对象（即不要把对象放到“白线”之外） |
| :fa-check-circle: 使用对象线工具添加较长的围栏段 | :fa-times-circle: 滥用对象来创建建筑形状或模拟其他对象（例如，不要把巴士埋进地面/建筑里来伪装成火车，或用油罐来模拟穹顶等） |
| :fa-check-circle: 在机场边界外添加与航空相关的对象（例如启德场周棋盘、VOR、航向信标天线），前提是它们与地形正确对齐（即没有穿模/悬空） | :fa-times-circle: 不要在登机口区域把 ULD 直接放在地面上（即没有放在集装板车上），这只应出现在仓储/货运区域 |
| -                                                            | :fa-times-circle: 在同一位置放置过多对象（例如，不要用汽车填满整个停车区域，在这类区域或大型太阳能板阵列中应谨慎使用） |
| -                                                            | :fa-times-circle: 在现实中没有该设施的登机口/机场添加 Safedock |
| -                                                            | :fa-times-circle: 在机场边界外添加对象   |
| -                                                            | :fa-times-circle: 添加任何类型的“彩蛋”             |
| -                                                            | :fa-times-circle: 将施工设备用于临时 NOTAM（例如任何不会在超过 2 个发布周期内过期的内容） |

+++

提示

+++ Bundles



有多种预设组合可用，通过插入某个特定地点常见的一组对象来节省编辑者时间，例如“Remote Parking”包含通常出现在远机位区域的对象。也可以按照以下步骤创建并共享自定义组合：



Step 1

: 添加你想要打包在一起的对象 *(见下方 [10.2.2](10.2-selection-and-placement.md#10.2.2))*



> 建筑不能添加到组合中，且对缩放所做的任何更改都不会保存在组合里



Step 2

: 点击、按住并在屏幕上拖动手指以选中所有对象（会出现一个白色方框来显示选区）。代表每个对象的所有蓝点会变成品红色，以显示已被选中的对象



Step 3

: 点击“File”，然后点击屏幕左侧的“Save Selected as Bundle”



Step 4

: 为该组合命名，然后点击“OK”。该组合将显示在屏幕右侧“Library”中的“Bundles”下



Step 5

: 通过从“Library”中选择该组合，然后点击屏幕左侧的“File”和“Share Selected Bundle”，即可共享任意组合

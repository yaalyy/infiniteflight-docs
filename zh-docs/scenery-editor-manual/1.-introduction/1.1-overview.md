# 1.1 概述



<a id="1.1.1"></a>
<a id="111"></a>
<a id="1.1.1"></a>
<a id="111"></a>
### 1.1.1

欢迎来到 Infinite Flight 场景编辑器手册！本手册旨在帮助新加入者和现有编辑者了解内部流程，同时涵盖所有 Infinite Flight 编辑工作所涉及的基本原则。**所有编辑者都应熟悉本手册，并在其于场景编辑团队任职期间持续了解其中内容。**{.red} 



必须

: 在本手册中使用 **must**{.red} 或 **must not**{.red} 被视为 **强制性**，并且必须 **严格遵守**。

应该

: 在本手册中使用 **should**{.red} 或 **should not**{.red} 被视为 **建议性**，并且 **强烈建议** 遵守。

[Infinite Flight 用户指南](/guide) 和 [IFC 论坛](https://community.infiniteflight.com/) 是编辑者 **应该**{.red} 使用的其他工具。

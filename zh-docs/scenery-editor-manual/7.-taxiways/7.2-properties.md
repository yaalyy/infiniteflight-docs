### 7.2.1

步骤 1

: 通过轻触滑行道上或附近的位置来选择滑行道 *(或使用矩形选择工具 - 见上方 [2.1.6](../2.-user-interface/2.1-editor-screen.md#2.1.6))*



步骤 2

: 如果附近有多个滑行道，你可能需要从下拉框中选择该滑行道。滑行道轮廓会变成洋红色，表示它已被选中 **(1)**



步骤 3

: 轻触屏幕右侧的 "Properties" 选项卡 **(2)**



![图像 7.2.1.1 - 滑行道属性](../../../_images/manual/frames/5.2.1.1.png)



步骤 4

: 然后你可以调整滑行道的以下属性：

| 按钮                  | 功能                                                         | 备注                                                         |
| --------------------- | ------------------------------------------------------------ | ------------------------------------------------------------ |
| 类别                  | 从 A 到 F                                                   | 确保为可在该滑行道上滑行的飞机类别选择正确的类别 *(见上方 [1.3](../1.-introduction/1.3-aircraft-categories.md))* |
| 方向                  | 可选择双向、正向、反向和无                                   | 见下方 [7.2.5](7.2-properties.md#7.2.6) |
| 线型                  | 可选择多种线型                                               | 见下方 [7.2.2](7.2-properties.md#7.2.2) |
| 滑行道网络用途        | 可选择未知、飞机或无                                         | 见下方 [7.2.3](7.2-properties.md#7.2.3) |
| 灯光类型              | 可选择多种灯光类型                                           | 见下方 [7.2.2](7.2-properties.md#7.2.2) |
| 纬度 / 经度           | 滑行道当前的纬度/经度                                         | 此项**不应**{.red}更改                                       |
| 高度                  | 这会显示滑行道当前的高度（以米为单位）。轻触该数字，然后输入新值即可调整 | 高度始终以机场海拔为基准（此项**不应**{.red}更改）           |
| 名称                  | 你可以使用此字段为滑行道命名                                 | 所有滑行道**都必须**{.red}使用合适的名称（例如 Alpha 滑行道用 "A"）。见下方 [7.2.4](7.2-properties.md#7.2.4) |

## 滑行道网络用途

<a id="7.2.3"></a>

### 7.2.3

“滑行道网络用途”属性的目的，是识别可在 ATC 通信中与飞机使用的任何线条（例如等待线或中心线）。下表概述了何时使用不同的用途类型：



| 用途类型 | 是否属于滑行道网络？ | 用途                                                         |
| -------- | -------------------- | ------------------------------------------------------------ |
| 未知     | 不使用               | 不使用                                                       |
| 飞机     | 是                   | 中心线和跑道等待线*                                          |
| 无       | 否                   | 停止线、滑行道边线、道路、机位轮廓、跑道掉头线以及其他等待线** |

**只有最靠近跑道的跑道等待线**必须通过将用途类型设置为 "Aircraft" 来包含在滑行道网络中* 

***所有其他等待线，包括 ILS 等待线，**都不得**{.red}包含在滑行道网络中*

## 线条命名

<a id="7.2.4"></a>
<a id="724"></a>
<a id="7.2.4"></a>
<a id="724"></a>
### 7.2.4

提示

: 应用内键盘是为线条命名的最佳工具，可通过轻触 "Taxiways > Keyboard" 访问。它还会记住你最近的几次选择以便快速调用，并且在输入时默认使用大写字母



步骤 1

: 通过轻触线上或线附近来选择该线条，如果附近有多个项目，你可能需要从下拉列表中选择该线条 *(或者使用矩形选择工具 - 见上方 [2.1.6](../2.-user-interface/2.1-editor-screen.md#2.1.6))*



> 你可以通过轻触 "Edit > Selection Add" 然后选择所有想要重命名的线条，来同时重命名多条线条



提示

: 轻触 "Freeze Non Taxi Lines" 可帮助避免选中除用途类型为飞机的滑行道网络线条之外的任何内容（要再次解除冻结，请轻触 "Edit > Unfreeze All"）



步骤 2

: 使用应用内键盘，或者进入 "Properties" 选项卡后轻触 "Name" 来为该线条命名



| 类型                                         | 名称                                                         | 备注                                                         |
| -------------------------------------------- | ------------------------------------------------------------ | ------------------------------------------------------------ |
| 已命名的滑行道中心线                         | **必须**{.red}与现实中图纸上的名称完全一致（例如 A、B 等）    |                                                              |
| 未命名的滑行道中心线/停机位                   | **必须**{.red}命名为 APRON                                      | 为了避免手动输入，你可以轻触 "Taxiways > Set as Apron" 来对所有选中的线条执行此操作 |
| 等待线                                       | **必须**{.red}与其服务的跑道名称完全一致（例如 04R-22L）。如果这些等待线在现实中被赋予了不同的名称，也可以添加这些名称（例如 EGLL 的 PLUTO） | 轻触 "Taxiways > Auto Assign Holds" 可自动将所有等待线分配到最近的跑道（如果附近有多条跑道，使用此功能可能无法正确标注） |

> 只有将 “Taxiway Network Usage” 设为 “Aircraft” 的线条才会被识别。因此，任何设为 “Unknown” 或 “None” 的线条都不需要命名



提示

: 轻触 "Select Invalid Taxilines" 可显示名称无效的洋红色线条

## 滑行道方向

<a id="7.2.6"></a>
<a id="726"></a>
<a id="7.2.6"></a>
<a id="726"></a>
### 7.2.6

所有滑行道**都必须**{.red}为 "TwoWay"，除非：



- 它是一个自滑入机位（例如 EGLC）
- 如果跑道出口没有等待线
- 或者该滑行道被标记为单行道，或者有禁止进入标志（不包括方向与跑道构型相关的情况）



提示

: 正向会按节点编号顺序排列，0 为起点，依次递增到最高编号的节点（0 - 1 - 2）。反向则相反（2 - 1 - 0）。

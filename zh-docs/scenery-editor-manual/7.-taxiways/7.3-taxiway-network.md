# 7.3 滑行道网络

<a id="7.3.1"></a>
<a id="731"></a>
<a id="7.3.1"></a>
<a id="731"></a>
### 7.3.1

滑行道网络允许将 ATC 滑行指令通过所生成的路径从应用内的管制员发送给飞机。

在上传机场供审核之前，滑行道网络**必须**{.red}先构建完成

## 滑行道连接

<a id="7.3.2"></a>
<a id="732"></a>
<a id="7.3.2"></a>
<a id="732"></a>
### 7.3.2

滑行道连接是创建连续路径所必需的，用于通过滑行道网络引导飞机。它们是连接那些在物理上并未相连的滑行道的不可见线。这样系统就能识别它可被用作路径，将飞机从跑道引导至机位（反之亦然）。在以下情况下需要滑行道连接：



- 起始位置与滑行道线在物理上未连接
- 跑道穿越处没有一条直接跨越跑道的实体线（不包括“line up”线）
- 或自定位机位，在停靠后没有实体线将飞机引回滑行道
- 没有实体线将 pushback 点连接到机位或主滑行道中心线



如果这样做可以减少节点/线条数量，这些连接允许与其他线条重叠

提示

: 在创建滑行道连接时，编辑者**应当**{.red}尝试创建与现实中实际存在的滑行道线外观相似的线条，因为当你在应用内飞行时，这些线条会显示在机场地图上



<a id="7.3.3"></a>
<a id="733"></a>
<a id="7.3.3"></a>
<a id="733"></a>
### 7.3.3

以下是创建这些连接时**必须**{.red}遵循的步骤：



步骤 1

: 点击 “Taxiways > Create Connection” 



步骤 2

: 点击机场中你希望创建滑行道连接的区域，系统会放置第一个节点



步骤 3

: 继续点击以添加节点，滑行道线将会在各节点之间持续绘制



提示

: 每当你连接建筑物/线条/人行道时，**必须**{.red}使用 “Snap” 功能，以避免出现缝隙和/或重叠 *(参见上方 [2.1.4](../2.-user-interface/2.1-editor-screen.md#2.1.4))*

## 构建滑行道网络

<a id="7.3.4"></a>
<a id="734"></a>
<a id="7.3.4"></a>
<a id="734"></a>
### 7.3.4

在为所有滑行道/等待线命名、分配滑行道网络用途并绘制所有滑行道连接之后，你可以按以下说明构建滑行道网络（如果你最近更改了跑道标识符，或者添加了新的标识符，滑行道网络检查器将会失败，直到主机场数据库在某个版本发布前刚刚更新为止）：

提示

: 对于没有跑道等待线的机场，请添加临时等待线以验证滑行道网络其余部分是否正确。然后可在上传审核前将其移除



步骤 1

: 点击 “Taxiways > Build Layout”



> 如果机场很大，这个过程最多可能需要 15 分钟



步骤 2

: 然后点击 “Taxiways > Check Layout”。每个起始位置都会显示所有跑道的列表，并以颜色编码显示其是否到该跑道具有有效路径： 

| 颜色  | 含义                                                 |
| ------ | ---------------------------------------------------- |
| 红色   | 没有到跑道边缘的有效路径                             |
| 橙色   | 到等待线有有效路径，但未延伸到跑道边缘               |
| 绿色   | 到跑道边缘有有效路径                                 |



步骤 3

: 如果某条跑道显示为红色，编辑者需要重新检查路径以排查问题

> 编辑者**不得**{.red}仅通过将线条重命名为 “APRON” 或将较长的滑行道线拆分为更小的片段来修复问题（除非滑行道属性需要这样做）



步骤 4

: 一旦进行了更改，就需要重新构建布局，然后才能再次检查布局（即重复步骤 1 和 2）



步骤 5

: 通过点击 “File > Airport Properties > Taxiway Routes Available” 来确认 Airport Properties *(参见上方 [3.2.2](../3.-getting-started/3.2-airport-properties.md#3.2.2))* 中已勾选 “Taxiway Routes Available” 复选框（选中后显示橙色勾选）



> 在勾选此复选框之前，滑行道网络在飞行模式下对管制员/飞行员都不会生效

提示

: 你控制时会使用你本地保存的滑行道网络。使用 training/IFATC 服务器是排查滑行道路径问题的绝佳方式

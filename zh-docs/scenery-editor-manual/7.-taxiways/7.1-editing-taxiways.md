## 创建滑行道

<a id="7.1.1"></a>
<a id="711"></a>
<a id="7.1.1"></a>
<a id="711"></a>
### 7.1.1

步骤 1

: 点击“Taxiways”，然后点击“Create Taxiway Line” **(1)**



步骤 2

: 点击你想要绘制滑行道线的机场区域 **(2)**，第一个节点将被放置



步骤 3

: 继续点击以添加节点 **(3)**，滑行道线会在各节点之间继续绘制



![Image 7.1.1.1 - 创建滑行道](../../../_images/manual/frames/5.1.2.1.png)

提示

: 避免在登机口附近创建没有节点的长直线段，否则飞行员可能会在自动 pushback 功能上遇到问题

提示

: 使用集装箱的墙面来帮助制作 90 度转角

## 编辑现有线条

<a id="7.1.2"></a>
<a id="712"></a>
<a id="7.1.2"></a>
<a id="712"></a>
### 7.1.2

步骤 1

: 通过点击线条上或附近来选择滑行道，如果附近有多个项目，你可能需要从下拉列表中选择滑行道 *(或使用矩形选择工具 - 见上方 [2.1.6](../2.-user-interface/2.1-editor-screen.md#2.1.6))*



步骤 2

: 点击右侧的“Modify Shape”按钮 **(1)**



步骤 3

: 选中后线条会变为品红色，并显示节点



步骤 4

: 点击一个节点时，它会变为品红色 **(2)**，表示它已被选中 *(或使用矩形选择工具 - 见上方 [2.1.6](../2.-user-interface/2.1-editor-screen.md#2.1.6))*



步骤 5

: 然后你可以点击、按住并在屏幕上拖动手指，将节点移动到所需位置



步骤 6

: 编辑完成后，点击“Modify Shape”以取消选择它（不这样做将无法编辑其他滑行道） 



![Image 7.1.2.1 - 编辑滑行道](../../../_images/manual/frames/6.3.1.1b.png)

提示

: 如果一条线的节点太多，请在 Line Options 下使用 Simplify 选项

## 移动/更改滑行道方向

<a id="7.1.3"></a>
<a id="713"></a>
<a id="7.1.3"></a>
<a id="713"></a>
### 7.1.3

步骤 1

: 通过点击滑行道上或附近来选择滑行道 *(或使用矩形选择工具 - 见上方 [2.1.6](../2.-user-interface/2.1-editor-screen.md#2.1.6))*



步骤 2

: 如果附近有多个滑行道，你可能需要从下拉框中选择滑行道。滑行道的轮廓会变为品红色，以表示它已被选中 **(1)**



提示

: 如果你刚刚创建了该滑行道，那么只需点击“Modify Shape”取消选择，然后滑行道就会被选中



步骤 3

: 会出现两个圆圈以及一个罗盘玫瑰。按住圆圈 **(2)** 可移动滑行道或更改其方向：



| 圆圈 | 功能                                                     |
| ------ | ------------------------------------------------------------ |
| 中心 | 通过拖动手指到所需位置来移动滑行道 |
| 外圈  | 通过沿着你希望朝向的方向拖动手指来更改滑行道的方向 |



![Image 7.1.3.1 - 移动/更改滑行道方向](../../../_images/manual/frames/5.1.3.1.png)

## 复制与粘贴滑行道

<a id="7.1.4"></a>
<a id="714"></a>
<a id="7.1.4"></a>
<a id="714"></a>
### 7.1.4

步骤 1

: 通过点击滑行道上或附近来选择滑行道 *(或使用矩形选择工具 - 见上方 [2.1.6](../2.-user-interface/2.1-editor-screen.md#2.1.6))*

## 分割线条

<a id="7.1.6"></a>
<a id="716"></a>
<a id="7.1.6"></a>
<a id="716"></a>
### 7.1.6

每条线只能拥有一组属性，因此每当线条属性发生变化时，你都需要新建一条线。建议始终先绘制一条长线，然后使用“split”功能将这条线拆分开来（以避免手动创建大量独立线条），按以下步骤操作：



步骤 1

: 点击你想要分割的线条，然后点击屏幕右侧的“Modify Shape”



步骤 2

: 选择你想要分割的节点



步骤 3

: 点击“Split Line”



步骤 4

: 在转弯处分割线条时，必须在该线条刚开始“分离”的那个节点处进行分割



提示

: 通常最简单的方法是将线条属性设置为编号“0”处节点所对应的属性。然后你可以选择在线条的哪个位置分割，此时该节点将变成新的“0”，接着你可以更改剩余线段的属性。重复这个过程，直到整条线的属性都按需要调整完毕

## 拉直线条

<a id="7.1.7"></a>
<a id="717"></a>

### 7.1.7

如果某一段线条有多个节点需要处于完全笔直的一条线上，你可以使用拉直工具将任意线条（或线段）拉直

步骤 1

: 点击你想要拉直的线条

: 选择所有需要位于直线上的节点

步骤 3

: 点击“Line Options”

步骤 4

: 点击“Straighten”

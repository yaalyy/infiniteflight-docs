# 7.1 Taxiways 注意事项与禁忌

下表列出了在处理 taxiways 时需要编辑的内容以及不应编辑的内容


| :fa-check-circle: 应做                                         | :fa-times-circle: 不应做                                     |
| ------------------------------------------------------------ | ------------------------------------------------------------ |
| :fa-check-circle: 添加所有可见的 taxiway 线和登机口轮廓 | :fa-times-circle: 用线条添加文字                        |
| :fa-check-circle: 为停机坪添加道路                        | :fa-times-circle: 用线条填充区域（例如箭头等）   |
| :fa-check-circle: 在机位处添加 stopbars                     | :fa-times-circle: 添加阴影区                           |
| :fa-check-circle: 添加等待线，并将其分配给相应的跑道 | :fa-times-circle: 添加与 taxiway 边缘线垂直的线条 |
| :fa-check-circle: 在现实中存在灯光的 taxiway 线上添加灯光 | :fa-times-circle: 编造标记                           |
| :fa-check-circle: 根据官方文档，为线条添加正确的 aircraft categories 和 taxiway 名称 | :fa-times-circle: 为现实中没有照明的线条添加灯光（尤其是机位线上的中心线灯，除非官方文档另有说明） |
| :fa-check-circle: 仅为永久关闭的 taxiways 和跑道添加 X 标记                                                            | :fa-times-circle: 为临时关闭的 taxiways 和跑道添加 X 标记       |
| -                                                            | :fa-times-circle: 添加任何类型的“彩蛋”             |
| -                                                            | :fa-times-circle: 使用过多节点来绘制曲线             |
| -                                                            | :fa-times-circle: 通过在其他线条上叠加线条来创建新的线型             |
| -                                                            | :fa-times-circle: 逐一绘制每个单独的汽车停车位（只允许绘制每个区块的外轮廓）             |

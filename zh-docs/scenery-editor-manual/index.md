## 指南版本：25.1.1

加入场景编辑器团队并使用场景编辑器上传机场时，所有编辑者都同意 [贡献者许可协议（CLA）](https://github.com/infiniteflight/infiniteflight-localization/blob/main/CONTRIBUTING.md)。

# 9.2 属性

<a id="9.2.1"></a>
<a id="921"></a>
<a id="9.2.1"></a>
<a id="921"></a>
### 9.2.1

步骤 1

: 通过点击建筑或其附近来选择建筑部分。如果附近有多个建筑/对象，可能需要从下拉列表中选择建筑 *(或者使用矩形选择工具 - 见上方 [2.1.6](../2.-user-interface/2.1-editor-screen.md#2.1.6))*



步骤 2

: 点击屏幕右侧的“属性”选项卡 **(1)**



![Image 9.2.1.1 - Building Properties](../../../_images/manual/scenery-editor/buildings-and-facades/building-properties.png)



步骤 3

: 然后你可以调整以下属性：



| 按钮                 | 功能                                                         | 说明                                                         |
| -------------------- | ------------------------------------------------------------ | ------------------------------------------------------------ |
| 高度                 | 这里显示建筑的高度（以米为单位）。点击数字并输入新值即可调整 | Google Earth 中的“3D Path”等工具是获取准确高度的实用方法。此外，建筑之间需要保持比例协调（例如，你知道可以停放一架 777 的机库，就应赋予它足以容纳该机型的高度 - *见下方 [9.2.2](9.2-properties.md#9.2.2)*） |
| 屋顶朝向             | 点击“+/-”符号可调整屋顶朝向（也可以使用“自动屋顶纹理”按钮） | 建筑屋顶有方格图案，可使用此工具让线条与建筑边缘对齐，以获得更好的美观效果。你也可以通过点击 Building Parts > Auto Texture Orientation 使用“自动纹理朝向”按钮（这可能仍需要手动调整 - *见上方 [2.1.2](../2.-user-interface/2.1-editor-screen.md#2.1.2)*） |
| 屋顶深度             | 这里显示建筑的屋顶深度（以米为单位）。点击数字并输入 0 到 1 之间的新值即可调整 | 会添加一段高度相对屋顶其余部分偏移的屋顶区域。若使用，只应添加到建筑的顶层 |
| 屋顶类型             | 可在此选择屋顶类型                                         | “None” - 当分层时，所有建筑**必须**{.red}使用，除非它是最上层（或悬空建筑如桥梁的最下层）。“Flat” - 用于没有檐口的建筑（使用时屋顶深度**必须**{.red}设为 0）。“Flat with Ledge” - 用于有檐口的建筑（屋顶深度可在此调整） |
|关闭                  | 使用墙体将最后一个节点与第一个节点连接起来，以围合建筑部分    | 使用此选项代替添加额外节点 |
| 纬度 / 经度           | 建筑当前的纬度/经度                                        | 这**不应**{.red}被更改                                      |
| 海拔                 | 这里显示建筑当前的海拔（以米为单位）。点击数字并输入新值即可调整 | 海拔始终以建筑底部为基准。如果建筑位于你希望其叠放到的建筑顶部，也可以通过点击 Object > Auto Altitude 使用“自动海拔”*(见下方 [9.1.2](9.1-editing-buildings.md#9.1.2))*，这对分层非常完美！ |
| 名称                 | 你可以使用此字段为建筑命名                                   | 为了更方便地分层，建议为不同层级赋予合适的名称（例如“Lvl 1 Terminal 1”） |

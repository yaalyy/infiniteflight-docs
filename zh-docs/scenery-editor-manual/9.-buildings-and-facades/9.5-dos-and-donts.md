# 9.5 建筑物注意事项与禁忌


下表列出了在处理建筑物时需要编辑的内容以及不应编辑的内容

| :fa-check-circle: 应做                                         | :fa-times-circle: 不应做                                     |
| ------------------------------------------------------------ | ------------------------------------------------------------ |
| :fa-check-circle: 在机场边界内添加建筑物，包括机场围栏外、飞行员可见且有助于体现机场特色的显著建筑物 | :fa-times-circle: 使用过多分层建筑创建斜坡形状 |
| :fa-check-circle: 使用分层来创建自定义立面      | :fa-times-circle: 在机场边界外添加无关建筑物，以及飞行员看不见的建筑物 |
| :fa-check-circle: 移除那些屋顶和楼层对用户不可见的层的屋顶 | :fa-times-circle: 用多个单独建筑物（每一层一个）来建造多层停车场。请改用现有的停车场纹理 |
| :fa-check-circle: 吸附建筑物以避免缝隙或重叠 | :fa-times-circle: 添加任何类型的“彩蛋”             |
| -                                                            | :fa-times-circle: 用建筑物拼出数字/字母      |
| -                                                            | :fa-times-circle: 使用建筑部件创建打开的门/窗     |

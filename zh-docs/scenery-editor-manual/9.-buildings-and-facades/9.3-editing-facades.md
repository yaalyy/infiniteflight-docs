# 9.3 编辑立面



<a id="9.3.1"></a>
<a id="931"></a>
<a id="9.3.1"></a>
<a id="931"></a>
### 9.3.1

目前，每个建筑部分只能设置 1 个立面或“面”。要创建具有不同面的建筑，应使用分层。更多信息请参见 [9.4](9.4-layering.md)。



<a id="9.3.2"></a>
<a id="932"></a>
<a id="9.3.2"></a>
<a id="932"></a>
### 9.3.2

步骤 1

: 点击建筑本体或其附近来选中建筑（如果附近有多个项目，可能需要从下拉列表中选择该建筑）



步骤 2

: 点击右侧面板上的“Building Texturing”按钮 **(1)**


步骤 3

: 点击左下角按钮 **(2)** 以选择不同的建筑样式。必要时滚动，然后点击以查看该建筑样式中的不同立面


步骤 4

: 在屏幕右侧的列表中上下滚动 **(3)**，查看该样式可用的不同立面



步骤 5

: 选择所需的立面，然后点击“Assign” **(4)**。所选建筑部分的所有墙面都将被更改

提示

: 你可以在面板左侧 **(5)** 查看并选择当前编辑会话中使用过的先前立面。只需点击并按下分配即可

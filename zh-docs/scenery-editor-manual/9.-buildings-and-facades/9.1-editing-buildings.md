# 9.1 编辑建筑物

Infinite Flight 中的建筑物由建筑部件创建。每个部件至少由 2 个节点和一个以米为单位的高度定义
（见下文）

如果一个建筑部件包含至少 3 个节点并形成至少一个拐角，也可以添加屋顶。还可以编辑其他对象属性，例如名称、该部件是否应为封闭以及高度
（见 [9.2](9.2-properties.md)）

每个建筑部件都可以分配一种纹理
（见 [9.3](9.3-editing-facades.md)）

将多个建筑部件叠加在一起称为“分层（layering）”，可用于创建复杂的建筑物
（见 [9.4](9.4-layering.md)）



提示

: 每当你连接建筑物/线条/路面时，**必须**{.red}使用“Snap”功能，以避免出现缝隙和/或重叠 *(见上方 [2.1.4](../2.-user-interface/2.1-editor-screen.md#2.1.4))*

## 选择并放置建筑物

<a id="9.1.1"></a>
<a id="911"></a>
<a id="9.1.1"></a>
<a id="911"></a>
### 9.1.1

步骤 1

: 点击左侧管理按钮中的“Building Parts”，然后点击“Create Building Part” **(1)**



步骤 2

: 点击你希望放置建筑物的机场区域 **(2)**，将放置第一个节点



步骤 3

: 继续点击以添加节点 **(3-5)**。一旦放置了 2 个节点，就会创建一面墙；按需添加更多节点以创建更多墙面



步骤 4

: 墙面仅在一侧可见，如果墙面看起来是“内外颠倒”，你可以点击屏幕右侧的“Line Options” > “Reverse Points”，这将反转所有点的编号 

步骤 5

: 如果你需要将建筑物封闭，请打开属性选项卡并勾选“Closed”复选框。此时会出现一面连接最后一个节点与第一个节点的墙。有关高度和屋顶类型等其他属性，请参见 [9.2](9.2-properties.md)


![Image 9.1.1.1 - Creating a Building](../../../_images/manual/scenery-editor/buildings-and-facades/editing-buildings-creating.png)

提示

: 使用角度吸附可获得完美角度（右侧菜单 > Snap > Angle Snapping On/Off）。角度吸附会以 5 度为增量进行吸附

## 编辑现有建筑物形状

<a id="9.1.2"></a>
<a id="912"></a>
<a id="9.1.2"></a>
<a id="912"></a>
### 9.1.2

步骤 1

: 点击建筑物上或附近来选择该建筑物；如果附近有多个对象，你可能需要从下拉列表中选择该建筑物 *(或者使用矩形选择工具 - 见上方 [2.1.6](../2.-user-interface/2.1-editor-screen.md#2.1.6))* 

步骤 2

: 选中后，墙体轮廓会变为红色

步骤 3

: 点击右侧的“Modify Shape”按钮 **(1)**。组成该建筑部件的节点将会显示出来


步骤 4

: 点击一个节点后，它会变为洋红色 **(2)**，表示它已被选中 *(或者使用矩形选择工具 - 见上方 [2.1.6](../2.-user-interface/2.1-editor-screen.md#2.1.6))* 



步骤 5

: 然后你可以点击、按住并在屏幕上拖动手指，将节点移动到所需位置



提示

: 当你在机场周围移动时，如果注意到建筑物出现渲染问题（例如“抖动”现象），说明建筑物被重复创建了，需要选中其中一个并删除以修复



步骤 6

: 编辑完成后，点击“Modify Shape”将其取消选中（否则你将无法编辑其他建筑物） 


![Image 9.1.2.1 - Editing Buildings](../../../_images/manual/scenery-editor/buildings-and-facades/editing-buildings-editing.png)

## 移动建筑物

<a id="9.1.3"></a>
<a id="913"></a>
<a id="9.1.3"></a>
<a id="913"></a>
### 9.1.3

步骤 1

: 点击建筑物上或附近来选择该建筑物；如果附近有多个对象，你可能需要从下拉列表中选择该建筑物 *(或者使用矩形选择工具 - 见上方 [2.1.6](../2.-user-interface/2.1-editor-screen.md#2.1.6))* 



提示

: 如果你刚刚创建了这个建筑部件，只需点击“Modify Shape”取消选择，此时该建筑部件将被选中



步骤 2

: 会出现三个圆圈以及一个罗盘玫瑰。按住圆圈 **(1)** 可移动建筑物或更改高度/朝向：



| 圆圈                           | 功能                                                         |
| ------------------------------ | ------------------------------------------------------------ |
| 中心                           | 通过拖动手指到所需位置来移动建筑物 |
| 上方（刚好在中心圆圈之上）     | 调整建筑物的高程或海拔        |
| 外圈                           | 通过将手指朝你希望朝向的方向拖动来改变建筑物的朝向 |


![Image 9.1.3.1 - Changing Building Orientation](../../../_images/manual/scenery-editor/buildings-and-facades/editing-buildings-moving.png)

<a id="9.1.4"></a>

<a id="9.1.4"></a>

### 9.1.4

: 点击建筑物上或附近来选择该建筑物；如果附近有多个对象，你可能需要从下拉列表中选择该建筑物 *(或者使用矩形选择工具 - 见上方 [2.1.6](../2.-user-interface/2.1-editor-screen.md#2.1.6))*

## 为建筑物放置下载 OSM

提示

: 如果使用 OSM，下载后它会自动放置建筑物 *(见上方 [3.1.4](../3.-getting-started/3.1-first-steps.md#3.1.4))*，不过你可能会发现它们与路面并不完全对齐，因此需要移动



<a id="9.1.6"></a>
<a id="916"></a>
<a id="9.1.6"></a>
<a id="916"></a>
### 9.1.6

也可以按照以下步骤使用 Open Street Map (OSM) 自动导入建筑物。添加后，它们可以像手动添加的建筑物一样进行编辑：



步骤 1

: 点击“File” **(1)**，然后点击“Download OSM” **(2)** 下载 OSM 数据


![Image 9.1.6.1 - Downloading OSM](../../../_images/manual/frames/6.1.5.1a.png)



提示

: 如果你之前已经下载过 OSM，但之后又误删了一些建筑物（并且这些更改已保存），那么使用“Download OSM at Cursor”可能更合适。此选项只会下载地图光标周围 200m 范围内的数据，并有助于避免重复下载建筑物（这可能是由于使用“Download OSM”按钮所导致的）



步骤 2

: 删除机场边界之外的所有建筑物 *(见上方 [9.1.5](9.1-editing-buildings.md#9.1.5))* 



提示

: 记得定期保存并上传你的工作。你可以点击“File > Save”来保存，然后通过点击“File > File Manager > Upload [as Draft/for Review]”来上传你的工作 *(见上方 [2.1.2](../2.-user-interface/2.1-editor-screen.md#2.1.2))*

# 12.2 编辑检查清单

提示

: 如果在机场完成前需要帮助或指导，编辑**应**{.red}使用 Discord 的 *#help* 频道，针对其机场提出具体问题

<a id="1221"></a>
<a id="12.2.1"></a>

### 12.2.1

以下是一份清单，编辑**应**{.red}在将机场标记为已完成并准备审核之前，确保其内容已全部完成：

## 机场设备

<a id="12.2.4"></a>
<a id="1224"></a>
<a id="12.2.4"></a>
<a id="1224"></a>
### 12.2.4

- [ ] 已在 IRL 位置添加机场信标塔（如适用）
- [ ] 已将信标灯添加到与机场信标/ATC 塔相同的位置（如适用）

- [ ] 如果 IRL 中存在 VOR，则已将其添加到 3D 机场中（利用可用影像和机场图表）
- [ ] VOR 的尺寸正确反映了机场 IRL 中的情况，即 VOR（小型）或 VOR 已放置在机场边界内

- [ ] 所有适用的跑道交叉口都已提供跑道警戒灯（如适用）
- [ ] 跑道警戒灯的朝向应符合其 IRL 状况，要么沿直线滑行中心线，要么沿曲线中心线，以便 PIC 可见

- [ ] 已在 IRL 位置添加 localizers，并设置为正确朝向（即箱体朝离跑道端点的方向）
- [ ] 已在 IRL 位置添加 Slope Antennas，并按跑道航向定向

- [ ] 风向袋已尽可能与 IRL 影像和机场图表数据保持一致（如有）
- [ ] ATC 塔已放置在 IRL 位置，并设置了正确的高度
- [ ] 塔台视角点已放置在 ATC 塔机舱内

## 铺装

<a id="12.2.5"></a>
<a id="1225"></a>
<a id="12.2.5"></a>
<a id="1225"></a>
### 12.2.5

- [ ] 所有 IRL 中存在的铺装都已添加

- [ ] 所有铺装都具有与 IRL 相同的表面类型

  > 除非其为不同的表面类型（基于现实来源），否则所有机库**必须**{.red}在机库下方添加混凝土铺装

- [ ] 所有铺装都已无缝对齐且没有间隙

- [ ] 铺装补片已添加在周围铺装之上（即下方没有创建洞）

  > 如果存在更高效的性能方案（即创建更少的节点），则这是可以接受的（由审核者酌情决定）。例如，将铺装补片吸附到铺装边缘而不是放在其上方，或允许下方创建洞

- [ ] 草地表面类型仅用于草地滑行道（例如，不用于航站楼外的草地区域）

## 滑行道

<a id="12.2.6"></a>
<a id="1226"></a>
<a id="12.2.6"></a>
<a id="1226"></a>
### 12.2.6

- [ ] 所有 IRL 中存在的滑行道线都已添加
  - [ ] 中心线
  - [ ] 等候线
  - [ ] 边线
  - [ ] 道路和登机口轮廓线
  
- [ ] 所有滑行道线都已按 IRL 设置为正确的线型

- [ ] 所有滑行道线都已按 IRL 设置为正确的灯光类型

  > 除非在可用的机场文档中明确说明，否则不要在机位线中添加中心线灯 

- [ ] 所有滑行道线都已吸附

- [ ] 所有滑行道中心线和等候线都已命名

- [ ] 只有滑行道中心线和等候线的 taxiway network usage type 设置为 aircraft

- [ ] 所有其他线的 taxiway network usage type 都设置为 none

- [ ] 所有滑行道中心线的 aircraft category 都设置为可使用该滑行道的最大机型类别

- [ ] 所有滑行道中心线的 directions 都已正确设置

- [ ] 已放置所有滑行道连接器（如需要）

- [ ] 滑行道网络已构建并检查

- [ ] 通过点击 "File > Airport Properties > Taxiway Routes Available" 勾选 "Taxiway Routes Available" 复选框（选中后显示橙色勾）

## 建筑和立面

<a id="12.2.8"></a>
<a id="1228"></a>
<a id="12.2.8"></a>
<a id="1228"></a>
### 12.2.8

- [ ] 建筑已按其 IRL 位置添加

- [ ] 建筑高度和屋顶深度看起来合理 

- [ ] 建筑与 2D Pavements 对齐

- [ ] 建筑分层是对称的，并且角点在所有交汇处都已准确放置

  > 任何不是顶层或悬空建筑（如桥梁）最底层的层级，其屋顶类型都应设置为 "none"

- [ ] 屋顶朝向已自动协调

- [ ] 立面已尽可能与 IRL 保持一致

- [ ] 屋顶设备，如空调、冷却塔、梯子和猫道，已按其 IRL 位置摆放

- [ ] 如果使用了 "Download OSM" 和 "Download OSM at Cursor"，则重复建筑已被移除

## 机场登机口

<a id="12.2.10"></a>
<a id="12210"></a>
<a id="12.2.10"></a>
<a id="12210"></a>
### 12.2.10

- [ ] 已为所有 IRL 中有引导标识的机位添加停靠引导
- [ ] 检查所有登机桥是否已分配给机位
- [ ] 确保登机桥高度已设置为能够根据机位生成尺寸容纳飞机
- [ ] 验证登机桥只分配给它应服务的机位（即未分配给航站楼另一侧的机位）
- [ ] 通过调整高度、伸出长度和旋转，登机桥应处于“收起”状态的摆放方式
- [ ] 确保登机桥覆盖范围（绿色弧线）覆盖机位以及所有可用飞机的全部舱门（部分覆盖不可接受 - 如有需要请使用 "Rotate Range +90" 按钮）
- [ ] 通过点击 "File > Airport Properties > Jet Bridges Available" 勾选 "Jet Bridges Available" 复选框（选中后显示橙色勾）

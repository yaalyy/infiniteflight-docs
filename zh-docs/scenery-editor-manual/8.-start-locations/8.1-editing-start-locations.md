## 如何查看飞机起始位置

<a id="8.1.1"></a>
<a id="811"></a>
<a id="8.1.1"></a>
<a id="811"></a>
### 8.1.1

在飞机起始位置附近放置对象之前，建议按照以下步骤开启飞机起始位置：



步骤 1

: 在屏幕左侧，点击“View”



步骤 2

: 然后点击“Start Locations”（其颜色会变为琥珀色，表示已被选中）



步骤 3

: 每个起始位置都会以一个蓝点表示。放大到某个起始位置后，你可以看到该起始位置的详细信息，包括：

- 标识符（即航站楼和机位编号）
- 类型（即 Gate、Tie-down、Misc 或 Hangar）
- 机位尺寸（即最大飞机类别）
- 坡位运行类型（即 GA、Airline、Cargo 或 Military）

## 选择并放置起始位置

<a id="8.1.2"></a>
<a id="812"></a>
<a id="8.1.2"></a>
<a id="812"></a>
### 8.1.2

步骤 1

: 向上/向下滚动屏幕右侧的列表以查看对象仓库（**必须**{.red} 选中“Library”标签）



步骤 2

: 通过点击来选择“Airport Items”下的“Start Location” **(1)**



步骤 3

: 点击你想添加起始位置的机场区域（可能需要按住不放），这会放置一个白色光标 **(2)**。按需调整后，点击“Add Object” **(3)**



提示

: 你可能需要“冻结”线条和铺装，以避免在屏幕上点击时选中它们。为此，请点击“Edit > Freeze All Lines / Freeze All Pavements”

## 更改起始位置的坐标/朝向

<a id="8.1.3"></a>
<a id="813"></a>
<a id="8.1.3"></a>
<a id="813"></a>
### 8.1.3

起始位置的蓝色圆圈是飞机生成时机头轮的默认位置，按照以下步骤调整起始位置的坐标和朝向，使其与现实中一致：



> 起始位置的朝向**必须**{.red}与停机位中心线的朝向完全一致



步骤 1

: 点击蓝色圆圈上或附近的位置来选择起始位置 *(或者使用矩形选择工具 - 见上方 [2.1.6](../2.-user-interface/2.1-editor-screen.md#2.1.6))*



步骤 2

: 圆圈会变成品红色，表示已被选中。如果附近有多个对象，会出现一个列表，供你选择想要的对象



步骤 3

: 将会出现两个圆圈以及一个罗盘玫瑰。按住圆圈 **(1)** 可移动起始位置或更改朝向：



| 圆圈 | 功能                                                     |
| ---- | ------------------------------------------------------------ |
| 中心 | 通过将手指拖到目标位置来移动起始位置 |
| 外圈 | 通过朝你希望的方向拖动手指来更改起始位置的朝向 |



![Image 8.1.3.1 - Changing Start Location Orientation](../../../_images/manual/frames/7.1.3.1a.png)

## 复制并粘贴起始位置

<a id="8.1.4"></a>
<a id="814"></a>
<a id="8.1.4"></a>
<a id="814"></a>
### 8.1.4

步骤 1

: 点击蓝色圆圈上或附近的位置来选择起始位置 **(1)** *(或者使用矩形选择工具 - 见上方 [2.1.6](../2.-user-interface/2.1-editor-screen.md#2.1.6))*



步骤 2

: 圆圈会变成品红色，表示已被选中。如果附近有多个对象，会出现一个列表，供你选择想要的起始位置



步骤 3

: 点击屏幕左侧的“Edit”按钮 **(2)**，然后点击“Copy”按钮 **(3)**



步骤 4

: 点击你想把复制的起始位置添加到的机场区域（可能需要按住不放），这会放置一个白色光标 **(4)**。按需调整后，点击“Paste” **(5)**



提示

: 你可能需要“冻结”线条和铺装，以避免在屏幕上点击时选中它们。为此，请点击“Edit > Freeze All Lines / Freeze All Pavements”



![Image 8.1.4.1 - Copy & Pasting a Start Location](../../../_images/manual/frames/7.1.4.1a.png)

## 删除起始位置

<a id="8.1.5"></a>
<a id="815"></a>
<a id="8.1.5"></a>
<a id="815"></a>
### 8.1.5

步骤 1

: 点击蓝色圆圈上或附近的位置来选择起始位置 *(或者使用矩形选择工具 - 见上方 [2.1.6](../2.-user-interface/2.1-editor-screen.md#2.1.6))*



步骤 2

: 圆圈会变成品红色，表示已被选中。如果附近有多个对象，会出现一个列表，供你选择想要的起始位置



步骤 3

: 点击屏幕右侧的“Delete Selection”按钮 **(1)**

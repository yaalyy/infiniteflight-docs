# 8.2 属性



<a id="8.2.1"></a>
<a id="821"></a>
<a id="8.2.1"></a>
<a id="821"></a>
### 8.2.1

步骤 1

: 通过点按起始位置本身或其附近来选择它 *(或使用矩形选择工具 - 见上方 [2.1.6](../2.-user-interface/2.1-editor-screen.md#2.1.6))*



步骤 2

: 如果附近有多个项目，您可能需要从下拉框中选择起始位置。起始位置的轮廓会变为品红色，表示它已被选中 **(1)**



步骤 3

: 点按屏幕右侧的 "Properties" 选项卡 **(2)**



![Image 8.2.1.1 - Start Location Properties](../../../_images/manual/frames/7.2.1.1a.png)



步骤 4

: 然后您可以调整起始位置的以下属性：

| 按钮               | 功能                                                     | 备注                                                         |
| ------------------ | ------------------------------------------------------------ | ------------------------------------------------------------ |
| Terminal           | 您可以使用此字段为航站楼命名                   | 这**必须**{.red}是生成点所在大区域的名称（例如 Terminal/Concourse/GA/Cargo/Apron/FBO 等） |
| Ramp Size          | 使用此设置可确定该机位可生成并停放的飞机类别最大尺寸 | 见上方 [1.3](../1.-introduction/1.3-aircraft-categories.md) |
| Ramp Start Type    | 指明此起始位置是 Gate、Tie-Down、Hangar 还是 Misc | 不适用                                                       |
| Ramp Operation Type | 指明起始位置的主要运营用途   | 不适用                                                       |
| Equipment Type     | 不适用                                                       | 目前不需要                                                   |
| Gate Stops         | 同一起始位置上不同机型的登机口停靠点 | 见下方 [8.2.2](8.2-properties.md#8.2.2) |
| Stand Guidance     | 不适用                                                       | 该内容会在应用以飞行模式启动时自动加载                         |
| Latitude / Longitude | 起始位置当前的纬度/经度             | 可更改以精确放置起始位置（例如使用图表中的坐标）               |
| Altitude           | 这会显示起始位置当前的高度（以米为单位） | **不应**{.red}更改                                           |
| Name               | 您可以使用此字段为机位命名                       | 建议使用类似 "Gate/Stand [字母数字/数字]" 的格式 - 编辑者**必须**确保航站楼名称（例如 T1）不包含在 "Name" 属性中 |

## 登机口停靠点

<a id="8.2.2"></a>
<a id="822"></a>
<a id="8.2.2"></a>
<a id="822"></a>
### 8.2.2

要添加/删除或编辑登机口停靠点，**必须**{.red}遵循以下步骤：



步骤 1

: 点按 "Gate Stops" 旁边的 "+" 符号 **(1)**



步骤 2

: 当前为该起始位置列出的所有登机口停靠点都会显示在下方，如果没有则为空白。点按右侧下方的 "+" 符号以添加更多 **(2)**



步骤 3

: 会出现一行 "No Types Specified"。其左侧会有一个 "+" 符号 **(3)**，点按它可展开该登机口停靠点，以便设置机型和偏移量



![Image 8.2.2.1 - Adding Gate Stops](../../../_images/manual/frames/5.3.4.1.png)



步骤 4

: 同样的符号随后会变为 "-" 符号 **(4)**，再次点按可隐藏这些展开信息



步骤 5

: 当每个登机口停靠点的列表展开后，点按 "Aircraft Type" **(5)** 可添加机型，随后会出现一个列表供您添加



步骤 6

: 点按 "Offset" **(6)** 可为该登机口停靠点添加以米为单位的偏移量，这将是从起始位置到您希望某些机型停止的位置的距离



步骤 7

: 然后您会看到新的登机口停靠点出现，并显示适用的机型

步骤 8
: 在添加任何其他登机口停靠点后，再添加一个 0m 偏移量、且未指定类型的登机口停靠点。起始位置上应显示 "Any"（否则该机位的廊桥将无法正常工作）



提示

: 如果多个机型具有相同的偏移量，请将这些机型都添加到同一个停靠点，而不是创建多个停靠点

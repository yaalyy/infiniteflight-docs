### 4.1.1

卫星影像用于帮助编辑器创建准确的机场。推荐使用 SASPlanet，因为它能够从不同来源导出正射影像，例如来自 Google、Bing 或 Yandex 地图的不同质量影像。下载的文件将以 zip 压缩包形式提供，可使用 Windows 资源管理器解压。该程序的下载链接如下：



> SASPlanet 仅可用于 Windows 和 Linux。MacOS 用户需要向其他编辑器请求正射影像



| 程序                                                         | 目的              |
| ------------------------------------------------------------ | ----------------- |
| [SASPlanet](https://gisenglish.geojamal.com/2018/06/download-sas-planet-nightly-all.html) | 卫星影像          |



提示

: 卫星影像可能会发生畸变，在编辑时牢记这一点非常重要。直线可能看起来弯曲，在这些情况下应使用你的最佳判断，以避免不真实的弯折或曲线

## 缩放级别

<a id="4.1.3"></a>
<a id="413"></a>
<a id="4.1.3"></a>
<a id="413"></a>
### 4.1.3

可用的缩放级别如下：

| 缩放级别 (z) | 质量       | 备注                                                         |
| ------------- | ---------- | ------------------------------------------------------------ |
| z22           | 商业级     | 仅限商业用途，不可用                                          |
| z21           | 高         | 从公开来源中可获得的最高质量                                 |
| z20           | 良好       | 有可用时应始终使用 z20 或更高版本 **应**{.red}                |
| z19           | 一般       | 如果没有更高质量的影像，可能已经足够                         |
| z18 或更低   | 较差       | **不应**{.red} 使用 z18 或更低                              |



<a id="4.1.4"></a>
<a id="414"></a>
<a id="4.1.4"></a>
<a id="414"></a>
### 4.1.4

要判断所需缩放级别是否可用：



步骤 1

: 点击 “Cached tiles map” 图标（它是从屏幕左侧数起第 5 个图标，显示为银黑色圆圈），然后勾选相应的缩放级别



步骤 2

: 如果瓦片清晰，则说明该缩放级别可用。否则，它们将显示为灰色



提示

: 你可以检查不同的卫星影像来源，以找到最新或质量最好的影像。不过，施工区域、过时影像以及较低的影像质量都可能使编辑变得相当困难，尤其是对新编辑器而言。如果你想编辑的机场影像质量较低，和/或存在大量妨碍编辑的施工区域，建议将该机场推迟到以后，等到有更新或更高质量的影像可用时再进行编辑

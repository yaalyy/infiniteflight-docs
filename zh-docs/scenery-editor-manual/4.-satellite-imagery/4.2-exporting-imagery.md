# 4.2 导出图像



<a id="4.2.1"></a>
<a id="421"></a>
<a id="4.2.1"></a>
<a id="421"></a>
### 4.2.1

步骤 1

: 下载 SASPlanet 后，打开该程序



步骤 2

: 使用缩放放大/缩小功能以及鼠标左键，导航到你想要获取卫星图像的区域



步骤 3

: 选择“Maps”，然后选择你想要使用的地图



提示

: 尽可能选择最佳/最新的来源非常重要。将图像与最新航图进行对比会很有帮助，这样你就能知道哪张卫星图像更新（如果不同来源之间的布局不同）。如果你很熟悉该机场，或者知道某个区域正在施工，你也可以寻找能显示这些细节的来源，以帮助你做出选择 



步骤 4

: 在“Selection Manager”按钮中选择“Polygonal Selection”（这是从左数第二个图标，图标表现为一块地图被一系列蓝线包围）。你也可以通过进入“Operations > Selection Manager > Polygonal Selection”来完成此操作



步骤 5

: 你可以使用缩放放大/缩小功能以及鼠标右键在屏幕上移动。每次左键单击都会放置一个新节点（在选择管理器被选中时，地图上会出现一个弹出窗口，这允许你在需要时删除之前的节点）



步骤 6

: 在你想要导出的地图区域周围放置节点。最好的方式是沿着机场边界放置，但要额外留出一定边距（对角线会由于瓦片的关系产生锯齿状边缘，因此太贴近边界会导致机场边界内的区域无法被完整包含在图像中）



步骤 7

: 当你放置完所有节点后，点击弹出窗口中的绿色勾号



步骤 8

: 将出现“Selection Manager”弹出窗口，选择缩放级别或级别 *(见上方的 [4.1.3](4.1-satellite.md#4.1.3) 和 [4.1.4](4.1-satellite.md#4.1.4))*



步骤 9

: 在选择管理器弹出窗口中点击“Start”，随后会出现另一个弹出窗口显示下载进度



步骤 10

: 完成后，会出现另一个弹出窗口，显示“The task is completed!”。现在你可以点击“Quit”



步骤 11

: 进入“Operations > Selection Manager > Last Selection”。选择管理器弹出窗口会再次出现，选择顶部的“Stitch”选项卡



步骤 12

: 在点击“Start”之前，**必须**{.red} 填写以下输入项：



| 窗口                       | 输入                                                         |
| -------------------------- | ------------------------------------------------------------ |
| Output Format              | JPEG*                                                        |
| Save To                    | 选择你想要的输出文件夹                                       |
| Map                        | 与用于下载图像的来源相同                                       |
| Zoom                       | 与用于下载图像的缩放相同                                       |
| Projection                 | 推荐使用 “Geographic (Latitude/Longitude) / WGS84 / EPSG: 4326” |
| Quality                    | 选择 50% - 如果文件需要更小，可以考虑使用更低的缩放级别，例如用 z20 代替 z21 |
| Create Georeferencing file | 勾选“.kml”                                                    |
| Split Image                | 分割图像可以让它在导入 Infinite Flight 时更易于管理，并提升性能 *(见下方 [4.2.2](4.2-exporting-imagery.md#4.2.2))* |

**JPEG 和 PNG 在质量上没有区别，不过 JPEG 使用压缩，因此可节省文件大小并提升性能***



> 50% 的质量与 100% 几乎完全相同，但文件大小大约小了 8 倍（例如，100% 图像质量、450MB 大小的文件，所提供的质量与 50% 图像质量、仅 70MB 的文件相同）。不过，文件更小并不意味着可以选择更大的区域。这是因为在加载时，文件会被转换为 BMP（bitmap）格式，这意味着在应用内它们会被转换为相同数量的数据（在上面的例子中，70MB 或 450MB 的文件在转换后都会变成 2.6GB 的数据）



步骤 13

: 完成后，前往该文件夹并删除任何白色瓦片图像，因为它们占用空间且并非必需



> 需要记住的是，限制设备的不是导入时的文件大小，而是它在应用内转换后的大小。虽然一个图像质量设置为 95% 的 213MB 文件可能可以使用，但一个图像质量设置为 50% 的 80MB 文件可能会超过最大文件大小限制。此外，zip 文件中有多少部分白色瓦片也很重要。作为 JPG 文件时，这些文件比其他瓦片小得多（使 zip 文件更小），但作为 BMP 文件时，它们与其他瓦片完全相同大小。因此，删除空白（白色）瓦片非常重要。



步骤 14

: 选择所有剩余文件，右键单击并选择压缩为“.zip”的选项。**确保你选择并压缩的是输出文件夹 *内部* 的文件，而不是输出文件夹本身** - 否则，这些图像 **将不会**{.red} 在 Infinite Flight 中打开



提示

: 你需要将一组图像保持在 400MB 以下，如果出现这种情况，你可能需要进一步拆分，不过这种情况很少见。如果使用 z20，那么这应该永远不会发生



步骤 15

: .zip 文件夹会出现在你发送到的文件夹中，然后你可以通过电子邮件或云服务（例如 Google Drive）将其发送到你的设备

## 分割图像

<a id="4.2.2"></a>
<a id="422"></a>
<a id="4.2.2"></a>
<a id="422"></a>
### 4.2.2

在查看“Selection Manager”弹出窗口中的“Stitch”选项卡时，卫星图像所在的瓦片会显示出来。通过分割图像，可以让它在导入 Infinite Flight 时更易于管理，并提升性能。为此，请按照以下步骤操作：



步骤 1

: 查看“Stitch”选项卡中“Number of Tiles”显示的瓦片数量



步骤 2

: 将第一个数字除以 100，然后再乘以 15。将这个数字向上取整，并在“Split Image”下、“Horizontally”窗口旁边输入该数值



步骤 3

: 对第二个数字（即 x 后面的数字）使用相同的方法，但将其输入到“Vertically”窗口旁边



**示例：**

- 显示的瓦片数量为 60 x 66

- 60 / 100 x 15 = 9

- 66 / 100 x 15 = 9.9（向上取整后为 10）

- 在“Horizontally”窗口中输入 9，在“Vertically”窗口中输入 10

# 4.3 导入影像



<a id="4.3.1"></a>
<a id="431"></a>
<a id="4.3.1"></a>
<a id="431"></a>
### 4.3.1

步骤 1

: 从屏幕左侧的管理按钮中点击“Satellite”



步骤 2

: 点击“Import Imagery”



步骤 3

: 将会出现一个窗口，允许你在设备中浏览以找到你想导入的文件



提示

: 影像导入可能需要一些时间（甚至几分钟），这是正常的。在导入进行中时，无法执行任何其他操作

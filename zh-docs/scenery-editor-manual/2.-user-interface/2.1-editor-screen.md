# 2.1 编辑器屏幕



<a id="2.1.1"></a>
<a id="211"></a>
<a id="2.1.1"></a>
<a id="211"></a>
### 2.1.1

![图像 2.1.1.1 - 场景编辑器屏幕](../../../_images/manual/scenery-editor/user-interface/editor-screen.png)



1. 管理按钮可让你管理文件、编辑最近操作、更改视图、调整对象高度，并添加/更改铺装、滑行道、建筑以及导入卫星影像 *(见下方 [2.1.2](2.1-editor-screen.md#2.1.2))*。

   

2. “最后保存”信息仅会显示当前编辑会话的内容。如果开始新的编辑会话，即使你仍留在应用内，它也会将底部栏上的“Last Saved”重置为“N/A”，直到该会话被保存为止。

   

3. 主导航栏包含对象库、属性和已加载条目 *(见下方 [2.1.3](2.1-editor-screen.md#2.1.3))*。

   

4. 编辑按钮可让你移动、复制和粘贴、编辑或删除所选建筑、对象和滑行道 *(见下方 [2.1.4](2.1-editor-screen.md#2.1.4))*。

   

5. 可在此更改当前使用的相机 *(见下方 [2.1.5](2.1-editor-screen.md#2.1.5))*。

   

6. 可在此更改时间、结束当前会话并调整设置（有关设置的更多信息可参见 [Getting Started Guide](https://infiniteflight.com/guide/getting-started-guide/home-user-interface/settings)）。

### 2.1.2

+++ 文件

| 按钮 | 功能 |
| ----------------------- | ------------------------------------------------------------ |
| Save Selected as Bundle | 选择一组建筑和/或对象，然后点按此按钮，可将它们保存为一个捆绑包，以便将来使用，从而加快编辑速度 |
| Share Selected Bundle   | 当从库中选中一个捆绑包时，可使用此按钮与其他编辑者共享 |
| Download OSM            | 点按此按钮后，将下载 OpenStreetMap 数据，通常可提供机场边界内（及其附近）的大多数建筑 |
| Download OSM at Cursor  | 如果建筑缺失，或者你不小心删除了某些建筑，可使用此按钮在光标位置下载 OSM 数据（大致范围为 200 米） |
| Scenery Stats           | 这会显示当前放置对象的关键统计信息，包括多边形数量。它还包含“Scenery Checker”，可确保你的机场符合已设定的限制（即性能限制、边界外的对象、命名问题/登机口重复等 - *见下方 [12.1.2](../12.-review-and-release/12.1-review-and-release-process.md#11.1.2)*） |
| Save                    | 将最新更改本地保存到你的设备。*注意：自动保存功能会每分钟自动保存一次，以确保工作不会丢失* |
| File Manager            | 这会显示其最后一次在本地修改的时间，以及上传、恢复备份和导出的选项 *(见下表)*。*注意：机场只有在显示“upload complete”时才会上传到服务器。从服务器下载某个版本会覆盖你本地设备上的版本* |
| Airport Properties      | 可更改机场的一般信息，包括 ICAO 代码、海拔、名称、机场等级和频率 |



**文件管理器：**

如果这是一个新机场，在首次上传后你会被分配该机场，以确保没有其他人能覆盖你在该机场的工作。

| 文件管理器 | 功能 |
| --------------------- | ------------------------------------------------------------ |
| Local                 | 最后一次在本地（你的设备上）修改 |
| Online                | 如果已有更改，这会表示本地更改已准备好上传 |
| Upload as Draft*      | 这会将你的工作在线保存（建议定期这样做，以便在应用出现问题导致你丢失最近编辑时，仍有一份在线副本）- 这对于同行审查也是必需的，因为其他编辑者之后就能看到你目前为止的工作 |
| Upload for Review*    | 当你的机场完成后，你可以提交正式审核 |
| Revert to last Upload | 如果你想回到上一次上传，这会撤销所做的任何工作 |
| Backups               | 可以点按某个备份来选中它（会变为琥珀色以表示已选中），然后再点按“Restore” |
| Restore               | 会恢复为备份列表中选定的上一版本 |
| Delete All Local      | 文件会按间隔自动保存，但这可能会累积并产生过多本地文件。此按钮会清除缓存 |
| Export                | 这会将文件从场景编辑器导出到你选择的位置，例如 Google Drive（非必需） |
| Close                 | 关闭文件管理器                                      |



**当上传最近编辑过的机场的新版本时（即点按“Upload as Draft”或“Upload for Review”），编辑者需要提交一份“changelog”，以突出显示该版本中发生了哪些更改。变更日志**必须**{.red}具体明确，以确保清楚知道改动了什么（例如：“调整了 C19 廊桥。更改了 Taxiway A 上的滑行道线类型”）。如有需要，可在 IFC 机场帖子中添加更多细节 *(见下方 [12.1](../12.-review-and-release/12.1-review-and-release-process.md))*。**

+++ 编辑

| 按钮 | 功能 |
| -------------------- | ------------------------------------------------------------ |
| Undo                 | 撤销你最近的一次编辑 |
| Redo                 | 重做上一次“撤销”的编辑 |
| Copy                 | 复制当前选区 |
| Paste                | 粘贴最近复制的选区 |
| Selection (Add)      | 创建由多个对象组成的选区，以便将它们作为一个组移动或编辑。启用“Selection (Add)”时，你点按或使用“矩形选择工具”选中的所有对象都会被加入选区 |
| Selection (Remove)   | 在“Selection (Remove)”启用时，通过点按或使用“矩形选择工具”选中的对象会从现有选区中移除 |
| Freeze Selected      | 冻结所选项目，使其无法移动或调整属性 |
| Freeze All Lines     | 冻结所有线条，使其无法移动或调整属性 |
| Freeze All Pavements | 冻结所有铺装，使其无法移动或调整属性（尤其适用于完成后不想意外移动/编辑的大面积铺装区域） |
| Freeze All Buildings Objects | 冻结所有建筑和对象，使其无法移动或调整属性 |
| Unfreeze All         | 解冻所有建筑、铺装、滑行道和/或对象，并允许移动它们及调整其属性 |

+++ 视图

| 按钮 | 功能 |
| -------------------- | ------------------------------------------------------------ |
| Buildings            | 当显示为“白色”时，建筑处于取消选中状态且不显示。当显示为“琥珀色”时，建筑处于选中状态并显示 |
| Models               | 当显示为“白色”时，对象处于取消选中状态且不显示。当显示为“琥珀色”时，对象处于选中状态并显示 |
| Taxiway Lines        | 当显示为“白色”时，滑行道线处于取消选中状态且不显示。当显示为“琥珀色”时，滑行道线处于选中状态并显示 |
| Pavements            | 当显示为“琥珀色”时，铺装处于选中状态并显示。再次点按后，文本会变为“Pavement Outlines”，此时只会显示铺装轮廓。再点按一次，文本会改回“Pavements”，颜色变为“白色”，这会取消选中它们并且不再显示 |
| Runways              | 当显示为“白色”时，跑道处于取消选中状态且不显示。当显示为“琥珀色”时，跑道处于选中状态并显示 |
| Taxiway Network      | 当显示为“白色”时，滑行道网络处于取消选中状态且不显示。当显示为“琥珀色”时，滑行道网络处于选中状态并显示（仅在通过“Build Taxiway Layout”构建后才可用） |
| Start Locations      | 当显示为“琥珀色”时，显示所有飞机可在应用内生成的位置。当显示为“白色”时，这些位置处于取消选中状态且不显示 |
| Satellite Background | 当显示为“白色”时，卫星背景处于取消选中状态且不显示。当显示为“琥珀色”时，卫星背景处于选中状态并显示 |
| Focus on Selected    | 点按后会将相机聚焦到所选项目 |
| Hide/Show Panel      | 隐藏或显示右侧面板 |

+++ 对象

| 按钮 | 功能 |
| ----------------- | ------------------------------------------------------------ |
| Auto Altitude     | 自动调整所选建筑和/或对象的高度，使其位于当前所处建筑之上（如果建筑/对象之前设置得更高或更低，而周围又没有其他物体，则会调整到地面高度） |
| Create Runway     | 在需要时可用于创建新跑道 - *见下方 [5.1](guide/scenery-editor-manual/5.-runways/5.1-editing-runways#5.1.1)* |
| Create Model Line | 点按此按钮后，点按你希望围栏第一条边出现的区域。每次点按都会创建一个新点，每个点会自动连接，从而形成一系列围栏（此工具目前仅适用于围栏及类似对象 - *见下方 [10.5](../10.-objects/10.5-model-lines.md)*） |

+++



+++ 铺装

| 按钮 | 功能 |
| --------------- | ------------------------------------------------------------ |
| Create Pavement | 点按此按钮后，点按你希望铺装第一条边出现的区域。每次点按都会创建一个新点，每个点会自动连接，从而形成一段铺装 |
| Move to Top     | 调整渲染顺序，并将所选铺装移到最上层（也适用于滑行道线） |
| Move Up         | 调整渲染顺序，并将所选铺装上移一层（也适用于滑行道线） |
| Move Down       | 调整渲染顺序，并将所选铺装下移一层（也适用于滑行道线） |
| Move Bottom     | 调整渲染顺序，并将所选铺装移到最底层（也适用于滑行道线） |

+++



+++ 建筑

| 按钮 | 功能 |
| ------------------------ | ------------------------------------------------------------ |
| Create Building          | 点按此按钮后，点按你希望建筑第一条边出现的区域。每次点按都会创建一个新点，每个点会自动连接，从而形成一段建筑 |
| Set Texture & Facades    | 一旦选中建筑，就可以选择并更改立面 |
| Auto Texture Orientation | 这会取所选建筑或铺装的最长边，并将纹理（建筑的屋顶图案）与这条边对齐 |

+++



+++ 滑行道

| 按钮 | 功能 |
| ------------------------- | ------------------------------------------------------------ |
| Create Taxiway Line       | 点按此按钮后，点按你希望滑行道线第一条边出现的区域。每次点按都会创建一个新点，每个点会自动连接，从而形成一系列滑行道线 |
| Create Roadway Line       | 点按此按钮后，点按你希望道路线出现的区域。每次点按都会创建一个新点，每个点会自动连接，从而形成一系列道路线 |
| Create Taxiway Connection | 点按此按钮后，点按你希望创建滑行道连接的区域。每次点按都会创建一个新点，每个点会自动连接，从而形成一系列滑行道连接 |
| Build Taxiway Layout      | 点按此按钮后，系统会检查每个起始位置到跑道的路线。如果进行了任何更改，在你再次“Check Taxiway Layout”之前，需要重新点按此按钮 |
| Check Taxiway Layout      | 此按钮会检查从起始位置到跑道的滑行道路线是否有效。它会按颜色编码显示在每个起始位置下方 |
| Set as Apron              | 这会把所选的任何滑行道重命名为 APRON。对于任何未在航图上命名的滑行道以及滑行道连接，**必须**{.red}这样做 |
| Freeze Non Taxi Line      | 这是滑行道线的编辑模式，会冻结所有使用类型不是“Aircraft”的线条（在处理滑行道线时建议始终使用） |
| Select Invalid Taxi Lines | 当滑行道网络完成后，点按此按钮可查看是否有遗漏的滑行道线。任何仍未成为网络一部分的滑行道线都会以洋红色显示（不受缩放级别影响） |
| Select Lines Near Start   | 选择靠近起始生成点的所有线条，以便将它们重新分类为不可作为滑行道路径的线条（这些是供飞机机头轮停放的线条） |

> “铺装”中的 “Move to Top/Bottom” 和 “Move Up/Down” 按钮也适用于滑行道线

+++



+++ 卫星

| 按钮 | 功能 |
| ---------------- | ------------------------------------------------------------ |
| Import Imagery   | 用于访问已预先保存、带有卫星影像的压缩 KML 文件，以便进行编辑 |
| Latitude Offset  | 按住后上下滑动手指，以调整卫星影像的纬度（可在 +/-0.01 到 +/-2.00 米之间） |
| Longitude Offset | 按住后上下滑动手指，以调整卫星影像的经度（可在 +/-0.01 到 +/-2.00 米之间） |

+++ 廊桥

| 按钮 | 功能 |
| ------------------------ | ------------------------------------------------------------ |
| Check Jetbridges         | 检查所有起始位置是否存在诸如廊桥未到达舱门之类的错误。这些会按颜色编码显示 *(见下方 [11.4.1](../11.-airport-gates/11.4-jet-bridge-animations.md#11.4.1))* |
| Freeze Non Jetbridges    | 这是廊桥的编辑模式，只允许选择廊桥末端部分和起始位置（在处理廊桥时建议使用） |
| Auto Assign Gates        | 自动将廊桥分配到登机口 *(见下方 [11.4.4](../11.-airport-gates/11.4-jet-bridge-animations.md#11.4.4))* |
| Rotate Range +90 degrees | 某些廊桥的朝向会导致动画无法到达舱门。此按钮会将基础位置旋转 90 度，并设置廊桥的收起角度，使其保持在原来的位置，同时允许更大的旋转范围 |
| Adjust Jet Bridge Alt    | 将所选廊桥所有元素的高度调整为与所选廊桥第一部分相同的高度 *(见下方 [11.4.7](../11.-airport-gates/11.4-jet-bridge-animations.md#11.4.7))* |

+++ 编辑

| 按钮 | 功能 |
| ------------------------------------- | ------------------------------------------------------------ |
| Create Hole                           | 在选中一段铺装时，此按钮可在一块铺装区域内创建孔洞 *(见下方 [6.1.5](../6.-pavements/6.1-editing-pavements.md#6.1.5))* |
| Line Options                          | 点按此项会显示以下选项：<br><br> **Simplify** - 这会减少形成一条线所需的节点数量，适合减少节点过多的滑行道曲线节点<br><br> **Reverse** - 所有点都有编号，此按钮会反转所有点的编号顺序（这也可用于“翻转”的建筑）<br><br> **Straighten** - 选择一系列点，然后点按此按钮，即可拉直所选所有点之间的线 |
| Split Line                            | 选中一条线，然后选中该线上的某个点。之后你可以点按“Split Line”将其拆分为两条独立的线（尤其适用于为当前仍属于同一条线的不同滑行道命名）。分割点之后的那一段线将保持选中状态 |
| Snap Off / Snap to All / Snap to Type  | 吸附功能允许编辑器将一个点“附着”到另一个点/线，以避免出现间隙和/或重叠。连接建筑/线条/铺装时**必须**{.red}使用吸附功能。选择“Snap Off”时将无法吸附。选择“Snap to All”时，可让建筑/线条/铺装彼此吸附。“Snap to Type” 的作用相同，但仅限同类型之间（例如线对线等） |
| Insert Point                          | 这会为任何已选中的建筑或铺装插入一个点。除非选中了线内的某个点，否则该点会按顺序添加（即在最后一个编号点之后）；如果选中了线内的某个点，则会在该点与下一个点之间创建新点 |
| Adding/Selecting Point(s)             | 点按此按钮可在“Adding”和“Selecting”之间切换。添加点时，如果点按两点之间的线/边，就会在这两点之间添加一个点；如果点按其他任意位置，则会在最后一个编号点之后添加。选择点则允许你选中某个点（不过即使选择的是“Adding Points”，你仍然可以这样做） |
| Modify Shape                          | 这个按钮**必须**{.red}被点按（选中时为琥珀色），才能修改任何建筑、滑行道点或铺装的形状。未选中时，你只能移动整个形状，而不能单独移动各个点 |
| Delete Selection                      | 此按钮会删除所选建筑和对象 |

### 2.1.6

要选择多个建筑/线条/铺装或对象，你可以使用矩形选择工具：



步骤 1

: 轻触、按住，然后在屏幕上拖动手指进行选择（会出现一个白色框，显示选取区域）



步骤 2

: 当白色框包含了你想要选择的内容后，松开手指，它们就会被选中

## 应用内标尺

<a id="2.1.7"></a>
<a id="217"></a>
<a id="2.1.7"></a>
<a id="217"></a>
### 2.1.7

要使用标尺，请按照以下步骤操作：



步骤 1

: 将两根手指放在设备屏幕上并保持按住



步骤 2

: 将会出现一把标尺（使用标尺时，两根手指必须始终留在屏幕上）



步骤 3

: 然后可以通过在屏幕上移动两根手指来进行测量。它会提供米、英尺和海里的测量结果，以及方位信息



提示

: 确保屏幕上显示的是你想要测量的内容（如果你尝试移动相机，标尺会消失）



步骤 4

: 完成标尺使用后，只需将手指从屏幕上移开即可



提示

: 标尺仅在地面上准确

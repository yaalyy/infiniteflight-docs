# 1A.2  Discord 规则

 

提示

: 所有编辑者**必须**{.red}确保其 Discord 昵称与 IFC 用户名或真实姓名相同 - 这意味着在需要时可以轻松找到编辑者 *(见下方 [1A.2.1](1a.2-discord-rules.md#1a.2.1))*

### 1A.2.1

- 编辑者**必须**{.red}拥有一个 Infinite Flight 账户
- 编辑者**必须**{.red}年满 13 岁
- 编辑者**必须**{.red}在编辑**之前**链接他们的社区论坛账户 [link](../../getting-started-guide/home-user-interface/user-profile.md#linking-community-forum-account)
- 编辑者**必须**{.red}确保其 Discord 昵称与 IFC 用户名或真实姓名相同
- 编辑者**不得**{.red}向外部分享 Scenery Editing 类别中包含的任何机场编辑资料或对话（包括音频），除非事先获得批准
- 编辑者**必须**{.red}尊重其他用户并遵守基本礼仪
- 编辑者**不得**{.red}使用任何在 Infinite Flight 独立判断下可能被视为冒犯性的语言（包括但不限于非法、威胁性、粗俗、带有性暗示，或在种族、民族或其他方面令人反感的语言）
- 批评和反馈通常会通过私信（DM）给出；不过，在某些情况下，如果被认为是编辑者群体中的普遍问题，也可能会公开提供
- 通过使用 Scenery Editor 上传机场，即表示你同意 [Contributor License Agreement (CLA)](https://github.com/infiniteflight/infiniteflight-localization/blob/main/CONTRIBUTING.md)
- Infinite Flight Server 的规则同样适用，并且**必须**{.red}遵守。这些规则可在 Welcome 选项卡下的 rules-and-info 频道中找到

## 语音频道

<a id="1A.2.2"></a>
<a id="1a.2.2"></a>
<a id="1a22"></a>
<a id="1A.2.2"></a>
<a id="1a.2.2"></a>
<a id="1a22"></a>
### 1A.2.2

- 必须始终使用英语**必须**{.red}
- 语音频道**只能**{.red}由正在与其他编辑者积极讨论编辑内容的成员使用
- 关于使用语音频道的协调**必须**{.red}仅在 *#editors-chat* Discord 频道中进行
- 编辑者**不得**{.red}传输任何可能被解释为扰乱秩序的内容
- 编辑者**不得**{.red}传输任何私人、身份识别信息或敏感信息
- 编辑者**不得**{.red}冒充其他用户
- 关于语音频道使用的更多指导可在 Discord Communication 中找到 *(见上方 [1A.1.3](1a.1-discord-communication.md#1a.1.3))*

### 1A.2.3

成员可随时联系工作人员成员或 IFC Moderator，举报严重违反语音频道规则的行为或不安全情况。编辑者成员的安全与隐私是首要任务。

> 由于广泛多样的社会规范，在兴奋状态下可能会出现无意的脱口而出，这通常不需要进行 moderation（例如，因突发事件而产生的轻微脏话和即兴短语）

## 支持

### 1A.2.4

- 首先，编辑者**应**{.red}尽一切努力利用可用资源寻求支持，包括本手册和其他编辑者
- 如果编辑者无法找到所需答案，可以在 *#editors-chat* Discord 频道中寻求帮助
- 等级结构有助于了解机场编辑中的不同角色，因此也能帮助判断应向谁提问 *(见下方 [1A.4.1](1a.4-rank-structure.md#1a.4.1))*
- 如果编辑者需要有关服务器相关咨询的协助，可以通过在 "Support" 选项卡下使用 #server-support 联系 Infinite Flight Server Moderators

### 1A.1.1    

Discord 是一款面向团队的即时通讯应用，旨在让工作更简单、更愉快，也更高效。有关此应用工作方式的更多信息，请参见 [此处](https://support.discord.com/hc/en-us)。

Scenery Editing 使用官方 Infinite Flight Discord 中的一个分类，入口可见 [此处](https://discord.gg/infiniteflight)

### 1A.1.2

 Scenery Editing 分类中的各个频道及其用途如下表所示：

| 频道              | 用途                                                      |
| ------------------ | :-------------------------------------------------------- |
| #announcements | Staff 和 Mods 发布公告的官方通信频道 |
| #guidelines-&-info | 重点说明 Scenery Editing 分类的规则和有用信息 |
| #editors-chat | 专供 Infinite Flight 场景编辑人员讨论机场开发相关事项的聊天频道 |
| #airport-assignments  | ASE（Apprentice Scenery Editors）请求机场分配的频道。编辑人员 **必须**{.red} 使用以下格式请求机场："Requesting ICAO"。随后，Scenery Editor Moderator 或 Reviewer 会为该编辑人员分配一个机场 |
| #sas-requests | 请求卫星影像的频道。编辑人员 **必须**{.red} 使用以下格式请求影像："Requesting SAS for ICAO"。              |
| #peer-review | 供编辑人员在机场提交正式审核前相互审查彼此机场的频道。编辑人员在请求 peer review 前，必须确保其机场已接近完成。编辑人员 **必须** 使用以下格式请求 peer review："Requesting PR for ICAO - URL to respective IFC topic" <br>*(见下方 [12.1.3](../12.-review-and-release/12.1-review-and-release-process.md#12.1.3))* |
| #support | 用于从 Scenery Editor Reviewers 或 Scenery Editor Moderators 获取直接支持的工单频道 |

### 1A.1.3

语音频道（VCs）**必须**{.red} 仅在遵守 Discord 规则的情况下使用 *(见下方 [1A.2.1](1a.2-discord-rules.md#1a.2.1))*。

### 1A.1.4

使用 VCs **不是必须的**{.red}，完全由编辑人员自行决定。 

需要注意的是，所有 pro 订阅用户都可以访问语音频道，因此只有在你愿意让你的机场进度公开时才使用这些频道（如果非编辑人员加入语音频道）

### 1A.1.5

要开启一个 VC，请遵循以下步骤：



步骤 1

: 打开官方 Infinite Flight Discord



步骤 2

: 进入 Voice Chat 分类

步骤 3

: 创建 voice chat



**与其他编辑人员的协调 **应**{.red} 在进入 VC 之前先在相应的 Discord 频道中完成（即 *#editors-chat*）**

### 1A.1.6

以下是一些关于 VCs 的实用提示：

- 你可以通过查看 [00/10] 频道人数来随时了解当前有多少成员在一个 VC 中
- 选择 "Mute"（麦克风图标）表示没人能听到你
- 选择 "Deafen"（耳机图标）表示你听不到其他任何人
- 始终仔细检查你的声音设置（即 Input = Mic，Output = Speaker）
- 连接到 VC 的体验很像电话通话，并且在编辑时可以在后台运行

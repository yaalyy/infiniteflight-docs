# 1A.6 纪律与停职流程

 

<a id="1A.6.1"></a>
<a id="1a.6.1"></a>
<a id="1a61"></a>
<a id="1A.6.1"></a>
<a id="1a.6.1"></a>
<a id="1a61"></a>
### 1A.6.1    

不遵守《Scenery Editing Manual》的编辑者可预期会按以下流程处理：

 

| 违规次数 | 采取的措施                               |
| ------- | ----------------------------------------- |
| 第 1 次 | 通过 DM 警告                            |
| 第 2 次 | 停止 Scenery Editor 和 Discord 权限 3 天 |
| 第 3 次 | 停止 Scenery Editor 和 Discord 权限 7 天 |
| 第 4 次 | 移出机场编辑团队                         |

任何停职结束后，编辑者将恢复到其之前所在的等级。通常，恢复权限的日期将作为该等级的新起始日期；不过，这会根据具体情况逐案处理。

### 1A.6.2

# 11.1 机位设备摆放



在搭建机位时，请确保不要过度堆砌物件，否则会导致性能下降，并且会让人觉得这些内容可能是复制粘贴出来的。请保持各个机位的独特性，并适当变换物体的朝向。 



尽量避免在彼此距离很近的位置重复放置某些物体。请根据适用情况查看各类物体的数量建议。



例如：



- G/A
- 货运
- 商业（机位和远机位）
- 军用
- 维修



应包含一些关于不要把拖杆连接到牵引车上，以及始终将集装箱放在托盘拖车上的说明

不要越过白线

不要把推回牵引车直接停在前起落架前方

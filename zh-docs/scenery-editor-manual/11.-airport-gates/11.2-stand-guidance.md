# 11.2 停机位引导



提示

: 你可能会发现先缩小视图会很有帮助，这样可以确保停机位引导朝向起始位置并与其保持在同一直线上（同一直线定义为在 +/- 5 度以内）。将会与停机位引导配对的是最近的起始位置（60m 范围内），前提是它与停机位引导在同一直线上



<a id="11.2.1"></a>
<a id="1121"></a>
<a id="11.2.1"></a>
<a id="1121"></a>
### 11.2.1

步骤 1

: 在屏幕右侧上下滚动列表，查看对象库（**必须**{.red} 选中 "Library" 选项卡）



步骤 2

: 在 "Stand Guidance" 下选择 "Safedock T1"



步骤 3

: 在你想要添加该对象的机场区域轻点（你可能需要按住不放），这会放置一个白色光标。按需要调整位置，然后轻点 "Add Object"



提示

: 最容易的方法可能是在该停机位的起始位置轻点，将停机位引导放置到该起始位置（你可能需要从下拉列表中选择该起始位置）



步骤 4

: 将会出现三个圆圈以及一个罗盘玫瑰。按住某个圆圈可移动对象，或更改高度/方向：



| 圆圈                         | 功能                                                     |
| ------------------------------ | ------------------------------------------------------------ |
| 中心                         | 通过拖动手指到所需位置来移动对象 |
| 顶部（中心圆圈正上方） | 调整对象的高度或海拔          |
| 外圈                          | 通过沿着你希望其朝向的方向拖动手指来改变对象的朝向 |



提示

: 停机位引导 **应该**{.red} 与设计停靠在该停机位的飞机处于视平高度，并且 **必须**{.red} 放置在该停机位的正确位置（这可能是在航站楼建筑上，甚至是在 "Generic Pole" 上）



步骤 5

: 停机位引导 **必须**{.red} 朝向起始位置，并且朝向必须正确（即带有传感器的一侧 **必须**{.red} 面向起始位置）

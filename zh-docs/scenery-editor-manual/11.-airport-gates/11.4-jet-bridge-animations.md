# 11.4 廊桥动画 



<a id="11.4.1"></a>
<a id="1141"></a>
<a id="11.4.1"></a>
<a id="1141"></a>
### 11.4.1

在添加了起始位置和廊桥，并调整好廊桥的收起位置后，编辑者就可以继续添加廊桥动画。以下是**必须**{.red}遵循的第一步：



步骤 1

: 检查所有起始位置的命名是否正确。进入步骤 2 之前，以下属性**必须**{.red}正确：



| 属性    | 条目                                                         |
| ------- | ------------------------------------------------------------ |
| Terminal | 例如 Concourse/Terminal/GA/Cargo/Apron/FBO 等。[名称/编号] |
| Name     | Gate [字母数字/数字]*                                        |

**编辑者**{.red}必须确保航站楼名称（例如 T1）不包含在 "Name" 属性中*



步骤 2

: 点击 "Auto Assign Gates" 按钮，将每座廊桥绑定到一个机位



步骤 3

: 在每座廊桥上方，会显示该廊桥被分配到的起始位置（例如 "Terminal 5/Gate 515"）



步骤 4

: 如果不正确，请点击所需的廊桥（如果尚未选中），然后点击 "Properties"。在 "General" 下方有 "Gate" 选项卡，点击它



步骤 5

: 该廊桥已分配的机位会列出，可点击其旁边的 "-" 符号将其移除。如果需要添加机位，请点击 "+" 符号，然后按 "Terminal Name/Gate Name" 格式输入机位名称



> 有时自动分配功能会错误地将廊桥分配给附近一个无法由该廊桥服务的机位，因此可能需要手动调整



步骤 6

: 点击 "Jet Bridges > Check Jet Bridges"，检查所有廊桥无法到达舱门的起始位置



步骤 7

: 在每个起始位置下方，会显示廊桥状态。使用以下颜色代码：



| 代码                                              | 消息                                                      |
| ------------------------------------------------- | ------------------------------------------------------------ |
| "All Airplanes OK" - 绿色                        | 对于任何配有廊桥的起始位置，这**必须**{.red}是显示的代码 |
| "Jet Bridges [Aircraft Type* and Reason]" - 琥珀色 | 需要重新调整廊桥，因为它无法到达所列机型的部分舱门 |
| "Jet Bridges [Aircraft Type* and Reason]" - 红色   | 需要重新调整廊桥，因为它无法到达所列机型的任何舱门 |
| "No Jet Bridges Available" - 灰色                 | 如果起始位置没有廊桥，这是预期结果    |

**为避免画面杂乱，最多只会显示 2 种机型*



步骤 8

: 如果任何起始位置不是绿色（即琥珀色或红色），你**必须**{.red}调整廊桥，使舱门可达*(见下方 11.4.2)*



步骤 9

: 通过点击 "File > Airport Properties > Jet Bridges Available" 检查 Airport Properties *(见上方 [3.2.2](../3.-getting-started/3.2-airport-properties.md#3.2.2))* 中是否已勾选 "Jet Bridges Available" 复选框（选中时显示橙色勾选）



> 在勾选此复选框之前，廊桥在飞行模式下对飞行员不会生效

## 调整廊桥

<a id="11.4.2"></a>
<a id="1142"></a>
<a id="11.4.2"></a>
<a id="1142"></a>
### 11.4.2

步骤 1

: 所有廊桥**必须**{.red}检查；对于任何配有廊桥的起始位置，先点击 "Jet Bridges"，然后点击 "Check Jet Bridges"，调整任何显示为红色、琥珀色或灰色的廊桥



> 编辑者**必须**{.red}确保即使是绿色的廊桥也符合下面第 5 步的要求



提示

: 在尝试移动廊桥之前，先点击 "Jet Bridges" 再点击 "Freeze Non Jet Bridges"，这会冻结所有其他对象，避免你不小心移动到别的东西



步骤 2

: 点击廊桥末端 **(1)**，会出现一个绿色弧线，显示该廊桥的动画范围 **(2)**



> 内侧绿色曲线表示廊桥完全收起时，其旋转头中心的最小范围；外侧绿色曲线表示廊桥可能达到的最大伸展范围。飞机舱门必须位于这个绿色区域内，廊桥才能到达



步骤 3

: 除了绿色弧线外，还会显示三个圆和一个方位罗盘。通过点击、按住并拖动这个外圈 **(3)**，可更改廊桥（以及绿色弧线）的朝向。可移动它，直到绿色弧线覆盖所有适用的起始位置



![图像 11.4.2.1 - 调整廊桥](../../../_images/manual/frames/7.5.2.1.png)



提示

: 可使用 "Rotate Range +90" 按钮将绿色弧线移动 90 度，同时收起状态廊桥的朝向保持不变（例如，当绿色弧线覆盖了过多航站楼区域而不是机位区域时，这会很有用）



步骤 4

: 重新点击 "Jet Bridges"，然后点击 "Check Jet Bridges"，检查这些位置现在是否显示为绿色 **(4)**



![图像 11.4.2.2 - 检查廊桥](../../../_images/manual/frames/7.5.2.3.png)



步骤 5

: 编辑者**必须**{.red}确保绿色弧线尽可能覆盖起始位置 **(5)**。如果绿色弧线有更多部分处于不可用区域（例如航站楼）中，可能会限制廊桥的范围 **(6)**



![图像 11.4.2.3 - 正确的廊桥设置](../../../_images/manual/frames/10.4.2.3a.png)



![图像 11.4.2.4 - 错误的廊桥设置](../../../_images/manual/frames/10.4.2.4a.png)

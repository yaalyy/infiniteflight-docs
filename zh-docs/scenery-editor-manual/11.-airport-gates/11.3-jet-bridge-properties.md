# 11.3 登机廊桥属性



<a id="11.3.1"></a>
<a id="1131"></a>
<a id="11.3.1"></a>
<a id="1131"></a>
### 11.3.1

步骤 1

: 通过点击廊桥本身或其附近来选择登机廊桥 *(或使用矩形选择工具 - 见上方的 [2.1.6](../2.-user-interface/2.1-editor-screen.md#2.1.6))*



步骤 2

: 如果附近有多个对象，你可能需要从下拉框中选择登机廊桥。登机廊桥的轮廓会变成品红色，表示它已被选中 **(1)**



步骤 3

: 点击屏幕右侧的 "Properties" 选项卡 **(2)**



![Image 11.3.1.1 - Jet Bridge Properties](../../../_images/manual/frames/10.3.1.1a.png)



步骤 4

: 然后你可以调整处于收起位置（即未连接到飞机）的登机廊桥的以下属性：



> 下方未列出动画，因为除非要调整登机廊桥底座的高度 *(见下方 x)*，否则 **不得**{.red} 编辑这些动画

| 按钮                 | 功能                                                         | 备注                                                         |
| -------------------- | ------------------------------------------------------------ | ------------------------------------------------------------ |
| Gates                | 显示分配给该登机廊桥的登机口                                      | 见下方 10.4                                                  |
| Stowed Arm Rotation  | 点击 "+/-" 符号可调整登机廊桥的朝向，它基于底座/连接器的默认位置，并逆时针旋转 | **必须**{.red} 调整，以避免碰撞                               |
| Stowed Arm Extension | 点击 "+/-" 符号可调整登机廊桥的收起长度                              | **必须**{.red} 调整，以避免碰撞                               |
| Stowed Head Rotation | 点击 "+/-" 符号可移动登机廊桥收起时的前端                              | **必须**{.red} 调整，以避免碰撞                               |
| Stowed Height        | 点击 "+/-" 符号可调整登机廊桥在收起位置时的默认高度                     | 高度 **必须**{.red} 调整到该机位可停靠的所有飞机舱门都能够到达 |
| Scale                | 点击 "+/-" 符号可调整缩放                                             | 除非要将登机廊桥恢复为 "1" 的缩放，否则 **不得**{.red} 更改缩放（动画要正常工作，缩放 **必须**{.red} 为 1） |
| Orientation          | 点击 "+/-" 符号可调整登机廊桥动画范围的朝向（显示为围绕登机廊桥本身的绿色弧形圆柱体） |                                                              |
| Latitude / Longitude | 登机廊桥当前的纬度/经度                                               |                                                              |
| Altitude             | 这里显示起始位置的当前高度（以米为单位）                                 | **不应**{.red} 更改                                           |
| Name                 | 你可以使用此字段为登机廊桥命名                                        | 目前不是必需项                                                |

## 调整登机廊桥底座高度

<a id="11.3.2"></a>
<a id="1132"></a>
<a id="11.3.2"></a>
<a id="1132"></a>
### 11.3.2

登机廊桥底座与末端之间的坡度是有限制的（如果登机廊桥较短，这尤其是个问题），因此可能需要调整底座高度，以适配所有可在该起始位置生成的机型。下面是一个未调整以适配窄体机的登机廊桥示例。



![Image 11.3.2.1 - Jet Bridge Base Too High for Narrow-Body Aircraft](../../../_images/manual/frames/7.5.7.1b.png)



<a id="11.3.3"></a>
<a id="1133"></a>
<a id="11.3.3"></a>
<a id="1133"></a>
### 11.3.3

为此，可以按照以下步骤操作：



步骤 1

: 点击中心的蓝色圆圈 **(1)** 或其附近来选择登机廊桥底座 *(或使用矩形选择工具 - 见上方的 [2.1.6](../2.-user-interface/2.1-editor-screen.md#2.1.6))*



步骤 2

: 如果附近有多个对象，会出现一个列表，供你选择登机廊桥底座



步骤 3

: 点击屏幕右侧的 "Properties" 选项卡 **(2)**，然后点击 "Animations" 旁边的 "+" 符号 **(3)**



步骤 4

: 会出现一个下拉列表，点击 "Height" 旁边的 "+" 符号 **(4)**



步骤 5

: 这会进一步展开，点击该项 **(5)** 后，你就可以更改登机廊桥底座的高度



步骤 6

: 在登机廊桥底座仍处于选中状态时（其高度已被调整）- 使用矩形选择工具 *(见上方的 [2.1.6](../2.-user-interface/2.1-editor-screen.md#2.1.6))* 或 "Edit > Selection (Add)" 选择你希望调整高度的其余所有登机廊桥元素



步骤 7

: 点击 "Jet Bridge"，然后点击 "Adjust Jet Bridge Alt"


提示

: 由于玻璃登机廊桥存在一个 bug，当使用 "Adjust Jetbridge Alt." 将末端部分连接到底座时，末端部分最终会低 0.060。一个变通方法是先将底座放高 0.060，使用 "Adjust Jetbridge Alt."，然后再将底座降低 0.060。

步骤 8

: 所有选中的登机廊桥元素的高度都会被改为与登机廊桥底座相同的高度



![Image 11.3.3.1 - Adjusting Jet Bridge Height](../../../_images/manual/frames/7.5.6.1c.png)

## A380 登机口

<a id="11.3.4"></a>
<a id="1134"></a>
<a id="11.3.4"></a>
<a id="1134"></a>
### 11.3.4

如果起始位置有三条登机廊桥，它会尝试将第三条登机廊桥连接到 A380 的 U1L（Upper 1 Left）舱门。编辑者 **应**{.red} 尽量抬高登机廊桥底座 *(见上方 [11.3.3](11.3-jet-bridge-properties.md#11.3.3))* 以及收起高度 *(见上方 [11.3.1](11.3-jet-bridge-properties.md#11.3.1))*，以减小登机廊桥连接到飞机舱门时的角度。

## 创建跑道

<a id="5.1.1"></a>
<a id="511"></a>
<a id="5.1.1"></a>
<a id="511"></a>
### 5.1.1

步骤 1

: 点击你想放置新跑道的机场区域 **(1)**



步骤 2

: 点击 "Object"，然后点击 "Create Runway"。跑道会被放置在光标所在位置，编辑器会自动进入 ShapeEditing 模式 **(2)**



步骤 3

: 调整跑道的节点，确保它与影像对齐。无法对跑道对象进行添加或删除节点操作



![Image 5.1.1.1 - Creating a Runway](../../../_images/manual/scenery-editor/editing-runways1.png)



> 如果新跑道在现实中有 ILS，那么它在 Infinite Flight 中 **必须**{.red} 同样添加。为此，请在 IFAET Discord 服务器中创建一个 Reviewer 工单，并通知他们你的机场有一条带 ILS 的新跑道。

## 编辑现有跑道

<a id="5.1.2"></a>
<a id="512"></a>
<a id="5.1.2"></a>
<a id="512"></a>
### 5.1.2

步骤 1

: 通过点击跑道线附近来选中跑道，如果附近有多个对象，可能需要从下拉列表中选择跑道 *(或者使用矩形选择工具 - 参见上方 [2.1.6](../2.-user-interface/2.1-editor-screen.md#2.1.6))*



步骤 2

: 点击右侧的 "Modify Shape" 按钮 **(1)**



步骤 3

: 跑道的节点将会出现



步骤 4

: 点击某个节点后，它会变成洋红色 **(2)**，表示已被选中 *(或者使用矩形选择工具 - 参见上方 [2.1.6](../2.-user-interface/2.1-editor-screen.md#2.1.6))*



步骤 5

: 然后你可以点击、按住并拖动屏幕上的手指，将节点移动到所需位置



步骤 6

: 编辑完成后，点击 "Modify Shape" 取消选择它（不这样做将无法编辑其他对象） 



> 如果修改后的跑道在现实中有 ILS，那么 ILS 属性 **必须**{.red} 也在 Infinite Flight 中进行修改。为此，请在 IFAET Discord 服务器中创建一个 Reviewer 工单，并通知他们你的机场有一条带 ILS 的修改后跑道。

## 移动/更改跑道方向

<a id="5.1.3"></a>
<a id="513"></a>
<a id="5.1.3"></a>
<a id="513"></a>
### 5.1.3

步骤 1

: 通过点击跑道上或附近来选中跑道 *(或者使用矩形选择工具 - 参见上方 [2.1.6](../2.-user-interface/2.1-editor-screen.md#2.1.6))*



步骤 2

: 如果附近有多条跑道，可能需要从下拉框中选择跑道。跑道名称会显示出来，表示它已被选中 **(1)**



提示

: 如果你刚刚创建了这条跑道，只需点击 "Modify Shape" 取消选择，它就会被选中



步骤 3

: 会出现两个圆圈以及一个罗盘玫瑰。按住圆圈 **(2)** 可移动跑道或更改方向：



| 圆圈 | 功能                                                     |
| ------ | ------------------------------------------------------------ |
| 中心 | 通过拖动手指到所需位置来移动跑道端点 |
| 外圈  | 通过沿着你希望其朝向的方向拖动手指来改变跑道端点的方向 |



![Image 5.1.3.1 - Moving/Changing Orientation of Runway](../../../_images/manual/scenery-editor/editing-runways2.png)



> 如果移动后的跑道在现实中有 ILS，只要它没有被其他方式修改，ILS 也会随跑道一起移动。

## 删除跑道

<a id="5.1.4"></a>
<a id="514"></a>
<a id="5.1.4"></a>
<a id="514"></a>
### 5.1.4

步骤 1

: 通过点击跑道上或附近来选中跑道 *(或者使用矩形选择工具 - 参见上方 [2.1.6](../2.-user-interface/2.1-editor-screen.md#2.1.6))*



步骤 2

: 如果附近有多条跑道，可能需要从下拉框中选择跑道。跑道名称会显示出来，表示它已被选中 **(1)**



步骤 3

: 在屏幕右侧的编辑按钮 **(2)** 中点击 "Delete Selection" 



![Image 5.1.4.1 - Deleting a Runway](../../../_images/manual/scenery-editor/editing-runways3.png)

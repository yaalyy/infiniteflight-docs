# 5.3 跑道的要做与不要做事项

下面的表格包含了在处理跑道时，你需要编辑的内容以及不需要编辑的内容

| :fa-check-circle: 要做                                         | :fa-times-circle: 不要做                                     |
| ------------------------------------------------------------ | ------------------------------------------------------------ |
| :fa-check-circle: 如果你修改了带有 ILS 的跑道，请通知审核者                                                          | :fa-times-circle: 添加跑道标记，包括移位跑道头和冲出区的标记 |
| :fa-check-circle: 只对永久关闭的滑行道和跑道添加 X 标记                                                            | :fa-times-circle: 为临时关闭的滑行道和跑道添加 X 标记       |
|

# 5.2 属性



<a id="5.2.1"></a>
<a id="521"></a>
<a id="5.2.1"></a>
<a id="521"></a>
### 5.2.1

步骤 1

: 点击跑道上或附近以选中跑道 *(或使用矩形选择工具 - 见上方 [2.1.6](../2.-user-interface/2.1-editor-screen.md#2.1.6))*



步骤 2

: 如果附近有多条跑道，你可能需要在下拉框中选择该跑道。选中后，跑道名称会显示出来



步骤 3

: 点击屏幕右侧的 "Properties" 选项卡



步骤 4

: 然后你可以调整该跑道的以下属性

步骤 5

: 跑道属性的更改不会立即生效。要让其反映出来，只需在跑道旁边放置一个对象，比如 Electrical Equipment Building，然后在更改跑道属性后移动它。这样就会使跑道更新为新设置。完成后别忘了移除该对象。

| 按钮 | 功能 | 备注 |
| ------ | -------- | ----- |
| Runway | 跑道属性，例如标记和灯光 | 见下方 [5.2.2](#5.2.2) |
| Latitude / Longitude | 跑道坐标 | **不应**{.red} 更改，这不会移动跑道本身 | 
| Altitude | 这里显示起点位置的当前高度（以米为单位）。*(继承自机场海拔 - 见 [3.2](../3.-getting-started/3.2-airport-properties.md#3.2.2))* | **不应**{.red} 更改 |
| Name | 你可以使用此字段为跑道命名 | 正确格式： "*(较低编号端 RWY ID)*[L/R/C/T]-*(较高编号端 RWY ID)*[L/R/C/T]"。L/R/C/T 为可选项，只有当跑道标识符在现实中包含其中一种时，才 **必须**{.red} 添加。示例：09-27, 08R-26L, 18C-36C, 03T-21T|

### 5.2.2

| 按钮 | 功能 | 备注 |
| ------ | -------- | ----- |
| Width | 你可以更改跑道宽度（以米为单位） | |
| Surface | 你可以通过点击此项更改跑道表面类型 | 表面类型 **必须**{.red} 根据机场文档来选择，而不是根据卫星影像所见来判断（例如，即使一条颜色上看起来像混凝土的明亮沥青跑道，仍然 **必须**{.red} 画成沥青） |
| ShoulderSurface | 你可以更改跑道肩部表面类型（混凝土或沥青） | 表面类型 **必须**{.red} 根据机场文档来选择，而不是根据卫星影像所见来判断（例如，即使一条颜色上看起来像混凝土的明亮沥青跑道，仍然 **必须**{.red} 画成沥青） |
| HasEdgeLights | 你可以更改跑道是否有边灯 | **必须**{.red} 按照机场文档设置 |
| HasCenterlineLights | 你可以更改跑道是否有中线灯 | **必须**{.red} 按照机场文档设置 |
| RunwayEnds | 跑道端属性 | 见下方 [5.2.3](#5.2.3) |
| Length | 显示跑道长度（以米为单位） | 不能在 Properties 窗口中更改。它是根据两个节点之间的距离计算得出的 |

### 5.2.3

RunwayEnds 属性包含两个跑道端组。它们的结构相同；其中的属性可能不同。

| 按钮 | 功能 | 备注 |
| ------ | -------- | ----- |
| Overrun | 你可以更改跑道超出区域（以米为单位） | |
| DisplacedThreshold | 你可以更改跑道阈值偏移量（以米为单位） | |
| Approach Lights | 你可以更改进近灯光 | 进近灯光 **必须**{.red} 按照机场文档设置 |
| Markings | 你可以更改跑道的标线类型 | |
| Touchdown Lighting | 你可以更改跑道端是否有接地灯光 | 目前在 Infinite Flight 中不可用。为确保未来兼容性，Touchdown lighting **必须**{.red} 按照机场文档设置。 |
| REILType | 你可以更改跑道端识别灯类型 | REIL 灯 **必须**{.red} 按照机场文档设置 |
| Location | 跑道端坐标 | **不应**{.red} 更改 |
| Identifier | 你可以更改跑道端标识符[^1] | 正确格式： "*(RWY ID)*[L/R/C/T]. L/R/C/T 为可选项，只有当跑道标识符在现实中包含其中一种时，才 **必须**{.red} 添加。 |
| Glideslope / Localizer | *不适用*[^2] | **不得**{.red} 设置 |
| Heading | 更改跑道端航向 | **不应**{.red} 通过 Properties 窗口更改，请改为移动跑道节点 *(见上方 [5.1.2](#5.2.1))* |



> [^1] 如果某条跑道的 ILS 端跑道标识符已被修改，请在 IFAET Discord 服务器中开一个 Reviewer ticket，并通知他们该跑道端标识符的变更。更改标识符后需要重启应用程序（请确保在重启前保存）。在数据库更新之前，Taxiway network checker 将无法工作（通常就在应用更新前）。



> [^2] 如果某条跑道缺少 ILS，请在 IFAET Discord 服务器中开一个 Reviewer ticket，并通知他们相应跑道缺少 ILS。

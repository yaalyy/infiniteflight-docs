# 6.3 铺装的应做事项和不应做事项

下面的表格列出了在处理铺装时需要编辑和不需要编辑的内容

| :fa-check-circle: 应做                                         | :fa-times-circle: 不应做                                     |
| ------------------------------------------------------------ | ------------------------------------------------------------ |
| :fa-check-circle: 按照图表和卫星影像所示添加道路和滑行道 | :fa-times-circle: 添加对使用该机场的飞行员不可见或无关的公共道路 |
| :fa-check-circle: 在草地用于航空器活动时添加草地铺装 | :fa-times-circle: 添加草地或绿色铺装来还原并非活动区域的草坪部分 |
| :fa-check-circle: 在从航空器活动区域清晰可见的地方添加公共道路 | :fa-times-circle: 添加混凝土或雪地铺装来还原明亮的沥青区域 |
| :fa-check-circle: 在机库建筑下方添加混凝土铺装（如果现实中存在该材质，也允许使用其他材质） | :fa-times-circle: 使用大量不必要的小段来创建铺装区域 |
| :fa-check-circle: 尽量将滑行道各段之间的连接节点数量保持最低 | :fa-times-circle: 添加雪地铺装来在地面上创建文字或符号 |
| :fa-check-circle: 在周围铺装之上添加铺装补片（即下方不创建空洞）* | :fa-times-circle: 添加任何类型的“彩蛋”             |
| - | :fa-times-circle: 为边缘使用过多节点 |
| - | :fa-times-circle: 还原破损的铺装 |

**如果存在更高性能的方式（即创建更少节点），那么这是可以接受的（由审阅者自行决定）。例如，将铺装补片吸附到铺装边缘，而不是将其放置在其上方，或者允许在下方创建空洞*

# 6.2 属性

<a id="6.2.1"></a>
<a id="621"></a>
<a id="6.2.1"></a>
<a id="621"></a>
### 6.2.1

步骤 1

: 轻点跑道铺面本身或其附近以选中该跑道铺面 *(或者使用矩形选择工具 - 参见上方 [2.1.6](../2.-user-interface/2.1-editor-screen.md#2.1.6))*



步骤 2

: 如果附近有多个跑道铺面，你可能需要在下拉框中选择该跑道铺面。跑道铺面的轮廓会变为洋红色，表示它已被选中 **(1)**



步骤 3

: 轻点屏幕右侧的 "Properties" 选项卡 **(2)**



![Image 6.2.1.1 - Pavement Properties](../../../_images/manual/frames/5.2.1.1.png)



步骤 4

: 然后你可以调整跑道铺面的以下属性：



| Button               | 功能                                                     | 备注                                                        |
| -------------------- | ------------------------------------------------------------ | ------------------------------------------------------------ |
| Surface Type         | 你可以通过轻点此项更改表面类型              | **必须**{.red}使用与卫星影像高度匹配的表面类型（例如，即使明亮的沥青从颜色上看像混凝土，仍然**必须**{.red}按沥青绘制） |
| Texture Orientation  | 添加 0 到 360 之间的任意数值，以更改纹理的纹理方向（以真北为基准） | 这对于让纹理与滑行道方向对齐特别有用。你也可以在左侧的管理按钮中轻点 "Building" > "Auto Texture Orientation" 来完成此操作 *(参见上方 [2.1.2](../2.-user-interface/2.1-editor-screen.md#2.1.2))* |
| Latitude / Longitude | 跑道铺面当前的纬度/经度                   | 这**不应**{.red}被更改                         |
| Altitude             | 这显示跑道铺面当前的高度（以米为单位）。轻点数字，然后输入新数值即可进行调整 | 该高度始终以机场海拔为基准（这**不应**{.red}被更改） |
| Name                 | 你可以使用此字段为跑道铺面命名                   | 跑道铺面不需要命名，但在编辑过程中，为不同跑道铺面添加标签有助于区分它们 |

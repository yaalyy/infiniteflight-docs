## 创建铺装面

<a id="6.1.1"></a>
<a id="611"></a>
<a id="6.1.1"></a>
<a id="611"></a>
### 6.1.1

步骤 1

: 点击左侧的管理按钮中的“Pavement”，然后点击“Create Pavement” **(1)**



步骤 2

: 点击你想要铺装面的机场区域 **(2)**，第一个节点将被放置



步骤 3

: 继续点击以添加节点 **(3)**，一旦放置了三个或更多节点，就会创建一段铺装面



![Image 6.1.1.1 - Creating Pavements](../../../_images/manual/frames/5.1.1.1.png)

提示

: 使用集装箱的侧壁来帮助制作 90 度拐角

## 编辑现有铺装面形状

<a id="6.1.2"></a>
<a id="612"></a>
<a id="6.1.2"></a>
<a id="612"></a>
### 6.1.2

步骤 1

: 通过点击铺装面上或附近来选择铺装面，如果附近有多个项目，可能需要从下拉列表中选择铺装面 *(或者使用矩形选择工具 - 参见上方的 [2.1.6](../2.-user-interface/2.1-editor-screen.md#2.1.6))*



步骤 2

: 点击右侧的“Modify Shape”按钮 **(1)**



步骤 3

: 选中后轮廓会变为洋红色，并且会显示节点



步骤 4

: 点击某个节点后，它会变为洋红色 **(2)**，表示它已被选中 *(或者使用矩形选择工具 - 参见上方的 [2.1.6](../2.-user-interface/2.1-editor-screen.md#2.1.6))*



步骤 5

: 然后你可以点击、按住并拖动屏幕上的手指，将节点移动到所需位置



步骤 6

: 编辑完成后，点击“Modify Shape”以取消选择它（不这样做就无法编辑其他铺装面）

## 移动/更改铺装面朝向

<a id="6.1.3"></a>
<a id="613"></a>
<a id="6.1.3"></a>
<a id="613"></a>
### 6.1.3

步骤 1

: 通过点击铺装面上或附近来选择铺装面 *(或者使用矩形选择工具 - 参见上方的 [2.1.6](../2.-user-interface/2.1-editor-screen.md#2.1.6))*



步骤 2

: 如果附近有多个铺装面，你可能需要从下拉框中选择铺装面。铺装面的轮廓会变为洋红色，以表示它已被选中 **(1)**



提示

: 如果你刚刚创建了该铺装面，只需点击“Modify Shape”将其取消选择，然后就会选中该铺装面



步骤 3

: 将会出现两个圆圈以及一个罗盘。按住圆圈 **(2)** 可移动铺装面或更改朝向：



| 圆圈 | 功能                                                     |
| ---- | ------------------------------------------------------------ |
| 中心 | 通过拖动手指到所需位置来移动铺装面 |
| 外圈 | 通过按你希望的朝向方向拖动手指来改变铺装面的朝向 |



![Image 6.1.3.1 - Moving/Changing Orientation of Pavement](../../../_images/manual/frames/5.1.3.1.png)

## 复制并粘贴铺装面

<a id="6.1.4"></a>
<a id="614"></a>
<a id="6.1.4"></a>
<a id="614"></a>
### 6.1.4

步骤 1

: 通过点击铺装面上或附近来选择铺装面 *(或者使用矩形选择工具 - 参见上方的 [2.1.6](../2.-user-interface/2.1-editor-screen.md#2.1.6))*



步骤 2

: 如果附近有多个铺装面，你可能需要从下拉框中选择铺装面。铺装面的轮廓会变为洋红色，以表示它已被选中 



步骤 3

: 点击左侧屏幕上的管理按钮中的“Edit”，然后点击“Copy” **(1)** 



步骤 4

: 点击你想要将复制的铺装面添加到的机场区域，这将放置一个白色光标 **(2)**。按需调整后，再点击“Paste”

## 在铺装面内创建孔洞

<a id="6.1.6"></a>
<a id="616"></a>
<a id="6.1.6"></a>
<a id="616"></a>
### 6.1.6

步骤 1

: 通过点击铺装面上或附近来选择铺装面 *(或者使用矩形选择工具 - 参见上方的 [2.1.6](../2.-user-interface/2.1-editor-screen.md#2.1.6))*



步骤 2

: 如果附近有多个铺装面，你可能需要从下拉框中选择铺装面。铺装面的轮廓会变为洋红色，以表示它已被选中 **(1)**



步骤 3

: 点击“Modify Shape” **(2)**，然后点击屏幕右侧编辑按钮中的“Create Hole” **(3)** 



步骤 4

: 点击你想要创建孔洞的铺装面区域 **(4)**，第一个节点将被放置



步骤 5

: 继续点击以添加节点 **(5)**，一旦放置了三个或更多节点，就会创建一个孔洞，你可以继续添加更多节点以创建所需的形状



![Image 6.1.6.1 - Creating a Hole within the Pavement](../../../_images/manual/frames/5.1.6.1.png)

### 12A.1.1

审核员团队的目的如下：

- 协助 Scenery Editing Team 的日常运作
- 为个别 Editors 提供领导和/或指导
- 将机场分配给 Apprentice 等级的 Editors
- 通过 “Official Review” 流程审查编辑质量*
- 并管理 Scenery Editing Team 的 Discord 频道



**Reviewers **不应**{.red}** 在未获得 Editors 明确同意的情况下，在 Official Review 流程中代表 Editors 上传更改，目的是促进 Editors 的技能提升并尊重 Editors 的工作，除非 Official Review 流程中发现的问题较小、并非持续存在，而且若由该机场的 Editor 自行修复，这些问题不会被认为值得为该机场重新进行一轮 OR。轻微问题的示例包括未正确吸附的线条、建筑物和/或跑道，以及具有一个或多个不准确属性的线条。建议 Reviewers 结合所审查机场的规模和复杂程度，凭判断来评估所发现问题的一致性与严重程度。例如，在 KLAX 出现 3 条未正确吸附的线条不会是多大的问题，但在一个小型 GA 机场就会是。若 Reviewer 确实决定在 Official Review 流程中代表 Editors 上传更改，应当提供所做更改的摘要，最好附上截图，以尊重 Editors 的工作。*



为执行这一点，Reviewers 将被加入 Discord 中的以下频道：

| 频道           | 目的                                                      |
| ---------------- | ------------------------------------------------------------ |
| #reviewer-info      | 仅供 Staff 和 Moderators 在此频道发布日常内容（如例行事务） |
| #reviewers        | 此频道用于在任何被认为有必要的情况下，促进所有 Reviewers 之间的交流 |
| #review-status    | 此频道用于发布机场审查的进度（包括开始、完成，以及更改已提交并随后重新审查时） |
| #role-assignments | 此频道供 Airport Moderators 和 Reviewers 在 #help-request 中创建新工单时为通知分配或取消分配自己 *(见上文 [1A.1.2](../1a.-administration/1a.1-discord-communication.md#1A.1.2))* |
| #navigation       | 此频道用于跟踪对 Infinite Flight 的 ILS 源文件所做的更改，该文件位于另一个独立的 GitHub 仓库中 |

### 12A.1.2

Reviewers 由 Airport Moderators 根据多项标准选出，包括但不限于：



- 在 Scenery Editing Team 中的当前表现
- 对 Scenery Editing Team 的贡献
- 运营需要
- 和/或在专业环境中协助团队内部事务的能力



> 根据 Airport Moderators 的判断，Reviewers 可能因任何原因被降级或移出 Reviewer Team（例如违反信任、滥用权力、缺乏投入等）

### 12A.1.3

Reviewers **不得**{.red} 对任何已根据 Official Review 流程提交审查的机场进行任何修改。必须将反馈提供给 Editor，以便其进行所需更改 *(见上文 [12.1.4](../12.-review-and-release/12.1-review-and-release-process.md#12.1.4))*。



> 如果 Reviewer 认为无需将其作为反馈指出给 Editor，则可以对处于 Official Review 流程中的机场进行非常小的修改

## 如何选择要审核的机场

### 12A.1.1

以下流程说明如何选择一个等待审核的机场：



步骤 1

: 前往 [Dashboard](https://dashboard.infiniteflight.com)，并使用你的 IFC 凭据登录（如有需要，登录通常会自动完成）



步骤 2

: 在屏幕左侧的导航栏中，在 "Scenery Editing" 下选择 "Airports"



步骤 3

: 从顶部导航栏中选择 "Waiting for Review"



步骤 4

: 点击机场右侧的三个点，选择你想审核的机场，然后点击 "Mark as In Review" 将该机场状态更改为审核中



> 机场按最早的机场排在最前。审核员 **should**{.red} 在选择要审核的机场时始终优先选择队列中最早的机场（如有疑问，审核员 **must**{.red} 向其他审核员和机场版主提出）。唯一的例外情况是：
>
> - 审核员可用时间有限，而有一个更小的机场可以在该时间内完成审核，或；
> - 某个机场在仅有轻微修改后重新提交审核，并且同一位审核员可以很快再次完成复审

## 如何审核机场



<a id="12A.1.2"></a>
<a id="12a.1.2"></a>
<a id="12a12"></a>
<a id="12A.1.2"></a>
<a id="12a.1.2"></a>

### 12A.1.2

以下流程说明审核机场时应遵循的顺序：



步骤 1

: 选定机场后，点击右侧三个点，然后选择 "View on Forum"。这会在新标签页中打开该机场当前的主题。审核员 **must**{.red} 在开始审核前确保查看该机场的历史记录（即是否已由其他审核员进行过任何先前审核） 



> 如果审核员对之前的反馈不确定，**should**{.red} 联系上一位审核员以寻求澄清，确保所有反馈保持一致



步骤 2

: 随后，审核员可以对机场进行完整审核，并结合该机场的任何历史记录，确保其符合本手册中规定的标准 *(见上方 [12.2](../12.-review-and-release/12.2-editor-checklist.md#12.2-editor-checklist))*



步骤 3

: **must**{.red} 在 IFC 机场帖子中给出反馈，以便留有记录



步骤 4

: 审核完成后，返回 [Dashboard](https://dashboard.infiniteflight.com)，并使用你的 IFC 凭据登录



步骤 5

: 在屏幕左侧的导航栏中，在 "Scenery Editing" 下选择 "Airports"



步骤 6

: 从顶部导航栏中选择 "In Review"



步骤 7

: 点击正在审核的机场右侧三个点，然后根据需要将机场状态更改为相应选项（即 "Needs Changes" 或 "Ready for Release"）



> 所有标记为 "Ready for Release" 的机场都会包含在应用的下一次更新中；因此，审核员 **must**{.red} 确保机场质量没有任何疑问

## 如何将机场分配给学徒

### 12A.1.3

以下流程说明如何将机场分配给一名学徒：



> 在某些情况下，编辑也可能需要手动分配机场（例如，如果该机场之前已分配给另一位编辑）。在这些情况下（通常是同一机场由多位编辑协作的情况），可以遵循以下流程



步骤 1

: 前往 [Dashboard](https://dashboard.infiniteflight.com)，并使用你的 IFC 凭据登录



步骤 2

: 在屏幕左侧的导航栏中，在 "Scenery Editing" 下选择 "Editors"



步骤 3

: 从顶部导航栏中选择 "Apprentices"



步骤 4

: 使用搜索功能定位该编辑。点击右侧三个点，然后选择 "Manage Assignments"



步骤 5

: 在搜索栏中输入 ICAO 机场代码，然后点击 "Update"



> 除非该机场已提交进行 Official Review，否则学徒 **must not**{.red} 同时被分配超过一个机场。学徒可以在等待其正在审核的机场反馈期间，分配并开始编辑下一个机场，但在收到反馈后，**must**{.red} 优先完成当前机场的修改

## 如何将学徒晋升为编辑



<a id="12A.1.4"></a>
<a id="12a.1.4"></a>
<a id="12a14"></a>
<a id="12A.1.4"></a>

<a id="12a14"></a>
### 12A.1.4

以下流程说明如何将一名学徒晋升为编辑：



> 所有学徒在晋升为编辑之前，**must**{.red} 至少完成两个机场（即已提交进行 Official Review 且已被标记为 "Ready for Release"）。之后，何时晋升学徒由审核员自行决定。需要注意的是，一旦晋升，他们在选择新的机场进行编辑时将不再需要分配。审核员 **should**{.red} 在晋升前结合以往反馈、学徒对反馈的接受情况以及整体判断进行考虑。审核员 **must**.{red} 在晋升学徒编辑前考虑其他审核员的意见。



步骤 1

: 前往 [Dashboard](https://dashboard.infiniteflight.com)，并使用你的 IFC 凭据登录



步骤 2

: 在屏幕左侧的导航栏中，在 "Scenery Editing" 下选择 "Editors"



步骤 3

: 从顶部导航栏中选择 "Apprentices"



步骤 4

: 使用搜索功能定位该编辑。点击右侧三个点，然后选择 "Promote from Apprentice"

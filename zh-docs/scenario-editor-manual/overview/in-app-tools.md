## Scenario Explorer

访问

: 在飞行模拟器中的某个场景里，打开 Systems -> SCENARIO CONTROL

这可以让你查看**每一步**以及当前步骤。查看 Completion Conditions，你可以看到它们是否匹配，或者期望值与实际值是否不同。

## State Explorer

访问

: 在飞行模拟器中的某个场景或自由飞行中，打开 Systems -> STATE EXPLORER

你可以实时查看 Infinite Flight 中的每个状态。这还会显示：
 - 当前值
 - 单位（如果可用）
 - 如果该状态只是 _可读_（不能编辑），则显示 `r`
 - 如果该状态可读且 _可写_（可以编辑），则显示 `rw`

你可以使用搜索来查找特定状态。

**注意：** 状态是按飞机分别保存的。请确保你场景中的飞机与在 State Explorer 中查看状态时所使用的飞机一致。

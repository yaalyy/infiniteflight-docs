以下是 Scenario Editor 值得了解的一些高级功能。

<a id="Translations"></a>
<a id="translations"></a>
<a id="Translations"></a>

## 翻译

Scenario Editor 支持 Infinite Flight 支持的所有语言内容。目前任何文本输入都需要英文字符串，但你可以按下 "Edit" 按钮旁边的 "Translate" 按钮来打开语言编辑器。

**语言是可选的，但目前仍需要英文。**

#### 使用 AI 翻译

Infinite Flight 提供了一个实验性的 **Translate with AI** 选项。只需输入英文文本，我们就会使用 GPT3.5 尝试用地道的技术术语和符合语言习惯的表达来翻译这些句子。欢迎就此提供任何反馈。

## 文本转语音音频

当你使用 Azure 的 Text to Speech 引擎为每种语言上传 Scenario 时，我们会自动为每个步骤生成文本转语音音频。欢迎就此提供任何反馈。

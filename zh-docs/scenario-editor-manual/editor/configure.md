## 飞机与涂装

**这是必填项，否则场景的其余部分将无法配置。** 这是因为状态是针对特定飞机的。

这将决定用户首次开始场景时可用的飞机和涂装。

说明
: 如果该飞机仅对 Pro 订阅用户开放，那么该场景也只会对 Pro 订阅用户可用。

## 开始信息

**这是必填项。**

你必须上传一个状态文件，其中包含在 Infinite Flight 中放置飞机并准备开始场景所需的信息。操作如下：

步骤 1

: 在 Infinite Flight 中开始飞行，并配置飞机（姿态、速度、自动驾驶、NAV 等）。

步骤 2

: 前往系统菜单并点击 `Save`

步骤 3

: 将你保存的 .pbf 文件传输到你正在运行 Scenario Editor 的设备上

步骤 4

: 上传状态文件。你可以根据 Editor 中显示的信息来验证其是否正确。

步骤 5

: 在右上角点击 `Upload Changes` 以保存它，并将其作为场景的一部分包含进去。

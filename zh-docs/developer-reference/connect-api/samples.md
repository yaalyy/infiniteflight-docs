# Connect API 示例

下面你可以找到一系列不同语言的示例，帮助你开始使用 Connect API。我们欢迎贡献，请在 Infinite Flight Community 上给 [@Cameron](https://community.infiniteflight.com/u/cameron) 或 [@KaiM](https://community.infiniteflight.com/u/kaim/) 发消息，并附上你的项目链接。

这些示例采用了不同的许可证，因此在自己的项目中使用之前，请先查看许可证条款。

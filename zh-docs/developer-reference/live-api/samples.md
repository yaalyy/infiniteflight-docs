# Live API 示例与客户端库

下面你可以找到各种语言的一系列示例，帮助你开始使用 Live API。目前支持的语言有 PHP、NodeJS、Kotlin 和 C#，但我们欢迎更多贡献。只需 Fork 并在 GitHub 上向 [velocity23/infiniteflightlive-samples](https://github.com/Velocity23/infiniteflightlive-samples) 提交 Pull Request，或者在论坛或 Discord 上联系我们，将你的项目添加进来。

- [NodeJS](https://github.com/Velocity23/infiniteflightlive-samples/tree/master/NodeJS)
- [C#](https://github.com/Velocity23/infiniteflightlive-samples/tree/master/C%23)
- [Kotlin](https://github.com/A-FitzGerald/InfiniteLiveKt)（感谢 @A-FitzGerald）
- [PHP](https://github.com/Velocity23/infiniteflightlive-samples/tree/master/PHP)
- [Python](https://github.com/robinb748/InfiniteFlight-LiveApi)（感谢 @SPEEDBIRD101）
- [Swift](https://github.com/sqeezelemon/SwiftyLiveApi)（感谢 @sqeezelemon）
- [Go](https://github.com/sqeezelemon/golive)（感谢 @sqeezelemon）

⚠️

: 此 API 仅用于模拟飞行，不得用于真实世界的飞行情境。

# 6.12  雷达引导

 

<a id="6.12.1"></a>
<a id="6121"></a>
<a id="6.12.1"></a>
<a id="6121"></a>
### 6.12.1    

雷达引导主要用于将航空器引入机场的 VFR 进近航线。管制员**应当**{.red}将航空器引导至一个可识别的位置（例如 downwind、base 等），并在移交给 Tower 之前，将航空器下降到航线高度（见下表）。当航空器在雷达引导后呼叫时，Tower **必须**{.red}发布航线进入许可、排序（如需要），然后再发布着陆许可。如果当前使用的跑道具有仪表进近（ILS 或 GPS），管制员可以将航空器引导至 localizer，但**不得**{.red}直接放行执行进近，而应移交给 tower，由其发布航线进入许可、排序（如需要），然后再发布着陆许可。



| 航空器类型 | 航线高度 |
| ------------- | ---------------- |
| 螺旋桨机      | 1000ft AAL       |
| 喷气机        | 1500ft AAL       |

 

<a id="6.12.2"></a>
<a id="6122"></a>
<a id="6.12.2"></a>
<a id="6122"></a>
### 6.12.2    

管制员**必须**{.red}核查其正在对航空器实施雷达引导的机场的机场标高，以便确定正确的航线高度；并且一如既往，**必须**{.red}将周边地形纳入考虑。



<a id="6.12.3"></a>
<a id="6123"></a>
<a id="6.12.3"></a>
<a id="6123"></a>
### 6.12.3    

如果相关机场的天气低于 VMC（见上文 [3.4](../3.-tower/3.4-pattern-work-transitions-flight-of-xx.md#3.4-pattern-work-%2F-transitions-%2F-flight-of-xx)），则**必须**{.red}将航空器引导至该机场的仪表进近（ILS 或 GPS），然后在一个允许航空器独立建立落地仪表进近的高度和位置将其移交给 Tower/Unicom。在这种情况下，不需要下降到航线高度，但**应当**{.red}指定一个合适的高度，以考虑其相对于机场和 G/S 的位置（见上文 [6.11.4](6.11-instrument-landing-system-(ils)-approach.md#6.11.4)）。

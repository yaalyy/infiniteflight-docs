## 什么是 ILS 进近？

<a id="6.11.1"></a>
<a id="6111"></a>
<a id="6.11.1"></a>
<a id="6111"></a>
### 6.11.1    

ILS 由两条信标组成：航向道（Localizer，LOC），提供横向引导（左/右）；以及下滑道（Glideslope，G/S），提供纵向引导（上/下）。



<a id="6.11.2"></a>
<a id="6112"></a>
<a id="6.11.2"></a>
<a id="6112"></a>
### 6.11.2  

跑道末端的锥标为飞行员和管制员提供了一个**视觉辅助**，用于指示 LOC 和 G/S 的位置，不过需要记住的是，LOC 和 G/S 并不局限于锥标内。LOC 和 G/S 是独立发出的无线电“信号”，因此会持续向外传播。飞机可以接收这些信号，因此可以截获它们 - 无论是在锥标内还是在锥标外。

## 截获 LOC 和 G/S

<a id="6.11.3"></a>
<a id="6113"></a>
<a id="6.11.3"></a>
<a id="6113"></a>
### 6.11.3   

要截获 ILS 的 LOC，管制员**应当**{.red}发布一个截获航向 *(例外情况见下方 [6.11.5](6.11-instrument-landing-system-(ils)-approach.md#6.11.5))*；该航向**应当**{.red}尽可能接近 30 度，并以跑道编号为基准偏置 *(见下方 6.11.3.1)*。截获航向需要为飞机提供良好的切入角，以便尽快进入 LOC，因此应避免使用 10 度或更小的角度。尽管用于确定截获航向的标准方法**应当**{.red}基于跑道编号（例如，对于 RWY 27，30 度截获将是 240 和 300 航向，如下图所示），但如果实际跑道航向被认为与此有明显差异，管制员可能需要考虑实际跑道航向（例如 KMIA RWY 08R 的实际航向为 092，因此理想的截获航向将是 060 或 120 度）。 



![Image 6.11.3.1 - Intercepting the localizer](../../../_images/manual/graphics/atc-intercept-loc-v2.jpeg)



<a id="6.11.4"></a>
<a id="6114"></a>
<a id="6.11.4"></a>
<a id="6114"></a>
### 6.11.4    

要截获 ILS 的 G/S，管制员**必须**{.red}发布一个低于 G/S 轨迹的高度 *(见下方 6.11.4.1)*。典型的 G/S 采用 3 度下滑角，引导飞机飞向跑道入口。距离 1nm 时，G/S 高度约为 300ft AAL（高出机场标高）；距离 2nm 时为 600ft AAL，依此类推。 



![Image 6.11.4.1 - Intercepting the glideslope](../../../_images/manual/graphics/atc-intercept-gs.jpg)



<a id="6.11.5"></a>
<a id="6115"></a>
<a id="6.11.5"></a>
<a id="6115"></a>
### 6.11.5

如果飞机提交的 STAR 和/或仪表进近满足以下任一条件，管制员可以在合适的位置发布 ILS 进近许可，而无需指定截获航向：



- 包含一个合理的*与最终进近航迹的截获角，或者
- 在距离 20nm 或更远处接入延长下滑航线



在所有情况下，在飞机稳定建立于航向道之前，仍**必须**{.red}指定一个合适的高度，作为最低许可高度。如果管制员对某机场特定 ILS 进近图有较高熟悉度，即使超出上述两种条件，仍然可以在不指定截获航向的情况下发布许可。要这样做，管制员**必须**{.red}已经熟悉该仪表进近程序，并能够通过目视判断飞机何时已建立。如果不确定，管制员**应当**{.red}选择发布向量 *(见上方 [6.11.3](6.11-instrument-landing-system-(ils)-approach.md#6.11.3))*。



**合理**是指任何类似于通常约 30 度的截获角，和/或能够让飞机顺利转入最终进近而不会遇到困难的角度*

## 确定截获高度

<a id="6.11.6"></a>
<a id="6116"></a>
<a id="6.11.6"></a>
<a id="6116"></a>
### 6.11.6  

如前所述 *(见上方 [6.11.2](6.11-instrument-landing-system-(ils)-approach.md#6.11.2))*，锥标是管制员可用于 ILS 或 GPS 进近的有用**视觉辅助**。锥标的标准长度约为 11nm，因此该位置的 G/S 高度约为 3500ft AAL。虽然这有助于确定用于截获的最佳高度，但还会受到以下因素影响：

 

 -    地形

 -    飞机位置

 -    机场标高

 

为确保飞机从下方截获 G/S，管制员**必须**{.red}使用低于截获点 G/S 的高度 *(见上方 [6.11.4](6.11-instrument-landing-system-(ils)-approach.md#6.11.4))* - 按惯例，这通常低 500ft，但这并不是硬性规定。例如，A 机场标高为 1000ft，因此锥标末端的 G/S 高度约为 4500ft。假设飞机在锥标末端截获，那么 4000ft 将是一个合理的截获高度（假设除机场标高外没有其他地形影响）。如果飞机要在锥标之外更远处截获，甚至在锥标内截获，则需要调整截获高度，以确保飞机在截获时不会高于 G/S。如果在管制前没有实际飞过该进近和/或使用进近图，将很难确定能够确保地形间隔且截获良好的最佳高度！

## 平行运行



> 仅应将平行运行的缩小间隔应用于正在执行 ILS 或 GPS 进近的飞机



<a id="6.11.7"></a>
<a id="6117"></a>
<a id="6.11.7"></a>
<a id="6117"></a>
### 6.11.7

管制员**必须**{.red}确保飞机持续满足 IFR 间隔标准 *(见上方 [6.2.2](6.2-separation.md#6.2.2))*，直到它们稳定建立于 LOC 或横向引导上 *(见下方 [6.14.2](6.14-handover-to-towerunicom.md#6.14.2))*。一旦建立，在与平行跑道对正的飞机之间就不再需要继续应用 IFR 间隔标准。



<a id="6.11.8"></a>
<a id="6118"></a>
<a id="6.11.8"></a>
<a id="6118"></a>
### 6.11.8

在平行运行期间，横向间隔总会先丧失，因此在截获过程中只能依赖垂直间隔。如果管制员识别出两架或多架在最终进近中将处于“平行”状态的飞机，应**遵循**以下两个步骤，以确保满足上述间隔要求：

- 确保所有相关飞机在你准备放行进近的高度上都处于**平飞**状态，并且至少相差 1000ft（理想情况下在基转之前完成）
- 让所有飞机以相互对齐的方式截获 LOC 或横向引导。这意味着在所有飞机都建立于 LOC 或横向引导之前，没有任何飞机开始沿 G/S 或纵向引导下降（这可能会破坏垂直间隔）



**示例：**

在下图 *(见下方 6.11.8.1)* 中，两架飞机都在截获前保持平飞（一架在 3000ft，另一架在 4000ft）。左侧示例中，飞机会在到达 G/S 之前先建立于 LOC。然而在右侧示例中，两架飞机没有以相互对齐的方式截获 LOC，因此原本处于 4000ft 的飞机已经截获 G/S 并开始下降。随后，在两架飞机都建立于 LOC 之前，垂直间隔就丧失了！

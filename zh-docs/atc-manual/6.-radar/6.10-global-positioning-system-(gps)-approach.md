# 6.10  全球定位系统（GPS）进近

### 6.10.1

全球定位系统（GPS）进近是 IF 中的一种非精密进近，但由于当前功能有限，并不常用。不过，如果飞行员请求此类进近，管制员**应**{.red}尽量在交通允许时予以配合。GPS 进近由一系列航路点和高度限制组成，飞行员将沿其飞向跑道入口，不依赖诸如 localizer/glideslope 等传统引导。



<a id="6.10.2"></a>
<a id="6102"></a>
<a id="6.10.2"></a>
<a id="6102"></a>
### 6.10.2

当飞行员请求 GPS 进近且该请求已被管制员批准时（或者如果 GPS 进近是由管制员发布的），管制员可以预期航空器将继续按其 FPL 飞行（如果之前已编排了不同的进近，则按新的 FPL 飞行）。在适当的时机（例如 base），放行航空器执行 GPS 进近。**不应**{.red}要求向量、指派高度和/或截获，飞行员应按照其飞行计划飞至跑道入口。



提示

: 如果飞行员编辑了其飞行计划（例如移除了 missed approach 段），可能会删除显示其具有已发布程序的前缀。管制员**应**{.red}在这种情况下自行判断，如果该程序看起来正确，仍可批准 GPS 进近



<a id="6.10.3"></a>
<a id="6103"></a>
<a id="6.10.3"></a>

### 6.10.3

一旦航空器建立好位置（对于某些偏置的 GPS 进近，这可能不会与跑道中心线一致），管制员随后可以在适当情况下将其移交给 Tower/Unicom。



<a id="6.10.4"></a>
<a id="6104"></a>
<a id="6.10.4"></a>
<a id="6104"></a>
### 6.10.4

在以下情况下，管制员可以优先使用向量： 



- 如果某条 STAR 不能引导航空器进入最终进近

- 如果在**当前**交通量下，允许航空器完整飞行其整个飞行计划并不高效

- 或者如果航空器已宣布 missed approach

  

在这些情况下，管制员**应**{.red}至少向航空器提供前往初始进近定位点（IAF）的向量；并且在**所有**情况下，**必须**{.red}确保航空器能够建立进入 GPS 进近的 inbound。只要这一点得到确认，**并且** 观察到的航空器航迹表明可以成功重新加入，便可放行该航空器执行 GPS 进近（*参见上文 [6.10.2](6.10-global-positioning-system-(gps)-approach.md#6.10.2)*）。



**建立 inbound 的定义是一条能够使航空器并入 FPL 的向量，或由管制员发送 "Continue as Filed"，以允许航空器自行前往 FPL*

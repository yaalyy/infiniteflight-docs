# 6.2 间隔



<a id="6.2.1"></a>
<a id="621"></a>
<a id="6.2.1"></a>
<a id="621"></a>
### 6.2.1    

地形间隔：飞机 **must**{.red} 在任何时候都必须保持至少 1000 英尺 AGL（地面以上高度）的地形净空。

 

<a id="6.2.2"></a>
<a id="622"></a>
<a id="6.2.2"></a>
<a id="622"></a>
### 6.2.2    

飞机间隔：飞机 **must**{.red} 在任何时候横向不得小于 3nm，或垂直不得小于 1000 英尺 *(见下方 6.2.2.1。)*



![Image 6.2.2.1 - Aircraft Separation](../../../_images/manual/graphics/atc-aircraft-separation.jpg)



<a id="6.2.3"></a>
<a id="623"></a>
<a id="6.2.3"></a>
<a id="623"></a>
### 6.2.3

如果飞机在初次联络时未满足间隔要求，雷达管制员 **should**{.red} 设法尽快提供该间隔。在满足最低间隔要求之前，任何在低于该要求下继续进行的飞行均由飞行员负责，因此这并不妨碍管制员提供服务（即“预期雷达引导至……”）。



<a id="6.2.4"></a>
<a id="624"></a>
<a id="6.2.4"></a>
<a id="624"></a>
### 6.2.4

防撞告警系统会向管制员提示空中冲突。如果认为告警有效，则管制员 **must**{.red} 立即发布交通告警，并在可行时提供立即的替代航路，以重新建立 IFR 分离最低标准。



| 防撞告警                     | 判定条件            |
| ---------------------------- | ------------------- |
| 红色目标                     | <1000ft 和/或 3nm   |
| 红色目标和声音警报           | <500ft 和/或 1.5nm  |



<a id="6.2.5"></a>
<a id="625"></a>
<a id="6.2.5"></a>
<a id="625"></a>
### 6.2.5

接受 VFR 服务的飞机应当在与其他飞机保持 **最少** 500 英尺垂直间隔的同时，遵循“目视避让”。

## 什么是等待程序？

<a id="6.7.1"></a>
<a id="671"></a>
<a id="6.7.1"></a>
<a id="671"></a>
### 6.7.1    

等待程序对雷达管制员来说是一个非常有用的工具，尤其可以帮助处理以下情况：

 

 -    空域拥挤

 -    需要通过等待来消耗高度的航空器

 -    延迟进场，以便协助清空冗长的离场队列

 -    目的地机场满负荷

 

<a id="6.7.2"></a>
<a id="672"></a>
<a id="6.7.2"></a>
<a id="672"></a>
### 6.7.2 

管制员可以使用机场、定位点或航空器当前位置来设置等待程序。选定后，它会创建一个等待程序，飞行员可以在其地图显示上跟随该程序，同时还会根据所选等待高度自动发出速度指令。



<a id="6.7.3"></a>
<a id="673"></a>
<a id="6.7.3"></a>
<a id="673"></a>
### 6.7.3 

目前，等待程序不会显示在雷达管制员的显示界面上。因此，了解飞行员在接收到等待指令后可能会如何飞行非常重要，包括等待程序的预期飞行路径 *(见下方 6.7.4.1)*，以及等待进入方式的类型 *(见下方 6.7.6.1)*。

## 等待进入方式

<a id="6.7.5"></a>
<a id="675"></a>
<a id="6.7.5"></a>
<a id="675"></a>
### 6.7.5  

等待进入方式有三种，分别是：

 

 -    直入

 -    平行

 -    泪滴形

 

<a id="6.7.6"></a>
<a id="676"></a>
<a id="6.7.6"></a>
<a id="676"></a>
### 6.7.6

如果航空器正如图所示从直入侧接近等待程序 *(见下方 6.7.6.1)*，管制员可以预期该航空器会“直飞”到等待程序的入口点，然后从那里按照标准等待航线飞行。对于平行进入，标准等待航线开始前，预计其飞行路径会类似下方蓝线所示。最后，对于泪滴形进入，预计飞行路径会类似红线所示。

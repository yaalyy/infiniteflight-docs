# 6.1 什么是雷达管制员？

 

提示

: 鼓励新雷达管制员从慢速开始，逐步过渡到更“高流量”的机场。这在高峰时段或活动期间尤为重要

 

<a id="6.1.1"></a>
<a id="611"></a>
<a id="6.1.1"></a>
<a id="611"></a>
### 6.1.1   

尽管雷达席位及其职责非常广泛，但从根本上说，主要有三个目标。它们是：

 

 -    提供飞机与地形间隔

 -    减轻塔台管制员的工作负荷

 -    提供高效的离场、航路和/或进场服务



<a id="6.1.2"></a>
<a id="612"></a>
<a id="6.1.2"></a>
<a id="612"></a>
### 6.1.2

操作雷达频率通常意味着更高的工作负荷，因此在管制员被授予这一特权之前，会进行大量培训 *(see [7.4](../7.-recruitment-and-training/7.4-radar-written-and-practical-tests.md) below)*。在确保遵守间隔规则的同时，仍要从不同方向、不同高度、航向和速度对飞机进行管制，并继续提供高效服务，这些都是造成这种情况的一些原因 *(see 6.1.2.1 below).*


![图片 6.1.2.1 - ATC Center Frequency](../../../_images/manual/frames/atc-center-frequency.png)

**在**开放之前，管制员**必须**确保自己已经制定好管理预期工作负荷的计划。

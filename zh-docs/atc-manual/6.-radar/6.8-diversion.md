# 6.8 改降



<a id="6.8.1"></a>
<a id="681"></a>
<a id="6.8.1"></a>
<a id="681"></a>
### 6.8.1

航空器可在其飞行过程中、处于活动雷达频率时的任何阶段请求改降。ATC 将有能力批准或拒绝该请求，并指示航空器恢复自主导航前往所请求的机场，或预期雷达引导。



<a id="6.8.2"></a>
<a id="682"></a>
<a id="6.8.2"></a>
<a id="682"></a>
### 6.8.2

在繁忙或复杂空域中，为避免飞行员离开该区域时做出不可预测的操作，航空器**应当**{.red}获得雷达引导。一旦离开该区域，可指示航空器恢复自主导航；或者，如果工作负荷允许，管制员也可选择在其辖区范围内为改降机场提供雷达服务。



<a id="6.8.3"></a>
<a id="683"></a>
<a id="6.8.3"></a>
<a id="683"></a>
### 6.8.3

拒绝改降**应当**{.red} *谨慎* 使用，并且仅用于防止改降至不适合的机场，或已达到容量的机场。

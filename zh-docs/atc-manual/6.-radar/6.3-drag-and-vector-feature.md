# 6.3  拖拽和向量功能

 

<a id="6.3.1"></a>
<a id="631"></a>
<a id="6.3.1"></a>
<a id="631"></a>
### 6.3.1    

拖拽和向量功能是雷达管制员可使用的最基本工具之一，**应该**{.red}加以利用。使用此功能时，系统会向管制员显示以下信息：



 -    航向

 -    与飞机当前位置的距离

 -    到达该点所需时间（以飞机当前速度计算）

 -    该点的最高地形高度

 -    以及附近的导航台名称

 

![Image 6.3.1.1 - Drag and Vector](../../../_images/manual/frames/atc-drag-and-vector-manual.png)

<a id="632"></a>
<a id="6.3.2"></a>
<a id="632"></a>
### 6.3.2    

为了确定飞机可飞行的最低安全高度，必须扫描你计划为飞机提供向量引导的预定航路，以查找最高地形。至少，发现的最高地形 **必须**{.red}先向上取整到下一个整千英尺，然后再额外加上 1000 英尺，以满足地形隔离规则 *(见上文 [6.2.1](6.2-separation.md#6.2.1))*。

### 6.3.3

从这张图片 *(见上文 6.3.1.1)* 可以看出，在这次从当前飞机位置到拖拽和向量功能当前所指位置的扫描中，发现的最高地形为 10,800ft。将该数值向上取整到下一个 1000ft，再额外加上 1000ft 以满足地形隔离规则后，这架飞机在该区域 **必须**{.red} 获得的最低高度为 12,000ft。

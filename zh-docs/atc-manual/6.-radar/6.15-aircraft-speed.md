## 指示空速（IAS）与地速（GS）

<a id="6.15.1"></a>
<a id="6151"></a>
<a id="6.15.1"></a>
<a id="6151"></a>
### 6.15.1    

关于指示空速（IAS）与地速（GS）之间的关系，常常存在一个误解。为简明起见，这里不讨论二者差异背后的原因，但最终会影响这种关系的有两个因素：风和高度！ 



<a id="6.15.2"></a>
<a id="6152"></a>
<a id="6.15.2"></a>
<a id="6152"></a>
### 6.15.2    

风：如果有 20kts 的顺风，这意味着除了飞机自身的正常速度外，还有 20kts 的风在推动飞机前进，因此 180kts IAS 会变成 200kts GS。同样地，如果有 20kts 的逆风，这意味着有 20kts 的风在阻碍飞机前进，因此 180kts IAS 会变成 160kts GS。



<a id="6.15.3"></a>
<a id="6153"></a>
<a id="6.15.3"></a>
<a id="6153"></a>
### 6.15.3    

高度：随着飞机高度的增加，IAS 与 GS 之间的差异也会增大。下面是一些非常“粗略”的数值，可供参考。在无风情况下，飞机以 250kts IAS 飞行时：

- 3000ft ~ 260kts GS（+10）
- 6000ft ~ 270kts GS（+20）
- 9000ft ~ 290kts GS（+40）
- 12000ft ~ 300kts GS（+50）



<a id="6.15.4"></a>
<a id="6154"></a>
<a id="6.15.4"></a>
<a id="6154"></a>
### 6.15.4

飞机当前的 IAS（FL280 以上为马赫数）会在打开其信息标签时连同其他数据一并显示；所有速度指令均以 IAS 或马赫数为参考，不过雷达屏幕上显示的是 GS，以帮助管制员了解高度和风的影响 *(见上文 [6.15.2](6.15-aircraft-speed.md#6.15.2) 和 [6.15.3](6.15-aircraft-speed.md#6.15.3))*。

## 马赫数（M）



<a id="6.15.5"></a>
<a id="6155"></a>
<a id="6.15.5"></a>
<a id="6155"></a>
### 6.15.5

IAS 会在 FL280 转换为马赫数，所有速度在该飞行高度层以上均以马赫数表示。下表列出不同机型典型的巡航马赫数范围。管制员 **应当**{.red} 注意，高度和重量会对马赫数产生巨大影响，因此如果要求飞机在下列速度范围之外运行，飞机可能无法照办：



| 类别           | 机型                             | 速度范围（M） |
| --------------- | -------------------------------- | ------------- |
| 涡桨机         | 例如 TBM-930、Dash-8 Q400 等      | .51 - .53     |
| 窄体喷气机     | 例如 CRJ、E-Jet、A320、B737 等    | .75 - .80     |
| 宽体喷气机     | 例如 A330、B777、MD-11 等         | .82 - .85     |

## 速度控制



提示

: 管制员 **应当**{.red} 选择 2-3 个常用速度（例如 250kts、210kts 和 180kts），并在使用时将它们添加到快捷指令标签列表中。使用相同的速度分配有助于标准化进近并管理交通流量！



<a id="6.15.6"></a>
<a id="6156"></a>
<a id="6.15.6"></a>
<a id="6156"></a>
### 6.15.6

向飞机发布速度控制时，管制员 **必须**{.red} 采用以下技巧：



- 在“尾随”情形下分配速度调整时，要补偿接近速度，可以先降低后机速度，或者先提高前机速度 *(见下文 [6.15.7](6.15-aircraft-speed.md#6.15.7))*
- 如有需要，实施具体的速度控制以保持间隔
- 给予足够的时间和距离以完成速度调整（尤其是在更高高度、较大速度差以及飞机处于洁净构型时）
- 确保飞机尽可能长时间保持洁净构型飞行 *(见下文 [6.15.8](6.15-aircraft-speed.md#6.15.8))*



<a id="6.15.7"></a>
<a id="6157"></a>
<a id="6.15.7"></a>
<a id="6157"></a>
### 6.15.7

需要注意的是，如果你只对单架飞机下达了速度分配（而实际涉及多架飞机），这很可能无法提供所需的间隔，例如：



- 如果没有给飞机 #2 设定一个不会超越飞机 #1 的限制，飞机 #1 就不能减速
- 如果飞机 #1 没有收到任何速度控制，飞机 #2 就无法减速以跟随飞机 #1



此外，“调整速度以跟随前机”可能很有用，但不能替代明确的速度指令，因此管制员 **应当**{.red} 谨慎使用。再者，如果在未对前机指定具体速度指令的情况下使用该功能，很可能会导致前机开始主导整个进入机场的流量，管制员 **必须**{.red} 避免这种情况。



<a id="6.15.8"></a>
<a id="6158"></a>
<a id="6.15.8"></a>
<a id="6158"></a>
### 6.15.8

当飞机减速时，可能需要进行构型设置；管制员 **应当**{.red} 避免让飞机减速到必须进行构型设置的位置，直到距触地点 20 条航迹英里以内为止 - 只有在飞机保持较高速度并接近机场时，才能实现高效进近。 



<a id="6.15.9"></a>
<a id="6159"></a>
<a id="6.15.9"></a>
<a id="6159"></a>
### 6.15.9

如果飞机曾处于等待程序中，一旦获准脱离等待程序，速度由其自行决定，除非随后又被分配了速度指令。



<a id="6.15.10"></a>
<a id="61510"></a>
<a id="6.15.10"></a>
<a id="61510"></a>
### 6.15.10

一旦飞机获准进近，速度由其自行决定，除非随后又被分配了速度指令。在这种情况下，管制员 **应当**{.red} 使用“在 X 海里最后进近前保持 XXXkts”的选项 *(见上文 [6.14.4](6.14-handover-to-towerunicom.md#6.14.4))*。

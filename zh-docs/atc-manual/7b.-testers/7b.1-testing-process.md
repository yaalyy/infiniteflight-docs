# 7B.1 测试流程



> 所有 Testers **必须**{.red} 确保“进行中的机场”已隐藏，以保证塔台与学员看到的滑行道网络一致，从而避免混淆（设置 > 隐藏进行中的机场）

<a id="7b.1.1"></a>

### 7B.1.1

所有测试（无论职位）都由 Recruiters 执行，并根据本节提供的材料和/或情景进行。测试情景会因学员而异。这样做是为了确保学员能更好地为 Expert Server 环境中遇到的各种情况做好准备。Recruiter(s) 应谨慎避免反复使用相同的测试情景。只有参与测试的人员**应**{.red}参加（除非事先已获授权用于特定目的）- 不允许旁观者。

### 7B.1.2

当新的 Testers 被选定后，他们将被加入 Discord 中的以下频道：



| 频道         | 目的                                                                 |
| ------------ | -------------------------------------------------------------------- |
| #tests       | Recruiters 会在此频道发布测试的安排和沟通信息 |
| #tester [VC] | 可将此处作为测试参与者的通用休息区，或在测试进行中用于协调操作。所有反馈**应**{.red}仍通过测试主题以书面形式提供 |
| #test-time   | 即将到来的测试的自动通知会出现在此频道。Testers **必须**{.red}对帖子“react”以确认出席。关于测试的进一步沟通将在 *#tests* Discord 频道中该测试的专用线程里进行 |



> 所有测试会话的协调**必须**{.red}按照 Recruiter 的指示在指定线程中进行

### 7B.1.3

维护对本节的熟悉并相应遵守所有流程，是所有 Recruiter(s)、Trainer(s) 和 Tester(s) 的责任。为确保测试以公平的方式进行，Recruiter(s) 提供的所有指示**必须**{.red}遵守。任何不符合 Testing Team 参与者期望的行为，都可能被 IFATC Manager 和/或 IFATC Moderator(s) 视为需要审查并采取适当纪律措施的理由。

### 7B.1.4

下表列出了 Tower 或 Radar 实操测试前（包括测试地点）**必须**{.red}给予 Recruit 的最短通知时间：



| 测试类型 | 最短通知时间 |
| --------- | ------------ |
| Tower     | 无最低要求   |
| Radar     | 24 小时*     |

**如果 Recruiter 与 Recruit 找到双方都能接受的时间，通知时间可以缩短*

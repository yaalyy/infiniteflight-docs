# 7B.3 雷达测试



> 培训员**不得**{.red}在测试站点进行培训（或允许培训在测试站点进行），以避免任何不公平优势 *(参见上方 [7A.2.8](../7a.-trainers/7a.2-training-structure.md#7a.2.8))*

### 7B.3.1

标准雷达测试**必须**{.red}由不超过 8 名测试人员组成，他们从招聘员分配的位置飞入。**应**{.red}尽量错开各飞机从其各自位置的起飞时间，以模拟 Expert Server 上常见的交通流量。在测试过程中，受训者必须根据以下内容接受评估： 



- 进近类型
- 地形间隔
- 航空器间隔
- 时间管理
- 以及复飞/进近失败 *(参见上方 [7.4.6](../7.-recruitment-and-training/7.4-radar-written-and-practical-tests.md#7.4.6))*。 



测试人员**必须**{.red}按照招聘员的指示执行若干列出的机动：



- 至少 ONE 次从测试机场起飞并请求雷达航线
- 至少 THREE 次以全停为目的的入场
- 至少 ONE 次入场，意图在第一次 touch & go 后执行一次雷达航线
- 至少 TWO 名飞行员**必须**{.red}在其 FPL 中嵌入 STAR 以用于测试目的（他们在按这些 STAR 入场时**必须**{.red}请求进近，并相应地接受处理）



进近类型将由招聘员酌情分配。不会对 Center 管制进行测试，不过关于该席位的处理信息将来自培训过程以及相关补充资料。

### 7B.3.2

雷达实操测试**必须**{.red}仅使用预先批准的雷达测试站点，这也适用于因官员被降级（例如从 Officer 降为 Specialist）或为返岗成员而进行的重测。有关地点请参见 *#tests* Discord 频道中的 “Post Guidelines”。

# 1.1 概述



<a id="1.1.1"></a>
<a id="111"></a>
<a id="1.1.1"></a>
<a id="111"></a>
### 1.1.1

欢迎阅读 Infinite Flight 空中交通管制员（IFATC）手册。本手册旨在帮助新加入的管制员以及现有管制员了解 IFATC 程序，同时涵盖 Infinite Flight 上所有管制设施相关的基本原则。**所有管制员都应熟悉本手册，并在其 IFATC 任职期间持续保持熟悉。**{.red} 



必须

: 本手册中使用的 **must**{.red} 或 **must not**{.red} 视为 **强制性要求**，必须严格遵守

应当

: 本手册中使用的 **should**{.red} 或 **should not**{.red} 视为 **建议性内容**，强烈建议遵守

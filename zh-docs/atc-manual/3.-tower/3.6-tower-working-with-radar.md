# 3.6  塔台与雷达配合工作

 

<a id="3.6.1"></a>
<a id="361"></a>
<a id="3.6.1"></a>
<a id="361"></a>
### 3.6.1    

沟通是确保你们协同工作的关键，这样才能提供尽可能好的服务。通常在繁忙时段，雷达管制员会接受培训以使用 **所有** 可用跑道，并在到达之间保持 5nm 的间隔，以便中间插入一次离场。若你担心离场队列正在累积并且需要更多间隔，你 **应该**{.red} 与管制员沟通，但雷达管制员很可能会监控这一情况并相应调整到达流量。你 **不得**{.red} 指定雷达管制员应使用哪些跑道用于到达与离场，**所有** 跑道 **都应**{.red} 使用 *(见下方 [4.2.1](../4.-atis/4.2-remarks-and-notams.md#4.2.1))*。此外，一旦航空器已经交接给塔台，对于仪表进近，跑道变更 **应**{.red} 尽量保持最少。

 

提示

: 当塔台管制员完成本轮执勤并交接给新的塔台管制员时，建议使用相同频率，除非已经与雷达管制员商定了切换后使用的频率 - 这有助于确保管制员交接期间，频率切换快速指令不受影响



<a id="3.6.2"></a>
<a id="362"></a>
<a id="3.6.2"></a>
<a id="362"></a>
### 3.6.2    

跑道盘旋飞行 **必须**{.red} 由塔台负责，且 **不得**{.red} 交由雷达管制员，除非已经决定拒绝跑道盘旋飞行；在这种情况下，处于盘旋飞行中的航空器可以通过交接给雷达管制员，转换为雷达盘旋程序。之后是否接受雷达盘旋飞行，将由雷达管制员根据其工作负荷自行决定（同时也 **应**{.red} 考虑塔台管制员的工作负荷，例如很长的离场排队）。

### 3.6.3    

下表总结了在有雷达服务时，何时使用盘旋入口、排序和放行许可：

 

| 进近类型        | 盘旋入口 | 排序 | 放行许可 |
| ---------------- | -------- | ---- | -------- |
| ILS/GPS          | 否       | 否   | 是       |
| 雷达引导         | 是       | 如需 | 是       |
| 航路跟随         | 是       | 如需 | 是       |
| 目视             | 否       | 如需 | 是       |

> “如需”表示，除非该航空器是第 1 架，否则在发放放行许可之前 **必须** 先进行排序

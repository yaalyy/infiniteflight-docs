# 3.1  间隔

在这些情形下应提供相同的间隔，以防范复飞/复飞返场。



<a id="3.1.1"></a>
<a id="311"></a>
<a id="3.1.1"></a>
<a id="311"></a>
### 3.1.1    

下表概述了 **所有**{.red} 飞机都**必须**{.red} 적용的间隔要求：

| Type                  | Rule                                                         |
| --------------------- | ------------------------------------------------------------ |
| Departure / Departure | 第一架飞机**必须**{.red} 已经离地，第二架飞机*才能开始滑跑起飞 |
| Arrival / Arrival     | 第一架飞机**必须**{.red} 已经离开跑道边缘（不是停止线），第二架飞机才能越过跑道入口线 |
| Departure / Arrival   | 第一架飞机**必须**{.red} 已经离地，第二架飞机才能越过跑道入口线 |
| Arrival / Departure   | 第一架飞机**必须**{.red} 已经离开跑道边缘（不是停止线），第二架飞机才能开始滑跑起飞 |
| Intersecting          | 到达/离场飞机在同一条跑道交叉口上，**必须**{.red} 已经越过交叉口，之后离场飞机才能开始滑跑起飞，或到达飞机才能在交叉跑道上越过入口线。对于跑道虽然没有实际相交，但飞机在起飞和着陆时的飞行路径会相交的延长中心线，也**应**{.red}加以考虑。在这些情况下，也**应**{.red}适用相同的间隔标准 |

**此外，也**应**{.red}考虑飞机类型，例如，如果第一架起飞的是 Cessna 172，而第二架是 Boeing 737；如果只按最小间隔规则执行，737 很可能会非常快地追上 C172，因此在第二架离场前**应**{.red}增加时间间隔，以便留出余量*

### 3.1.2

鼓励预判，并且在适当时**应**{.red}使用。例如，如果一架 Boeing 737 已经获准起飞并正在滑跑，而不是向下一架飞机发出 LUAW 放行，请先判断：基于第一架飞机在第二架飞机准备开始滑跑时应已离地这一假设，直接发出起飞许可是否合适 *(见下方 [3.2.3](3.2-departures.md#3.2.3)。)*



提示

: 已获准起飞的飞机并不保证一定会离地，如有需要，它们可能会中止起飞滑跑。管制员必须持续监控，以确保与其他飞机之间的间隔保持不变（例如，如果同一跑道上的另一架飞机也已获准起飞，则取消其起飞许可）



<a id="3.1.3"></a>
<a id="313"></a>
<a id="3.1.3"></a>
<a id="313"></a>
### 3.1.3    

如果在任何时候看起来可能会失去间隔，管制员**必须**{.red} 主动处理。这一点在“离场 / 到达”序列中尤为重要；可以让到达飞机复飞，但也**应**{.red}考虑是否应向离场飞机“取消起飞许可”，以防离场流量爬升进正在执行复飞的飞机流中 *(见下方 [3.5.4](3.5-exit-runway-go-around.md#3.5.4)。)*



> 一般认为，当飞机速度超过 100kts 时，再要求其中止起飞滑跑已经太晚了



<a id="3.1.4"></a>
<a id="314"></a>
<a id="3.1.4"></a>
<a id="314"></a>
### 3.1.4  

大多数民航飞机的进近速度在 120-150kts 之间。如果管制员需要更大的间隔，可以使用“保持尽可能慢的实用速度”，但在距着陆点 4 英里以内**不应**{.red}使用，因为此时飞机很可能已经处于最终进近速度。此外，管制员在发出该指令前，**还应**{.red}查看相关飞机的地速（GS）/指示空速（IAS），因为飞机可能已经接近最终进近速度。无论飞机位置如何，如果飞机 IAS 过高，这条指令都可能有用，但需要注意两点：

- 如果飞机已经很接近跑道，可能已经太晚，复飞也许是唯一剩下的选择
- 如果你有雷达管制员在场，尽量不要过早让飞机减速，因为他们可能已经在安排一串进近飞机，这样做会对他们的间隔造成不利影响（如果你需要更多间隔且有雷达管制员在场，请告诉他们 - *见下方 [3.6.1](3.6-tower-working-with-radar.md#3.6.1)*）

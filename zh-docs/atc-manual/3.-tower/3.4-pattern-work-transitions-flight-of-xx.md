## 练习起落



<a id="3.4.1"></a>
<a id="341"></a>
<a id="3.4.1"></a>
<a id="341"></a>
### 3.4.1    

练习起落高度为螺旋桨机 1000ft AAL（高出机场标高）和喷气机 1500ft AAL（见下方 3.4.1.1）。建议管制员在开塔前，先在计划管制的机场进行飞行。管制员**必须**{.red}通过以下三个条件评估是否适合进行练习起落：

 

- 必须存在目视气象条件（VMC）才允许进行练习起落 - 仅针对 IF 的目的，这表示最低能见度为 3 statute miles（约 5000 米）
- 航空器**必须**{.red}能够合理地完成标准航线起落；如果由于地形原因无法做到这一点（例如 KASE、LOWI、NZQN 等），则**必须**{.red}拒绝练习起落
- 如果**当前**交通量增加到使管制员无法提供足够服务的程度，则**应**{.red}**暂时**关闭练习起落 - 一旦交通量恢复到可管理水平，管制员**必须**{.red}恢复练习起落

## 穿越



<a id="3.4.2"></a>
<a id="342"></a>
<a id="3.4.2"></a>
<a id="342"></a>
### 3.4.2    

除非航空器受该机场的雷达管制设施管辖，否则航空器**必须**{.red}在穿越塔台管制员空域时申请穿越。对于 Infinite Flight，塔台空域定义为机场周围最直接的一圈/边界，并向上延伸至 5000ft AAL（因此如果机场标高为 1000ft，则塔台空域为 1000ft–6000ft）。

![Image 3.4.2.1 - KDFW 的塔台空域](../../../_images/manual/frames/atc-tower-airspace.png)




<a id="3.4.3"></a>
<a id="343"></a>
<a id="3.4.3"></a>
<a id="343"></a>
### 3.4.3    

穿越**必须**{.red}仅在塔台空域内批准（以上例而言，不得高于 6000ft）。如果塔台管制员在航线起落中有航空器，则**必须**{.red}实施间隔。



<a id="3.4.4"></a>
<a id="344"></a>
<a id="3.4.4"></a>
<a id="344"></a>
### 3.4.4    

以上述示例为例，如果塔台管制员在航线中有 2 架喷气式航空器，且机场标高为 1000ft，则预计它们将在 2500ft 执行航线起落，因此对另一架航空器的穿越**必须**{.red}在仍能让其保持在塔台空域内（最高至 6000ft）的同时，也要为航线中的航空器提供间隔。3000ft 将是可用于为 VFR 航空器提供 500ft 间隔的最低高度，不过建议使用 1000ft 或更高，以满足 IFR 间隔规则（见下方 [6.2](../6.-radar/6.2-separation.md#6.2-separation)）。

## XX 编队飞行



<a id="3.4.5"></a>
<a id="345"></a>
<a id="3.4.5"></a>
<a id="345"></a>
### 3.4.5    

在使用“Flight of XX”呼号管制航空器时，你**必须**{.red}只向领机发送指令，并将整个 XX 编队视为一架航空器。间隔由飞行员负责，而且在进近和着陆期间，它们彼此之间很可能会保持在 ½ 海里间隔内。

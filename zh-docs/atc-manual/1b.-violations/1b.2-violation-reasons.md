### 1B.2.1

下面列出了一些可能导致发出处罚的情形：



 -    未遵循 ATIS 或已发布的 TFR/NOTAM 中广播的程序
 -    未获许可进行推出/滑行
 -    撞上其他飞机/建筑物/物体或滑行进入其中*
 -    在滑行道或草地上起飞/降落
 -    未获许可进入跑道
 -    未获许可起飞/降落
 -    未按给定的顺序执行
 -    未遵循已放行的高度/航向/速度
 -    飞行员在 2-3 次指令后仍不响应**
 -    飞行员发送重复消息或不必要的请求
 -    在频率上刷屏
 -    反复扰乱秩序
 -    使用侮辱性或不合适的呼号/用户名或飞行路径/计划
 -    含有脏话或歧视/种族主义词汇的呼号/用户名
 -    机场环境中速度过高***



**渲染问题可能意味着飞机未看到其他飞机/建筑物/物体，应谨慎确保只有那些明显故意这样做的飞机才会被处罚*



***沿 VNAV 下降的飞机在收到警告后，如果仍不响应 **且** 与其他飞机构成冲突，可能会被处罚*



****导致与其他飞机迅速逼近、失去间隔或空域干扰的速度可被视为“过高”。必须**{.red} 使用良好的判断*



> 战斗机在 10,000 英尺以下且受 ATC 管制时，**不得**{.red} 超过 350KIAS；不过，当飞行员在其他飞机附近，或管制员要求减速时，仍应保持合理速度。若表现出缺乏礼仪，则可因过高速度而报告违规。军用货运飞机同样适用商用飞机的标准速度限制（即在 10,000 英尺以下且受 ATC 管制时，最大 250 KIAS）

### 1B.2.2

下面列出了每个席位可在应用内选择的完整选项（包括飞行员将收到的违规等级）；但是，重要的是要注意，管制员**不得**{.red} 通过选择某个原因来决定飞行员获得 2 级还是 3 级违规。每项违规都与特定等级绑定，因此管制员**必须**{.red} 选择正确的原因，并让系统自动决定发出哪一级违规：



+++ 地面

| 原因                                                 | 违规等级 |
| ---------------------------------------------------- | -------- |
| 阻塞活动滑行道                                       | 2        |
| 未经许可越过等待线                                   | 2        |
| 未经许可进入跑道                                     | 3        |
| 未遵循 ATIS                                         | 2        |
| 未遵循 TFR                                          | 3        |
| 未让行                                             | 2        |
| 不合适的呼号                                         | 3        |
| 未按指令执行                                         | 2        |
| 刷频 - 不必要的重复请求                               | 2        |
| 未经许可滑行                                         | 2        |
| 穿过草地或航站区滑行                                  | 2        |
| 滑行穿过其他飞机                                     | 2        |
| 与前方飞机距离过近                                   | 2        |
| 无法通信                                             | 不适用     |
| 在爬升、下降或机动时无响应                             | 2        |

### 7A.2.3

以下是塔台或雷达新成员完整培训流程的摘要：



+++ 塔台/雷达新成员

步骤 1

: 前往 [Dashboard](https://dashboard.infiniteflight.com)，并使用你的 IFC 凭据登录（如有需要，登录通常会自动完成）



步骤 2

: 在屏幕左侧的导航栏中，在 “IFATC” 下选择 “ATC Recruits”



步骤 3

: 从顶部导航栏中选择 “Training Waitlist”



步骤 4

: 所有等待培训的成员都会被列出，成员可通过点击与该成员同一行中的黄色人物/加号按钮被接受为学员（Trainer **应**{.red}在接受前考虑该成员的时区，以确保时间可行）



步骤 5

: 要查看学员的 “ATC Recruitment” 档案，请返回 “ATC Recruits” 页面，然后从顶部导航栏中选择 “In Training”，再勾选 “Show Only My Recruits” 复选框以筛选列表



步骤 6

: 点击与你想要选择的学员同一行中的紫色箭头按钮



步骤 7

: 此操作将打开其 “ATC Recruitment” 档案



>对于雷达学员，Trainer **必须**{.red}在学员准备好进行雷达实操测试时通知指定的 Recruiter

## 培训课程

<a id="7A.2.4"></a>

### 7A.2.4

在预定课程开始前，Trainer **必须**{.red}在成员的 ATC Recruitment 档案中使用 “Add Session” 功能（并确保在 “Type” 下选择了 “Training Session”）。这会向用于飞行员的 *#training-time* Discord 频道发送自动通知。一旦为该课程确定了具体使用的频道，之后所有协调**应**{.red}仅在该频道中进行。



> 通知会在开始时间前 30 分钟发送，除非该课程是在少于 30 分钟的提前通知下添加的，在这种情况下通知将立即发送

### 7A.2.5

在对学员表现进行复核之前，允许的最大培训课程数量如下：

| 学员类型 | 最大培训课程数 |
| ------------ | ------------------------- |
| 塔台        | 15                        |
| 雷达        | 20                        |

达到课程上限后，培训团队将审查整体进展，以确定是否已准备好参加测试、是否需要终止，或者是否会安排更多课程以达到认证所需的技能水平。

<a id="7a26"></a>
### 7A.2.6

Trainer 保留在任何时候终止培训的权利 *(见上方* *[7.1.4](https://infiniteflight.com/guide/atc-manual/7.-recruitment-and-training/7.1-overview#7.1.4)* *)*，但**应**{.red}在终止前与学员的 Recruiter 沟通，因为这可能影响学员加入 IFATC 的资格（如果已在 IFATC 内，则可能影响未来晋升）。通常会执行两次违规政策，在出现错误时给予学员合理怀疑的机会，不过申诉可由培训团队管理员和/或 IFATC 经理根据具体情况进行审查。



终止原因可能包括（但不限于）：



- 未能回应或与其指定 Trainer 沟通
- 未能参加已安排的培训课程
- 对反馈不接受和/或态度不佳

### 7A.2.8

以下列表列出了雷达培训推荐机场（鼓励 Trainer 定期轮换使用每个地点）。Trainer **不得**{.red}在测试地点进行培训（或允许培训在那里进行），以避免任何不公平优势 *(见下方 [7B.2.1](../7b.-testers/7b.2-tower-testing.md#7b.2.1) 和 [7B.3.2](../7b.-testers/7b.3-radar-testing.md#7b.3.2)）*：



+++ 初级机场

**位置：KSBP（海拔 212ft）**

| RWY  | 进近类型 |
| ---- | ------------- |
| 07   | GPS           |
| 11   | ILS           |
| 25   | GPS           |
| 29   | GPS           |

> 机场附近地形较少（东侧地势较高，但不构成因素）。单 ILS 跑道配置



**位置：NZAA（海拔 23ft）**

| RWY  | 进近类型 |
| ---- | ------------- |
| 05R  | ILS           |
| 23L  | ILS           |

> 机场附近地形较少。单 ILS 跑道配置，建议使用 23L 跑道。非常适合用于 STAR 管理入门训练

+++



+++ 中级机场

**位置：PHOG（海拔 53ft）**

| RWY  | 进近类型 |
| ---- | ------------- |
| 02   | ILS           |
| 05   | GPS           |
| 20   | GPS           |
| 23   | GPS           |

> 机场东侧和西侧地势较高。对于 RWY05 目视进近，建议将流量引导至 RWY02 的右侧下风，并在 RWY02 到达航班之间插入，或者直接将其引导至 RWY05 的左侧下风。学员必须掌握何时将飞机转入基准腿/最后进近，以保持与地形的间隔



**位置：SKRG（海拔 7027ft）**

| RWY  | 进近类型 |
| ---- | ------------- |
| 01   | ILS           |
| 19   | GPS           |

推荐 STAR：KORB1A（北）、OPME1A（西北）和 MATR3A（南）

> RWY01 左/右侧下风存在高地形。非常适合用于地形意识、高海拔机场以及 STAR 管理的入门训练



+++ 高级机场

**位置：LFMN（海拔 12ft）**

| RWY  | 进近类型               |
| ---- | --------------------------- |
| 04L  | ILS                         |
| 04R  | ILS                         |
| 22L  | GPS（建议仅目视） |
| 22R  | GPS（建议仅目视） |

推荐 STAR：PERU6R（西北）、ABDI6R（西）和 ABLA6R（西）

> 机场北侧、东北侧和西侧地势较高。由于平行跑道距离较近，建议使用交错进近技术。西南向跑道构型可用于高级目视进近训练



**位置：MMMX（海拔 7316ft）**

| RWY  | 进近类型 |
| ---- | ------------- |
| 05L  | GPS           |
| 05R  | ILS           |
| 23L  | ILS           |
| 23R  | GPS           |

推荐 STAR：AVSA1C（北）和 TIKE1C（西北）

> 机场周围地势高。建议 RWY05R 使用 6 海里短最后进近，采用左侧下风并在 San Mateo（SMO）VOR 转弯。非常适合用于飞机速度管理和高海拔机场训练



**位置：OAKB（海拔 5876ft）**

| RWY  | 进近类型 |
| ---- | ------------- |
| 11   | GPS           |
| 29   | ILS           |

> 左/右侧下风存在高地形，且该区域内有多个高峰。地形意识至关重要，也为课前规划提供了良好的训练机会

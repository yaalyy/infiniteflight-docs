### 7A.1.1

培训团队（Trainers）负责在其各自的管制学习领域内对个人进行教育和培训，确保其具备通过测试的准备，并维持高标准的管制水平。

<a id="7a.1.2"></a>

### 7A.1.2

Trainers **must**{.red} 在接收 Trainee 之前确保所有要求都已满足。在存在歧义的情况下，本手册优先于任何相互冲突的信息。对于 Trainee 的具体情况（或既定指南的任何可能豁免）不确定的 Trainers，**must**{.red} 向 Recruiter 咨询以获得最终裁定。

### 7A.1.3	

培训团队成员仅依据过去服务表现及当前作为 Controller 的技能水平，以择优方式选拔。择优标准包括但不限于：



- 社区服务

- 良好的行为表现

- 对本手册的全面理解

- 以及在选拔时其他适当的考量

  

任何被考虑的 Controller **must**{.red} 至少持有 Officer 军衔，方可符合资格（这是为了确保培训计划的所有组成部分都能被教授）。

### 7A.1.4

当新增 Trainers 时，他们将进入为期 30 天的试用期，在此期间 Trainer **must not**{.red} 在任何时刻同时接收超过 3 名 trainees（这样做是为了让 Trainers 决定该角色是否适合自己，并避免在覆盖出现缺口时产生人员配置问题）。

### 7A.1.5

作为培训团队的代表，Trainers **must**{.red} 以专业的方式行事，体现团队及其每天提供的服务。如果未达到预期，Trainers 可能会被降职或移出培训团队。

### 7A.1.6

当选出新的 Trainers 时，他们将被加入 Discord 中的以下频道：



| 频道           | 用途                                                         |
| -------------- | ------------------------------------------------------------ |
| #leadership-hq | 此频道将作为所有领导角色的只读公告频道。需要时，讨论提示将在线程中进行 |
| #tests         | Recruiters 将在此频道发布测试的分配与沟通信息 |
| #tester [VC]   | 该频道可供测试参与者作为一般休息区使用，或在测试进行中用于协调操作。所有反馈 **should**{.red} 仍应通过测试主题以书面形式提供 |
| #test-time     | 即将到来的测试的自动通知会出现在此频道。Testers **must**{.red} 对帖子“react”以确认出席。有关测试的进一步沟通将在 *#tests* Discord 频道中该测试对应的专用线程里进行 |
| #trainers      | 培训团队内部协调的主频道 |
| #training      | Trainers 将使用此频道为每个安排好的培训会创建主题。培训会目标、任务与反馈都将在这里提供 |
| #training-time | 当 Trainers 需要 pilots 加入培训会时，他们会在此频道发帖。可参加该场次的 pilots 可以对帖子“react”以表示出席。如果所有可用名额已满，Pilots **must not**{.red} 对请求“react” |
| #training [VC] | 该频道可供参与者作为一般休息区使用，或在培训进行中用于协调操作。所有反馈 **should**{.red} 仍应通过培训主题以书面形式提供 |



> 所有测试会话的协调 **must**{.red} 按照 Recruiter 的指示在指定频道中进行

### 7A.1.7

Trainers 与其 Trainees 之间使用 VC 进行协调 **must**{.red} 遵循第 1A 节 - 管理 *(see [1A.1.4](../1a.-administration/1a.1-discord-communication.md#1a.1.4) and [1A.2.2](../1a.-administration/1a.2-discord-rules.md#1a.2.2) above)*。其用途是通过会话进行一对一培训，但也可用于在会话前后进行简报/复盘，或用于一般性的 Trainer/Trainee 会议。该方式完全自愿，并由 Trainer 和 Trainee 自行决定。

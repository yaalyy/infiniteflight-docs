# 7D.2 违规

### 7D.2.1

Supervisors 被授予以飞行员身份发出违规的权限，以履行其管理 Infinite Flight Expert Server 的职责。



<a id="7D.2.2"></a>
<a id="7d.2.2"></a>
<a id="7d22"></a>
<a id="7D.2.2"></a>

<a id="7d22"></a>
### 7D.2.2

以下是一些可能适合行使此权限的情况示例：

- 没有秩序的无人在管机场
- 明显违反 Expert Server 规则
- IFATC 管制员未执行指令的环境



<a id="7D.2.3"></a>

### 7D.2.3

对于明显且严重到 Expert Server 上的飞行员已受到其他飞行员行为负面影响的违规，**必须**{.red} 发出违规。

在没有管制员的情况下，穿过其他飞机滑行、降落到其他飞机上方/未复飞、在受管制环境中速度过快，以及/或其他明显可辨识的干扰行为，都是发出违规最常见的原因。

<a id="7d.2.4"></a>

### 7D.2.4

可按以下流程发出违规：



步骤 1

: 在地图/小地图中点击飞机图标



步骤 2

: 飞行员的呼号/显示名称将出现，点击它以打开信息选项卡



步骤 3

: 点击举报按钮并选择最合适的原因

### 7D.2.5

飞行员可以在 7 天内通过 IFC 上的 @appeals 对其违规提出申诉 *(见上文 [1B.3.1](../1b.-violations/1b.3-incident-resolution-procedure.md#1b.3.1))*。强烈建议 Supervisors 在此期间保留其会话回放，以便在需要时处理查询。Moderators、Appeals Team 和/或 IFATC Manager 保留对申诉裁定的最终决定权。

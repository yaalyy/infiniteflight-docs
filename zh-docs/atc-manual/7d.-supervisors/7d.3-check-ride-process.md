# 7D.3 考核飞行流程

### 7D.3.1

当一名管制员进入“Check Ride”阶段时 *(参见上文 [1A.7](../1a.-administration/1a.7-check-ride-process.md#1a.7-check-ride-process))*，每当该管制员开启一个频率时，系统都会向 *#supervisors* Discord 频道发送一条自动消息。作为“Check Ride”阶段的一部分，监督员**应当**{.red} 尽量观察和/或为正在接受考核的管制员进行飞行，这样做是为了确保其达到一定的质量标准，并具备适当的改进水平。

### 7D.3.2

在参与管制员的会话后，以下流程概述了如何提交反馈：



步骤 1

: 进入 *#supervisor* Discord 频道，并点击 Infinite Flight Bot 为你希望提供反馈的管制员提供的“Give Feedback”按钮



步骤 2

: 这将打开“Give Checkride Feedback”文本框，可在其中添加任何反馈内容



步骤 3

: 完成后，点击“Submit”按钮

### 7D.3.3

在管制员试用期结束时，IFATC Manager 将审核监督员在“Check Ride”会话中提交的反馈 *(参见上文 [1A.7.6](../1a.-administration/1a.7-check-ride-process.md#1a.7.6) 和 [1A.7.8](../1a.-administration/1a.7-check-ride-process.md#1a.7.8))*。将作出决定，如有必要会重复进行。

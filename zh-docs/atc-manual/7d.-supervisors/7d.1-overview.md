### 7D.1.1

监督员团队的目的是协助 IFATC 的日常运营，为个别管制员提供领导和/或指导，通过 “Check Ride” 流程监督管制质量，并管理 Infinite Flight Expert Server。



为实现这一目标，监督员将被添加到 Discord 中的以下频道：

| 频道           | 目的                                                         |
| -------------- | ------------------------------------------------------------ |
| #leadership-hq | 此频道将作为所有领导角色的只读公告频道。必要时，讨论提示将以线程形式进行 |
| #supervisors   | 此频道用于促进所有监督员之间在任何被认为必要的事项上的沟通 |

### 7D.1.2

监督员由 IFATC 经理根据多项标准选出，包括但不限于：



- 在 IFATC 内的当前表现
- 对 IFATC 的贡献
- 运营需要
- 和/或 在专业环境中协助内部团队事务的能力



> 监督员可能因 IFATC 经理认为的任何原因（例如：失去信任、滥用职权、缺乏投入等）而被降职或移出监督员团队。

### 7D.1.3

监督员**必须**{.red}通过满足最低活动要求来保持熟练度 *(见上文 [1A.5.1](../1a.-administration/1a.5-activity-requirements.md#1a.5.1))*。因不活跃而被移出 IFATC，也将导致监督员职务被取消。

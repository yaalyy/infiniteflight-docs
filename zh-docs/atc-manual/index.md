## 指南版本：25.1.0



欢迎阅读 Infinite Flight 空中交通管制员（IFATC）手册。本手册旨在帮助新加入的管制员和现有管制员了解 IFATC 程序，并涵盖 Infinite Flight 上所有管制设施相关的基本原则。**所有管制员都应熟悉本手册，并在加入 IFATC 期间持续查阅。**{.red}



必须

: 在本手册中使用 **must**{.red} 或 **must not**{.red} 视为 **强制性**，并且要求严格遵守。

应当

: 在本手册中使用 **should**{.red} 或 **should not**{.red} 视为 **建议性**，并且**强烈建议**遵守。

# 7E.2 上诉流程



> 涉及当前 IFATC 的所有违规 **必须**{.red} 由 IFATC Manager/Moderators 处理 *(参见上文 [1A.8.2](../1a.-administration/1a.8-disciplinary-and-suspension-procedure.md#1a.8.2))*

### 7E.2.1

以下违规 **不应**{.red} 被撤销：

- 1 级违规，因为这些是系统生成的（除非所提供的证据能够表明根本原因是技术问题 - *参见上文 [7E.1.2](7e.1-overview.md#7e.1.2)*）
- 发生在用户离开设备期间的违规
- 与网络/设备问题相关的违规

### 7E.2.2

申诉 **应**{.red} 按先到先服务的原则处理，以便尽可能迅速地为用户找到解决方案。按照惯例，一旦上诉团队成员开始处理某个申诉，就由该成员负责确保找到解决方案并完成申诉关闭。不过，如果另一名团队成员随后有空，并发现有机会加快流程，则这是允许的，但他们 **应**{.red} 确保先与最初分配的团队成员沟通，以避免混淆情况。

### 7E.2.3

以下流程说明了申诉 **必须**{.red} 如何处理。如果上诉团队成员认为需要例外，他们可以在愿意的情况下事先咨询 Staff/IFC Moderators：



步骤 1

: 用户可通过发起一个公开主题，或在 IFC 上向 *@appeals* 组发送直接消息来发起 2 级/3 级违规申诉 *(参见下文 [7E.2.5](7e.2-appeals-process.md#7e.2.5))*



步骤 2

: 滚动到私信底部，点击 "Assign" 来分配给自己（如果使用移动设备，点击 "Topic Controls"，然后从下拉列表中选择 "Assign"）



步骤 3

: 输入你的 IFC 用户名并点击 "Assign"（如果误操作，可以用相同方法点击 "Unassign" 取消分配）



步骤 4

: 如果用户尚未提供，请要求其提供所有相关信息，这可以通过若干模板回复来完成 *(参见下文 [7E.2.7](7e.2-appeals-process.md#7e.2.7))*



> 当请求补充信息时，必须给予用户 72 小时回复时间。如果工作量允许，IFC Moderators 可以在申诉上设置 72 小时计时器；如果未收到回复，申诉将自动关闭。如果系统没有自动关闭，上诉团队成员仍需主动请求 IFC Moderator 关闭该申诉



步骤 5

: 成功审查违规所需的最低信息包括：呼号和/或用户标识、接收日期/时间、管制员姓名、回放/截图（如适用）以及场景详情 - **超过 7 天的违规不符合申诉条件，但由上诉团队酌情决定时，仍可进行审查**{.red}



提示

: 在审查回放时，除了使用 "Map and Messages" 和 "States" 标签页外，你还可以点击地图上的飞机并选择 "Show Details for [callsign]" 来查找用户信息



步骤 6

: 然后使用申诉请求中提供的所有可用工具、视角和媒体来审查申诉。随后决定维持还是撤销该违规，并将申诉结果通知用户（当违规有充分理由且不会影响他人，或用户的资料状态良好时，可谨慎地撤销该违规）



+++ 决定 - 维持违规

- 先感谢他们发送回放
- 可以考虑指出该用户为何被判定违规。这将为你的决定建立基础
- 描述导致违规被判定的事件经过
- 补充你可能注意到的其他问题
- 最后以礼貌的方式告知他们申诉被驳回，并尽可能提供资源（例如 User Guide、Video Tutorial、Community Topics 和/或对正确流程的说明），以防未来再次出现类似违规

+++



+++ 决定 - 撤销违规

- 先感谢他们发送回放
- 如果回放显示用户在违规前已按指示操作，或者其行为未对其他用户造成负面影响（且他们对该情况保持礼貌和理解），则可以移除该违规
- 如果是 ATC 的责任，请代表管制员为造成的不便致歉
- 在控制面板中移除该违规并添加适当备注，然后通知用户重新启动 Infinite Flight 应用以使撤销生效

> 如果这是一次礼节性撤销，上诉团队成员 **必须**{.red} 明确说明这是一次“一次性”提供的处理

+++



> 如果该违规被维持且用户是 IFATC 成员，必须通知 IFATC Manager 或 Moderators，以便进一步采取纪律处分 *(参见上文 [1A.8.2](../1a.-administration/1a.8-disciplinary-and-suspension-procedure.md#1a.8.2))*

### 7E.2.4

申诉完成后，上诉团队成员 **必须**{.red} 按以下步骤将申诉 "Archive"：



步骤 1

: 在 [IFC](https://community.infiniteflight.com) 中打开该消息 *(与下文 [7E.2.7](7e.2-appeals-process.md#7e.2.7) 的步骤 1 - 5 相同)*



步骤 2

: 通过滚动到私信底部并点击 "Unassign" 来取消自己的分配（如果使用移动设备，点击 "Topic Controls"，然后从下拉列表中选择 "Unassign"）



步骤 3

: 在私信底部选择 "Archive"



步骤 4

: 该消息将被发送到 Appeals Archive，之后如有需要可在未来访问



> 除非用户在申诉最终决定后继续发送消息，或已经超过 72 小时仍未收到回复 *(参见上文 [7E.2.3](7e.2-appeals-process.md#7e.2.3))*，或用户具有攻击性 *(参见下文 [7E.3.2](7e.3-escalation-process.md#7e.3.2))*，否则申诉不需要被 "closed"（"archiving" **应**{.red} 已足够）

### 7E.2.5

如果在添加 *@appeals* 团队时，发出违规的管制员已经在场，并且已经清楚说明了违规原因（且你也能看出这些理由是成立的），则无需额外输入，除非：

- 用户尚未接受这一决定并请求复核
- 和/或 管制员已要求上诉团队介入

如果在申诉时该管制员不在 topic/PM 中，除非被认为绝对必要，否则 **不应**{.red} 添加。任何未参与申诉的人都 **必须**{.red} 通过请求 IFC Moderator 将其移除。如果需要管制员提供意见，上诉团队成员 **应**{.red} 私下联系并提出请求。 



> 如果你发现自己就是发出该违规的管制员，你 **应**{.red} 让另一名上诉团队成员处理该申诉，以提高透明度

### 7E.2.6

以下流程说明了如何撤销违规：



步骤 1

: 访问 Appeals Administrator Dashboard（链接可在 *#appeals* Discord 频道中找到）



步骤 2

: 从导航栏中选择 "Users"，然后输入用户信息以搜索其资料



步骤 3

: 要访问用户资料，请选择与其用户信息同一行中的 "Profile" 下方箭头



步骤 4

: 从导航栏中选择 "Violations"，然后滚动查找你想要撤销的违规



步骤 5

: 勾选对应复选框，然后滚动到页面顶部并选择 "Delete" 以移除它。任何被撤销的违规都会提示上诉团队成员输入原因（例如：*"Violation Reversed: User performed go-around as instructed and was not given ample time to react"*）。 



> 必须记录用户备注，以便监测潜在的用户趋势、上诉团队行动，并识别重复违规者。如果由于任何原因未添加用户备注，**必须**{.red} 提请 IFC Moderator 注意，以便更正

### 7E.2.7

下面列出了可在 IFC 上发送的不同模板。上诉团队成员 **应**{.red} 尽可能经常使用这些模板，以便为用户提供标准化体验，不过在某些情况下，可能有必要发送这些模板之外的消息，或对其进行自定义：



| 模板                               | 推荐用途                                                     |
| ---------------------------------- | ------------------------------------------------------------ |
| Appeals - 1st - Replay Request         | 如果尚未发送回放文件                                          |
| Appeals - 2nd - Correct Template Reply | 如果原始消息包含处理申诉所需的全部信息 *(参见上文 [7E.2.3](7e.2-appeals-process.md#7e.2.3))* |
| Appeals - Sending Options Only         | 如果你不想发送完整的 "Replay Request" 消息，和/或已经与用户进行过对话，可以发送一条包含 "Sending Options Only" 的自定义消息 |
| Appeals - Violation Removal            | 如果违规已被移除                                             |



步骤 1

: 登录 [IFC](https://community.infiniteflight.com)



步骤 2

: 点击右上角的头像



步骤 3

: 依次点击两次消息标签（以信封图标表示）



步骤 4

: 从屏幕左侧的导航栏中选择 "appeals"（如果你使用的是移动设备，可能需要先选择 "inbox" 才能找到 "appeals" 消息）



步骤 5

: 选择你想要处理的 appeals 消息



步骤 6

: 使用 "reply" 图标，然后选择 "settings cog" 图标



步骤 7

: 选择 "Insert Template"，然后滚动查找你想使用的回复（在 PC 上这会显示在消息界面的右侧）



步骤 8

: 点击对应的 "clipboard" 图标，将消息移入回复窗口，然后即可在发送前进行编辑（如有需要），最后点击 "reply" 发送

### 7E.1.1

Infinite Flight 申诉团队的目标是审查由 IFATC 在 Expert Server 上发出的、用户提出申诉的 [2 级和 3 级违规](../../getting-started-guide/pilot-user-interface/violations.md)。申诉团队成员 **必须**{.red} 考虑所有因素，并根据服务器规则、用户历史记录以及个人 ATC 经验，独立或作为团队决定维持或撤销已发出的违规。 



为执行此项工作，申诉团队成员将被添加到 Discord 中的以下频道：

| 频道           | 目的                                                         |
| -------------- | ------------------------------------------------------------ |
| #appeals       | 申诉团队可在此讨论申诉、流程，并向 Staff 和 IFC Moderators 请求补充意见 |
| #leadership-hq | 此频道将作为所有领导角色的只读公告频道。需要时，讨论提示将在线程中进行 |

### 7E.1.2

在极少数情况下，如果 1 级违规是由于用户控制范围之外的技术问题导致的，则可以对其提出申诉并进行审查 *(见下方 [7E.2.1](7e.2-appeals-process.md#7e.2.1))*



> 会话时长合计达到 50 小时或以上的用户重放 **应当**{.red} 被忽略，并建议用户定期刷新应用。过度使用应用是不被鼓励的，并可能导致无法复现的技术错误

### 7E.1.3

以下规则 **必须**{.red} 始终遵守：



- 申诉团队 **必须**{.red} 始终以专业且尊重的方式沟通，以最能代表 Infinite Flight 作为公司声音的延伸
- 成员 **不得**{.red} 使用任何可能被视为冒犯性的语言，并 **必须**{.red} 保持基本礼貌，以更好地服务于一个极为多元化的用户群体
- 申诉团队成员 **不得**{.red} 在适当频道之外讨论申诉或分享用户重放，以维护用户保密性
- 申诉团队成员 **不得**{.red} 分享 Appeals Administrator Dashboard 的内容；如果发现敏感信息被传播，可能会失去在 Infinite Flight 的服务资格
- 成员 **必须**{.red} 努力保持活跃，以降低每位成员的负担

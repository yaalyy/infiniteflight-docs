# 7.3  塔台笔试与实操测试



> 招募对象**必须**{.red}确保其设备有足够的电量，并且拥有良好/可靠的互联网连接

<a id="731"></a>
<a id="7.3.1"></a>

### 7.3.1    

加入 IFATC 的最低要求、申请说明以及未通过时的重考期限，均列在 IFC 频道 [这里](https://community.infiniteflight.com/t/atc-recruiting/843545)。



管制员**必须**{.red}确保自己在**申请前**满足最低要求。



[立即申请](/joinatc){.button}



<a id="7.3.2"></a>
<a id="732"></a>
<a id="7.3.2"></a>
<a id="732"></a>
### 7.3.2    

招募对象如愿意，可在没有任何培训的情况下，按照 IFC 频道中所述完成完整的招募流程。不过，如果他们希望使用这一资源，培训团队**可以**{.red}提供协助。为确保招募对象确有加入意愿，在招募对象至少通过塔台笔试之前，**不得**{.red}提供培训。



> IFATC 的回归成员如果在离开 IFATC 后 1 年内提交加入申请，则无需完成塔台笔试



<a id="7.3.3"></a>
<a id="733"></a>
<a id="7.3.3"></a>
<a id="733"></a>
### 7.3.3

**当前塔台培训由招募官酌情决定**{.red} 

在成功完成塔台笔试后，招募对象将获得接受培训的选项。如被接受，培训师将在 7 天内与招募对象联系并开始培训。受训者将获得 15 次培训课次。达到 15 次后，培训团队将审查整体进度，以确定是否已为测试做好准备、是否需要终止，或者是否会分配更多课次，以达到认证所需的技能水平。

<a id="7.3.4"></a>
<a id="734"></a>
### 7.3.4    

塔台实操测试中出现的所有航空器**必须**{.red}按照保守航线飞行，并且**不得**{.red}大于波音 757（通航和战斗机同样可接受）。下表列出了塔台实操测试所包含的项目：

 

| 测试项目                  | 所需熟练程度*                                        |
| ----------------------------- | ------------------------------------------------------------ |
| Pushback                      | 能正确识别区域是否清空，以便飞机开始 pushback 机动 |
| Taxi                          | 有效的地面管理、跑道选择（通常基于风向）以及在适当时使用让行指令 |
| Departure                     | 在适当时使用 LUAW 或预期间隔；对仍留在航线中的航空器使用左/右流量 |
| **Aircraft Separation**{.red} | 确保始终遵守间隔最小值，即 Dep/Dep、Arr/Arr、Dep/Arr 以及相交 *(见上文 [3.1.1](../3.-tower/3.1-separation.md#3.1.1))* |
| Runway  Usage                 | 有效利用两条跑道，并在需要时协助跑道变更请求 |
| Pattern                       | 有效的航线管理，包括航线进入（如需要）、排序（如需要）以及放行 |
| Transition                    | 提供过渡指令，使进港航空器保持在塔台空域内，并避开航线中的航空器 |
| Go-Around                     | 主动监控进场航空器之间的间隔，并在需要时使用复飞 |
| Runway  Exit                  | 使用离场跑道指令，并在需要时适当使用 expedite |

**自动不合格：如果红色标记项目未达到要求，则测试将自动判定为不合格。**{.red}

**招募官对测试结果拥有最终决定权（见上文 [7.1.1](7.1-overview.md#7.1.1)）*

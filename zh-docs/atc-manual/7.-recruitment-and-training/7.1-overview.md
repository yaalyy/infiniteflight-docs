# 7.1  概述

 

> 招募者有责任在申请**之前**确保自己符合最低要求。未能做到这一点可能会使招聘申请失效，并且在一段时间内可能不会获准进一步推进

 

<a id="7.1.1"></a>
<a id="711"></a>
<a id="7.1.1"></a>
<a id="711"></a>
### 7.1.1    

招聘团队（Recruiters）有两项主要职责：其一是在招聘过程中管理新加入者以加入 IFATC，其二是负责所有笔试和实操测试，并对测试结果拥有最终决定权（即通过/不通过）。



<a id="7.1.2"></a>
<a id="712"></a>
<a id="7.1.2"></a>
<a id="712"></a>
### 7.1.2    

培训团队（Trainers）负责在各自的研究领域内对个人进行教育和培训，使其成为空中交通管制员，确保测试准备就绪并保持高水平的管制标准。



<a id="7.1.3"></a>
<a id="713"></a>
<a id="7.1.3"></a>
<a id="713"></a>
### 7.1.3    

为便于本手册使用，定义如下：

 

| 定义 | 含义                                                      |
| ---------- | ------------------------------------------------------------ |
| Recruit    | 处于塔台招聘流程中的潜在 IFATC 管制员，或处于雷达招聘流程中的现任 IFATC 管制员 |
| Trainee    | 已分配 Trainer 且正在接受培训的 Recruit |

 

> 管制员的发展是 IFATC 中的关键环节，因此管制员在当前岗位上如果认为自己需要帮助，可随时寻求培训。无论是否正在接受培训，管制员在 IFATC Team 期间都可以期待获得反馈，**并且必须利用这些反馈来提升自己。**{.red}. 

 

<a id="7.1.4"></a>
<a id="714"></a>
<a id="7.1.4"></a>
<a id="714"></a>
### 7.1.4    

所有管制相关内容都会接受培训，但 Trainees **应该**{.red}明确自己希望重点提升的领域，以便更有效地利用分配的时间，为管制员带来更大收益。**Trainer 保留在任何时间终止培训的权利，若其认为 Trainee 没有进展或未表现出所需的投入。**{.red} Trainees **不得**{.red}在任何 24 小时内参加超过 1 次培训会话。



> 尽管培训会话通常持续约 30 分钟，但时长可能会有所变化，因此所有参与者 **必须**{.red} 确保自己在整个会话期间均可参加



<a id="7.1.5"></a>
<a id="715"></a>
<a id="7.1.5"></a>
<a id="715"></a>
### 7.1.5

*#training-time* Discord 频道由 Trainers 用于协调 Trainee 的培训会话，方式是公布需要多少飞行员加入，以及应加入哪个频道。希望通过飞行参与这些培训会话的管制员，可以在 *#role-assignments* Discord 频道中通过对相关角色“反应”来开启通知 *(参见上文 [1A.1.2](../1a.-administration/1a.1-discord-communication.md#1a.1.2))*。 



任何参与培训会话的管制员都应尽可能以最标准、最可预测的方式飞行，以营造良好的培训环境。速度以及爬升/下降率 **必须**{.red} 保持适合终端环境，且管制员 **必须**{.red} 对所有 ATC 指令做出及时/准确的响应。培训会话期间出现扰乱性或分散注意力的飞行员行为将不被容忍，并可能导致被断开连接或被举报。随后将以与 IFATC 中其他违规行为相同的方式处理 *(参见上文 [1A.8.2](../1a.-administration/1a.8-disciplinary-and-suspension-procedure.md#1a.8.2))*。



**商用飞机推荐剖面：**

| 航线阶段  | 速度          |
| -------- | -------------- |
| Downwind | 210 - 250 KIAS |
| Base     | 180 - 210 KIAS |
| Final    | 160 - 180 KIAS |

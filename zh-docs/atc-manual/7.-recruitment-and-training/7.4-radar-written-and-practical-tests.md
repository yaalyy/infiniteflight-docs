# 7.4 雷达书面和实操测试



> 新兵**必须**{.red}确保其设备拥有足够的电量，并且具备良好/可靠的互联网连接



<a id="7.4.1"></a>
<a id="741"></a>
<a id="7.4.1"></a>
<a id="741"></a>
### 7.4.1    

成为 Officer 并随后控制雷达设施的最低要求已在军衔结构中概述 *(见上文 [1A.6.4](../1a.-administration/1a.6-rank-structure.md#1a.6.4))*。此外，他们**必须**{.red}在以下方面表现出高水平的能力：

 

 -    完整掌握本手册的全部内容，并在有明确要求时完全遵守（即使用**必须**{.red}/**不得**{.red}）

 -    能够同时在 Ground 和 Tower 频率上管理大量交通

 -    在大型 Bravo 机场或“枢纽”机场进行管制

 -    在活动、周末和 flashflight 等繁忙时段进行管制



管制员**必须**{.red}确保在**申请之前**满足最低要求。



[立即申请](/joinatc){.button}



<a id="7.4.2"></a>
<a id="742"></a>
<a id="7.4.2"></a>
<a id="742"></a>
### 7.4.2

提交申请后，Recruiter 将对该管制员的表现进行审核。本节中列出的要求 *(见上文 [7.4.1](7.4-radar-written-and-practical-tests.md#7.4.1))* 将帮助 Recruiter 评估该管制员胜任该职位的能力与适配度。如果审核被认为成功，管制员将获得 Radar Written Test。为确保新兵已做好准备，在新兵至少通过 Radar Written Test 之前，**不得**{.red}提供培训。若管制员被认为尚未准备就绪，将安排一段等待期（最少 30 天），在此期间管制员**必须**{.red}努力根据所收到的反馈进行改进。后续审核将持续进行，直到不再对其是否适合该职位存在任何疑问。



<a id="7.4.3"></a>
<a id="743"></a>
<a id="7.4.3"></a>
<a id="743"></a>
### 7.4.3

成功完成 Radar Written Test 后，新兵将被列入“Training Waitlist”，等待分配 Trainer。Officer 军衔的培训是强制性的，并且**必须**{.red}在 Radar Practical Test **之前**成功完成。



<a id="7.4.4"></a>
<a id="744"></a>
<a id="7.4.4"></a>
<a id="744"></a>
### 7.4.4    

Trainer 会将自己分配到新兵的申请上，随后开始 Radar Training。Radar Training 计划将由结构化培训课程组成，旨在教授不同机场环境中的基础雷达原理和技术。受训者将获得 20 次培训课。在达到 20 次课程后，培训团队将审核整体进度，以确定是否已准备好参加测试、是否需要终止，或是否将分配更多课程以达到认证所需的技能水平。



<a id="7.4.5"></a>
<a id="745"></a>
<a id="7.4.5"></a>
<a id="745"></a>
### 7.4.5

在培训过程中，由 Trainer 视适当时机决定；Recruiter 将发放 Radar Practical Test，并在结果上作适当的简报说明 - *见上文 [7.1.1](7.1-overview.md#7.1.1)*。只有在 Trainer 确认受训者已准备就绪后，才会安排 Radar Practical Test。在 Training Server 上进行管制仅在 Trainer 明确许可下才允许 - 只有当受训者已满足晋升为 Officer 的要求 *(见上文 [1A.6.4](../1a.-administration/1a.6-rank-structure.md#1a.6.4))*，并且已经与 Trainer **开始**了 Radar Training 时，才会获得授权。



<a id="7.4.6"></a>
<a id="746"></a>
<a id="7.4.6"></a>
<a id="746"></a>
### 7.4.6    

在培训期间，如果 Trainer 不在场，受训者可能希望寻找其他管制员在 IFATC Server 上飞行雷达航线以获得额外练习。只要受训者获得 Trainer 的许可，即可使用 Discord *#training-time* 频道来尝试寻找有空的管制员。



<a id="7.4.7"></a>
<a id="747"></a>
<a id="7.4.7"></a>
<a id="747"></a>
### 7.4.7

Radar Practical Test 中出现的所有航空器**必须**{.red}按照所提供的雷达服务进行飞行；此外，可以选择任何机型，但**必须**{.red}被认为适合满足培训目标。下表列出了 Radar Practical Test 中包含的项目：

 

| 测试项目                       | 所需能力*                                                     |
| ------------------------------ | ------------------------------------------------------------ |
| **地形间隔**{.red}             | 确保始终与地形保持至少 1000 英尺的间隔 |
| **航空器间隔**{.red}           | 确保始终保持至少 3 海里横向间隔或 1000 英尺垂直间隔 |
| 效率                           | 始终为所有处于雷达管制下的航空器提供高效的进近，尽量减少为将航空器引导至正确进近区域所需的修正，并在适当时使用组合指令（高度和航向） |
| 进近类型                       | 能够提供本手册中所述的所有类型服务，尤其是 ILS/GPS 进近拦截航向时的时机一致性和正确技术（低于 G/S） |
| 复飞                           | 正确使用 missed-approach 指令以及后续引导。主动监控并在航空器针对其所飞进近类型设置错误时使用 go-around |

**自动失败：如果红色标记的项目未达到所要求的能力标准，测试将自动判定失败。**{.red} 

**Recruiter 对测试结果拥有最终决定权（见上文 [7.1.1](7.1-overview.md#7.1.1)）**

### 7.4.8    

在 Radar Practical Test 中表现合格的新兵将被晋升，并进入 Officer Check Ride 阶段 *(见上文 [1A.7.6](../1a.-administration/1a.7-check-ride-process.md#1a.7.6))*。

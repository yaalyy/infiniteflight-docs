# 7.2  IFATC 支持文档

 

<a id="7.2.1"></a>
<a id="721"></a>
<a id="7.2.1"></a>
<a id="721"></a>
### 7.2.1    

IFATC 支持文档是本手册的一系列补充章节，包含各个部门运作所需的相关程序和指南。它们不对公众开放，因此在未事先获得授权的情况下，**不得**{.red} 在相关团队频道之外分享。

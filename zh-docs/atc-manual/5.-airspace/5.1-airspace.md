# 5.1 空域

 

<a id="5.1.1"></a>
<a id="511"></a>
<a id="5.1.1"></a>
<a id="511"></a>
### 5.1.1 

管制空域由其垂直管辖范围、横向边界以及该设施所使用的频率范围所定义。以下是各管制席位的摘要：



| 设施               | 垂直管辖范围         | 横向边界                                             |
| ------------------ | --------------------- | ---------------------------------------------------- |
| Tower              | SFC - 5000ft AAL      | 围绕机场最近的一圈/边界                                  |
| Departure/Approach | SFC - 18,000ft/FL180  | 50nm                                                 |
| Center             | SFC - 60,000ft/FL600  | 白色边界                                             |

> 在特殊活动期间，空域参数和 ATC 管辖范围可能会通过使用 NOTAM 和/或 TFR 进行调整

![Image 5.1.1.1 - Airspace layout](../../../_images/manual/graphics/atc-airspace-layout.jpg)



<a id="5.1.2"></a>
<a id="512"></a>
<a id="5.1.2"></a>
<a id="512"></a>
### 5.1.2 

Departure/Approach 设施旨在服务单个机场或相互接近的一组机场，而 Center 则是一个基于区域的设施，用于填补 Departure/Approach 无线电覆盖范围之外的空白。



<a id="5.1.3"></a>
<a id="513"></a>
<a id="5.1.3"></a>
<a id="513"></a>
### 5.1.3

如果没有终端雷达设施（即 Departure/Approach），Center 管制员可以行使 Departure/Approach 职能，但这**应当**{.red}受到限制，且主要应专注于 Center 管制员职责 *(见下方 [6.6.1](../6.-radar/6.6-center.md#6.6.1))*。



<a id="5.1.4"></a>
<a id="514"></a>
<a id="5.1.4"></a>
<a id="514"></a>
### 5.1.4

特殊用途空域，例如军事活动区（MOAS）、警告区和限制区，以洋红色边界标识。就 Infinite Flight 而言，这些目前不受执行或监控。



<a id="5.1.5"></a>
<a id="515"></a>
<a id="5.1.5"></a>
<a id="515"></a>
### 5.1.5

不同类型的空域使用颜色代码进行定义，以下表格**仅供参考**{.red}：



| 空域类型                        | 颜色代码    |
| ------------------------------- | ----------- |
| Class B                         | 蓝色        |
| Class C                         | 洋红色       |
| Class D                         | 浅蓝色       |
| Terminal Control Area           | 浅绿色       |
| Flight Information Region (FIR) | 白色       |

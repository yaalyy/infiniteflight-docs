# 5.2 守听程序

 

提示

: 在开启某个频率时，管制员**必须**{.red}留出时间让局势稳定下来；例如，不要在飞机最后进近时对其发出“on guard”指令，应让飞机落地并完整完成滑跑，不受打扰


<a id="5.2.1"></a>
<a id="521"></a>
<a id="5.2.1"></a>
<a id="521"></a>
### 5.2.1    

管制员在发送“on guard”消息之前，**必须**{.red}始终先确认飞机当前调谐到哪个频率，以防其正在与其他塔台/雷达席位通信。雷达管制员**也应**{.red}注意飞机的 active/away 状态 *(见下方 [6.6.5](../6.-radar/6.6-center.md#6.6.5))*。以下概述了“on guard”程序适用的时机，飞机**不得**{.red}在这些限制之外被“on guard”：

| 设施               | 垂直和横向限制                         |
| ------------------ | -------------------------------------- |
| Tower              | SFC - 10,000ft AAL 且在 25nm 范围内    |
| Departure/Approach | SFC - 18,000ft AAL / FL180 且在 50nm 范围内  |
| Center             | SFC - FL600 且在白色边界内            |

> 如果机场标高被认为较高，管制员可以自行决定将这一因素考虑在内（例如，机场标高为 5000ft 时，管制员可分别将“on guard”高度/FL 调整 5000ft/FL50）



<a id="5.2.2"></a>
<a id="522"></a>
<a id="5.2.2"></a>
<a id="522"></a>
### 5.2.2

在被“on guarded”之后，应给予飞机合理的时间调谐到该频率，并且如果飞机仍在另一个活动频率上，**不得**{.red}对其进行“on guard”。

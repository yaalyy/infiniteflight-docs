# 2.2  滑行与让行指令的使用

 

提示

: 如果可能，请将航空器发送到当前使用的最近跑道（视交通流量和航空器性能而定）

 

<a id="2.2.1"></a>
<a id="221"></a>
<a id="2.2.1"></a>
<a id="221"></a>
### 2.2.1    

在需要使用“让行”指令时，必须进行主动地面监控。此外，管制员**必须**{.red}监控跑道侵入，并优先向可能与离开跑道的交通冲突的航空器发出“让行”指令。  



提示

: 如果存在冲突，请先发出“让行”指令，然后再发出滑行指令。这样可以确保飞行员在开始滑行**之前**知晓潜在冲突。



<a id="2.2.2"></a>
<a id="222"></a>
<a id="2.2.2"></a>
<a id="222"></a>
### 2.2.2    

“滑行至 RWYXX，准备好时联系塔台”和“滑行至停机位”是管制员在指挥离场/进场航空器滑行时**必须**{.red}使用的默认指令。在可用时，管制员**应**{.red}使用“drag and taxi”功能来发出具体滑行路线。管制员**必须**{.red}对航空器所经过的每条跑道逐一发出穿越许可（且航空器**必须**{.red}先穿越前一条跑道，之后才可发出下一条跑道穿越许可）。



提示

: 在大型且复杂的机场（例如 KORD、EHAM、KJFK 等）中，通常更有效的做法是向中间等待点发出分段滑行指令，而不是一次性给出从停机位到跑道的完整路线（或反之）。



<a id="2.2.3"></a>
<a id="223"></a>
<a id="2.2.3"></a>
<a id="223"></a>
### 2.2.3

对于请求滑行至停机位的进场航空器，管制员**不应**{.red}为其指定具体登机口。停机位的选择**应**{.red}由飞行员决定，并在可能时由 ATC 予以配合。对于请求滑行至停机位但未指定具体位置的航空器，可以通过渐进式指令或 drag & taxi 路线为其提供具体航线，以与其他交通流解冲突；但在所有冲突解决后，**应**{.red}允许其继续前往所需停机位。



<a id="2.2.4"></a>
<a id="224"></a>
<a id="2.2.4"></a>
<a id="224"></a>
### 2.2.4

管制员还可以使用渐进式滑行指令来协助地面移动，包括单向系统、潜在冲突和跑道交叉起飞。管制员**应**{.red}注意，使用此工具时需要**极其密切的监控**，因此**应**{.red}仅在绝对必要时使用它。在使用之前，管制员**应**{.red}向相关航空器发送“Expect Progressive Taxi Instructions”（尽管这并不总是可行），完成后可使用以下指令：

 

 -    穿越跑道 XX

 -    左/右转进入下一条滑行道

 -    继续直行

 -    180 度转弯（管制员**必须**{.red}确保航空器在滑行道上有足够空间完成 180 度转弯）

 -    跟随前方航空器

 -    已获准穿越

 

一旦不再需要渐进式滑行指令，管制员**必须**{.red}发送“按你自行判断继续滑行”。

 

<a id="2.2.5"></a>
<a id="225"></a>
<a id="2.2.5"></a>
<a id="225"></a>
### 2.2.5

如果航空器在收到“滑行至 RWYXX，准备好时联系塔台”后请求更改频率（这种情况通常发生在航空器在跑道前等待时），**应**{.red}使用“frequency change already sent”消息。有时飞行员并未意识到上一条指令已经允许其更改频率。

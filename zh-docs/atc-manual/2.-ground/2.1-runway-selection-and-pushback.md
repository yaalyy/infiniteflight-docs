提示

## 跑道选择 



<a id="2.1.1"></a>
<a id="211"></a>
<a id="2.1.1"></a>
<a id="211"></a>
### 2.1.1    

管制员在开放前 **must**{.red} 熟悉滑行道布局，这包括了解可接受的最大飞机类型，以及该机型是否能够在不限制交通流的情况下实际机动 *(see [4.2.1](../4.-atis/4.2-remarks-and-notams.md#4.2.1) below)*。一旦开放，**must**{.red} 与其他管制员协调以确定起飞和落地使用的跑道，并同时查看机场布局中当前交通的位置。



<a id="2.1.2"></a>
<a id="212"></a>
<a id="2.1.2"></a>
<a id="212"></a>
### 2.1.2    

跑道的颜色（即绿色、琥珀色和红色）仅供参考。你 **must**{.red} 查看 METAR（Meteorological Aerodrome Report）来确定某条跑道的逆风或顺风分量（H/TWC）。你 **should**{.red} 也查看 TAF（Terminal Aerodrome Forecast），它会提供未来数小时预计风向风速的趋势。管制员 **should**{.red} 尽量避免更换跑道，因为这会造成延误。大多数飞机可在高达 10 节的尾风分量下着陆。因此，如果可能，**should**{.red} 在此之前避免更换跑道。

### 2.1.3    

在发出推出许可前，管制员 **must**{.red} 确认区域内没有障碍。如果区域未清空，**must**{.red} 先使用“hold position”或让行指令，然后才能发出推出许可（可以设置提醒，以免忘记该飞机，或者在非常繁忙时使用）。

> 通过查看条带；最早的“hold position”指令会被发送到选项卡底部，从而为谁最先请求推出提供有用的参考

<a id="2.1.4"></a>
<a id="214"></a>
<a id="2.1.4"></a>
<a id="214"></a>
### 2.1.4   

在大多数情况下，由于所有飞机都有推出设备，且停机位配置多种多样，管制员 **should**{.red} 批准飞机首次请求推出或滑行，无论飞机类型或停机位如何。

> 管制员 **should**{.red} 在执管时熟悉机场的停机位配置。例如，飞机能否直接穿过远机位？飞机是否需要推出才能安全离开机位？

<a id="2.1.5"></a>
<a id="215"></a>
<a id="2.1.5"></a>
<a id="215"></a>
### 2.1.5

应尽可能在符合条件的机场使用自动推出和/或尾部位置分配，以为受管飞机确定推出路径和开始滑行的位置。若要暂停正在进行的自动推出，请指示飞机“hold position”。随后再次发出“pushback approved”即表示批准恢复先前分配的自动推出。当不存在冲突时，管制员 **may**{.red} 选择批准不带尾部或自动推出引导的推出。

> 如需修改推出路径，管制员应指示飞机“hold position”，并使用修改后的路径重新发出新的推出许可。

<a id="2.1.6"></a>
<a id="216"></a>
<a id="2.1.6"></a>
<a id="216"></a>
### 2.1.6    

当管制员认为有必要时，**may**{.red} 使用“expect runway xx”；不过，这并不是每次推出许可都必需。

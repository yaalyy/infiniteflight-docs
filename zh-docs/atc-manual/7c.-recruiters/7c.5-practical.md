### 7C.5.1

一旦塔台笔试成功通过，学员即可进入塔台实操测试 *(见上方 [7B.1](../7b.-testers/7b.1-testing-process.md#7b.1-testing-process) 和 [7B.2](../7b.-testers/7b.2-tower-testing.md#7b.2-tower-testing))*。招募员**必须**{.red}确保在双方达成一致后，向学员提供充分通知，包括测试的时间和地点 *(见下方 [7C.1.3](7c.1-overview.md#7c.1.3))*。如果该学员由该招募员培训过，则**应**{.red}由另一名招募员主持测试 *(见上方 [7C.1.4](7c.1-overview.md#7c.1.4))*。

<a id="7c52"></a>
### 7C.5.2

在已安排的测试前，招募员**必须**{.red}在学员的 ATC 招募档案中使用“Add Session”功能（并确保在“Type”下选择“Practical Test”）。这会向飞行员的 *#test-time* Discord 频道发送自动通知。一旦用于该场次的具体频道确定，后续所有协调**应**{.red}仅在该频道中进行。



> 除非该场次是在距离开始时间不足 30 分钟时添加的，否则通知会在开始前 30 分钟发送；如果不足 30 分钟，则通知会立即发送



<a id="7C.5.3"></a>

<a id="7c53"></a>
### 7C.5.3

塔台实操测试结束后，招募员**必须**{.red}将结果告知学员。如果学员未通过，则需要遵守以下等待期：



| 表现        | 重新尝试前的等待期 |
| ----------- | ------------------ |
| 差          | 30 天              |
| 一般        | 14 天              |
| 未确定      | 由招募员酌情决定    |

> 塔台实操测试连续失败三次会导致需要等待 90 天才能重新开始流程。对已安排的测试“未到场”不算一次尝试，但除非给出有效理由（由招募员判定），否则会导致在重新尝试前等待 14 天。再次“未到场”将导致招募流程终止。招募员**必须**{.red}确保将所有内容记录在学员的“User Notes”中 *(见上方 [7C.1.6](7c.1-overview.md#7c.1.6))*。

<a id="7c54"></a>
### 7C.5.4

在塔台笔试和实操测试都通过后，可以邀请学员加入 IFATC Team（当在学员的“ATC Recruitment”档案中点击“Passed Practical”按钮时，此流程会自动执行）。

### 7C.5.5

一旦雷达笔试和雷达培训都成功通过，学员即可进入雷达实操测试 *(见上方 [7B.1](../7b.-testers/7b.1-testing-process.md#7b.1-testing-process) 和 [7B.3](../7b.-testers/7b.3-radar-testing.md#7b.3-radar-testing))*。招募员**必须**{.red}确保在双方达成一致后，向学员提供充分通知，包括测试的时间和地点 *(见上方 [7C.1.3](7c.1-overview.md#7c.1.3))*。如果该学员由该招募员培训过，则**应**{.red}由另一名招募员主持测试 *(见上方 [7C.1.4](7c.1-overview.md#7c.1.4))*。



> 如果学员属于 *#testers* 组，**必须**{.red}在测试开始**前**将其移除。招募员**必须**{.red}提前足够时间在 *#recruiters* 中发帖，以便给版主留出移除该用户的时间 - 测试完成后，可以用同样的方式将其重新加入

雷达实操测试结束后，招募员**必须**{.red}将结果告知学员。如果学员未通过，则需要遵守以下等待期：

### 7C.5.8

在雷达笔试、雷达培训和雷达实操测试都通过后，学员可以晋升为 Officer（当在学员的“ATC Recruitment”档案中点击“Passed Practical”按钮时，此流程会自动执行）。

### 7C.4.1

一旦候选人参加了塔台笔试，最终分数将决定流程是否可以继续。要进入塔台实操测试，**必须达到 80% 或以上的通过分数**{.red}。如果候选人未通过，则需要遵守以下等待期：



| 分数     | 重新参加前的等待期 |
| -------- | ------------------ |
| 00 - 49% | 30 天              |
| 50 - 79% | 14 天              |

> 塔台笔试三次未通过后，需等待 90 天才能重新开始流程。如有必要，可由 Recruiter 和/或 IFATC Manager 酌情修改。Recruiter **必须**{.red}在仪表板上使用“暂停申请”功能，并设置 90 天冷却期（同时确保添加一条说明原因的用户备注）



提示

: 一旦候选人通过塔台笔试，如果愿意，他们将有资格接受培训。Recruiter **必须**{.red}确保候选人知晓这一点 *(参见上方 [7.3.2](../7.-recruitment-and-training/7.3-tower-written-and-practical-tests.md#7.3.2))*。如果培训员认为学员的表现存在问题，并因此终止培训，培训员 **应**{.red}告知 Recruiter。之后，Recruiter 可自行决定这是否会影响该学员加入 IFATC Team 的资格标准 *(参见上方 [7A.2.6](../7a.-trainers/7a.2-training-structure.md#7a.2.6))*

### 7C.4.2

一旦候选人参加了雷达笔试，最终分数将决定流程是否可以继续。要进入雷达培训和雷达实操测试（前提是培训员已批准*），**必须达到 70% 或以上的通过分数**{.red}。如果候选人未通过，则需要遵守以下等待期：



| 分数     | 重新参加前的等待期 |
| -------- | ------------------ |
| 00 - 40% | 30 天              |
| 41 - 69% | 14 天              |

> 雷达笔试三次未通过后，需等待 90 天（但无需重新开始流程，等待期结束后即可继续）



**一旦通过雷达笔试，候选人 **必须**{.red} 完成雷达培训，并获得培训员许可后，才能进入雷达实操测试*

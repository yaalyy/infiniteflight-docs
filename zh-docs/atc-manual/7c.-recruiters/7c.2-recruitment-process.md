### 7C.2.1

以下摘要概述了 Tower 和 Radar 招募的完整招募流程。



+++ Tower 招募

步骤 1

: 前往 [Dashboard](https://dashboard.infiniteflight.com)，并使用你的 IFC 凭据登录（如果需要，登录通常会自动完成）



步骤 2

: 从屏幕左侧的导航栏中，在 "IFATC" 下选择 "ATC Recruits"



步骤 3

: 从顶部导航栏中选择 "Recruit Waitlist"



步骤 4

: 通过点击橙色的 "Assign Yourself" 按钮，选择你想要接受的 Recruit（招募员**应当**{.red}在接受前考虑 Recruit 的时区，以确保时间安排可行）

> 随后，招募员需要向 Recruit 发送一条私信（可通过 Discord 或 IFC 完成）



步骤 5

: 从顶部导航栏中选择 "Written Test"，然后勾选 "Show Only My Recruits" 复选框以筛选列表



步骤 6

: 点击与所选 Recruit 同一行的带箭头符号的紫色按钮



步骤 7

: 此操作将打开他们的 "ATC Recruitment" 资料。从这里，点击 "Assign Written Test"。回归的 IFATC 成员可能不需要完成 Written Test *(见下方 [7C.1.7](7c.1-overview.md#7c.1.7))* 

> 这将自动向 Recruit 再发送一条私信，内含完成 Written Test 所需的说明、链接和唯一测试代码



步骤 8

: 一旦他们完成 Tower Written Test，系统会指示他们在已创建的私信中向招募员发送消息，并提出他们有的任何问题。在通过的前提下，他们也可以请求培训，如果他们希望在继续进行 Tower Practical Test 之前先接受培训，也可以这样做

> 测试结果以及分配培训或 Tower Practical Test 都可以在 "ATC Recruitment" 资料中完成



步骤 9

: 要访问测试结果/请求培训/分配实践测试，请从顶部导航栏中选择 "Written Test"，然后勾选 "Show Only My Recruits" 复选框以筛选列表



步骤 10

: 点击与所选 Recruit 同一行的带箭头符号的紫色按钮



步骤 11

: 此操作将打开他们的 "ATC Recruitment" 资料，在那里可以使用这些选项

+++



+++ Radar 招募

> 对于 radar 认证流程，招募员只需要：
>
> - 审核 Recruit，并在批准其培训前进行 Radar Written Test
> - 以及进行 Radar Practical Test（需经 Trainer 批准）
>
> 招募员**不应**{.red}被要求负责其他功能，但仍保留在必要时终止 Trainee radar 流程的权利



步骤 1

: 前往 [Dashboard](https://dashboard.infiniteflight.com)，并使用你的 IFC 凭据登录（如果需要，登录通常会自动完成）



步骤 2

: 从屏幕左侧的导航栏中，在 "IFATC" 下选择 "ATC Recruits"



步骤 3

: 从顶部导航栏中选择 "Recruit Waitlist"



步骤 4

: 通过点击橙色的 "Assign Yourself" 按钮，选择你想要接受的 Recruit（招募员**应当**{.red}在接受前考虑 Recruit 的时区，以确保时间安排可行）



步骤 5

: 对 Recruit 进行审核，并判断其是否适合该角色



步骤 6

: 从顶部导航栏中选择 "Written Test"，然后勾选 "Show Only My Recruits" 复选框以筛选列表



步骤 7

: 点击与所选 Recruit 同一行的带箭头符号的紫色按钮



步骤 8

: 此操作将打开他们的 "ATC Recruitment" 资料；如果他们已获批准，则可以在此分配 Radar Written Test，否则**必须**{.red}告知他们在再次审核申请前商定的等待时间，以及需要改进的方面

> 招募员需要向 Trainee 发送一条私信，其中包含说明、唯一链接（在点击 "Assign Written Test" 时会复制到你的剪贴板，可直接粘贴到私信中），以及测试代码 *terrainpullup*，以完成 Written Test



步骤 9

: 一旦他们完成 Radar Written Test，系统会指示他们在已创建的私信中向招募员发送消息，并提出他们有的任何问题。在通过的前提下，他们即可开始培训，Trainer 将会通知他们何时准备好进行 Radar Practical Test



步骤 11

: 要访问测试结果/请求培训/分配实践测试，请从顶部导航栏中选择 "Written Test"，然后勾选 "Show Only My Recruits" 复选框以筛选列表



步骤 12

: 点击与所选 Recruit 同一行的带箭头符号的紫色按钮



步骤 13

: 此操作将打开他们的 "ATC Recruitment" 资料，在那里可以使用这些选项

+++

### 7C.2.2

如果以下任一时限被超出，招募员可以将 Recruit 终止出流程（如果他们仍希望加入 IFATC，则需要重新提交申请）：

| 招募阶段                     | 到期时间                  |
| ---------------------------- | ------------------------- |
| 向 Recruit 发送初始消息       | 30 天                    |
| Tower Written Test 代码       | 24 小时                  |
| 通过* Tower Written Test      | 30 天                    |
| Discord 邀请                 | 24 小时（一次性代码）     |

**在通过 Tower Written Test 后，Recruit 有 30 天时间进行第一次 Tower Practical Test 尝试（招募员可自行决定是否延长此期限）***

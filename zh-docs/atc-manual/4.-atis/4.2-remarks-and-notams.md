# 4.2 备注和 NOTAM

 

提示

: 管制员 **应**{.red} 避免在单个 ATIS 中加入过多 REMARKS 和 NOTAMS，因为这会削弱信息效果 - 管制员 **应**{.red} 先问自己哪些信息最重要，并按需要进行优先排序 *(见下方 [4.2.1](4.2-remarks-and-notams.md#4.2.1))*



<a id="4.2.1"></a>
<a id="421"></a>
<a id="4.2.1"></a>
<a id="421"></a>
### 4.2.1

下表强调了何时 **应**{.red} 使用某些 REMARKS 或 NOTAMS：

 

| REMARK  / NOTAM       | 何时使用？                                                   |
| --------------------- | ------------------------------------------------------------ |
| 禁止交叉跑道离场      | 除非会阻塞飞机到达全长跑道入口的唯一滑行道 **并且** 会影响离场/到场流量，否则 **必须**{.red} 始终允许交叉跑道离场 *(见上方 [3.2.5](../3.-tower/3.2-departures.md#3.2.5))* |
| 禁止航线盘旋          | 天气低于 VMC？地形导致无法按标准航线盘旋飞行？**当前** 交通量会导致服务标准下降？当满足其中 1 项条件时，**必须**{.red} 使用禁止航线盘旋 *(见上方 [3.4.1](../3.-tower/3.4-pattern-work-transitions-flight-of-xx.md#3.4.1))* |
| Gate Hold             | 应优先使用保持位置 *(见上方 [2.1.3](../2.-ground/2.1-runway-selection-and-pushback.md#2.1.3))*，但如果需要放行一长列离场航班，而滑行道空间有限，可以使用 gate hold（它 **应**{.red} 限制在最多 10 分钟内） |
| No Light Aircraft     | 此命令 **不得**{.red} 用于以通航为主的机场，但在其他任何机场，管制员可根据机场条件（例如通航停机位和机场布局）、当前交通量以及机场值班人员情况自行决定是否使用。管制员 **应**{.red} 尽一切努力在 IRL 会接收轻型飞机的机场接收轻型飞机。<br />轻型飞机定义为 C172、SR22、XCub、Spitfire Mk VIII 和 P38。 |
| Rolling Dept.         | 为加快离场 - 当飞机获准起飞时，预计其会立即进入跑道排队并开始起飞滑跑。即使如此，在存在运行优势时，仍然可以使用 LUAW 命令，例如到场/离场顺序，或第一架飞机起飞滑跑较慢的离场/离场顺序 |
| FPL Required          | 仅在天气低于 VMC 最低标准时使用 *(见上方 [3.4.1](../3.-tower/3.4-pattern-work-transitions-flight-of-xx.md#3.4.1))*，或在必须使用 SID/STAR 时使用 |
| 直飞离场 **           | 起飞后 **必须**{.red} 按跑道航向飞行，直到不存在冲突 **并且** 达到或超过塔台管制员指定的高度 *(见上方 [3.2.8](../3.-tower/3.2-departures.md#3.2.8))* |
| 使用多频率            | *(见上方 [4.1.5](4.1-overview.md#4.1.5))* |
| 查看论坛              | 仅在将飞行员引导至 IFC 页面上的特殊说明时使用，例如 VARB Summit |
| 建议使用 SID/STAR***  | 当交通量较少到中等，且使用 SID/STAR 对流量管理并非必要时，**应**{.red} 使用此命令 *(见下方 [4.2.2](4.2-remarks-and-notams.md#4.2.2))* |
| 要求使用 SID/STAR***  | 当交通量繁忙且使用 SID/STAR 对流量管理至关重要时，**应**{.red} 使用此命令，**或** 用于活动和/或主要枢纽机场 *(见下方 [4.2.2](4.2-remarks-and-notams.md#4.2.2))* |
| 活动                  | 仅限 IF LLC 赞助活动                                 |
| 尺寸限制              | 当由于飞机尺寸会限制机场流量（即阻塞滑行道或机坪区域）而无法容纳任何飞机时，**必须**{.red} 使用此命令 *(见上方 [2.1.1](../2.-ground/2.1-runway-selection-and-pushback.md#2.1.1))* |
| 低能见度              | 低能见度 - 能见度小于 1/4 法定英里（400m） |



***请注意，使用“直飞离场”可能会使飞机无法飞行其所选定的 SID（见上方 [3.2.8](../3.-tower/3.2-departures.md#3.2.8)）*

****仅在机场已公布 SID/STAR 程序可用时使用*

### 4.2.2

管制员可以为机场选择首选的 SID/STAR，并且 **应**{.red} 包含合理多样的授权程序，以允许来自 **所有** 方向的离场/到场。按惯例，这 **应**{.red} 由雷达管制员决定（在其不在场时，塔台管制员可以选择，但不建议这样做）。

# 4.1 概述



<a id="4.1.1"></a>
<a id="411"></a>
<a id="4.1.1"></a>
<a id="411"></a>
### 4.1.1

自动终端情报服务（Automatic Terminal Information Service，称为 ATIS）使管制员能够播报当前天气以及备注和 NOTAM，以便让飞行员及时了解信息。



<a id="4.1.2"></a>
<a id="412"></a>
<a id="4.1.2"></a>
<a id="412"></a>
### 4.1.2

ATIS 播报通过字母拼音字母表中的一个字母来标识。该字母随后会在飞行员与管制员之间传递，以确保所有人都基于相同的机场信息进行运行。任何时候，如果当前 ATIS 未反映实际情况（包括天气变化或正在使用的 SID/STAR 变化），管制员**必须**{.red}立即更改 ATIS，并确保与其他相关管制员进行实时协调。作为**最低要求**，ATIS 至少每小时更新一次。此外，**必须**{.red}在 Ground/Tower/Radar 播报，以确保飞行员查看新的 ATIS。



> 飞行员在联系管制员时会告知他们收到的 ATIS 信息。使用错误 ATIS 标识进行呼叫的飞行员可能会被要求重新核对最新的 ATIS 信息。之后，飞行员需自行承担在提出进一步请求前核对信息的责任。管制员无需在此后再次核实飞行员是否已收到最新 ATIS 信息。



<a id="4.1.3"></a>
<a id="413"></a>
<a id="4.1.3"></a>
<a id="413"></a>
### 4.1.3

更新 ATIS 时使用的字母**必须**{.red}按字母顺序递增，通常从 Alpha 开始，除非该管制员刚从另一位管制员手中接班。



<a id="4.1.4"></a>
<a id="414"></a>
<a id="4.1.4"></a>
<a id="414"></a>
### 4.1.4

**所有**可用跑道**应**{.red}予以使用 - 应尽量避免一条跑道用于起飞、另一条跑道用于着陆的做法。  
然而，在某些机场，地形、机场布局或天气可能会阻止**所有**跑道被使用；在这种情况下，不使用**所有**跑道是可以接受的（如果对于应采用何种策略存在任何疑问，管制员**应**{.red}向 Supervisor 或更高级别人员寻求指导）。



<a id="4.1.5"></a>
<a id="415"></a>
<a id="4.1.5"></a>
<a id="415"></a>
### 4.1.5

当有负责雷达的席位处于活跃状态时，ATIS **必须**{.red}指明当前使用的进近类型（ILS、GPS 或目视进近）。所播报的进近方式**必须**{.red}在程序选择菜单中可用（例如，如果机场播报的是 GPS 进近，那么该机场就必须已发布 GPS 进近）。管制员仍可在操作上更有利时偏离播报的进近方式。仅有塔台的机场也可播报当前使用的进近方式，不过标准航线进入方式将主要决定飞机如何航向着陆跑道。



<a id="4.1.6"></a>
<a id="416"></a>
<a id="4.1.6"></a>
<a id="416"></a>
### 4.1.6

部分机场可以开放多个 Ground/Tower/Radar 频率。这在管理繁忙流量时会很有用。如果要这样使用，管制员**必须**{.red}确保 ATIS 已更新以反映这一点（即应联系哪个频率、从哪个方向接入）；并且应事先与其他管制员完成协调；在管制期间，应使用 IFATC Discord 频道来提供良好服务。

### 1A.1.1    

Discord 是一款供团队使用的即时通讯应用，旨在让工作更简单、更愉快且更高效。有关此应用工作方式的更多信息可在 [这里](https://support.discord.com/hc/en-us) 找到。

### 1A.1.2

 下表概述了各频道及其用途：

| Channel                | Purpose                                                      |
| ---------------------- | :----------------------------------------------------------- |
| #atc-schedule          | ATC Schedule 简报室频道可用于简要说明/规划任何与当天精选机场相关的事项 |
| #announcements         | 仅由 ATC Manager、Staff 和 Moderators 在此频道发布官方 Infinite Flight 更新（例如新的博客更新、ATC Manual 新版本以及 Beta 信息） |
| #botcommands           | 所有 bot 命令 **应当**{.red} 仅在此频道使用。可在此频道输入 *!command* 以显示可用命令列表 *(见下文 [1A.1.3](1a.1-discord-communication.md#1a.1.3))* |
| #controllers           | 所有正常的管制员通信都应在此频道进行。除非**正在积极**值勤，否则 **不应**{.red} 使用此频道。管制员若愿意，在发送开启/关闭消息时可使用本表下方列出的缩写代替完整设施名称 |
| #discussions           | 这是供活跃管制员讨论 IFATC、ATC、Infinite Flight 和航空相关话题的频道。**当前**值勤的管制员 **不应**{.red} 在此频道交谈，除非出于运行上的关键需要 |
| #events                | Events 简报室频道可用于协调官方和非官方活动，例如 FF、GA Day 和直播 |
| #flights               | 此频道用于管制员协调整个编队飞行。所有协调 **应当**{.red} 保留在此频道内 |
| #help-request          | 如果管制员需要在其他地方找不到的支持，可以通过对相关角色作出反应在此频道“提交”工单 *(更多指导见下文 [1A.2.4](1a.2-discord-rules.md#1a.2.4))* |
| #important-info        | 此处包含有用链接以及 **必须**{.red} 通过“反应”接受的条款与条件，之后才能获得进入服务器其余部分的权限 |
| #infinite-flight-rules | 提示 IFATC Discord 服务器规则的查找位置 |
| #offtopic              | 这是用于讨论与 IFATC 或 Infinite Flight 无关内容的频道。所有对话 **应当**{.red} 保持适当。*#offtopic* 是一种特权，若使用不当，所有成员都可能随时被移除。此频道仅供活跃成员使用 |
| #readonly              | 仅由 ATC Manager、Staff 和 Moderators 在此频道发布日常帖子（例如行政事务和特定活动流程） |
| #role-assignments      | 此频道内有一个“通知订阅”菜单 - 管制员可以通过对相应表情作出反应来订阅；当使用提及短语时，管制员将收到通知。使用该提及短语的管制员 **必须**{.red} 仅在必要时使用，以免向其他管制员发送垃圾通知 *(见下文 [1A.3.1](1a.3-controller-rules.md#1a.3.1))* |
| #screenshots           | 这是分享 Infinite Flight 截图的地方（需适度）。不得分享其他模拟器、游戏或与主题无关的内容，且所有截图 **应当**{.red} 具有高质量 |
| #social-media          | 自动发布的官方 Infinite Flight 社交媒体更新。管制员 **不得**{.red} 回复此频道中的任何内容，以便所有管制员都能被有效联系到 |
| #training-time         | 当培训师需要飞行员加入培训课程时，会在此频道发布消息 *(见下文 [7.1.5](../7.-recruitment-and-training/7.1-overview.md#7.1.5))* |



> 当管制员发送开启/关闭消息时，如果他们觉得比使用完整设施名称更方便，可以使用以下字母/缩写：
>
> - G - Ground
>
> - T - Tower
> - S - ATIS
> - A or App - Approach
> - D or Dep - Departure
> - C or Center - Center
>
> 例如："EGLL GTS open"

### 1A.1.4

语音频道（VCs）**必须**{.red} 严格按照 Discord Rules 使用 *(见下文 [1A.2.1](1a.2-discord-rules.md#1a.2.1))*。独立运行机场且没有协助的管制员 **不应**{.red} 占用 VC，除非：

- 控制席位被拆分（例如，在仍然执掌 Tower 的同时，将 Ground 控制移交给另一位成员）
- 有 Radar 管制员在该机场上线
- 和/或所有设施管制员都选择通过 *#controllers* Discord 频道使用 VC 进行沟通

### 1A.1.5

使用 VC **不是必需的**{.red}，完全由管制员自行决定（在某些特定活动中，为保证运行效率，可能要求使用 VC - 如果是这种情况，不愿使用语音的管制员可能需要到其他地方执勤）。希望出于教学目的在 VC 中观察他人的管制员，**仅在** VC 中**所有**运行中的管制员都同意时才可这样做。观察者 **不得**{.red} 干扰正在进行的 ATC 运行，且 **应当**{.red} 保持静音。

### 1A.1.6

要开启 VC，请按以下步骤操作：



Step 1

: 打开 IFATC Discord，并使用屏幕左侧的导航栏找到 "Controlling" 选项卡



Step 2

: 在其下方点击 "Select to Create VC"，系统将创建一个新的 VC，你将成为该频道的所有者。频道将自动以你的 Discord 用户名作为标题



Step 3

: 随后 **必须**{.red} 将 VC 标题更改为合适的*名称，以便其他管制员清楚了解该 VC 的用途 *(见下文 [1A.1.7](https://infiniteflight.com/guide/atc-manual/1a.-administration/1a.1-discord-communication#1a.1.7))* 



**合适的名称应当没有歧义 - 标准或首选命名方式是使用正在管制的机场 ICAO 代码（例如 EGPH）；然而，如果某个 VC 内正在管制多个机场，则可以选择更通用的标题（例如 New York Area、Oceanic Centers、Dubai Flyout Event 等）。*



提示

: 只有 VC 的所有者才能更改名称或用户上限 *(见下文 [1A.1.7](https://infiniteflight.com/guide/atc-manual/1a.-administration/1a.1-discord-communication#1a.1.7))*

### 1A.1.7

以下命令可在 *#botcommands* Discord 频道中用于管理 VC：



| Commands                    | Purpose                                             |
| --------------------------- | --------------------------------------------------- |
| !voice-claim @[username]    | 认领 VC 的所有权                           |
| !voice-limit [number]       | 更改 VC 的用户上限（默认值为 10） |
| !voice-owner                | 告诉你当前 VC 的所有者是谁  |
| !voice-rename [ICAO code]   | 重命名 VC                                       |
| !voice-transfer @[username] | *转移 VC 的所有权                       |

**所有权只能转移给位于该 VC 内的管制员。VC 所有者 **应当**{.red} 确保在离开 VC 之前完成所有权转移，以避免频道被关闭（频道在空置 1 分钟后会自动关闭）*

### 1A.1.8

以下是一些关于 VC 的实用提示：

- 你可以通过查看 [00/10] 频道人数显示，随时了解当前有多少成员在该 VC 中
- 选择 "Mute"（麦克风图标）表示无人能听见你
- 选择 "Deafen"（耳机图标）表示你听不到其他任何人
- 始终仔细检查你的声音设置（即 Input = Mic，Output = Speaker）
- 连接到 VC 的方式很像电话通话，并且在执勤时可以在后台运行

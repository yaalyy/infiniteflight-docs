### 1A.8.1    

不遵守 ATC Manual 的管制员可预期以下处理流程：

 

| 违规次数 | 采取措施                         |
| ------- | ------------------------------------- |
| 第 1 次     | 通过 DM 发出警告                        |
| 第 2 次     | 停权 3 天（Controller & Discord） |
| 第 3 次     | 停权 7 天（Controller & Discord） |
| 第 4 次     | 移出 IFATC Team           |

在任何停权结束后，管制员将以其先前所持有的职级返回。通常情况下，其恢复任职的日期将作为该职级新的起始日期；不过，这将按个案处理 *(这是为了考虑职级升级所需的最低要求 - 参见上方 [1A.6.1](1a.6-rank-structure.md#1a.6.1))*。

### 1A.8.2

如果某位管制员在作为飞行员执飞时被判定为 Level 2 或 Level 3 Violation，IFATC Moderator 将启动对该场次的审查，以确定该违规是否应被维持或撤销。过多的违规或对规则完全缺乏尊重，可能导致 IFATC 停权或永久移除。

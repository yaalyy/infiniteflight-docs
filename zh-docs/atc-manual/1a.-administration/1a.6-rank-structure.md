# 1A.6  职级结构

 

提示

: 当你晋升后，你将可以管制通常流量更大的机场。建议你从较低强度开始，逐步适应新职级下这些“高流量”机场。尤其是在高峰时段或官方活动期间，这一点尤为重要。如果有疑问，在开放前先到 *#controllers* 寻求建议 - 适应繁忙流量需要时间，请**缓慢**开始

### 1A.6.1    

下表概述了当前的职级结构。晋升依据活跃度、表现、反馈，在某些情况下还包括培训和测试：

 

| 职级       | 可用频率               | 是否需要测试                | 考核飞行 |
| ---------- | ---------------------- | ---------------------------- | -------- |
| 学员       | B / C / D / ATIS       | 理论和实操（塔台）          | 否       |
| 专员       | B / C / D / ATIS       | 否                           | 是*      |
| 官员       | Radar / B / C / D / ATIS | 理论和实操（雷达）        | 是**     |
| 主管       | 无限制                  | 否                           | 否       |

**晋升为 Specialist 后，管制员会处于试用期，直到完成 “Specialist Check Ride” 阶段（见下方 [1A.7.4](1a.7-check-ride-process.md#1a.7.4)）*

***晋升为 Officer 后，管制员会处于试用期，直到完成 “Officer Check Ride” 阶段（见下方 [1A.7.6](1a.7-check-ride-process.md#1a.7.6)）*



> 所有管制员都可能因活跃度、表现和反馈而在任何时候被晋升/降级！

### 1A.6.2

这是 IFATC 的入门职级，因此在开放任何机场时，最大到达数为 25 架飞机。学员**不得**{.red} 管制任何直播机场、官方活动机场，或 ATC Schedule 上发布活动的 HUB 机场 *(其他官方活动允许，但另有说明的除外 - 见上方 [1A.4.1](1a.4-airport-selection.md#1a.4.1))*



> 开放后，到达数超过此限制是可以接受的；不过，学员**应当**{.red} 尽量选择合适的机场，同时考虑自己预计管制的时长以及流量增加的情况 *(见上方 [1A.4.1](1a.4-airport-selection.md#1a.4.1) 和 [1A.5.3](1a.5-activity-requirements.md#1a.5.3))*

### 1A.6.3

晋升为 Specialist 职级将按个案处理，而不仅仅依据任职时长。基于这一点，学员管制员**必须**{.red} 避免询问自己何时会被晋升；相反，**应当**{.red} 专注于提供高质量的 ATC 服务。管制员一旦晋升并进入 Specialist Check Ride 阶段，就会收到通知 *(见下方 [1A.7.4](1a.7-check-ride-process.md#1a.7.4))*。

### 1A.6.4

晋升为 Officer 职级仅可通过申请 *(见下方 [7.4.1](../7.-recruitment-and-training/7.4-radar-written-and-practical-tests.md#7.4.1))*，并且必须成功通过 Radar Training 计划，才能获得该职级，并进一步管制雷达设施。

### 1A.6.5

在开始 Officer 职级培训之前，必须满足以下要求：



- 至少在 Specialist 职级停留 60 天

- 全部历史操作次数至少 2000 次

- 作为飞行员参加过总计 10 次训练课程 
  
  _注_: 一旦被接受，受训者作为飞行员参加的训练课程次数，预计至少应与其获得的 ATC 训练课程次数相当
  
- 在过去 30 天内保持活跃的管制记录*，以确保熟练度（这将由 Recruiter 在申请时确定）



**活跃的管制记录通常指每周 2-3 次 ATC 课程*

<a id="1A.6.7"></a>

### 1A.6.7

Supervisor 职级仅在有需要时授予，并且只授予那些在 IFATC 中展现出高标准管制能力和职业操守的管制员。其职责是协助 IFATC 的日常运营，为个别管制员提供领导和/或指导，通过 “Check Ride” 流程监督管制质量，并管理 Infinite Flight Expert Server。晋升为 Supervisor 职级需满足以下前提条件：



- Officer 职级，并在**所有**设施类型/类别上表现出熟练度
- 正确使用举报功能，且无滥用记录
- 熟练的飞行员，以身作则，并按照所有服务器规则飞行
- 良好的 IFATC 记录
- 能够以尊重且专业的方式沟通

### 1A.6.8

除了上述职级结构之外，个人还可能在 IFATC 中担任其他角色。如下所示：



| 职称       | 职责                                                         | 职级             | 违规撤销           |
| ---------- | ------------------------------------------------------------ | ---------------- | ------------------ |
| Appeals    | 处理违规申诉                                                 | N/A              | 是                 |
| Tester     | 参加实操测试                                                 | N/A              | 否                 |
| Trainer    | 培训候选人/管制员                                            | Officer 或以上   | 否                 |
| Recruiter  | 管理招募并执行所有理论/实操测试                              | Officer 或以上   | 仅限与官方测试相关 |
| Moderator  | 管理 IFATC 团队，包括日常运营、质量保证、人员问题、成员违规、表现以及纪律性降级和/或停权 | N/A              | 是                 |
| Manager    | 代表管理所有 IFATC 的 Infinite Flight Staff 团队             | N/A              | 是                 |



> IFC Moderators 存在于 IFATC 团队中，不过 IFATC Moderators 通常会处理大多数日常事务

# 1A.7  考核飞行流程



<a id="1A.7.1"></a>
<a id="1a.7.1"></a>

### 1A.7.1

考核飞行流程用于监控新晋升的 Specialist 和 Officer，需遵循的程序如下：



| Check Ride    | Period  | Max Arrival Count* | Eligibility                                                  |
| ------------- | ------- | ------------------ | ------------------------------------------------------------ |
| Specialist    | 7 天  | 50                 | 参见上方 [1A.6.2](1a.6-rank-structure.md#1a.6.2) |
| Officer       | 30 天 | 50                 | 参见上方 [1A.6.3](1a.6-rank-structure.md#1a.6.3) |
| Prior Officer | 15 天 | 50                 | 参见上方 [1A.6.6](1a.6-rank-structure.md#1a.6.6) |

**在开放时* 

> 考核飞行流程的主要环节之一，是确保在管制员的新角色下仍能保持服务质量。因此，在评估期间，管制员选择合理机场并设定个人限制的能力 **必须**{.red} 达到令人满意的标准，才能完成考核飞行阶段。

### 1A.7.2

当管制员符合晋升为 Specialist 的条件（基于活跃度、表现和反馈）或已经通过 Officer 等级的 Radar Practical Test 时，他们会收到一条 DM，告知其以试用性质获得晋升。管理员和/或监督员会在管制员开台时收到自动通知，能够前往该管制员当前会话并监控其表现。在考核飞行阶段结束时，所有评估将被汇总，并进行最终审查。管制员会被告知是否通过，并在适用时获得反馈。

<a id="1a.7.3"></a>
<a id="1a73"></a>

<a id="1a.7.3"></a>
<a id="1a73"></a>
### 1A.7.3

考核飞行阶段的时长不应超过上述所列期间 *(见上方 [1A.7.1](1a.7-check-ride-process.md#1a.7.1))*，但是如果管理员和/或监督员在其试用期内无法参加管制员的某次会话，只要他们已经遵循了本节中列出的 **所有** 指示，尤其是定期进行管制以最大限度提高被审查的机会，则其试用期将被延长。若不是这种情况，他们将被降回原先等级，并将在适当时候进行后续晋升。

### 1A.7.4

当前处于 Specialist 考核飞行阶段的管制员：

- **必须**{.red} 尽可能管制 Bravo 级别机场（如果 Charlie 级别机场也能提供足够的评估，则可接受）
- **必须**{.red} 定期管制（至少 3 次独立开台）

- **不得**{.red} 管制在开放时总进场数达到 50 或以上的任何设施

- **不得**{.red} 管制任何直播机场、官方活动机场，或 ATC Schedule 中已发布活动的 HUB *(除非另有说明，否则允许其他官方活动 - 见上方 [1A.4.1](1a.4-airport-selection.md#1a.4.1))*



提示

: 与其他管制员分频（例如只管制 Ground）非常受鼓励，尤其是在特色机场

### 1A.7.6

当前处于 Officer 考核飞行阶段的管制员：

- **不得**{.red} 管制任何在开放时总进场数达到 50 或以上的设施（包括 Center）

- **不得**{.red} 管制任何直播机场、官方活动机场，或 ATC Schedule 中已发布活动的 HUB *(除非另有说明，否则允许其他官方活动 - 见上方 [1A.4.1](1a.4-airport-selection.md#1a.4.1))*



> 对于管制员的新角色，期望其能够负责任地履职；循序渐进，确保服务质量优先于数量。

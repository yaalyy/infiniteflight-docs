# 1A.2 Discord 规则

 

提示

: 所有管制员**必须**{.red}确保其 Discord 昵称与其 IFC 用户名或真实姓名一致 - 这意味着在需要时可以轻松找到管制员 *(见下方 [1A.2.1](1a.2-discord-rules.md#1a.2.1))*

## 通用

<a id="1A.2.1"></a>
<a id="1a.2.1"></a>
<a id="1a21"></a>
<a id="1A.2.1"></a>
<a id="1a.2.1"></a>

### 1A.2.1

- 所有管制员**必须**{.red}在执勤**之前**将其 [Community Forum](../../getting-started-guide/home-user-interface/user-profile.md#linking-community-forum-account) 和 [Discord](../../getting-started-guide/home-user-interface/user-profile.md#linking-a-discord-account) 账户关联起来
- 管制员**必须**{.red}确保其 Discord 昵称与其 IFC 用户名或真实姓名一致
- 管制员**不得**{.red}向外部分享任何 IFATC Discord 内包含的 IFATC 资料或对话（包括音频）（除非已事先获得批准）
- 管制员**必须**{.red}对其他用户保持礼貌并遵守基本礼节
- 管制员**不得**{.red}使用任何根据 Infinite Flight 的唯一裁量权可能被视为冒犯性的语言（包括但不限于违法、威胁、粗俗、露骨性内容，或在种族、民族或其他方面令人反感的语言）
- 批评和反馈通常会通过 DM 给予；不过，在某些情况下，如果被认为是管制员群体中的更广泛问题，也可能公开提供

## 语音频道

<a id="1A.2.2"></a>
<a id="1a.2.2"></a>
<a id="1a22"></a>
<a id="1A.2.2"></a>
<a id="1a.2.2"></a>
<a id="1a22"></a>
### 1A.2.2

- 必须始终使用英语
- 语音频道**只能**{.red}由正在与其他管制员实际执勤的成员使用
- 使用语音频道的协调**只能**{.red}在 *#controllers* Discord 频道中进行
- 管制员**不得**{.red}传输任何可能被解释为具有干扰性的内容
- 管制员**不得**{.red}传输任何私人、可识别或敏感信息
- 管制员**不得**{.red}冒充其他用户
- 关于使用 VC 的进一步指导，请参见 Discord Communication *(见上方 [1A.1.4](1a.1-discord-communication.md#1a.1.4))*

### 1A.2.3

成员可随时联系 Staff Member 或 IFC Moderator，以报告严重违反 VC 规则的行为或不安全情况。IFATC 成员的安全和隐私是首要任务。

> 由于 ATC 的性质以及广泛多样的社会规范表现，可能会出现因激动而引发的无意失言，这些情况通常不需要进行管理处分（例如：轻微脏话，以及因突发事件而产生的自然反应）

## 支持

<a id="1A.2.4"></a>
<a id="1a.2.4"></a>
<a id="1a24"></a>
<a id="1A.2.4"></a>
<a id="1a.2.4"></a>
<a id="1a24"></a>
### 1A.2.4

- 首先，管制员**应**{.red}尽一切努力利用可用资源，包括本手册和其他管制员，来寻求支持
- 如果管制员无法找到所需答案，他们可以通过对相关角色进行“回应”，在 *#help-request* Discord 频道中“提交”工单。系统会创建一个新的私密频道，管制员随后可以打开该频道开始对话并获得所需支持
- 等级结构有助于了解 IFATC 中不同角色分别是什么，因此也能判断该向谁提问更合适 *(见下方 [1A.6.1](1a.6-rank-structure.md#1a.6.1))*

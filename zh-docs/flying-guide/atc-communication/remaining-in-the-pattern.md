## 保持在航线中通信摘要

步骤 1

: 选择当前有效的 Tower 频率



![Active Tower Frequency](../../../_images/manual/frames/active-tower-frequency.png)



步骤 2

: 点击“Request Departure”



![Request Departure 2](../../../_images/manual/frames/request-departure-2.png)



步骤 3

: 选择你正在等待放行的跑道，然后点击“Remaining in the Pattern”



![Select Departure Runway 2](../../../_images/manual/frames/select-departure-runway-2.png)



![Send Remaining in the Pattern Request](../../../_images/manual/frames/send-remaining-in-the-pattern-request.png)



步骤 4

: 当你收到起飞放行（或来自管制员的其他通联）时，通信按钮会闪烁琥珀色，消息会显示在屏幕顶部，点击通信按钮回复该消息



![Reply to Take-Off Clearance 2](../../../_images/manual/frames/reply-to-take-off-clearance-2.png)



步骤 5

: 一旦离地，你至少会收到一个序列和放行；如果需要，你也可能会收到一个航线入口（例如由于跑道变更）



![Sequence and Clearance](../../../_images/manual/frames/sequence-and-clearance.png)


手册

: 确保在保持在航线中时飞行高度正确。螺旋桨飞机的航线高度为 1000ft AAL（高于机场标高），喷气机为 1500ft AAL。[更多信息？](https://infiniteflight.com/guide/atc-manual/3.-tower/3.4-pattern-work-transitions-flight-of-xx#3.4.1)

## 保持在航线中通信表

以下是 Tower 管制员可以发送给飞行员的所有 ATC 指令，以及飞行员可以请求或回应的内容：



+++ 飞行员对 Tower 管制员（地面上）

| 请求/消息（地面上）                         | 何时发送                                                                 | 何时不发送               |
| :------------------------------------------- | :----------------------------------------------------------------------- | :----------------------- |
| 请求起飞 - Departing                        | 当飞行员准备从当前活动跑道起飞时，应请求起飞。方向应与飞行员将离开 Tower 空域的方向相对应。当不是起飞队列第一位时，可包含 “In Sequence”。 | 其他任何情况。 |
| 请求起飞 - 保持在航线中                      | 如果飞行员计划飞标准航线（在同一机场起飞并降落），应说明自己将保持在航线中。当不是起飞队列第一位时，可包含 “In Sequence”。 | 其他任何情况。 |
| 请求跑道穿越                                | 如果飞行员正在与 Tower 管制员通联，并希望穿越跑道，应请求穿越活动跑道末端的许可。 | 其他任何情况。 |
| 请求频率变更                                | 如果飞行员希望更换频率，且尚未获得相应许可，应请求频率变更。 | 其他任何情况。 |

+++



+++ 飞行员对 Tower 管制员（空中）

| 请求/消息（空中）            | 何时发送                                                                 | 何时不发送               |
| :---------------------------- | :----------------------------------------------------------------------- | :----------------------- |
| 进近着陆                     | 如果飞行员没有收到进近许可，或已获得雷达引导或航迹跟随，则应发送此消息。 | 其他任何情况。 |
| 按 ILS 进近                   | 如果飞行员已获准 ILS 进近，应通报 ILS 进近。 | 其他任何情况。 |
| 按 GPS 进近                   | 如果飞行员已获准 GPS 进近，应通报 GPS 进近。 | 其他任何情况。 |
| 按目视进近                   | 如果飞行员已获准目视进近，应通报目视进近。 | 其他任何情况。 |
| 通报复飞                     | 复飞的原因包括进近不稳定、跑道被航空器占用，或与前机失去间隔。 | 其他任何情况。 |
| 请求起飞                     | 如果飞行员在按航线飞行后离开 Tower 空域，应请求起飞。 | 其他任何情况。 |
| 报告位置                     | 如果飞行员尚未获得许可且即将着陆，应报告其位置。 | 其他任何情况。 |
| 报告位置 - 全停              | 飞行员可发送此消息通知 ATC，他们将在按航线飞行后着陆。 | 其他任何情况。 |
| 请求跑道变更                 | 如果飞行员想在航线中或在通报进近后更换跑道，可请求跑道变更。 | 其他任何情况。 |
| 请求过渡                     | 如果飞行员将穿越 Tower 空域，应请求过渡。 | 其他任何情况。 |
| 请求频率变更                 | 如果飞行员希望更换频率，且尚未获得相应许可，应请求频率变更。 | 其他任何情况。 |
| 通报复飞中断进近             | 如果飞行员的进近因任何原因看起来不正常，应通报中断进近。 | 其他任何情况。 |

+++



+++ Tower 管制员对飞行员

| 指令/消息                                         | ATC 意图                                                      | 飞行员动作                                                   |
| ------------------------------------------------ | -------------------------------------------------------------- | ------------------------------------------------------------ |
| 准许起飞                                         | ATC 允许飞行员起飞。                                           | 飞行员应开始起飞滑跑。                                       |
| 取消起飞放行，保持位置                           | ATC 取消飞行员的起飞放行。                                     | 飞行员应中止起飞并在跑道上保持。                             |
| Hold Short                                       | ATC 要求飞行员在跑道外保持位置。                               | 飞行员应前往等待线并停下（管制员也可能告知飞行员起飞排序信息）。 |
| Line Up and Wait                                 | ATC 要求飞行员进入跑道并保持位置。                             | 飞行员应进入跑道、停下，并准备起飞。                         |
| Back Taxi                                        | ATC 要求飞行员进入跑道并沿跑道滑行至指定端。                   | 飞行员应在跑道上滑行，并根据指令选择离开并联系 Ground，或进入跑道等待。 |
| Exit Runway                                      | ATC 要求飞行员离开刚刚降落的跑道。                             | 飞行员应滑出跑道并联系 Ground。                              |
| Exit Runway, Cross Runway XX and Contact Ground. | ATC 要求飞行员以受控速度离开跑道、穿越 Runway XX，并联系 Ground。 | 飞行员应将航空器减速至安全速度，穿越指定跑道，并联系 Ground。无需再与 Tower 进行任何通联。 |
| Exit Runway, Hold Short of Runway XX             | ATC 要求飞行员以受控速度离开跑道，并在 Runway XX 前保持。      | 飞行员应将航空器减速到受控速度，并在指定跑道前等待。应继续与 Tower 保持联系；无需申请穿越跑道。 |
| 由你决定速度                                     | ATC 希望飞行员自行管理速度。                                   | 飞行员可在遵守速度限制的前提下，以任何安全速度飞行。         |
| 保持当前速度                                     | ATC 要求飞行员在另行通知前保持当前速度。                       | 飞行员应检查速度，并保持该速度直到另行通知。                 |
| 保持最低可行速度                                 | ATC 希望飞行员尽可能以安全的最低速度飞行。                     | 飞行员应尽可能降低速度。                                     |
| 保持最佳前进速度                                 | ATC 希望飞行员尽可能以安全的最高速度飞行。                     | 飞行员应尽可能提高速度。                                     |
| 调整速度以跟随前方航空器                         | ATC 希望飞行员减速，以保持与前方航空器的间隔。                 | 飞行员应调整速度，使其飞行速度等于或低于前方航空器。         |

+++

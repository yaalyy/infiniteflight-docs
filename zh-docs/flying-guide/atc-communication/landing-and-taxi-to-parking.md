## 着陆通信摘要



Step 1

: 选择当前有效的塔台频率



Step 2

: 点击“呼叫进场”



![Call Inbound](../../../_images/manual/frames/call-inbound.png)



Step 3

: 选择你的意图（“着陆”或“触地复飞”）



![Intention](../../../_images/manual/frames/intention.png)



Step 4

: 接下来会显示以下选项：



| 通信内容                | 发送时机                                                     |
| ----------------------- | ------------------------------------------------------------ |
| 发送                    | 未由雷达管制员批准进近时                                       |
| 请求特定跑道            | 未由雷达管制员批准进近时                                       |
| 按 ILS 进场             | 已获雷达管制员批准 ILS 进近，或正在执行已编排的 ILS 进近时       |
| 按 GPS 进场             | 已获雷达管制员批准 GPS 进近，或正在执行已编排的 GPS 进近时       |
| 按目视进场              | 已获雷达管制员批准目视进近，或正在执行已编排的目视进近时         |



![Type](../../../_images/manual/frames/type.png)



Step 5

: 如果选择了“发送”以外的任何选项，系统随后会让你选择跑道。请确保发送雷达管制员在批准时指派的跑道（如果没有雷达管制员，则发送当前用于着陆和/或根据你所在位置最合适的跑道）



![Send](../../../_images/manual/frames/send.png)



Step 6

: 你发送的进场报告将决定塔台管制员的回复：



| 已发送通信            | 塔台回复                                                     |
| --------------------- | ------------------------------------------------------------ |
| 发送                  | 航线进入、排序（如有需要）、第 [sequence] 号，获准 [着陆/执行相应动作] |
| 请求特定跑道          | 航线进入、排序（如有需要）、第 [sequence] 号，获准 [着陆/执行相应动作] |
| 按 ILS 进场           | 第 [sequence] 号，获准 [着陆/执行相应动作]                 |
| 按 GPS 进场           | 第 [sequence] 号，获准 [着陆/执行相应动作]                 |
| 按目视进场            | 排序（如有需要）、第 [sequence] 号，获准 [着陆/执行相应动作] |



![Sent](../../../_images/manual/frames/sent.png)



Step 7

: 当你收到许可（或管制员的其他通信）时，通信按钮会闪烁琥珀色，消息会显示在屏幕顶部，点击通信按钮即可“回复”该消息



![Reply to Landing Clearance](../../../_images/manual/frames/reply-to-landing-clearance.png)

## 着陆通信表

以下是塔台管制员可向飞行员发送的所有 ATC 指令，以及飞行员可以请求或回复的内容：



+++ 飞行员发给塔台管制员

| 请求/消息（空中）           | 发送时机                                                     | 不发送时机                 |
| :--------------------------- | :----------------------------------------------------------- | :------------------------- |
| 进场着陆                    | 如果飞行员没有收到进近许可，或已收到雷达引导/飞行跟随，应发送此项。 | 其他任何情况均不应发送。     |
| 按 ILS 进场                 | 如果已获准 ILS 进近，飞行员应报告按 ILS 进场。                | 其他任何情况均不应发送。     |
| 按 GPS 进场                 | 如果已获准 GPS 进近，飞行员应报告按 GPS 进场。                | 其他任何情况均不应发送。     |
| 按目视进场                  | 如果已获准目视进近，飞行员应报告按目视进场。                  | 其他任何情况均不应发送。     |
| 报告复飞                    | 复飞原因包括进近不稳定、跑道被其他飞机占用，或与前机失去间隔。   | 其他任何情况均不应发送。     |
| 请求离场                    | 飞行员在航线飞行后离开塔台空域时应请求离场。                    | 其他任何情况均不应发送。     |
| 报告位置                    | 如果尚未获准且即将着陆，飞行员应报告当前位置。                  | 其他任何情况均不应发送。     |
| 报告位置 - 全停              | 飞行员可以发送此项，告知 ATC 他们将在航线飞行后执行全停着陆。    | 其他任何情况均不应发送。     |
| 请求更改跑道                | 如果飞行员希望在航线中或呼叫进场后更改跑道，可以请求更改跑道。   | 其他任何情况均不应发送。     |
| 请求穿越                    | 如果飞行员将穿越塔台空域，应请求穿越许可。                       | 其他任何情况均不应发送。     |
| 请求更改频率                | 如果飞行员希望更改频率且尚未获得许可，应请求更改频率。           | 其他任何情况均不应发送。     |
| 报告复飞进近                | 如果飞行员的进近因任何原因看起来不正常，应报告复飞进近。         | 其他任何情况均不应发送。     |

+++



+++ 塔台管制员发给飞行员

| 指令/消息                                      | ATC 意图                                                     | 飞行员操作                                                  |
| --------------------------------------------- | ------------------------------------------------------------ | ---------------------------------------------------------- |
| 允许起飞                                      | ATC 已允许飞行员起飞。                                        | 飞行员应开始起飞滑跑。                                      |
| 取消起飞许可，保持位置                          | ATC 正在取消飞行员的起飞许可。                                 | 飞行员应中止起飞并在跑道上保持位置。                        |
| 在跑道外等待                                  | ATC 希望飞行员在跑道外保持位置。                               | 飞行员应前往等待线并停下（管制员也可能告知飞行员离场排序信息）。 |
| 进入跑道等待                                  | ATC 希望飞行员进入跑道并保持位置。                             | 飞行员应进入跑道、停下，并准备起飞。                        |
| 反向滑行                                      | ATC 希望飞行员进入跑道并滑行至指定端。                         | 飞行员应沿跑道滑行，并根据指令离开后联系地面，或进入跑道等待。 |
| 离开跑道                                      | ATC 希望飞行员离开刚刚降落的跑道。                             | 飞行员应滑出跑道并联系地面。                                |
| 离开跑道，穿越 XX 跑道并联系地面。             | ATC 希望飞行员以受控速度离开跑道、穿越 XX 跑道并联系地面。      | 飞行员应将飞机减至安全速度，穿越指定跑道，并联系地面。无需再与塔台通信。 |
| 离开跑道，在 XX 跑道前等待                     | ATC 希望飞行员以受控速度离开跑道，并在 XX 跑道前等待。          | 飞行员应将飞机减至受控速度，并在指定跑道前等待。应继续与塔台保持联系；无需请求穿越跑道。 |
| 速度由你自行掌控                              | ATC 希望飞行员自行管理速度。                                   | 飞行员可以以任何安全速度飞行，并遵守速度限制。               |
| 保持当前速度                                  | ATC 希望飞行员在另行通知前保持当前速度。                         | 飞行员应确认当前速度并保持，直到另行通知。                  |
| 保持可行的最低速度                            | ATC 希望飞行员以尽可能慢且安全的速度飞行。                       | 飞行员应尽可能降低速度。                                    |
| 保持可行的最高前进速度                        | ATC 希望飞行员以尽可能快且安全的速度飞行。                       | 飞行员应尽可能提高速度。                                    |
| 调整速度以跟随前方飞机                        | ATC 希望飞行员减速，以保持与前方飞机的间隔。                     | 飞行员应调整速度，使其飞行速度等于或低于前方飞机。            |

+++

## 滑行至停机位通信摘要



Step 1

: 着陆后，请以受控方式尽快脱离跑道。离开跑道的通报还可能包含从哪一侧离开，以及其他跑道的等待/穿越指令



![Runway Exit Instruction](../../../_images/manual/frames/runway-exit-instruction.png)



Step 2

: 当你可以时，点击通信按钮并回复塔台管制员发送的消息（这可能包括“联系地面”的指令）



![Wilco](../../../_images/manual/frames/wilco.png)



Step 3

: 如果你已获准更改频率，请点击通信标签页中的返回箭头，然后选择地面频率



![Contact Ground](../../../_images/manual/frames/contact-ground.png)



提示

: 在联系地面前，请务必完全脱离跑道。别忘了，你不需要完全停下，尽量保持移动以提高效率！



Step 4

: 一旦你更改了频率，点击“请求滑行”，然后选择“停机位”



![Request Taxi to Parking](../../../_images/manual/frames/request-taxi-to-parking.png)



Step 5

: 当收到滑行指令（或管制员的其他通信）时，通信按钮会闪烁琥珀色，消息会显示在屏幕顶部，点击通信按钮即可“回复”该消息



![Reply to Ground](../../../_images/manual/frames/reply-to-ground.png)

## 滑行至停机位通信表

以下是地面管制员可向飞行员发送的所有 ATC 指令，以及飞行员可以请求或回复的内容：



+++ 飞行员发给地面管制员

| 请求/消息                         | 发送时机                                                     | 不发送时机                                                   |
| --------------------------------- | ------------------------------------------------------------ | ------------------------------------------------------------ |
| 请求滑行至当前使用跑道            | 当飞行员没有跑道偏好时发送。                                   | 飞行员正在推出时不应发送此项。                                 |
| 请求滑行至特定跑道                | 当飞行员有跑道偏好时发送。                                     | 飞行员不应请求当前 ATIS 指示为非使用中的跑道。                 |
| 请求推出                          | 当飞行员希望推出时，应请求推出许可。                           | 如果用户驾驶的飞机不具备推出能力（C172, C208, TBM-930, SR22, XCub, F18, F22, F16, F14, A-10, Spitfire, or P-38）或位于不需要推出的停机位，则不应请求此项。 |
| 请求穿越跑道                      | 如果飞行员的滑行路线需要穿越跑道，必须请求穿越许可。请求的跑道应与当前使用跑道相同。 | 其他任何情况均不应发送。                                       |
| 请求更改频率                      | 如果飞行员希望更改频率且尚未获得许可，应请求更改频率。         | 飞行员在滑行至跑道时不应向地面请求更改频率。频率变更已包含在滑行指令中（“准备好时联系塔台”）。 |

+++



+++ 地面管制员发给飞行员

| 指令/消息                                  | ATC 意图                                                     | 飞行员操作                                                  |
| ----------------------------------------- | ------------------------------------------------------------ | ---------------------------------------------------------- |
| 滑行至跑道，准备好后联系塔台               | ATC 已允许飞行员滑行至 XX 跑道。                              | 飞行员应开始滑行至分配的跑道。                                |
| 推出已批准                                | ATC 已给予飞行员推出许可。                                    | 飞行员应推出到滑行道上。                                      |
| 保持位置                                  | ATC 希望飞行员立即停下飞机。                                   | 如果在停机位，飞行员应等待推出许可。如果正在滑行，飞行员应将飞机完全停下，并等待“继续滑行”指令。 |
| 继续滑行                                  | ATC 正在解除“保持位置”指令。                                   | 飞行员可以继续滑行。                                          |
| 在跑道前等待                              | ATC 希望飞行员在跑道前等待。                                   | 飞行员应让整架飞机停在等待线后方。                            |
| 穿越跑道                                  | ATC 已允许飞行员穿越跑道。                                     | 飞行员应穿越跑道。如果包含“请加快”，飞行员应加快穿越。         |
| 让行给飞机                                | ATC 希望飞行员让行给另一架飞机。                                | 飞行员应让行给相应飞机。                                       |
| 预计将收到逐步滑行指令                    | ATC 将使用逐步滑行指令。                                       | 在收到进一步指令前，飞行员应保持正常滑行。                     |
| 在下一个滑行道左转/右转                   | ATC 希望飞行员在下一个滑行道分别左转/右转。                    | 飞行员应在下一个滑行道分别左转/右转，并继续滑行，直到收到进一步指令。 |
| 继续直行                                  | ATC 希望飞行员继续沿当前所在滑行道直行。                        | 飞行员应保持在该滑行道上，直到收到进一步指令。                 |
| 掉头 180 度                               | ATC 希望飞行员掉头 180º。                                      | 飞行员应掉头并等待进一步指令。                                 |
| 跟随前方飞机                              | ATC 希望飞行员跟随前方飞机。                                   | 飞行员应跟随前方飞机，直到收到进一步指令。                      |
| 由你自行决定继续滑行                      | ATC 希望告知飞行员，他们不再受逐步滑行指令约束。                | 飞行员可以自行决定继续滑行。如果还有其他滑行指令，则应遵循那些指令。 |

+++

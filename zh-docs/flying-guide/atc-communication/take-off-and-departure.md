## 起飞通信摘要

步骤 1

: 选择当前有效的 Tower 频率



![当前塔台频率](../../../_images/manual/frames/active-tower-frequency.png)



步骤 2

: 点按 "Request Departure"



![请求离场](../../../_images/manual/frames/request-departure.png)



步骤 3

: 选择你正在等待的跑道，然后点按 "Departing" 或 "Remaining in the Pattern"



![选择离场跑道](../../../_images/manual/frames/select-departure-runway.png)



![发送离场请求](../../../_images/manual/frames/send-departure-request.png)



提示

: 如果你要离场，你需要告知塔台管制员你将朝哪个方向离开他们的空域（例如，如果你的 SID 向南离场，请务必选择 "South"）。如果你不是第一个准备起飞的，可以在离场请求末尾加上 "In Sequence"（管制员在你排队期间的任何时候都可能告知离场排序）



步骤 4

: 当你收到起飞放行（或管制员的其他通信）时，Communication 按钮会闪烁琥珀色，消息会显示在屏幕顶部，点按 Communication 按钮以 "Reply" 回复消息



![回复起飞放行](../../../_images/manual/frames/reply-to-take-off-clearance.png)

## 起飞通信表

以下是塔台管制员可以发送给飞行员的所有 ATC 指令，以及飞行员可以请求或响应的内容：



+++ 飞行员 -> 塔台管制员（地面）

| 请求/消息（地面）                          | 何时发送                                                                 | 何时不要发送             |
| :------------------------------------------ | :----------------------------------------------------------------------- | :----------------------- |
| Request Departure - Departing              | 当飞行员准备从当前活动跑道起飞时，应请求离场。方向应与飞行员将离开 Tower 空域的方向一致。如果不是第一个准备起飞的，可以包含 "In Sequence"。 | 其他任何情况。           |
| Request Departure - Remaining in the Pattern | 如果飞行员计划进行航线飞行（在同一机场起飞并降落），应说明他们将留在航线中。如果不是第一个准备起飞的，可以包含 "In Sequence"。 | 其他任何情况。           |
| Request Runway Crossing                    | 如果飞行员正在与塔台管制员联系，并希望穿越一条跑道，应请求穿越活动跑道末端的许可。 | 其他任何情况。           |
| Request Frequency Change                   | 如果飞行员希望更换频率，但尚未获得许可，应请求更换频率。 | 其他任何情况。           |

+++



+++ 飞行员 -> 塔台管制员（空中）

| 请求/消息（空中）       | 何时发送                                                                 | 何时不要发送             |
| :----------------------- | :----------------------------------------------------------------------- | :----------------------- |
| Inbound for Landing      | 如果飞行员没有收到进近许可，或被提供了雷达引导或飞行跟随，应发送此消息。 | 其他任何情况。           |
| Inbound on the ILS       | 如果飞行员已获准进行 ILS 进近，应报告 ILS inbound。 | 其他任何情况。           |
| Inbound on the GPS       | 如果飞行员已获准进行 GPS 进近，应报告 GPS inbound。 | 其他任何情况。           |
| Inbound on the Visual    | 如果飞行员已获准进行目视进近，应报告 visual inbound。 | 其他任何情况。           |
| Announce Go Around       | 需要复飞的原因包括进近不稳定、跑道被其他飞机阻挡，或与前机间隔丧失。 | 其他任何情况。           |
| Request Departure        | 当飞行员在航线中飞行后离开 Tower 空域时，应请求离场。 | 其他任何情况。           |
| Report Position          | 如果飞行员尚未获得放行，但即将降落，应报告自己的位置。 | 其他任何情况。           |
| Report Position - Full Stop | 飞行员可以发送此消息，告知 ATC 他们将在航线飞行后落地停机。 | 其他任何情况。           |
| Request Runway Change    | 如果飞行员希望在航线中或呼叫 inbound 后更换跑道，可以请求更换跑道。 | 其他任何情况。           |
| Request Transition       | 如果飞行员将穿越 Tower 空域，应请求过境。 | 其他任何情况。           |
| Request Frequency Change  | 如果飞行员希望更换频率，但尚未获得许可，应请求更换频率。 | 其他任何情况。           |
| Announce Missed Approach  | 如果飞行员的进近由于任何原因看起来不正常，应宣布复飞。 | 其他任何情况。           |

+++



+++ 塔台管制员 -> 飞行员

| 指令/消息                                      | ATC 意图                                                     | 飞行员动作                                                     |
| ---------------------------------------------- | ------------------------------------------------------------ | ------------------------------------------------------------ |
| Cleared for Take-Off                           | ATC 正在为飞行员放行起飞。                                   | 飞行员应开始起飞滑跑。                                       |
| Cancel Take-Off Clearance, Hold Position       | ATC 正在取消飞行员的起飞放行。                               | 飞行员应中止起飞并在跑道上保持位置。                         |
| Hold Short                                     | ATC 希望飞行员在跑道外保持位置。                             | 飞行员应前往等待线并停下（管制员也可能告知飞行员离场排序信息）。 |
| Line Up and Wait                               | ATC 希望飞行员进入跑道并保持位置。                           | 飞行员应进入跑道、停下，并准备起飞。                         |
| Back Taxi                                      | ATC 希望飞行员进入跑道并沿跑道滑行至指定端。                 | 飞行员应在跑道上滑行，并根据指令离开后联系 Ground，或进入跑道并等待。 |
| Exit Runway                                    | ATC 希望飞行员离开刚刚降落的跑道。                           | 飞行员应滑出跑道并联系 Ground。                              |
| Exit Runway, Cross Runway XX and Contact Ground. | ATC 希望飞行员以受控速度滑出跑道，穿越 Runway XX，并联系 Ground。 | 飞行员应将飞机减至安全速度，穿越指定跑道，并联系 Ground。无需再与 Tower 通信。 |
| Exit Runway, Hold Short of Runway XX           | ATC 希望飞行员以受控速度滑出跑道，并在 Runway XX 前等待。   | 飞行员应将飞机减至受控速度，并在指定跑道前等待。应继续保持与 Tower 的联系；无需申请穿越跑道。 |
| Speed at your Discretion                        | ATC 希望飞行员自行管理速度。                                 | 飞行员可在遵守速度限制的前提下，以任何安全速度飞行。         |
| Maintain Present Speed                           | ATC 希望飞行员在另行通知前保持当前速度。                     | 飞行员应检查自己的速度，并保持该速度直到另行通知。           |
| Maintain Slowest Practical Speed                 | ATC 希望飞行员以尽可能慢且安全的速度飞行。                   | 飞行员应尽可能降低速度。                                     |
| Maintain Best Forward Speed                      | ATC 希望飞行员以尽可能快且安全的速度飞行。                   | 飞行员应尽可能提高速度。                                     |
| Adjust Speed to Follow Aircraft Ahead            | ATC 希望飞行员减速，以保持与前方飞机的间隔。                 | 飞行员应调整速度，使其飞行速度不高于前方飞机的速度。         |

+++

## 离场通信摘要



步骤 1

: 一旦起飞并离地，等待塔台管制员发送 "Frequency change approved, good day" 或将你移交到另一个正在工作的频率



![联系雷达频率](../../../_images/manual/frames/contact-radar-frequency.png)



步骤 2

: Communication 按钮会闪烁琥珀色，消息会显示在屏幕顶部，点按 Communication 按钮以 "Reply to Handoff"



![回复移交](../../../_images/manual/frames/reply-to-handoff.png)



步骤 3

: 如果你收到的是 "Frequency change approved, good day"，则表示你所在区域当前没有正在工作的管制员 - 我们建议你直接点按 "Tune out of [airport ICAO code] Tower" 退出当前频率，并继续航路飞行。如果你已被移交到一个正在工作的频率，它会给你两个选项，分别是 "Send & Switch"（会先回复并自动调到下一个频率）或 "Send"（会先回复，但之后你需要手动调到下一个频率）



![发送并切换](../../../_images/manual/frames/send-and-switch.png)



步骤 4

: 一旦你调到雷达管制员的频率，下表列出可发送的请求： 



| 离场类型            | Check In [IFR] | Flight Following [VFR] |
| ------------------- | -------------- | ---------------------- |
| 有飞行计划          | Yes            | Yes                    |
| 无飞行计划          | No             | Yes                    |



![首次联系](../../../_images/manual/frames/initial-contact.png)



提示

: 请确保只发起 ONE 个请求，多个传输会增加管制员负担，并可能导致 [Violation](../../getting-started-guide/pilot-user-interface/violation-reasons.md#spamming-frequency---unnecessary-duplicate-requests)！

## 离场通信表

以下是雷达管制员可以发送给飞行员的所有 ATC 指令，以及飞行员可以请求或响应的内容：



+++ 飞行员 -> 雷达管制员

| 请求/消息                | 何时发送                                                                 | 何时不要发送                                             |
| ------------------------ | ----------------------------------------------------------------------- | -------------------------------------------------------- |
| Request Approach         | 如果飞行员希望获得 ILS、GPS 或目视进近，应请求进近。                     | 其他任何情况。                                           |
| Request Flight Following | 如果飞行员希望在不接受进近的情况下飞往目的地，可以请求 Flight Following。若获批准，飞行员可按自己的飞行计划飞行，并自行决定高度。 | 该服务不应在 Check In 之后请求。                         |
| Request Radar Vectors    | 如果飞行员不想要 ILS、GPS 或目视进近，且尚未请求其他服务，可以请求雷达引导。ATC 会将其引导至 VFR 航线，并在航线高度将其移交给 Tower/Unicom。 | 其他任何情况。                                           |
| Request Altitude Change   | 如果飞行员距离地形在 1,000 英尺以内，或与另一架飞机的距离在 3 海里 / 1,000 英尺以内，应请求此项。ATC 会检查其周围环境，并在必要时采取行动。如果飞行员想要爬升至初始巡航高度之上，也可以请求此项。 | 飞行员不应在起飞时请求此项。Check In 会赋予飞行员对高度的自主决定权。 |
| Executing Missed Approach | 如果飞行员无法继续进近，可以宣布复飞。如果正在复飞，应在联系雷达管制员时发送此消息。 | 其他任何情况。                                           |
| Check In                 | Check In 主要与 Center 和 Departure 一起使用。获得批准后，飞行员可按照其 FPL 中提交的横向和垂直导航飞行。 | 飞行员不应在进近阶段使用 Check In，而应直接请求进近。     |
| Request Descent via STAR  | 如果飞行员距离 TOD 还有 1 分钟，并且已提交 STAR，应请求此项。 | 如果 Radar 要求飞行员说明其进近请求，飞行员不应请求下降。 |
| Request Frequency Change  | 如果飞行员希望更换频率，但尚未获得许可，应请求更换频率。 | 飞行员不应急躁地使用此项。频率切换并不总会立即获得。       |
| Airport In Sight          | 如果飞行员在目视进近中能够看到机场，可以报告 Airport In Sight。 | 其他任何情况。                                           |

+++



+++ 雷达管制员 -> 飞行员


| 指令/消息                                      | ATC 意图                                                     | 飞行员动作                                                     |
| ------------------------------------------------ | ------------------------------------------------------------ | ------------------------------------------------------------ |
| Continue As Filed                                | ATC 希望飞行员按其自行决定继续飞行。                         | 飞行员应按飞行计划继续飞行；所有高度变化和航向变化都不需要放行。 |
| Resume Own Navigation                            | ATC 希望飞行员自行导航。                                     | 飞行员应继续自行导航；所有航向变化都不需要放行。所有高度变化都需要放行。 |
| Speed at Your Discretion                         | ATC 希望飞行员自行管理速度。                                 | 飞行员可在遵守速度限制的前提下，以任何安全速度飞行。         |
| Maintain Present Speed                           | ATC 希望飞行员在另行通知前保持当前速度。                     | 飞行员应检查自己的速度，并保持该速度直到另行通知。           |
| Maintain Slowest Practical Speed                 | ATC 希望飞行员以尽可能慢且安全的速度飞行。                   | 飞行员应尽可能降低速度。                                     |
| Maintain Best Forward Speed                      | ATC 希望飞行员以尽可能快且安全的速度飞行。                   | 飞行员应尽可能提高速度。                                     |
| Adjust Speed to Follow Aircraft ahead.           | ATC 希望飞行员减速，以保持与前方飞机的间隔。                 | 飞行员应调整速度，使其飞行速度不高于前方飞机的速度。         |
| Please Expedite Altitude Change                  | ATC 希望飞行员加快高度变化。                                 | 飞行员应增加垂直速度，尽快下降或爬升。                       |
| Amend Flight Plan to Include ATC Preferred STAR. | ATC 需要调节交通流量。                                        | 飞行员应在飞行计划中添加 ATC 首选的 STAR。                  |

+++

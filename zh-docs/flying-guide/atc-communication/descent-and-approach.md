## 下降通信摘要

步骤 1

: 如果目的地的 ATIS 处于启用状态，请使用你的[地图](../../getting-started-guide/pilot-user-interface/flight-planning.md#map)或[小地图](../../getting-started-guide/pilot-user-interface/flight-planning.md#mini-map)点击机场，在列表中选择该机场，点击“ATIS”，然后点击“TUNE”



步骤 2

: 确保你已选择“ATC Preferred”到达方式（如果有列出），并且所选进近方式对应当前用于着陆的跑道



步骤 3

: 点击通信按钮并选择相应的 Radar 频率以建立初始联系：



| 设施 | 初始无线电通话 | 何时*                                               |
| ---- | -------------- | --------------------------------------------------- |
| Center   | “Check In”                 | 在进入地图上的白色边界之前不久 |
| Approach | “Approach Request”**       | 低于或等于 FL180 且距目的地 50nm 以内      |

*如果你正在与一个启用的 ATC 设施通联，未经许可不要更改频率

**点击“Approach Request”后；选择机场、进近类型和跑道



!["Check In" with Center](../../../_images/manual/frames/_check-in_-with-center.png)



步骤 4

: 如果你正在巡航，在到达 Top of Descent 前 1 分钟，向 Radar 控制员发送“request descent via [STAR]”（前提是你的 Flight Plan 中已选择 STAR）



![Request descent via](../../../_images/manual/frames/request-descent.png)



步骤 5

: 一旦收到放行，你就可以开始下降 - 注意观察周围，确认空域清空，并使用[摄像机](../../getting-started-guide/pilot-user-interface/cameras.md#camera)和[小地图](../../getting-started-guide/pilot-user-interface/flight-planning.md#mini-map)来协助你



![Descent Clearance](../../../_images/manual/frames/descent-clearance.png)

## 进近通信摘要

步骤 1

: 如果有 Approach 控制员在线，Center 控制员会在预定位置将你移交给他们（通常是 FL180 或距目的地 50nm） - 未经许可不要更改频率！



步骤 2

: 当你收到频率切换请求（或来自控制员的其他通信）时，通信按钮会闪烁琥珀色，消息会显示在屏幕顶部；点击通信按钮即可“回复”该消息。如果你收到的是“Frequency change approved, good day”，则表示你所在区域当前没有控制员在线 - 我们建议你直接点击“Turn out of [airport ICAO code] [facility]”退出当前频率，并继续航路飞行。如果你已被移交到一个启用中的频率，它会给你两个选项：要么“Send & Switch”（会回复并自动切换到下一个频率），要么“Send”（会回复，但你之后需要手动切换到下一个频率）



![Reply to Handoff 2](../../../_images/manual/frames/reply-to-handoff-2.png)



步骤 3

: 调入频率后，点击“Request Approach”



![Request Approach](../../../_images/manual/frames/request-approach.png)



步骤 4

: 选择相应的机场



![Destination Airport](../../../_images/manual/frames/destination-airport.png)



提示

: 将你的目的地机场添加为飞行计划中的最后一个 fix。这样，机场频率就会显示在列表顶部！



步骤 5

: 点击你想要执行的进近类型，选择“any runway”，或者选择特定跑道和进近类型



![Approach and Runway](../../../_images/manual/frames/approach-and-runway.png)



步骤 6

: Radar 控制员会指示你“continue as filed”，在这种情况下继续下降并按计划自主导航；或者指示你“expect vectors”，在这种情况下，请准备接收进近矢量



![Continue as Filed](../../../_images/manual/frames/continue-as-filed.png)



![Expect Vectors](../../../_images/manual/frames/expect-vectors.png)



步骤 7

: 在进近过程中，随时准备接收矢量和/或高度指令；点击“reply”并立即按指令飞行



![Receive Vectors](../../../_images/manual/frames/receive-vectors.png)



步骤 8

: 一旦你建立好进近且间隔要求已满足，Radar 控制员会酌情将你移交给 Tower 控制员（如果有）



![Contact Tower](../../../_images/manual/frames/contact-tower.png)

## 下降与进近通信表

以下是 Radar 控制员可以发送给飞行员的所有 ATC 指令，以及飞行员可以请求或回应的内容：



+++ 飞行员向 Radar 控制员

| 请求/消息                 | 何时发送                                                   | 何时不发送                                             |
| ------------------------- | ---------------------------------------------------------- | ------------------------------------------------------ |
| Request Approach          | 如果飞行员希望获得 ILS、GPS 或目视进近，就应请求进近。 | 任何其他情况下均不应发送。                                   |
| Request Flight Following  | 如果飞行员希望飞往目的地但不接受进近服务，可以请求此项。如果获准，他们可以按自己的 Flight Plan 飞行，并自行决定高度。 | 在 Check In 之后不应请求此服务。      |
| Request Radar Vectors     | 如果飞行员不想要 ILS、GPS 或目视进近，且尚未请求其他服务，则可以请求 radar vectors。ATC 会将其引导至 VFR 航线的一段，并在航线高度将其移交给 Tower/Unicom。 | 任何其他情况下均不应发送。                                   |
| Request Altitude Change   | 如果飞行员距离地形不足 1,000ft，或与另一架飞机的距离在 3NM/1,000ft 以内，则应请求此项。ATC 会检查周边环境，并在必要时采取行动。如果飞行员想爬升到初始巡航高度之上，也可以请求此项。 | 飞行员不应在起飞后请求此项。Check In 会让飞行员自行决定高度。 |
| Executing Missed Approach | 如果飞行员无法继续进近，可以通报 missed approach。如果复飞，这条信息应在接通 radar controller 后发送。 | 任何其他情况下均不应发送。                                   |
| Check In                  | Check In 主要用于 Center 和 Departure。获得批准后，飞行员可按照 FPL 中计划的横向和纵向引导飞行。 | 飞行员不应在进近时 Check In。应直接请求进近。 |
| Request Descent via STAR  | 如果飞行员距离 Top of Descent（TOD）还有 1 分钟，并且已编入 STAR，则应请求此项。 | 如果 Radar 要求飞行员说明其进近请求，飞行员不应请求下降。 |
| Request Frequency Change  | 如果飞行员希望更换频率，并且尚未被许可这样做，则应请求频率更改。 | 飞行员不应不耐烦地使用此项。频率更改并不总会立即获准。 |
| Airport In Sight          | 如果飞行员在目视进近时看见机场，可以报告 airport in sight。 | 任何其他情况下均不应发送。                                   |



+++



+++ Radar 控制员向飞行员


| 指令/消息                                      | ATC 意图                                                | 飞行员操作                                                |
| ---------------------------------------------- | ------------------------------------------------------- | -------------------------------------------------------- |
| Continue As Filed                                | ATC 希望飞行员按其自主决定继续飞行。 | 飞行员应按计划继续飞行；所有高度变化和方向变化都不需要许可。 |
| Resume Own Navigation                            | ATC 希望飞行员自行导航。           | 飞行员应继续按自主决定导航；所有方向变化都不需要许可。所有高度变化都需要许可。 |
| Speed at Your Discretion                         | ATC 希望飞行员自行管理速度。          | 飞行员可以在遵守速度限制的前提下，以任何安全速度飞行。 |
| Maintain Present Speed                           | ATC 希望飞行员保持当前速度，直到另有指示。 | 飞行员应注意自己的速度，并保持该速度，直到另有指示。 |
| Maintain Slowest Practical Speed                 | ATC 希望飞行员以尽可能慢且安全的速度飞行。               | 飞行员应尽可能降低速度。   |
| Maintain Best Forward Speed                      | ATC 希望飞行员以尽可能快且安全的速度飞行。               | 飞行员应尽可能提高速度。   |
| Adjust Speed to Follow Aircraft ahead.           | ATC 希望飞行员减速，以保持与前机的间隔。 | 飞行员应调整速度，使其以不高于前方飞机的速度飞行。 |
| Please Expedite Altitude Change                  | ATC 希望飞行员加快高度变化。       | 飞行员应增加垂直速度，尽快下降或爬升。 |
| Amend Flight Plan to Include ATC Preferred STAR. | ATC 需要调节交通流量。                          | 飞行员应在飞行计划中加入 ATC preferred STAR。 |

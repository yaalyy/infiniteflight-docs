# 自动刹车

@[vimeo](690477241)



自动刹车系统有两个主要用途，分别是：



- 在中断起飞时减少刹车距离
- 在着陆期间建立并维持选定的减速率，从而提升乘客舒适度并降低机组工作负荷



在选择自动刹车设置时，扰流板会自动**ARM**，以便为起飞或着陆做好准备。

## 起飞

在离场前，自动刹车应始终设置为**MAX**（如果装备了），以便在复飞中止起飞（RTO）时飞机配置正确。



为此，请打开 [Systems](../../getting-started-guide/pilot-user-interface/systems.md#systems) 菜单并选择以下内容：



| 其他       | 操作   |
| ---------- | ------ |
| Autobrakes | **MAX** |

{.checklist}

## 着陆

着陆时，飞行员可以选择手动刹车，或设置自动刹车档位（即 **LOW** 或 **MED**）。建议始终选择自动刹车（如果装备了），因为在着陆滑跑过程中，如不再需要，随时可以将其解除。 



为此，请打开 [Systems](../../getting-started-guide/pilot-user-interface/systems.md#systems) 菜单并选择以下内容：



| 其他       | 操作               |
| ---------- | ------------------ |
| Autobrakes | **LOW** 或 **MED** |

{.checklist}



> 如果在未接地时选择，**MAX** 不可用于着陆，并会自动默认为 **MED**

## 发动机启动后

 

在发动机启动完成后、开始滑行之前，应完成启动后检查：



步骤 1

: 将 [扰流板](../../getting-started-guide/pilot-user-interface/flight-controls.md#flight-controls) 设为 **ARMED**



步骤 2

: 将 [配平和襟翼](../../getting-started-guide/pilot-user-interface/flight-controls.md#flight-controls) 调整到起飞设置



步骤 3

: 通过访问 [系统](../../getting-started-guide/pilot-user-interface/systems.md#systems) 菜单并选择以下内容，将 [自动刹车](autobrake.md) 设为 **MAX**（如果配备）：



| 其他     | 操作  |
| -------- | ----- |
| Autobrakes | **MAX** |

{.checklist}

## 滑行

 

步骤 1

: 检查周围环境以确保安全，使用 [摄像机](../../getting-started-guide/pilot-user-interface/cameras.md#camera) 和 [小地图](../../getting-started-guide/pilot-user-interface/flight-planning.md#mini-map) 来帮助你

 

步骤 2

: 使用当前 ATC 申请 [请求滑行](../atc-communication/atis-pushback-and-taxi.md#taxi-communication-summary)，如果没有当前 ATC，则在 Unicom 频率上通报滑行 - 在移动过程中注意监听其他交通流量

 

步骤 3

: 松开 [停机刹车](../../getting-started-guide/pilot-user-interface/flight-controls.md#flight-controls)，并增加 [推力](../../getting-started-guide/pilot-user-interface/hud.md#head-up-display-(hud)) 开始滑行

 

提示

:   我们建议滑行时不要超过 40% N1，一旦开始移动，通常只需要怠速推力就够了！

 

步骤 4

: 使用 [方向舵](../../getting-started-guide/pilot-user-interface/flight-controls.md#flight-controls) 保持在滑行道中心线上，并使用 [方向舵刹车或停机刹车](../../getting-started-guide/pilot-user-interface/flight-controls.md#flight-controls) 控制速度

 

提示

:   为避免游戏内违规，请勿超过 35kts 地速。我们建议在直线滑行时将速度控制在 25kts 以下，90° 转弯时控制在 10kts 或更低，以确保安全运行

 

步骤 5

: 如果你在滑行时需要穿越跑道，请务必使用当前 ATC [请求穿越跑道](../atc-communication/atis-pushback-and-taxi.md#pilot-to-ground-controller-communication-table)，如果没有当前 ATC，则在 Unicom 频率上通报穿越 - 进入跑道前务必确认跑道空闲！别忘了访问 [系统](../../getting-started-guide/pilot-user-interface/systems.md#systems) 菜单并选择以下内容：

 

| 灯光  | 操作 |
| ----- | ---- |
| Strobes | **ON** |
| Land    | **ON** |

{.checklist}

 

一旦你完全离开跑道，就可以将这些灯光重新设为 **OFF**。

## 推出

 

步骤 1

: 检查周围环境，确保没有障碍物，使用 [摄像机](../../getting-started-guide/pilot-user-interface/cameras.md#camera) 和 [小地图](../../getting-started-guide/pilot-user-interface/flight-planning.md#mini-map) 帮助你。如果已经使用了地面服务，推出前必须先取消这些服务



> 在断开地面电源之前，请确保 APU 正在运行（如果配备）



步骤 2

: 打开 [地面服务](../../getting-started-guide/pilot-user-interface/ground-services.md) 菜单，并取消选择以下服务（如果它们已被选择，它们会以橙色高亮显示）：

 

| 地面      | 操作  |
| --------- | ------- |
| PAX       | **TAP** |
| CATERING  | **TAP** |
| CARGO     | **TAP** |
| GND POWER | **TAP** |

{.checklist}



> 地面服务可以按任意顺序断开，通常是在该地面服务已完成飞行员分配的任务后进行



| 推出   | 操作  |
| ------ | ------- |
| Attach Tug | **TAP** |

{.checklist}



步骤 3

: 调至活动频率并 [请求推出](../atc-communication/atis-pushback-and-taxi.md#pushback-communication-summary)；如果没有活动 ATC，则调至 Unicom 频率 - 在开始推出前先监听交通情况

 

步骤 4

: 打开 [系统](../../getting-started-guide/pilot-user-interface/systems.md#systems) 菜单，并选择以下内容：

 

| 灯光  | 操作 |
| ----- | ------ |
| Beacon | **ON** |

{.checklist}



步骤 5

: 打开 [地面服务](../../getting-started-guide/pilot-user-interface/ground-services.md) 菜单，并选择以下内容：

| 推出     | 操作  |
| -------- | ------- |
| Push     | **TAP** |

{.checklist}



> 在开始推出之前，你的停放刹车必须设置为 **OFF**



步骤 6

: 先规划好推出方向。ATC 也可能会告知你预计起飞使用的跑道。推出过程中请始终使用 [摄像机](../../getting-started-guide/pilot-user-interface/cameras.md#camera) 和 [小地图](../../getting-started-guide/pilot-user-interface/flight-planning.md#mini-map)，并使用 [方向舵](../../getting-started-guide/pilot-user-interface/flight-controls.md#flight-controls) 进行方向控制

 

步骤 7

: 当你准备停止推出时，打开 [地面服务](../../getting-started-guide/pilot-user-interface/ground-services.md) 菜单，并选择以下内容：

 

| 推出       | 操作  |
| ---------- | ------- |
| Push       | **TAP** |
| Detach Tug | **TAP** |

{.checklist}



> 推出完成后、在断开拖车之前，你应该将停放刹车设置为 **ON**



提示

:   当将飞机与滑行道中线对齐时，需要提前量。别忘了，飞机越大，你就要越早开始转弯！

## 自动推出

自动推出会自动将你的飞机移动到你或 ATC 所定义的滑行道位置。这样你就可以专注于其他事情，例如 [发动机启动](#Engine-Start)。更多信息请观看下面的视频

@[vimeo](1050790791)

![Auto Pushback Screen](../../../_images/manual/flying-guide/on-the-ground/auto-pushback.png)

按需前后倾斜以放大/缩小

1. 罗盘 - 用于遵循 ATC 的“机尾朝向（方向）”指令
2. 飞机将被推出到的位置
3. 飞机将被向前牵引到的位置（可选）
4. 开始/结束按钮 - 用于开始自动推出流程（启动后会变为结束）
5. 暂停/继续按钮 - 用于暂停/继续自动推出流程
6. 按下“Detach Tug”或“Auto Pushback”会退出自动推出模式/摄像机

## 发动机启动

发动机可以在推出过程中或推出完成后开始启动。

 

步骤 1

: 检查周围环境，确保没有障碍物，使用 [摄像机](../../getting-started-guide/pilot-user-interface/cameras.md#camera) 和 [小地图](../../getting-started-guide/pilot-user-interface/flight-planning.md#mini-map) 帮助你

 

步骤 2

: 打开 [系统](../../getting-started-guide/pilot-user-interface/systems.md#systems) 菜单，并选择以下内容：

 

| 发动机         | 操作  |
| ------------- | ------- |
| Eng ‘X’ 0% N1 | **TAP** |

{.checklist}



你所选择的发动机启动序列将开始。

 

提示

:   为了更真实的体验，请一次只启动一台发动机 - 在启动下一台发动机之前，等待 % N1 变为绿色。

 

或者，你也可以使用 **Auto Start** 功能，以获得更轻松的体验，选择以下内容：

 

| 其他       | 操作  |
| ---------- | ------- |
| Auto Start | **TAP** |

{.checklist}



步骤 3

: 一旦至少有一台发动机在运行，打开 [系统](../../getting-started-guide/pilot-user-interface/systems.md#systems) 菜单，并选择以下内容：

 

| 电气系统 | 操作  |
| -------- | ------- |
| APU*     | **OFF** |

{.checklist}



*如果配备 - 目前并非所有飞机都安装了 APU

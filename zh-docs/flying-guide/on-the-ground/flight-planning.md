## 重量与平衡

 

当你在机位生成后，点击 [暂停界面](../../getting-started-guide/pilot-user-interface/fly-screen.md) 按钮进入 [重量与平衡](../../getting-started-guide/pilot-user-interface/pause-menu.md#weight-%26-balance) 页面，在这里你可以调整燃油、乘客载荷和货物载荷。



提示

: 确保携带足够的燃油，以考虑到诸如更强的逆风和交通延误等特殊情况

## ATIS

 

自动终端情报服务，通常称为 ATIS，会在你处于覆盖范围内时，通过专用频率发送最新的机场信息（如果有 ATC）。它通常包括：



- 最新的 METAR*
- 正在使用的跑道
- 备注和/或 NOTAM，用于向飞行员提供更多信息（例如：“不允许场内机动飞行”）
- 如果有多个频率开放，则告知应联系哪一个



**气象终端航空报告（更常称为 METAR）是机场的当前天气，通常显示记录的日期/时间、风向和风速、能见度、天气和云况、温度和露点，以及最后的气压*



数字 ATIS（D-ATIS）会显示与 ATIS 相同的信息，但以文本格式呈现。要查找 D-ATIS，请按以下步骤操作：



步骤 1

: 在地图上[点击你选择的机场附近](../../getting-started-guide/pilot-user-interface/flight-planning.md#getting-more-from-your-map-and-mini-map)，会出现一个下拉列表，你可以在其中选择机场

 

步骤 2

: 默认会显示信息选项卡，点击“wx”（天气）选项卡



步骤 3

: 如果所选机场有 ATC 且正在使用 ATIS 频率，D-ATIS 将显示这些信息 



提示

: D-ATIS 的范围不受限制；可在调至活动频率之前用它来帮助规划



想了解 ATIS 中各项内容的含义？请访问我们的 [ATC 手册](../../atc-manual/4.-atis/4.1-overview.md) 了解更多！

## 自动驾驶仪（AP）设置

起飞前，你的自动驾驶仪应先设置初始“目标”，请按以下步骤操作：



步骤 1

: 通过点击屏幕右侧的“AP OFF”打开 [自动驾驶仪](../../getting-started-guide/pilot-user-interface/autopilot.md) FCU（飞行控制组件）



步骤 2

: 更改“SPD”（速度）按钮，以选择起飞后的目标爬升速度（应为 V2）



步骤 3

: 更改“ALT”（高度）按钮，以选择你希望在离场后停止爬升的目标高度（通常是你计划飞行的 [SID](../take-off-to-cruise/standard-instrument-departure-(sid)-navigation.md) 的停止高度）



步骤 4

: 此时你应该会在 PFD 和 HUD 上看到这些目标

## 空域 

地图和小地图会使用颜色代码来定义不同类型的空域。如下表所示：


| 空域类型                         | 颜色代码    |
| ------------------------------- | ----------- |
| B 类空域                        | 蓝色        |
| C 类空域                        | 洋红色      |
| D 类空域                        | 浅蓝色      |
| 终端管制区                      | 浅绿色      |
| 飞行情报区（FIR）               | 白色        |

希望增加飞行真实性的飞行员可能会希望遵循现实世界中的程序，但就 Infinite Flight 而言，ATC 对空域的使用已被简化。有关飞行时你可以从 ATC 预期到什么的更多信息，请访问 [ATC 手册](../../atc-manual/5.-airspace/5.1-airspace.md#5.1-airspace)。

# 起飞前



到达等待点并准备起飞了吗？请按照下面的分步指南操作，确保你已为起飞做好准备！



步骤 1

: 检查周围环境，确保跑道和周边区域清空，使用 [Cameras](../../getting-started-guide/pilot-user-interface/cameras.md#camera) 和 [Mini Map](../../getting-started-guide/pilot-user-interface/flight-planning.md#mini-map) 来帮助你



步骤 2

: 调至当前塔台频率并[报告已准备好起飞](../atc-communication/take-off-and-departure.md#take-off-communication-summary)，如果没有可用 ATC，则调至 Unicom 频率

  

步骤 3

: 一旦你获得放行许可（如适用）且进近方向清空；打开 [Systems](../../getting-started-guide/pilot-user-interface/systems.md) 菜单并选择以下设置：

 

| LIGHTS  | 操作 |
| ------- | ---- |
| Strobes | **ON** |
| Land    | **ON** |

{.checklist}

 

步骤 4

: 如果 ATC 已经允许你 Line Up and Wait（LUAW），请滑行进入跑道中线并停下。如果 ATC 已经允许你起飞，或者你在使用 Unicom，只要跑道完全清空，就可以立即开始起飞滑跑

 

提示

:   性能受限？如果你因为飞机重量、环境因素或跑道长度而受到性能限制，请使用过度转向技巧，尽可能为起飞节省跑道长度

## 目视飞行规则（VFR）是什么意思？

目视飞行规则（VFR）是一套在飞机以目视方式飞行时必须遵守的规定；具体来说，是在目视气象条件（VMC）下。 



在适合的天气条件下，才能执行 VFR 飞行。这意味着飞行员必须能够：



- 依靠目视导航
- 并通过“目视避让”来避开地形和其他航空器等障碍物（与其他航空器保持 **至少** 500 英尺的垂直间隔）

## 目视气象条件（VMC）是什么意思？

目视气象条件（VMC）是一组 VFR 飞行所需满足的天气最低标准。 



具体最低标准会因国家以及飞行所在空域类型而异。不过，就 Infinite Flight 而言，当能见度达到 3 statute miles（约 5000 米）或以上时，即视为满足 VMC。因此，在这些条件存在时，ATC 将允许 VFR 飞行和航线盘旋训练（视地形和交通情况而定）。



请注意，IFR（仪表飞行规则）航空器可以在 IMC（仪表气象条件）或 VMC 下飞行，但 VFR 航空器只能在 VMC 下飞行。

## 空域

管制员空域由其垂直管辖范围、水平边界以及所服务设施的频率范围定义。就 Infinite Flight 而言，以下是各管制席位的概述：



| 位置               | 垂直管辖范围        | 水平边界                                             |
| ------------------ | --------------------- | ---------------------------------------------------- |
| 塔台               | SFC - 5000ft AAL      | 围绕机场最直接的环形/边界 |
| 离场/进近          | SFC - 18,000ft/FL180  | 50nm                                                 |
| 区调               | SFC - 60,000ft/FL600  | 白色边界                                             |

注意：在特殊活动期间，空域参数和 ATC 管辖范围可能会通过 NOTAM 和/或 TFR 进行调整。

## 航行优先权

所有航空器，尤其是 VFR 流量，必须以“目视避让”的原则运行。基本原则是，没有优先权的航空器必须采取修正动作，通常表现为向右转。



提示

: 如果你拥有优先权；请保持高度、航向和速度不变（除非需要进行避碰）



| 航行优先权           | 规则                                                         |
| ---------------------- | ------------------------------------------------------------ |
| 交叉冲突              | 如果航空器在大致相同高度上相向汇聚，则右侧有另一架航空器的那一方拥有优先权 |
| 迎头相遇              | 两架航空器都没有优先权，因此双方都必须向右转避让 |
| 超越航空器            | 被超越的航空器拥有优先权，超越的航空器必须从右侧超越 |
| 着陆                  | 正在着陆或最后进近的航空器优先于所有其他航空器*。当两架或多架航空器接近机场时，较低高度的航空器拥有优先权** |



**航空器不得利用此规则强行让另一架已经着陆的航空器离开跑道*

***航空器不得利用此规则插到着陆流量前方。此外，在有有效 ATC 的情况下，其排序优先于此规则*



提示

: 记住，如果航空器在你右侧，它就拥有优先权！

## VFR 航路程序



步骤 1

: 不要求飞行计划，但如果你有飞行计划，可以用它来帮助你导航



提示

: [ForeFlight](../../getting-started-guide/home-user-interface/settings.md#foreflight) 是一个很好的飞行计划工具，务必试试看！



步骤 2

: 利用地形、海岸线、岛屿等视觉标志来帮助你导航



步骤 3

: 确保调整你的 [巡航高度](step-climbs-and-cruising-altitudes.md#ifr%2Fvfr-semi-circular-rules)，以满足地形净空和 VFR 半圆规则



步骤 4

: 如果你正在接近受管制空域，请务必调入并留意其他交通



步骤 5

: 如果是雷达管制员，你可以[签到](../atc-communication/take-off-and-departure.md#departure-communication-summary)或请求 [VFR 航班跟随](../../atc-manual/6.-radar/6.5-flight-following.md#6.5-flight-following)（不过如果你明确想以 VFR 飞行，建议使用后者 - 如果你有飞行计划，管制员在你签到时可能会认为你是在请求 IFR 航班跟随）。如果是塔台管制员，你需要[请求通行](../atc-communication/take-off-and-departure.md#pilot-to-tower-controller-communication-tables)以穿越其空域



提示

: 如果空域未受管制，尝试调到最近的 Unicom 频率，以留意附近其他交通。你也可以发送交通通告，或者在想了解某个特定机场的更多信息时请求交通通告

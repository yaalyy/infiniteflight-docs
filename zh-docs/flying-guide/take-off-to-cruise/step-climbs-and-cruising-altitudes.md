## 什么是阶梯爬升？

一般来说，飞机飞得越高，燃油效率就越高（不考虑环境因素、重量或飞机设计规格）。问题在于，当飞机较重时，你可能无法立刻爬升到那里，所以我们需要尽可能接近“最佳高度”（综合上述因素后，最适合飞行的最高效高度）飞行，而这最终会提高飞机的航程。



这就是阶梯爬升发挥作用的地方。它是一种帮助飞机尽可能接近最佳高度飞行的技术。最初的高度可能相当低；但随着飞行推进以及燃油持续消耗，飞机最终会减轻到足以“阶梯式”爬升到下一个高度。根据飞行时长，整个飞行过程中可能会进行多次阶梯爬升。



阶梯爬升主要有两种技术：



**技术 1**

![Step Climb Technique 1](../../../_images/manual/graphics/step-climb-technique-1.jpg)

步骤 1
: 保持初始巡航高度不变，随着飞机变轻，最佳高度会逐渐升高。等到两者差值约为 2000 英尺时再继续



步骤 2
: 此时开始爬升，直到飞机巡航在与最佳高度相同的高度差上方（本例中为 2000 英尺）



步骤 3

: 保持该高度，直到再次低于预定值的最佳高度，然后重复上述过程



**技术 2**

![Step Climb Technique 2](../../../_images/manual/graphics/step-climb-technique-2.jpg)

步骤 1
: 保持初始巡航高度不变，随着飞机变轻，最佳高度会逐渐升高。等到两者差值约为 2000 英尺时再继续



步骤 2
: 此时开始爬升，直到飞机到达最佳高度



步骤 3
: 保持该高度，直到再次低于预定值的最佳高度，然后重复上述过程



提示
: 如果你在环境因素、重量或飞机设计规格方面已经接近飞机限制，那么技术 1 可能不可行，因为有些飞机在高于最佳高度时表现会较差。因此，在这种情况下可能需要采用技术 2

## 如何规划阶梯爬升

目前在 Infinite Flight 中还无法直接确定最佳高度；不过，为了帮助你规划，我们建议如下：



- 如果你在接近最大起飞重量（MTOW）时起飞，不要立刻爬升到最终巡航高度。使用飞行规划工具来规划在飞行过程中需要阶梯爬升到的各个高度
- 如果你不确定根据飞行方向应该飞到什么高度，请参考 [巡航高度](step-climbs-and-cruising-altitudes.md#what-are-cruising-altitudes%3F)
- 如果你发现飞机失速、俯仰姿态异常，或者无法保持当前高度，你可能太重，无法在该高度飞行！你需要下降到更低高度，消耗更多燃油，然后在飞行后期、重量更低时再尝试爬升
- 只携带这次飞行所需的燃油。如果你并不需要，切勿加注 100% 燃油，因为这只会限制你能巡航到多高



提示

: 如果仍然有问题，或者发现飞机的发动机功率设置高于平时，可以尝试下降 2000 英尺到适合当前飞行方向的下一个可用高度，看看是否有所改善



**示例飞行**

![Step Climbing Example](../../../_images/manual/graphics/pilot-step-climb-example.jpg)



在上图所示的示例飞行中，这架飞机正在从 EGLL 飞往 CYYZ。它的初始巡航高度是 FL340，由于它正向西飞行，因此其飞行高度层通常应为偶数。当天空中飞机准备爬升时，大量跨洋交通使其无法直接爬升到 FL360，因此它先进行一次中间爬升到 FL350。随后在最终到达 FL360 后，飞机继续消耗燃油，直到能够最后一次爬升到 FL380。接下来的航程末段保持该高度，随后开始下降并进近多伦多。

## 什么是巡航高度？



巡航高度是飞行途中阶段，飞机通常会在这一高度停留飞行大部分时间。高度会因多种因素而变化，包括：



- 飞行方向（航向）
- 飞行时长（短途航班通常会在较低高度巡航）
- 空域或航路限制
- 交通流量
- 技术故障

## IFR/VFR 半圆规则



尽管巡航高度会因上述部分或全部因素而变化，但按照惯例，会遵循以下规则：



**IFR** - 假设你处于 RVSM 空域中

| 航向              | 高度层                              |
| ----------------- | ----------------------------------- |
| 360 - 179 度      | 奇数（例如 FL330、FL350、FL370 等） |
| 180 - 359 度      | 偶数（例如 FL320、FL340、FL360 等） |



**VFR** - 奇数或偶数高度层，并在所有高度层上额外加 500 英尺

| 航向              | 高度层                           |
| ----------------- | -------------------------------- |
| 360 - 179 度      | 奇数（例如 1500、3500、5500 等） |
| 180 - 359 度      | 偶数（例如 2500、4500、6500 等） |

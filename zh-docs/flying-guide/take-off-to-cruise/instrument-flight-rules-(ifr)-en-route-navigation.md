## 什么是仪表飞行规则（IFR）？

仪表飞行规则（IFR）是一套规定，飞行员在仪表气象条件（IMC）或特定空域内运行航空器时必须遵守。

## 什么是仪表气象条件（IMC）？

被归类为仪表气象条件（IMC）所需的具体条件会因国家和所飞行空域类型而异。不过，就 Infinite Flight 而言，当能见度低于 3 法定英里（约 5000 米）时，即视为处于 IMC。因此，在这些条件下，ATC 不会允许 VFR 飞行和航线机动飞行。



请注意，IFR 航空器可以在 IMC 或 VMC（目视气象条件）下飞行，但 VFR（目视飞行规则）航空器只能在 VMC 下飞行。

## 空域

管制空域由其垂直管辖范围、横向边界以及该管制席位的频率范围定义。就 Infinite Flight 而言，以下是各管制席位的概述：



| 位置               | 垂直管辖范围        | 横向边界                                           |
| ------------------ | --------------------- | ---------------------------------------------------- |
| 塔台               | SFC - 5000ft AAL      | 围绕机场的最近一层环形/边界                         |
| 离场/进近          | SFC - 18,000ft/FL180  | 50nm                                                 |
| 中心               | SFC - 60,000ft/FL600  | 白色边界                                             |

注意：在特殊活动期间，空域参数和 ATC 管辖范围可能会通过 NOTAM 和/或 TFR 进行调整

## 间隔

当航空器按照 IFR 飞行时，必须始终与其他航空器保持至少 3nm 的水平间隔或 1000ft 的垂直间隔。

## IFR 航路程序



第 1 步

: IFR 航班始终需要飞行计划，你可以使用仪表或自动驾驶仪导航系统来导航并遵循你的飞行计划



提示

: [ForeFlight](../../getting-started-guide/home-user-interface/settings.md#foreflight) 是一个很棒的飞行计划工具，一定要试试看！



第 2 步

: 确保调整你的 [巡航高度](step-climbs-and-cruising-altitudes.md#ifr%2Fvfr-semi-circular-rules)，以满足地形净空和 IFR 半圆规则



第 3 步

: 如果你正在接近受控空域，请务必调入并留意其他交通



第 4 步

: 如果是雷达管制员，只需 [签到](../atc-communication/take-off-and-departure.md#departure-communication-summary)。如果是塔台管制员，则需要 [请求过渡](../atc-communication/take-off-and-departure.md#pilot-to-tower-controller-communication-tables) 以穿越其空域



提示

: 如果该空域未受控，尝试调到最近的 Unicom 频率，留意附近的其他交通。你也可以发送交通通告，或者在你想了解某个特定机场更多信息时请求交通通告



第 5 步

: 你也可以请求 [雷达向量](../../atc-manual/6.-radar/6.12-radar-vectors.md#6.12-radar-vectors) 或其他 ATC 服务，此后将适用 IFR 间隔规则（包括航空器与地形间隔）

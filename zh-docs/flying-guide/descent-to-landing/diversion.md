## 什么是备降？

备降是指航空器已无法继续飞往原定目的地，而改飞至新的机场。触发备降的原因有很多，但在 Infinite Flight 中一些最常见的原因包括：



- 目的地机场已满，不再接收进港航空器
- 目的地机场延误很长，而你已没有足够燃油等待进近

## 备降前的考虑因素

下表列出了在启动备降前应考虑的各种因素：



| 因素                 | 考虑事项                                                     |
| ------------------- | ------------------------------------------------------------ |
| 燃油                | 你有足够燃油飞到那里吗？                                      |
| 天气                | 天气是否适合进近和着陆？可用的进近方式有哪些？                |
| 航路                | 沿途是否有你需要注意的地形或空域？                            |
| 机场设施            | 滑行道、机坪和停机位是否适合你的机型尺寸？                   |
| 着陆性能            | 跑道长度是否足以让你安全着陆？                                |



为了帮助你在备降期间减轻工作负荷，你可以提前做一些准备：



步骤 1

: 起飞前，务必检查目的地附近的备降机场，并确认它们是否符合上述条件



步骤 2

: 确保至少选择一个备降机场，并加载完成所需燃油



步骤 3

: 如果你预计目的地机场会很繁忙，就多加一些燃油！



提示

: 提前做好准备后，你就能更有把握地做出决定，并更快地执行备降！

## 如何启动备降



步骤 1

: 确保备降机场符合[备降前的考虑因素](diversion.md#considerations-for-a-diversion)



步骤 2

: 通过[选择新的服务，例如向新机场提出进近请求](../atc-communication/descent-and-approach.md#pilot-to-radar-controller-communication-table)向 ATC 传达你打算备降的意图（如果你已经被指示备降，则按 ATC 给出的指令执行）



提示

: 在与 ATC 通信前，确保你已经准备好备降 - 如果你需要更多时间，可以考虑减速，或找个地方等待



步骤 3

: 如果 ATC 能够提供雷达引导和高度指派，就按其执行。如果不能，则选择一个合适的航向，朝机场的大致方向飞去（监控交通，确保始终保持间隔）



步骤 4

: 检查沿途地形，并选择一个合适的高度以确保地形间隔（如果 ATC 没有指派高度）



步骤 5

: 监控你所飞越的空域，以防需要切换到另一个活动频率



步骤 6

: 一旦进入航路中，你就可以开始设置进近了

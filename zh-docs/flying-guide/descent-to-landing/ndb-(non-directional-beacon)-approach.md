## 什么是 NDB 进近？

NDB 进近是一种仅提供侧向引导的非精密进近。最终进近航线（以相关进近图表中的公布内容为准）利用来自 NDB 的径向来提供这种侧向引导。



你可以使用这里展示的技巧在 Infinite Flight 中执行 NDB 进近，不过 ATC 目前还无法支持这类进近请求。暂时建议你找一个无管制机场或较为空闲的区域来练习！



提示

: 请务必先查看我们的 [NDB 导航](../take-off-to-cruise/ndb-(non-directional-beacon)-navigation.md#ndb-(non-directional-beacon)-navigation) 页面，先掌握基础再飞行 NDB 进近！

## 我该如何飞行 NDB 进近？



步骤 1

: 在飞往目的地的途中，查看天气以确定最佳进场跑道；完成后，查看该跑道的进近图表，如果它有 NDB 进近，就可以开始为这次进近做准备



步骤 2

: 确保你已为该进近[调谐](../../getting-started-guide/pilot-user-interface/navigation.md#tuning-to-a-vor-or-adf)所需的 NDB，并将 “BRG 1（或 2）” 设为 ADF 以显示它



步骤 3

: 按照图表在正确的距离/高度[截获径向](../take-off-to-cruise/ndb-(non-directional-beacon)-navigation.md#how-to-navigate-using-an-ndb)，并始终提前思考“下一件事”，让自己领先于飞机一步



提示

: 感觉负担太重？通过启用[自动驾驶](../../getting-started-guide/pilot-user-interface/autopilot.md#autopilot)，并使用航向和 V/S 按照剖面飞行，而不是手动操纵，从而减轻工作负荷



步骤 4

: 继续监控横向和纵向偏差，并进行必要调整，使其保持居中。在适当时机，结合 ATC 对速度控制的要求以及适用于你机型的推荐剖面；继续调整构型，以满足稳定进近标准

## 什么是稳定进近标准（SAC）？

稳定进近标准（SAC）用于判断你是否完成了稳定进近，以及是否应继续落地或复飞。



所有进近都必须在 1000 英尺 AGL（地面以上高度）前满足 SAC。SAC 包括：



- 处于计划的着陆构型
- 在正确的垂直剖面上稳定
- 在目标进近速度上稳定




如果任一 SAC 未满足，则必须执行[复飞](go-around-baulked-landing.md#go-around%2Fbaulked-landing)。



一旦选择了最终构型并已减速到目标进近速度，我们建议保持在以下容差范围内，以满足稳定性要求：



| 参数 | 容差 |
| ------------------ | ---------------------------------------------------------- |
| 速度 | 目标进近速度 -5/+10 节 |
| 下降率 | 不超过 1000 英尺/分钟* |
| 俯仰 | 机头下俯不超过 2.5 度，或上仰不超过 10 度 |
| 倾斜 | 角度不超过 7 度 |
| 横向导航 | 横向偏差不超过 1 格 |

**尾风等环境条件，或比通常更陡的飞行路径角，可能会使所需下降率增加到超过 1000 英尺/分钟*。**

## 滑行至停机位

步骤 1

: 一旦你已离开跑道，打开 [Systems](../../getting-started-guide/pilot-user-interface/systems.md#systems) 菜单并选择以下内容：



| LIGHTS  | Action  |
| ------- | ------- |
| Strobes | **OFF** |
| Land    | **OFF** |

{.checklist} 



步骤 2

: 在你获得许可的前提下，切换到 Ground 频率并 [请求滑行至停机位](../atc-communication/landing-and-taxi-to-parking.md#taxi-to-parking-communication-summary)，或者如果没有可用 ATC，则在 Unicom 频率上宣布滑行至停机位 - 在你移动时留意其他交通流量



提示

: 当你离开跑道时，不要停下并继续移动，除非这样做会导致碰撞！你拥有优先权；如果你停下，可能会与后方起飞/降落的交通造成冲突



步骤 3

: 收起 [襟翼](../../getting-started-guide/pilot-user-interface/flight-controls.md#flight-controls) 并将 [扰流板](../../getting-started-guide/pilot-user-interface/flight-controls.md#flight-controls) 设为 **OFF**。打开 [Systems](../../getting-started-guide/pilot-user-interface/systems.md#systems) 菜单并选择以下内容：



| Electrical | Action    |
| ---------- | --------- |
| APU*       | **START** |

{.checklist}



*如果有配置 - 并非所有飞机目前都装备了 APU



步骤 4

: 持续观察周围环境，确保通道畅通，使用 [Cameras](../../getting-started-guide/pilot-user-interface/cameras.md#camera) 和 [Mini Map](../../getting-started-guide/pilot-user-interface/flight-planning.md#mini-map) 来帮助你

 

提示

:   我们建议你滑行时不要超过 40% N1，并且一旦开始移动，通常不需要超过慢车推力！

 

步骤 5

: 使用 [Rudder](../../getting-started-guide/pilot-user-interface/flight-controls.md#flight-controls) 保持在滑行道中心线上，并使用 [Rud Brakes 或 Park Brake](../../getting-started-guide/pilot-user-interface/flight-controls.md#flight-controls) 控制速度

 

提示

:   为避免游戏内违规，请不要超过 35kts 地速；我们建议你在直线滑行时将速度控制在 25kts 以下，在 90° 转弯时控制在 10kts 或更低，以确保安全操作

 

步骤 6

: 如果你在滑行时需要穿越跑道，请确保向当前 ATC [请求穿越跑道](../atc-communication/atis-pushback-and-taxi.md#pilot-to-ground-controller-communication-table)；如果没有可用 ATC，则在 Unicom 频率上宣布穿越 - 在进入跑道前务必确认跑道无障碍！别忘了打开 [Systems](../../getting-started-guide/pilot-user-interface/systems.md#systems) 菜单并选择以下内容：

 

| Lights  | Action |
| ------- | ------ |
| Strobes | **ON** |
| Land    | **ON** |

{.checklist}

 

一旦你完全离开跑道，就可以将这些灯重新设为 **OFF**。

## 关车

步骤 1

: 确保你要停靠的机位或停车位足够容纳你的机型，你可以提前使用在线工具进行辅助检查



> 如果机位有 [stand guidance](../on-the-ground/stand-guidance.md)，它会告诉你该机位是否适合该机型，太小或太大都会提示



步骤 2

: 使用 [Rudder](../../getting-started-guide/pilot-user-interface/flight-controls.md#flight-controls) 保持在滑行道中心线上，并使用 [Rud Brakes 或 Park Brake](../../getting-started-guide/pilot-user-interface/flight-controls.md#flight-controls) 控制速度



步骤 3

: 将地速降至 10kts 以下，如果你驾驶的是大型飞机，请使用过转技术，在转入机位或停车位时将飞机与中心线对正



> 如果机位有 [stand-guidance](../on-the-ground/stand-guidance.md)，请遵循屏幕上的指示



步骤 4

: 到达停放位置后，设置 [Park Brake](../../getting-started-guide/pilot-user-interface/flight-controls.md#flight-controls)。打开 [Systems](../../getting-started-guide/pilot-user-interface/systems.md#systems) 菜单并选择以下内容：

 

| Engines         | Action  |
| --------------- | ------- |
| Eng ‘X’ 'X'% N1 | **TAP** |

{.checklist}



| Lights | Action  |
| ------ | ------- |
| Beacon | **OFF** |

{.checklist}




| Passengers | Action  |
| ---------- | ------- |
| Seat Belts | **OFF** |

{.checklist}



步骤 5

: 打开 [Ground Services](../../getting-started-guide/pilot-user-interface/ground-services.md) 菜单并选择以下服务：

 

| Ground    | Action  |
| --------- | ------- |
| PAX       | **TAP** |
| CATERING  | **TAP** |
| CARGO     | **TAP** |
| GND POWER | **TAP** |

{.checklist}



> 要使用地面服务，飞机必须停在足够容纳该机型的机位上，设置好停车刹车，并将发动机和 Beacon 关闭

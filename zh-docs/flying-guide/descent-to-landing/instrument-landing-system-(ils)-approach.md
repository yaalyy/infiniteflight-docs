## 什么是 ILS 进近？

ILS 由两束信号组成，航向道（Localizer，LOC）提供横向引导（左/右），下滑道（Glideslope，G/S）提供纵向引导（上/下）。跑道尽头的锥形区域为飞行员和管制员提供关于 LOC 和 G/S 位置的**目视参考**，但重要的是要记住，LOC 和 G/S 并不局限于锥形区域。LOC 和 G/S 是独立发射的无线电“信号”，因此会继续向外传播。飞机可以接收这些信号，从而截获它们 - 无论是在锥形区域内还是外部。



要截获 ILS 的 LOC，管制员会向飞机发布一个截获航向，尽可能接近 30 度，并相对于跑道编号偏置 *(见下文 6.10.3.1)*。如果飞机已经按照合适的 STAR 和/或仪表进近飞行，则可能会在合适的位置获得 ILS 进近许可，而不需要指定航向或标准的 30 度截获角度。 



![Image 6.10.3.1 - Intercepting the localizer](../../../_images/manual/graphics/atc-intercept-loc-v2.jpg)



要截获 ILS 的 G/S，管制员会发布一个低于 G/S 路径的高度 *(见下文 6.10.4.1)*。典型的 G/S 采用 3 度下滑角，引导飞机飞向跑道入口。距离 1nm 时，G/S 高度应为 300ft AAL（高于机场标高）；距离 2nm 时为 600ft AAL，依此类推。



![Image 6.10.4.1 - Intercepting the glideslope](../../../_images/manual/graphics/atc-intercept-gs.jpg)

## 我该如何飞 ILS 进近？

步骤 1

: 在飞往目的地途中，查看 ATIS/D-ATIS 以了解正在使用的跑道



提示

: 在进近过程中，通常会被要求执行向量引导和/或高度指令，请务必遵从这些指令 - ATC 指令优先于你的飞行计划！



步骤 2

: 按照我们的分步指南 [这里](../../getting-started-guide/pilot-user-interface/navigation.md#tuning-to-an-ils) 调谐到 ILS



步骤 3

: 如果你不再遵循飞行计划，或者不再需要 [GPS 导航](../../getting-started-guide/pilot-user-interface/navigation.md#gps-navigation)，你可以按照我们的分步指南 [这里](../../getting-started-guide/pilot-user-interface/navigation.md#displaying-an-ils-in-your-aircraft) 显示 ILS



步骤 4

: 如果 ATC 处于活动状态，你需要获得许可才能加入 ILS 进近。这种许可通常会以从你的 STAR/仪表进近接入，或者通过一个截获航向的形式给出



提示

: 感觉负担太重？可以通过启用 [自动驾驶](../../getting-started-guide/pilot-user-interface/autopilot.md#autopilot) 和 APPR 模式来降低工作负荷，飞机将保持指定航向，然后自动截获 LOC 和 G/S。请务必只在获得进近许可后再设置 APPR 模式为待命！



步骤 5

: 要跟随 LOC，请确保绿色的航向道偏差条与 HSI 上绿色的航线选择指针对齐。当横向偏差在 1 个点以内时，表示你已建立进近 - 在没有冲突的情况下，随后你会从 Radar 移交给 Tower（如果 ATC 处于活动状态），未经许可不要更改频率！



步骤 6

: 要跟随 G/S，请确保绿色的下滑道偏差点与 HUD 上方的高度中央标记对齐



提示

: 在你尚未建立 LOC 之前，不要沿着 G/S 下降！



步骤 7

: 持续监控 LOC 和 G/S 的偏差，并做出必要调整以保持居中。在适当时机，基于 ATC 的速度控制以及你机型推荐的进近剖面；继续构型，以满足稳定进近标准

## 什么是稳定进近标准（SAC）？

稳定进近标准（SAC）用于判断你是否完成了稳定进近，以及是否应继续着陆或复飞。



所有进近都必须在 1000ft AGL（距地高度）前满足 SAC。SAC 包括：



- 处于计划中的着陆构型
- 在正确的垂直剖面上保持稳定
- 在目标进近速度上保持稳定




如果未满足任何一项 SAC，必须执行 [复飞](go-around-baulked-landing.md#go-around%2Fbaulked-landing)。



当最终构型已设定且你已减速至目标进近速度后，我们建议在以下容差范围内保持，以满足稳定性要求：



| 参数 | 容差 |
| -------------------- | ---------------------------------------- |
| 速度 | 目标进近速度 -5/+10 kts |
| 垂直速度 | 不超过 1000ft/min* |
| 俯仰 | 机头下俯不超过 -2.5 度，或机头上仰不超过 +10 度 |
| 横滚 | 角度不超过 7 度 |
| 航向道/下滑道 | 横向/纵向偏差不超过 1 个点 |

**尾风等环境条件，或比通常更陡的飞行路径角，可能会使所需下沉率增加到超过 1000ft/min***

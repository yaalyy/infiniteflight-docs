## 什么是目视进近？

目视进近是指在 [IFR](../take-off-to-cruise/instrument-flight-rules-(ifr)-en-route-navigation.md#instrument-flight-rules-(ifr)-en-route-navigation) 条件下对跑道进行的进近，但在获得许可后，飞行员会以目视参照方式继续飞行。这意味着，在管制员允许飞机执行目视进近之前，飞行员必须已经建立目视。



向飞行员发出目视进近的方式有多种，但一般来说，在地形允许的情况下，雷达管制员会将飞行员定位到一个容易识别的位置，例如 downwind、base，甚至直接截获直进。随后，飞行员会被要求“报告已目视机场”，一旦确认后，飞行员就会获准执行进近，并在适当的时候移交给 Tower/Unicom。



提示

: 为了获得更真实的体验，为什么不试着找到你要飞往机场的进近图表并实际尝试一下呢？

## 我该如何执行目视进近？

步骤 1

: 在飞往目的地途中，检查 ATIS/D-ATIS，确认当前使用的跑道



提示

: 在进近过程中，通常会收到雷达引导和/或高度指令，请务必遵循这些指令 - ATC 指令优先于你的飞行计划！



步骤 2

: 在联系雷达管制员时，请求对当前使用跑道执行目视进近



提示

: 在交通情况允许的前提下，这一请求通常会被批准，但如果无法满足，请准备接受其他进近方式！



步骤 4

: 雷达管制员会发出雷达引导和/或高度指令，帮助你进入合适的位置，然后要求你“报告已看见机场” - 使用 [摄像机](../../getting-started-guide/pilot-user-interface/cameras.md#camera) 和 [小地图](../../getting-started-guide/pilot-user-interface/flight-planning.md#mini-map) 来帮助你定位机场



提示

: 感到任务过载了吗？可以通过开启 [自动驾驶](../../getting-started-guide/pilot-user-interface/autopilot.md#autopilot) 来减轻工作负担！



步骤 5

: 一旦你建立目视，告诉雷达管制员，他们就会放行你执行进近。获准后，你可以继续以目视方式飞向跑道入口进行着陆，并在适当的时候移交给 Tower/Unicom



步骤 6

: 持续监控你的横向和纵向飞行剖面，并在需要时进行调整。在适当时机，根据 ATC 的速度控制以及你所飞机型的推荐剖面，继续完成构型设置，以满足稳定进近标准

## 什么是稳定进近标准（SAC）？

稳定进近标准（SAC）用于判断你是否完成了稳定进近，以及是否应继续着陆或复飞。



所有进近都必须在距地 1000 英尺 AGL（above ground level）之前满足 SAC。SAC 包括：



- 处于计划中的着陆构型
- 在正确的纵向飞行剖面上保持稳定
- 以目标进近速度保持稳定



如果任何一项 SAC 未满足，必须执行 [复飞](go-around-baulked-landing.md#go-around%2Fbaulked-landing)。



一旦最终构型已设置，并且你已减速到目标进近速度，我们建议保持在以下容差范围内，以满足稳定性要求：



| 参数 | 容差 |
| -------------- | ---------------------------------------- |
| 速度 | 目标进近速度 -5/+10 节 |
| 垂直速度 | 不超过 1000 英尺/分钟* |
| 俯仰 | 机头向下不超过 2.5 度，或机头向上不超过 10 度 |
| 横滚 | 与跑道延长中线对正后，倾斜角不超过 7 度 |

**环境条件，例如顺风，或比平时更大的下滑角，可能会使所需下降率超过 1000 英尺/分钟*

***某些机场可能需要在低高度转弯以对正跑道*

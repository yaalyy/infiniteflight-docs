## 什么是安全着陆？

为了确保安全着陆，以下标准必须始终满足：

| 标准               | 原因                                                                 |
| ------------------ | -------------------------------------------------------------------- |
| 着陆性能           | 这是为了确保可用着陆距离（Landing Distance Available, LDA）对该机型而言足够合适 |
| 稳定进近           | 在进近过程中必须始终满足稳定进近标准（Stable Approach Criteria, SAC） |
| 安全接地           | 这是为了确保正常跑道接地 - 在飞机限制范围内、着陆区内以及远离跑道边缘 |
| 安全滑跑           | 飞机以能够确保在跑道末端之前安全停下的方式减速 |

## 拉平高度

开始拉平的高度可能会有很大差异，在确定正确高度时应始终考虑以下因素：



- 飞机类型
- 飞机重量
- 机场标高
- 更陡的进近下滑坡度（相较于标准 3 度）
- 顺风
- 跑道坡度

## 着陆类型



| 类型         | 定义                               |
| ------------ | ---------------------------------- |
| 全停着陆     | 正常着陆后，飞机离开跑道 |
| 接地复飞     | 正常着陆后不完全停下，直接再次起飞 |
| 停止再飞     | 正常着陆并完全停下后，从当前位置再次起飞 |
| 低空进近     | 在进近后执行的 [复飞](go-around-baulked-landing.md#go-around%2Fbaulked-landing) 机动 |

## 着陆技巧 

在获得许可（如适用）且跑道完全清空后，你可以按照以下步骤着陆：



步骤 1

: 在拉平之前，避免破坏进近稳定性 - 注视跑道尽头，以帮助判断拉平高度



步骤 2

: 在适合该飞机和环境条件的高度执行拉平动作，并将推力减至怠速



步骤 3

: 保持所选着陆姿态，直到接地



提示

: 我们建议不要继续向后拉杆来延长拉平过程，以尝试获得更平顺的接地；这会增加未达到安全接地标准的风险，而且更容易发生尾擦地！ 



步骤 4

: 如果在任何时候无法确保安全着陆，请执行 [复飞](go-around-baulked-landing.md#go-around%2Fbaulked-landing) 或 [中止着陆](go-around-baulked-landing.md#what-is-the-difference-between-a-go-around-and-a-baulked-landing%3F) 程序。

## 滑跑和脱离跑道（全停）

步骤 1

: 接地后，选择反推（如有），确保 [扰流板](../../getting-started-guide/pilot-user-interface/flight-controls.md#flight-controls) 已展开（如有），并监控飞机减速情况



步骤 2

: 使用 [方向舵](../../getting-started-guide/pilot-user-interface/flight-controls.md#flight-controls) 保持在跑道中线。随着速度下降，方向舵的空气动力作用也会减弱，在更低速度下需要更大的输入



步骤 3

: 适当调节你的 [刹车](../../getting-started-guide/pilot-user-interface/flight-controls.md#flight-controls) 和反推使用（如有），以尽快但受控地脱离跑道。你应始终提前规划离场路线，但也要保持灵活；飞机的减速速度可能比预期更快或更慢



提示

: 快速脱离滑行道（RET）具有设计脱离速度，这个速度可能非常高 - 但是由于 [地面超速一级违规](../../getting-started-guide/pilot-user-interface/violations.md#what-are-violations%3F)，我们建议你在脱离跑道时不要超过 35 节。对于 90 度转弯的脱离方式，你的地速应低于 10 节



步骤 4

: 有些机场可能要求在跑道上后滑行以脱离跑道。请查看我们的 [后滑行](../take-off-to-cruise/back-taxi.md#back-taxi) 页面，了解分步骤指南



步骤 5

: 脱离跑道时，请继续前进，直到飞机完全越过等待线，以确保跑道已为下一次起飞/进场清空。你应始终避免完全停下，并在移动中 [尽量与 ATC 通信](../atc-communication/landing-and-taxi-to-parking.md#taxi-to-parking-communication-summary)（如果有的话），以避免在你后方造成交通拥堵！

## 如何执行接地复飞

在获得许可（如适用）且跑道完全清空后，你可以按照以下步骤着陆：



步骤 1

: 接地后，确保 [扰流板](../../getting-started-guide/pilot-user-interface/flight-controls.md#flight-controls) 已展开（如有），并监控飞机减速情况 - 不要选择反推（如有）



步骤 2

: 使用 [方向舵](../../getting-started-guide/pilot-user-interface/flight-controls.md#flight-controls) 保持在跑道中线。随着速度下降，方向舵的空气动力作用也会减弱，在更低速度下需要更大的输入



步骤 3

: 将 [襟翼](../../getting-started-guide/pilot-user-interface/flight-controls.md#flight-controls) 收至起飞设定，并将 [扰流板](../../getting-started-guide/pilot-user-interface/flight-controls.md#flight-controls) 设为 **OFF**



步骤 4

: 设置完成后，增加推力至起飞功率，并按正常 [起飞](../take-off-to-cruise/take-off-and-initial-climb.md#take-off-and-initial-climb) 程序继续



提示

: 对于停止再飞，请遵循与上述相同的步骤，但在开始 [起飞](../take-off-to-cruise/take-off-and-initial-climb.md#take-off-and-initial-climb) 滚行前，必须先完全停下

## 什么是 GPS 进近？

全球定位系统（GPS）进近由一系列航路点和高度限制定义，飞行员将沿其飞至跑道入口，过程中不依赖航向道/下滑道等传统引导。GPS 进近在 Infinite Flight 中属于非精密进近，但由于当前功能受限，通常并不常用。你可以选择的不同类型 GPS 进近可在[这里](../../getting-started-guide/pilot-user-interface/flight-planning.md#selecting-departure%2C-arrival-and-approach-procedures)找到。

## 如何飞行 GPS 进近？

步骤 1

: 在飞往目的地途中，查看 ATIS/D-ATIS 以确认当前使用的跑道



提示

: 在进近过程中，常常会收到雷达引导和/或高度指令，请务必遵从这些指令 - ATC 指令优先于你的飞行计划！



步骤 2

: 按照我们的分步指南[这里](../../getting-started-guide/pilot-user-interface/flight-planning.md#selecting-departure%2C-arrival-and-approach-procedures)确保已经选择了 GPS 进近



步骤 3

: 如果你的航班已被雷达引导偏离飞行计划，雷达管制员会在给出进近许可前确保你被指示为“Continue as Filed”。使用你的[GPS Navigation](../../getting-started-guide/pilot-user-interface/navigation.md#gps-navigation)来按照飞行计划和进近飞行



提示

: 感觉工作量太大？启用[Autopilot](../../getting-started-guide/pilot-user-interface/autopilot.md#autopilot)，并同时使用[LNAV](../../getting-started-guide/pilot-user-interface/navigation.md#gps-navigation)和[VNAV](vertical-navigation-(vnav).md#vertical-navigation-(vnav))进行导航，可降低工作负荷，飞机将自动沿进近飞行



步骤 5

: 若要手动跟随 GPS 进近，请确保 HSI 上的洋红色横向偏差条与洋红色航向选择指针对齐。当横向偏差在 1 个点以内时，即表示已稳定建立进近 - 在不存在冲突时，如果 ATC 处于开启状态，你将随后由雷达移交给塔台，不要在未经许可的情况下更改频率！



提示

: VNAV 只会在飞行计划中的最后一个高度限制之前生效。在这之后，你需要手动接管！



步骤 7

: 持续监控横向和纵向偏差，并进行所需调整以保持居中。在适当时机，依据 ATC 的速度控制和你所执飞机型的推荐剖面；继续构型以满足稳定进近标准

## 什么是稳定进近标准（SAC）？

稳定进近标准（SAC）的作用是评估你是否完成了稳定进近，以及是否应继续着陆或复飞。



所有进近都必须在距地 1000 英尺 AGL（Above Ground Level）时满足 SAC。SAC 包括：



- 处于计划的着陆构型
- 稳定在正确的垂直剖面上
- 稳定在目标进近速度上



如果未满足任何 SAC，必须执行[复飞](go-around-baulked-landing.md#go-around%2Fbaulked-landing)。



一旦选择了最终构型并减速到目标进近速度，我们建议保持在以下容差范围内，以确保进近稳定性：



| 参数             | 容差                                   |
| ---------------- | -------------------------------------- |
| 速度             | 目标进近速度 -5/+10 节                 |
| 垂直速度         | 不超过 1000 英尺/分钟*                 |
| 俯仰             | 机头向下不超过 2.5 度，或机头向上不超过 10 度 |
| 倾斜             | 角度不超过 7 度                         |
| 横向导航         | 横向偏差不超过 1 个点                  |

**尾风或比平常更陡的飞行路径角等环境条件，可能会使所需下降率超过 1000 英尺/分钟***

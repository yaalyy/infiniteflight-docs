## 什么是 VOR 进近？

VOR 进近是一种仅提供横向引导的非精密进近。最终进近航线（以相关进近图上的公布内容为准）使用来自 VOR 的径向来提供这种横向引导。 



你可以按照此处展示的技术在 Infinite Flight 中执行 VOR 进近，不过目前 ATC 还无法支持这类进近请求 - 目前我们建议你找一个无管制机场或安静区域来练习！



提示

: 在执行 VOR 进近之前，务必先查看我们的 [VOR 导航](../take-off-to-cruise/vor-(vhf-omni-directional-range)-navigation.md#vor-(vhf-omni-directional-range)-navigation) 页面，先掌握基础知识！

## 我该如何飞行 VOR 进近？



步骤 1

: 在前往目的地途中，先查看天气，以确定最适合落地的跑道 - 完成后，查阅该跑道的进近图；如果它有 VOR 进近，你就可以开始为这一进近做准备



步骤 2

: 确保你已经为该进近[调谐](../../getting-started-guide/pilot-user-interface/navigation.md#tuning-to-a-vor-or-adf)所需的 VOR，并将 CRS 调整为你需要截获的目标磁航向



步骤 3

: 如果你不再跟随飞行计划，或者不再需要 [GPS 导航](../../getting-started-guide/pilot-user-interface/navigation.md#gps-navigation)，你可以将 "SOURCE" 设置为 NAV 1（或按需要设置为 2）来[显示](../../getting-started-guide/pilot-user-interface/navigation.md#displaying-a-vor-in-your-aircraft)所需的 VOR



步骤 4

: 按照图表，在正确的距离/高度上[截获目标磁航向](../take-off-to-cruise/vor-(vhf-omni-directional-range)-navigation.md#how-to-navigate-using-a-vor)，并始终想着“下一事件”，让自己保持领先于飞机的状态



提示

: 感觉工作量太大？通过启用[自动驾驶](../../getting-started-guide/pilot-user-interface/autopilot.md#autopilot)，并使用 Heading（或 LNAV）和 V/S 来沿着剖面飞行，而不是手动驾驶，从而减轻你的工作负担



步骤 5

: 继续监控横向和垂直偏差，并进行必要的调整，使其保持居中。在合适的时机，基于 ATC 的速度控制以及你所飞行机型的推荐剖面，继续调整构型，以满足稳定进近标准

## 什么是稳定进近标准（SAC）？

稳定进近标准（SAC）用于评估你是否完成了稳定进近，以及是否应继续落地还是复飞。



所有进近必须在 1000ft AGL（距地高度）之前满足 SAC。SAC 要求如下：



- 处于计划中的着陆构型
- 稳定在正确的垂直剖面上
- 稳定在目标进近速度上




如果未满足任一 SAC，必须执行[复飞](go-around-baulked-landing.md#go-around%2Fbaulked-landing)。



一旦你选择了最终构型并已减速到目标进近速度，我们建议保持在以下容差范围内，以评估你的稳定性：



| 参数             | 容差                                                     |
| ------------------ | ------------------------------------------------------------ |
| 速度              | 目标进近速度 -5/+10 节                                  |
| 垂直速度         | 不超过 1000ft/min*                                  |
| 俯仰             | 机头下俯不超过 2.5 度，或机头上仰不超过 10 度 |
| 坡度              | 角度不超过 7 度                                      |
| 横向导航         | 横向偏差不超过 1 个点                                |

**诸如顺风或比平常更陡的飞行路径角等环境条件，可能会使所需的下降率增加到超过 1000ft/min*
